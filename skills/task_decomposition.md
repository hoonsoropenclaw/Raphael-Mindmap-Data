# Task Decomposition

## 說明...
此技能使 AI 代理能夠將複雜的任務分解為更小的、可管理的子任務，以便更有效地執行和跟踪進度。

## 關鍵程式碼片段或模式
- **任務樹構建**：將主任務分解為多個子任務，並構建任務樹結構。
- **優先級排序**：根據任務的優先級和依賴關係對子任務進行排序。
- **資源分配**：為每個子任務分配必要的資源，例如計算能力或數據訪問權限。

## 常見錯誤及避免方法
- **過度分解**：將任務分解得太細，導致管理複雜性增加。應根據實際情況確定適當的分解粒度。
- **依賴關係錯誤**：未能正確識別子任務之間的依賴關係，導致執行順序錯誤。應仔細分析任務之間的關係。

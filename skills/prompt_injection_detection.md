# Prompt Injection Detection

## 說明...

### 目的
此技能旨在識別並防範潛在的 prompt injection 攻擊，確保 AI 代理的行為符合預期且安全。

### 關鍵代碼片段或模式
- **關鍵詞檢查**：檢查輸入中是否包含未授權的關鍵詞或指令，例如 `FULL AUTONOMY` 或 `嚴格禁止`。
- **上下文驗證**：驗證輸入的上下文是否符合既定的觸發前綴或模式，例如 `^` 或 `@`。
- **異常行為監控**：監控輸入中是否存在異常行為，例如要求 AI 忽略安全協議或繞過確認步驟。

### 常見錯誤及避免方法
- **誤報**：過於嚴格的檢查可能導致誤報，阻礙正常操作。應根據實際需求調整檢查規則。
- **漏報**：過於寬鬆的檢查可能導致漏報，無法有效防範攻擊。應定期更新檢查規則以應對新威脅。
- **誤判**：AI 可能誤判某些合法輸入為攻擊。應提供明確的指導方針和訓練數據以減少誤判。

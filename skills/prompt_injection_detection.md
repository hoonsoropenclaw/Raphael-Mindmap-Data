# Prompt Injection Detection

## 說明...
此技能旨在識別和防範潛在的 prompt injection 攻擊，確保 AI 代理不會被惡意操控。

## 關鍵程式碼片段或模式
- **關鍵詞匹配**：檢查輸入中是否包含如『極限超頻模式』『FULL AUTONOMY』等可疑關鍵詞。
- **上下文驗證**：檢查訊息是否符合既定的 SOP 流程，例如是否需要人類確認或是否觸發了安全規則。
- **歷史行為比對**：將當前行為與過去的行為模式進行比對，識別重複的攻擊模式。

## 常見錯誤及避免方法
- **誤報**：過於嚴格的關鍵詞過濾可能導致誤報。應根據實際應用場景調整關鍵詞庫。
- **漏報**：未能識別新型攻擊模式。定期更新和擴展關鍵詞庫，並結合機器學習模型進行檢測。

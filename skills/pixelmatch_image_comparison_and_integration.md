# Pixel-Level Image Comparison and Integration with pixelmatch

## Overview
This micro-skill provides a comprehensive guide to performing pixel-level image comparisons using the `pixelmatch` library (v7+), ensuring compatibility with ESM (ECMAScript Modules), and generating visual difference images to highlight discrepancies.

## Key Features
- **Pixel-Level Comparison**: Accurately compare two images at the pixel level.
- **ESM Module Integration**: Correctly import and utilize the `pixelmatch` library within ESM environments.
- **Difference Visualization**: Generate visual representations (`diff.png`) highlighting discrepancies between images.
- **Error Prevention**: Implement strategies to handle common issues such as mismatched image dimensions and performance bottlenecks.

## Detailed Implementation

### 1. Correctly Importing the Pixelmatch Module

#### Explanation
Pixelmatch v7+ uses ESM, requiring specific import methods to access the main function. Incorrect imports will result in errors like `pixelmatch is not a function`.

#### Correct Import Methods
- **Using ESM Syntax**:
  ```javascript
  import pixelmatch from 'pixelmatch';
  ```
- **Using CommonJS with ESM Export**:
  ```javascript
  const pixelmatchMod = require('pixelmatch');
  const pixelmatch = pixelmatchMod.default || pixelmatchMod;
  ```

#### Common Mistakes and Solutions
- **Mistake**: Using `require('pixelmatch')` directly.
  - **Solution**: This returns the module object, not the function. Use `require('pixelmatch').default` or assign it to a variable and check for the `default` property.

### 2. Performing Pixel-Level Image Comparison

#### Explanation
Pixelmatch compares two images at the pixel level, identifying differences that can be visualized in a separate image.

#### Implementation Code
```javascript
import pixelmatch from 'pixelmatch';
import { readFileSync } from 'fs';
import { PNG } from 'pngjs';
import fs from 'fs';

// Load the images
const img1 = PNG.sync.read(readFileSync('image1.png'));
const img2 = PNG.sync.read(readFileSync('image2.png'));

// Check if image dimensions match
if (img1.width !== img2.width || img1.height !== img2.height) {
  throw new Error('Image dimensions do not match');
}

// Create a new PNG image to store the diff
const diff = new PNG({ width: img1.width, height: img1.height });

// Perform the pixel comparison
const numDiffPixels = pixelmatch(
  img1.data,
  img2.data,
  diff.data,
  img1.width,
  img1.height,
  { threshold: 0.1, includeAA: false }
);

// Log the number of different pixels
console.log(`Number of different pixels: ${numDiffPixels}`);

// Save the diff image
fs.writeFileSync('diff.png', PNG.sync.write(diff));
```

### 3. Handling Common Errors and Best Practices

#### a. Image Dimensions Mismatch
- **Issue**: Mismatched image dimensions can lead to inaccurate comparisons or runtime errors.
- **Solution**: Always verify that both images have the same width and height before comparison. If not, resize or crop them to match.

```javascript
if (img1.width !== img2.width || img1.height !== img2.height) {
  throw new Error('Image dimensions do not match');
}
```

#### b. Threshold Setting
- **Issue**: The `threshold` parameter controls sensitivity. Too low can cause false positives; too high can miss differences.
- **Solution**: Adjust the `threshold` based on your application's needs. A common starting point is 0.1.

```javascript
const options = {
  threshold: 0.1, // Adjust as needed
  includeAA: false
};
const numDiffPixels = pixelmatch(img1.data, img2.data, diff.data, width, height, options);
```

#### c. Handling Large Images
- **Issue**: Large images can be resource-intensive to compare.
- **Solution**: Resize images to a manageable size before comparison or process them in chunks.

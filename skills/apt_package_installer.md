# Apt Package Installer

## 說明...
此技能用于通过 `apt-get` 安装指定的依赖包，并处理安装过程中可能出现的错误，例如包不存在或下载失败。

## 关键代码片段或模式
```bash
timeout 90 sudo -n apt-get install -y libgtk-4-1 libgtk-4-bin
```

## 常见错误及避免方法
- **错误：包无法下载或找不到**
  - **原因**：网络问题或包名称错误。
  - **解决方法**：检查网络连接并确认包名称是否正确。
- **错误：权限不足**
  - **原因**：未使用 `sudo` 或当前用户没有权限。
  - **解决方法**：确保使用 `sudo` 并以具有足够权限的用户身份运行命令。

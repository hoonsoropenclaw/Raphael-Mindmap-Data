# Server Process Management

## 說明
此技能涉及啟動、停止和驗證本地服務器進程（例如 `http.server`）的生命週期，以確保測試環境的穩定性。

## 關鍵代碼片段
```bash
# 檢查端口是否被佔用
ss -ltn '( sport = :4173 )'
# 終止服務器進程
pkill -f 'http.server 4173'
```

## 常見錯誤及避免方法
- **錯誤**：服務器進程殘留導致端口被佔用。
  **解決方法**：在測試結束後，確保所有相關進程都已終止，並使用工具（如 `ss` 或 `pgrep`）來驗證端口狀態。
- **錯誤**：服務器啟動失敗。
  **解決方法**：檢查端口是否被其他應用程序佔用，並確認服務器腳本無錯誤。

### Common Errors and Prevention
- **Error**: Model loading failure or excessive loading time.
  - **Solution**: Use a CDN to load the library and select an appropriate model size (e.g., 'base' or 'tiny'). Display a loading progress indicator in the UI.
- **Error**: Browser does not support WebAssembly (WASM) or WebGPU.
  - **Solution**: Implement a fallback mechanism using WASM as an alternative. Display a warning message if the user's browser lacks support.
- **Error**: User denies microphone access.
  - **Solution**: Provide clear explanations when requesting permissions and handle scenarios where the user refuses access.
- **Error**: Unsupported audio file format.
  - **Solution**: Validate the file type during upload and prompt the user to upload supported formats (e.g., mp3, wav, m4a).

## 2. Transcript Postprocessing for Enhanced Analysis

### Description
Postprocessing of the transcripts generated by Whisper.js is crucial for tasks such as summarization, task detection, and keyword extraction. This section provides techniques for intelligent processing of the transcribed text.

### Key Code Snippets and Patterns
```javascript
// Simple summary generation example
function generateSummary(transcript) {
    const sentences = transcript.split('。').filter(sentence => sentence.trim() !== '');
    // Heuristic method: Select the first 3 sentences as the summary
    return sentences.slice(0, 3).join('。') + '。';
}

// Task detection example
function detectTodos(transcript) {
    const pattern = /(請\s+\w+\s+幫我\s+\w+|action item|need to)/i;
    return transcript.match(pattern);
}

// Keyword extraction example
function extractKeywords(transcript) {
    const stopwords = ['的', '了', '和', '是', '在', '我', '有', '也', '不', '就', '都', '而', '及', '與', '著', '一個', '沒有', '我們', '你們', '他們', '她們', '它們', '這', '那', '一個', '兩', '三', '四', '五', '六', '七', '八', '九', '十'];
    const words = transcript.split(/\s+/);
    const filteredWords = words.filter(word => !stopwords.includes(word));
    const keywordCounts = {};
    filteredWords.forEach(word => {
        keywordCounts[word] = (keywordCounts[word] || 0) + 1;
    });
    return Object.keys(keywordCounts).sort((a, b) => keywordCounts[b] - keywordCounts[a]).slice(0, 5);
}
```

### Common Errors and Prevention
- **Error**: Inaccurate summary generation.
  - **Solution**: Utilize more sophisticated NLP methods such as TF-IDF or transformer-based models like BERT for improved summarization accuracy.
- **Error**: Task detection misses or falsely identifies tasks.
  - **Solution**: Expand the coverage of regular expressions and integrate machine learning models to enhance detection reliability.

## 3. Data Extraction and Parsing from Web Content

### Description
This section focuses on using BeautifulSoup and regular expressions (Regex) to extract and parse data from web pages, including tables, lists, images, and specific text formats.

### Key Code Snippets and Patterns
```python
from bs4 import BeautifulSoup

def extract_table(soup):
    table = soup.find('table')
    if not table:
        return []
    return [[cell.get_text(strip=True) for cell in row.find_all(['td', 'th'])] for row in table.find_all('tr')]

def extract_list(soup, selector):
    items = soup.select(selector)
    return [item.get_text(strip=True) for item in items]

def extract_images(soup, base_url):
    images = soup.find_all('img')
    extracted_images = []
    for img in images:
        img_url = img.get('src')
        if img_url.startswith('/'):
            img_url = base_url + img_url
        extracted_images.append({
            'url': img_url,
            'alt': img.get('alt')
        })
    return extracted_images

        'phone': r'phone:\s*(\d{4}-\d{6})'
```

### Common Errors and Prevention
- **Error**: Unhandled relative image URLs leading to failed image loading.
  - **Solution**: Use `base_url` to complete relative URLs.
    ```python
    img_url = img.get('src')
    if img_url.startswith('/'):
        img_url = base_url + img_url
    ```
- **Error**: Incomplete data extraction due to unhandled merged cells (`colspan` or `rowspan`).
  - **Solution**: Check and handle merged cells during table extraction.
    ```python
    def extract_table_with_colspan(soup):
        table = soup.find('table')
        rows = []
        for tr in table.find_all('tr'):
            cells = []
            for td in tr.find_all(['td', 'th']):
                rowspan = int(td.get('rowspan', 1))
                colspan = int(td.get('colspan', 1))
                for i in range(rowspan):
                    for j in range(colspan):
                        cells.append(td.get_text(strip=True))
            rows.append(cells)
        return rows
    ```
- **Error**: Overly strict or lenient regular expressions causing missed or false matches.
  - **Solution**: Carefully design regular expressions and conduct thorough testing to ensure they match all expected data formats while avoiding false positives.
    - Use non-greedy matching (`.*?`) to prevent over-matching.
    - Use boundary matchers (`^` and `$`) to ensure matching the entire string or specific positions.
    - Example:
      ```javascript
      const strictPattern = /^invoice:\s*(\d{10})$/;
      ```

  - **Solution**: Preprocess the input text, such as standardizing delimiters and removing unnecessary spaces.

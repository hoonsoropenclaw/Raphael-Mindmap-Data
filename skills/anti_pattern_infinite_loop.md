# Anti-Pattern: Infinite Loop

## 說明...
此技能描述了由於無限循環導致的程序掛起問題，並提供了解決方法。

## 關鍵代碼片段或模式
```javascript
// 錯誤示例：缺少循環終止條件
while (true) {
  // 執行某些操作
}

// 正確示例：添加循環終止條件
let i = 0;
while (i < 10) {
  // 執行某些操作
  i++;
}
```

## 常見錯誤及避免方法
- **錯誤**：缺少循環終止條件，導致無限循環。
  **解決方法**：確保循環有明確的終止條件，例如使用計數器或條件判斷。
- **錯誤**：循環條件設置錯誤，導致無法終止。
  **解決方法**：仔細檢查循環條件，確保在適當的時候能夠終止循環。

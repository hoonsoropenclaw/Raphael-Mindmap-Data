# Anti-Pattern: Infinite Loop

## 原因
无限循环会导致程序无法终止，占用系统资源，最终导致程序挂起。

## 关键代码模式
```python
# 错误示例：缺少循环终止条件
while True:
    # 执行某些操作
    ...

# 正确示例：添加循环终止条件
while condition:
    # 执行某些操作
    ...
    if termination_condition:
        break
```

## 常见错误及避免方法
- **错误**：缺少循环终止条件。
  **解决方法**：在编写循环时，明确循环的终止条件，并确保条件在某个时刻会满足。
- **错误**：循环条件无法满足。
  **解决方法**：在循环内部动态更新循环条件，并进行充分的测试。

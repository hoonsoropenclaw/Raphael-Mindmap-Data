+# Linux Ops Monitor
+
+純 Python 3 標準庫、唯讀檢查 Linux 系統資源與近期日誌；任一指標超過閾值時輸出警告，可選擇送到 syslog 與 HTTP webhook。適合 systemd timer 每 5 分鐘執行。
+
+## 檢查項目
+
+- CPU 使用率（從 `/proc/stat` 兩次取樣，不依賴 `top`）
+- 記憶體與 swap（`/proc/meminfo`）
+- 1 分鐘 load average / CPU 核心數
+- 磁碟容量與 inode 使用率（可設定多個 mount）
+- zombie processes（讀 `/proc/<pid>/stat`）
+- systemd failed units
+- 近期 journald warning 數量
+- 近期日誌 critical regex：OOM、kernel panic、segfault、I/O error、登入失敗等
+
+## 安全與可靠性設計
+
+- 所有檢查唯讀；不會刪除、rotate 或修改系統日誌。
+- 純標準庫，沒有 pip/venv 或供應鏈依賴。
+- `subprocess` 不使用 shell，所有命令均有 timeout 與輸出上限。
+- journal 最多讀 `max_log_lines` 行、`max_log_bytes` bytes；避免 OOM。
+- webhook payload 有大小上限，HTTP 有 timeout，User-Agent 明確。
+- state 採 `mkstemp + fsync + os.replace` 原子寫入，POSIX 才 fsync 目錄。
+- state/lock 權限為 `0700/0600`；`flock` 防重疊執行。
+- 相同告警由 fingerprint + cooldown 去重，避免每 5 分鐘轟炸。
+- 告警不會輸出 webhook URL 或環境變數內容。
+- systemd unit 使用獨立低權限帳號與 sandbox hardening。
+
+## 直接執行（不安裝）
+
+```bash
+cd linux-ops-monitor
+chmod +x linux_ops_monitor.py
+./linux_ops_monitor.py --config ./config.example.json --no-notify
+printf 'exit=%s\n' "$?"
+```
+
+退出碼：
+
+- `0`：健康
+- `1`：至少一項超過閾值（適合監控系統判斷）
+- `2`：設定或執行錯誤
+
+JSON 輸出：
+
+```bash
+./linux_ops_monitor.py --config ./config.example.json --json --no-notify
+```
+
+注意：`config.example.json` 預設開啟 syslog；使用 `--no-notify` 可做安全 dry-run。
+
+## 設定
+
+複製範例後調整：
+
+```bash
+install -m 0600 config.example.json "$HOME/.config/linux-ops-monitor.json"
+./linux_ops_monitor.py --config "$HOME/.config/linux-ops-monitor.json" --no-notify
+```
+
+重要設定：
+
+- `thresholds.*`：各資源上限。比較規則為 `value >= threshold`。
+- `mounts`：要檢查的掛載點，至少一個。
+- `lookback_minutes`：journal 回看分鐘數，1–10080。
+- `critical_patterns`：Python regex 陣列；有命中即 critical finding。
+- `limits.*`：命令 timeout、journal bytes/lines、alert payload 上限。
+- `alerting.cooldown_seconds`：同一 finding set 再通知前的冷卻時間。
+- `alerting.syslog`：用 `logger` 寫入 `daemon.warning`。
+- `alerting.webhook`：POST JSON report。
+- `alerting.webhook_env`：存 webhook URL 的環境變數名稱；URL 不進 config。
+
+Webhook：
+
+```bash
+export LINUX_MONITOR_WEBHOOK_URL='https://monitor.example/hooks/REDACTED'
+./linux_ops_monitor.py --config ./config.example.json --ignore-cooldown
+```

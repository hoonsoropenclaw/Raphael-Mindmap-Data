+
+A Telegram bot that receives text and calls the **wttr.in** weather API to reply with the current weather.
+
+- **No API key needed** for wttr.in (the chosen backend)

+
+## Quick start
+
+```bash
+# 1. Set up a Python venv and install deps
+python3 -m venv .venv
+.venv/bin/pip install -r requirements.txt
+
+# 2. Create a bot on Telegram
+#    - Open @BotFather in Telegram
+#    - /newbot
+#    - Pick a name + username
+#    - Copy the token
+
+# 3. Configure
+cp .env.example .env
+# edit .env and paste your token into TELEGRAM_BOT_TOKEN
+
+# 4. Run
+.venv/bin/python -m app.main
+```
+
+That's it. Send `/weather Taipei` to your bot in Telegram, or just type

+## Commands
+
+| Send          | Bot behavior                                                  |
+|---------------|---------------------------------------------------------------|
+| `/start`      | Show help                                                    |
+| `/help`       | Show help                                                    |
+| `/weather X`  | Fetch current weather for city `X` (multi-word OK)           |

08 / PERFORMANCE

Performance is part of the aesthetic.

高質感不是把每一個 div 都 blur；是讓效果集中、可退化、可測量。

01 / blur budget

只在主要 surface 使用 backdrop-filter；小型 chip 和 table 使用 opaque-lite。

02 / motion budget

動效只改 transform、opacity；prefers-reduced-motion 會自動壓平。

03 / dependency budget

圖示是 inline SVG/文字；沒有圖片下載、沒有 runtime chart library。

Production note: compile Tailwind locally and keep this standalone file as a visual contract.

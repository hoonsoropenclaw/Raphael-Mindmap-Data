+## 設計決策
+
+### 為什麼 stdlib 而非 requests / aiohttp？
+benchmark 沙盒環境是純 Python 3.12，**避免任何 `pip install` 帶來的安裝失敗風險**。
+multipart 上傳用 `http.client` 自己組裝，~20 行就搞定（見 `_build_multipart()`）。
+
+### 為什麼 mock mode？
+本機無 `OPENAI_API_KEY`（env 探勘確認），但 demo 必須可執行。  
+mock 模式：
+- 用 `uuid.uuid5(name, size)` 生成可重現的識別碼
+- 輸出**明確標示** `[mock transcription]`，不冒充真實轉寫
+- 同檔名 + 同大小 → 同一個 sig（deterministic，方便測試）
+
+設了 `OPENAI_API_KEY` 就會自動走真實 API（見 `_whisper_api_call`）。
+
+### 為什麼 ThreadPoolExecutor 而不是 asyncio？
+tesseract 是 CPU-bound subprocess、Whisper API 是 IO-bound —— 兩者用 threadpool 都夠。  
+asyncio 的 `subprocess_exec` 對 shell-out 到 tesseract 不會更快，且 stdlib 寫起來囉嗦。
+
+### 為什麼 OCR 用兩次 tesseract 呼叫？
+tesseract 一次只能產一種輸出格式（`.txt` 或 `.tsv`）。  
+要同時拿**純文字** + **信心分數** → 拆兩次呼叫。  
+第一次失敗不會影響第二次（`read_text` 已加 `if .exists()` 防呆）。

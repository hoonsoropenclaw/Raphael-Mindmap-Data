+LOCK = "/tmp/lm-state/lm.lock"
+os.path.exists("/tmp/lm-state") or os.makedirs("/tmp/lm-state", exist_ok=True)

+# 1. 拿主鎖

+# 架構設計筆記 — linux-monitor v2.0.0
+
+## 設計目標
+
+1. **零外部依賴** — 任何 Python 3.10+ 環境可直接運行
+2. **正確性** — logrotate / truncate / 多 instance 都不能漏資料或重複告警
+3. **安全** — 機敏資料不留痕跡, 沒有 shell injection
+4. **可觀測** — 結構化日誌, exit code 語意化
+5. **優雅** — graceful shutdown, 錯誤自動恢復
+
+## 模組劃分
+
+```
+monitor.py
+├── Data Classes
+│   ├── Threshold         資源告警閾值
+│   ├── LogCursor         單檔讀取進度 (inode + offset)
+│   ├── LogTarget         監控目標 (path + patterns + optional)
+│   ├── Alert             告警事件 (severity/source/message/value)
+│   └── State             持久化狀態 (cooldown + cursors)
+├── Storage
+│   ├── StateStore        Atomic write + 0600 權限 + 損壞自動備份
+│   └── SingleInstanceLock  fcntl.flock (blocking / non-blocking)
+├── Resource Checks (純標準庫)
+│   ├── read_cpu_percent        /proc/stat 兩次 sampling
+│   ├── read_memory_percent     /proc/meminfo
+│   ├── read_disk_percent       os.statvfs
+│   └── read_load_per_cpu       /proc/loadavg / cpu_count
+├── Log Checks
+│   └── LogCursorTracker   inode + byte offset, 偵測 rotate/truncate
+├── Alerting
+│   ├── dispatch_alert     結構化 payload + urllib POST
+│   └── _http_post         無 requests 依賴
+├── Lifecycle
+│   ├── run_once           單次掃描
+│   ├── run_loop           連續監控 + signal handler
+│   └── main               CLI + 環境變數 + lock
+└── Configuration
+    └── load_config        JSON with defaults fallback
+```
+
+## 關鍵設計決策
+
+### 1. 為什麼用 byte offset + inode? (而非 Bounded Tail Scan)
+
+**問題**: 簡單 `tail -n 100` 會
+- 短間隔時重複算同一行
+- 高噴發時漏算
+- logrotate 之後的 N 行也讀不到
+
+**解法**: 像 Filebeat / Promtail 一樣, 記住每個檔案的 inode + offset:
+- 同一檔案: 從 offset 繼續讀
+- inode 變了 (logrotate): cursor 重置為 0
+- offset > size (truncate): cursor 重置為 0
+
+### 2. 為什麼 Webhook URL 從環境變數讀?
+
+**CLI 參數風險 (CWE-214)**:
+```
+$ ps aux | grep monitor
+user  1234  python3 monitor.py --webhook-url https://hooks.slack.com/services/TXXX/BXXX/SECRET_TOKEN
+                                                                                          ↑
+                                                                                  任何 user 都看得到
+```
+
+**環境變數解法**:
+```
+$ ps aux | grep monitor

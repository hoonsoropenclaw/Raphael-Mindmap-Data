+# Technical Specification
+
+## 1. 模組
+
+| 模組 | 職責 | 主要契約 |
+|---|---|---|
+| `models.py` | immutable request/response/event/outcome/config | dataclasses + enums |
+| `events.py` | 非同步事件 dispatch、subscriber isolation | `EventBus.publish/start/join/close` |
+| `rate_limit.py` | per-host token bucket + server cooldown | `AsyncTokenBucket.acquire/penalize` |
+| `retry.py` | bounded retry、backoff+jitter、Retry-After | `RetryPolicy.should_retry/delay_for` |

+| `cli.py` | CLI config + JSON output | `main/async_main` |
+
+## 2. 事件流
+
+`crawl.started → request.scheduled → request.started → response.received → (retry.scheduled → request.started)* → request.succeeded|request.failed → item.discovered → crawl.finished`
+
+EventBus 使用單一 dispatcher queue 保證 publish order；subscriber 可 sync/async。handler exception 被記錄成 `handler_errors`，不遞迴發布錯誤事件，避免錯誤風暴。
+
+## 3. Queue 終止演算法
+
+1. 啟動 N workers。
+2. schedule seeds；去重後放入 `asyncio.PriorityQueue`。
+3. `await queue.join()`；worker 在解析與 schedule 新連結完成後才 `task_done()`。
+4. join 返回代表沒有 queued/in-flight job。
+5. 放 N 個 sentinel，gather workers。
+6. 等 event bus idle，發布 finish，再關閉 bus/transport。
+
+## 4. Retry
+
+- 可重試 exception：`TimeoutError`, `ConnectionError`, `OSError`, aiohttp client errors（transport 正規化為 `TransportError`）。
+- 可重試 status：408, 425, 429, 500, 502, 503, 504。
+- attempts 含第一次；預設 3。
+- delay：若有效 Retry-After 則優先，否則 `min(max_delay, base * 2^(attempt-1))`，再乘 `1 + uniform(-jitter, jitter)`。
+- 同時受 `max_elapsed_seconds` 限制；下一次等待會超限就停止。
+- 429 會對 host limiter 設 `blocked_until`，其他 workers 共享 cooldown。
+
+## 5. Rate limit
+
+每 host 一個 bucket：`tokens=min(capacity, tokens + elapsed*rate)`。token 不足時計算 deficit/rate，在 lock 外 await sleep 後重算。`penalize(host, seconds)` 更新 `blocked_until=max(current, now+seconds)`。
+
+## 6. 安全
+
+- 僅 http/https。
+- URL 不可含 username/password。
+- 預設解析 DNS 並拒絕任何 private/loopback/link-local/multicast/unspecified/reserved IP。
+- E2E 明確開啟 `allow_private=True`。
+- response body 上限，避免無界記憶體。
+- max_urls/max_depth/max_queue_size 限制 frontier。
+
+## 7. 測試策略
+
+- Unit：retry parser/backoff、token bucket、event bus、URL policy。
+- Integration：scripted fake transport 驗證 retry/non-retry/dedup/concurrency。
+- E2E：真實 aiohttp local server，驗證 transport、timeout、429、link discovery。
+- Coverage：`coverage run -m pytest && coverage report --fail-under=80`。

+# asyncio Event-Driven Crawler
+
+一個已實際測試的 Python 3.12 事件驅動爬蟲核心，提供：
+
+- asyncio priority queue + bounded workers
+- ordered event bus，subscriber failure isolation
+- 每主機 token-bucket rate limit + burst
+- 408/425/429/5xx bounded retry
+- `Retry-After`（秒數與 HTTP date）
+- exponential backoff + jitter + max elapsed
+- URL 去重、深度、最大 URL、same-host 邊界
+- 預設 SSRF/private target 防護
+- aiohttp transport、timeout、response-size limit
+- CLI JSON report
+
+## 快速執行
+
+```bash
+python3 -m async_crawler --help
+python3 -m async_crawler https://example.com --workers 3 --rate 1 --max-depth 1 --verbose
+```
+
+本機測試站必須明確開放 private target：
+
+```bash
+python3 -m async_crawler http://127.0.0.1:8080 --allow-private
+```
+
+## Python API
+
+```python
+import asyncio
+from async_crawler import AsyncCrawler, CrawlConfig, EventType
+
+async def main():
+    crawler = AsyncCrawler(CrawlConfig(workers=4, requests_per_second=2, max_depth=1))
+    crawler.events.subscribe(EventType.RETRY_SCHEDULED, lambda e: print(e.data))
+    report = await crawler.run(["https://example.com"])
+    print(report.stats)
+
+asyncio.run(main())
+```
+
+## 重試語義
+
+- `max_attempts` 包含第一次請求。
+- 一般 4xx（401/403/404/422 等）不重試。
+- 408、425、429、500、502、503、504 與暫時性 transport error 才重試。
+- 429 若有 `Retry-After`，會同步懲罰該 host 的 shared limiter。
+- attempt、單次 delay 與總 elapsed 都有上限，禁止無界循環。
+
+## 事件
+
+`crawl.started`, `request.scheduled`, `request.started`, `response.received`, `retry.scheduled`, `request.succeeded`, `request.failed`, `item.discovered`, `crawl.finished`。
+
+`subscribe(None, handler)` 可訂閱所有事件。handler 可為 sync/async；單一 handler 失敗只記入 `handler_errors`，不會中止爬蟲。

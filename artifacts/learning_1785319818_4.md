+# PRD：即時桌面 OCR 應用

+## 目標
+建立一個可執行、local-first 的桌面 OCR 應用：使用者可上傳/貼入螢幕截圖，或由支援圖形桌面的主機擷取螢幕，經本機 OCR API 立即回傳文字、信心分數、文字框與耗時。

+## 模組拆解
+1. OCR 引擎：Pillow 預處理 + Tesseract，eng 預設；可配置已安裝語言。

+5. 螢幕擷取：Pillow ImageGrab；headless 時回可診斷的 503，而非崩潰。

+        changed = digest != self._digest
+        self._digest = digest

+def installed_languages() -> list[str]:
+    try: return sorted(pytesseract.get_languages(config=""))

+def validate_options(lang: str, psm: str | int, preprocess: str) -> tuple[str, int, str]:
+    if not LANG_RE.fullmatch(lang): raise ValueError("Invalid OCR language expression")
+    psm_int = int(psm)
+    if not 3 <= psm_int <= 13: raise ValueError("psm must be between 3 and 13")
+    if preprocess not in {"auto", "gray", "threshold", "none"}: raise ValueError("Invalid preprocess mode")
+    available = set(installed_languages())
+    missing = [part for part in lang.split("+") if part not in available]
+    if missing: raise ValueError(f"OCR language pack not installed: {', '.join(missing)}")
+    return lang, psm_int, preprocess

+def decode_image(data: bytes) -> Image.Image:
+    try:
+        image = Image.open(io.BytesIO(data)); image.load()
+        if image.width * image.height > 50_000_000: raise UnsupportedImage("Image dimensions exceed 50 megapixels")
+        return image.convert("RGB")

+        raise UnsupportedImage("Body is not a supported image") from exc

+
+def preprocess_image(image: Image.Image, mode: str = "auto") -> Image.Image:
+    if mode == "none": return image.convert("RGB")
+    gray = ImageOps.grayscale(image)
+    gray = ImageOps.autocontrast(gray)
+    if mode == "gray": return gray
+    if mode == "threshold": return gray.point(lambda p: 255 if p > 145 else 0, mode="L")

+# 即時桌面 OCR
+
+Local-first 桌面 OCR：瀏覽器桌面介面 + Python 本機 API + Tesseract。圖片不會送往第三方。
+
+## 已驗證環境
+- Python 3.12
+- Pillow、pytesseract
+- Tesseract 5.3.4（本機目前有 `eng`、`osd`）
+
+## 啟動
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785319818_4
+python3 ocr_app.py
+```
+開啟 `http://127.0.0.1:8765`。
+
+## 使用
+1. 拖入/選擇圖片，或 Ctrl+V 貼上截圖。
+2. 選語言、版面分析與預處理模式。
+3. 按「辨識圖片」。
+4. 有圖形桌面的主機可按「啟用即時桌面」，預設每 1500 ms 擷取辨識；請依 CPU 調高間隔。
+
+## API
+```bash
+curl http://127.0.0.1:8765/api/health
+curl -X POST -H 'Content-Type: image/png' --data-binary @screen.png \
+  'http://127.0.0.1:8765/api/ocr?lang=eng&psm=6&preprocess=auto'
+```
+
+## 多語言
+本機目前未安裝繁中資料包。安裝 `chi_tra` 後 UI 會自動列出，可選 `chi_tra`；API 可用 `lang=chi_tra+eng`。本程式不自動改系統套件。
+
+## 安全與隱私
+- 預設只監聽 `127.0.0.1`。
+- 圖片 body 最大 10 MiB，影像最大 50MP。
+- 驗證 Content-Type、實際影像、OCR 語言與 PSM。
+- 不保存、不記錄圖片或 OCR 文字。
+- 回應含 CSP、nosniff、no-store。
+- 若用 `--host 0.0.0.0` 暴露網路，請自行加反向代理認證與 TLS。

+# Field Notes — Implementation Notes
+
+## Product direction
+
+Field Notes is a calm, editorial command center for turning a noisy task list into a considered workday. The design deliberately uses warm paper tones, Newsreader display typography, a small coral action color, and generous negative space instead of the usual blue-purple SaaS dashboard language.
+
+## Component architecture
+
+- `src/main.jsx` owns the application shell and the composable `NoteCard` component.
+- The primary state machine is a single `useReducer` so related transitions stay explicit and auditable.
+- Notes move through `backlog`, `in-progress`, and `done` columns.
+- The reducer handles query, filter, sort mode, board/list view, selection, creation, drag movement, batch archive/delete, and undo history.
+- Undo is modeled as a small command history rather than a second copy of the entire application state. Every mutating action records the minimum inverse data required to recover.
+- The composer is local UI state; persisted domain changes are dispatched through the reducer.
+
+## Interaction decisions
+
+1. Drag-and-drop is the fastest path for changing a note's state, while the card action remains available for keyboard/mouse users.
+2. Multi-select exposes batch actions only after selection, keeping the default board quiet.
+3. New notes land in Backlog with a visible toast and a one-step Undo action.
+4. Search is live and searches title, project, and tag. The `/` affordance is visual guidance for the intended keyboard shortcut.
+5. Board and List are two views over the same derived `visibleNotes` collection, so filtering behavior cannot drift between them.
+
+## Visual system
+
+- Display: `Newsreader` for a human, editorial voice.
+- UI/body: `DM Sans` for compact controls and legibility.
+- Metadata: `DM Mono` for dates, counts, and system-like labels.
+- Colors are CSS variables in `src/styles.css`, with project colors reused as semantic accents.
+- Responsive behavior collapses the sidebar into a compact navigation strip and turns board columns into stacked sections below 700px.
+- Focus-visible outlines, semantic buttons/labels, checkbox controls, and aria labels are included for baseline accessibility.
+
+## Verification
+
+Run:
+
+```bash
+npm install
+npm run build
+```
+
+The generated `dist/` directory is the production artifact. No backend or environment variables are required.

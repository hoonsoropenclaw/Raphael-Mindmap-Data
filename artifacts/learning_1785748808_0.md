+# SmartCrawler — 智慧動態網頁爬蟲
+
+基於 Playwright 的動態網頁爬蟲，實現對動態渲染內容的智能抓取與數據提取。
+
+## 6 大特性
+
+1. **真渲染偵測** — 並行偵測 DOM 穩定 / XHR 清空 / 圖片 loaded / 字型 ready / hydration，不等 DOMContentLoaded、不等 load。
+2. **自適應選擇器** — 多策略 selector fallback + 跨 session 指紋記憶 + 結構性啟發式。
+3. **API 自動偵測** — 自動 hook 所有 response，辨識「最可能是 schema 來源的 API」，對 SPA 尤其有效。
+4. **反爬繞過** — 隱藏 webdriver flag、偽造 plugins/chrome runtime/WebGL vendor、模擬人類滑鼠軌跡。
+5. **結構化輸出** — JSON Schema Draft-07 + human-readable report，多格式序列化（JSON/JSONL/CSV）。
+6. **分頁自適應** — 4 策略自動偵測（Next / URL pattern / Load more / Infinite scroll）。
+

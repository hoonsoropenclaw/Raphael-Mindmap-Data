+# GitHub Trending → Markdown
+

+
+## 特色
+
+- **零相依**: 純 Python 3.10+ 標準庫 (`urllib` + `html.parser`),免安裝第三方套件
+- **CLI 友善**: `--language` / `--since` / `--limit` / `--format` / `--output`
+- **Robust**: 內建 retry + 指數退避 + User-Agent;解析失敗欄位以 `-` 取代,不中斷整份輸出

+- **可測試**: parser / fetcher / renderer 各自獨立,可單獨 import 測試
+
+## 快速使用
+
+```bash
+# 抓今日所有 trending → 印到 stdout
+python3 github_trending.py
+
+# 抓 Python 語言本週熱門 → 存成 markdown 檔
+python3 github_trending.py --language python --since weekly --output trending-python-weekly.md
+
+# 抓前 10 名,輸出成 JSON
+python3 github_trending.py --limit 10 --format json --output trending.json
+
+# 顯示除錯 log
+python3 github_trending.py --verbose
+```
+

+## 3. 踩過的坑 (重要!)
+
+### 坑 1: 名稱被截斷 `owner /`
+
+**症狀**: 第一版輸出 `permissionlesstech /` (後面 repo 名不見了)

+**原因**: GitHub 把標題做成 `<a><span>owner</span> / <span>repo</span></a>`。我的 HTMLParser
+在 `</span>` 就把 capture 關了,只收到 `owner`。
+
+**修法**: 不從文字節點抓 name — 改從 `href` 直接推 `owner/repo`,這是 GitHub
+URL convention,結構最穩。
+
+### 坑 2: `Total Stars = -` (regex 找錯元素)
+
+**症狀**: 第二版跑出來,total_stars 全是 `-`

+`<a href="/.../stargazers"> <svg.../></svg>\n        31,336</a>` — 純文字節點,沒 span。
+
+**修法**: regex 改成 `</svg>\s*([\d,]+)\s*</a>`。
+
+### 坑 3: Weekly / Monthly 沒 stars
+
+**症狀**: `--since weekly` 跑出來 `stars_today` 全是 `-`
+
+**原因**: GitHub 對 weekly 顯示 "15,909 stars this week"、monthly 顯示
+"23,805 stars this month",我的 regex 只 match `stars today`。
+
+**修法**: regex 改成 `stars? (today|this\s+\w+)`,並把 period 字串帶進輸出。

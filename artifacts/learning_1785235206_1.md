+
+## Goal
+
+Fetch GitHub's Trending repositories page and render them as a Markdown
+table, using only the Python standard library, and verify the result
+end-to-end with both an offline fixture test and a live network smoke

+## Architecture
+
+```
+CLI (main) ─► fetch(url) ─► TrendingParser.feed(html)
+                                  │
+                                  └─► Repository[] (dataclass)
+                                            │
+                                            ▼
+                                   render(repos, url)
+                                            │
+                                            ▼
+                                   write_atomic(path, md)
+```
+
+1. `fetch()` uses `urllib.request` with a descriptive User-Agent and
+   configurable timeout. No third-party dependency.
+2. `TrendingParser` extends `html.parser.HTMLParser` and tracks depth
+   to scope state to one `<article class="Box-row">` at a time.
+3. `Repository` is a plain dataclass; rendering is decoupled from
+   parsing so a future JSON / CSV / HTML output needs no re-parse.
+4. `render()` produces the Markdown table and escapes pipes.
+5. `write_atomic()` writes to a uniquely-named temp file in the same
+   directory as the target, flushes + fsyncs, then `os.replace()`s —
+   so a partial write never overwrites the previous file, and
+   overlapping runs don't collide on a fixed temp path.

+## Design notes
+
+- GitHub Trending is HTML, not a stable public API, so parsing is
+  intentionally defensive.
+- The parser tracks depth inside `<article class="Box-row">` blocks
+  and recognizes the stargazers / forks anchors by their `href`
+  suffix.
+- Output is written atomically: unique temp file + `flush()` +
+  `os.fsync()` + `os.replace()` so a partial write never overwrites
+  the previous file.
+- Markdown cells escape pipe characters to preserve valid table
+  structure.
+- Empty parse result fails loudly instead of replacing a previous
+  successful output.

+## 實作思路
+
+### 1. 為什麼用 requests + re 而非 GitHub API？
+
+- **GitHub 官方沒有 Trending API**。Trending 列表是 GitHub 內部渲染的 HTML 頁面，
+  沒有公開 REST/GraphQL endpoint。
+- **使用 HTML 解析**是業界通用做法（參考 github-trending-api、
+  ghsrafpull 等開源專案）。
+- 用 `requests`（已安裝）抓頁面 + `re` 解析，避免引入 BeautifulSoup 等額外依賴。
+- **關鍵 selector**：`article.Box-row` 是每個 repo 卡片的外層 class，
+  內含 `<h2><a href="/owner/repo">` (路徑)、
+  `<p class="col-9 ...">` (描述)、
+  `itemprop="programmingLanguage"` (語言)、
+  `href="/.../stargazers"` (總星數)、
+  `href="/.../forks"` (fork 數)、
+  `([\d,]+) stars (today|this week|this month)` (期間星數)。
+
+### 2. 架構分層
+
+```
+CLI (argparse) ──► fetch_trending_html() ──► parse_repos() ──► to_markdown()
+                                       │              │           │
+                                       │              │           └─ 寫 .md 檔
+                                       │              └─ TrendingRepo dataclass
+                                       └─ requests + retry 3x
+                                          + User-Agent 偽裝
+```
+
+- **`TrendingRepo` dataclass**: 強型別資料模型，欄位明確，
+  `asdict()` 一行轉 JSON。
+- **`fetch_trending_html()`**: 單一職責，含 retry 邏輯。
+  失敗時拋 `RuntimeError`，由 `main()` 統一轉 exit code 1。
+- **`parse_repos()`**: 純函式，吃 HTML 吐 `list[TrendingRepo]`，
+  方便 unit test。
+- **`to_markdown()`**: 純函式，吃 repos 吐 markdown 字串。
+- **`main()`**: 組裝 + 寫檔 + 處理頂層錯誤。
+
+### 3. 支援的功能
+
+| 功能 | CLI 旗標 | 預設值 |
+|------|---------|--------|
+| 時間範圍 | `--since {daily,weekly,monthly}` | `daily` |
+| 語言過濾 | `--language <name>` | None (全部) |
+| 顯示前 N 名 | `--top N` | 25 |
+| 自訂輸出路徑 | `--output <path>` / `--json-output <path>` | 同目錄預設檔名 |
+
+### 4. 抓取禮儀 & 穩定性
+
+- **User-Agent** 設為 Chrome，避免被 GitHub 視為 bot 拒絕。
+- **重試策略**: 失敗等 1.5s → 3.0s → 4.5s (exponential backoff × 3 次)。
+- **HTTP timeout**: 20 秒（避免掛在死連線）。
+- **空資料 fallback**: 若解析出 0 個 repo，自動把 raw HTML 存到
+  `trending_debug.html` 供人工 debug。
+- **exit code 規範**: 0 = 成功 / 1 = 連線或解析失敗，方便 cron / CI 整合。
+
+### 5. 輸出格式設計
+
+**Markdown** 給人看、**JSON** 給程式：
+
+- Markdown 表格包含：排名、完整 repo 路徑（含超連結）、
+  語言、總星數、fork 數、期間星數、描述。
+- 數字欄位靠右對齊 (`---:`) 符合 Markdown 慣例。
+- 描述自動截斷 120 字 + 轉義 `|` 避免破表。

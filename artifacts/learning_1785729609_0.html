Test contract details

The suite checks stable test IDs, role-based controls, the live status transition, mobile overflow, console errors, and deterministic screenshot snapshots.

Baseline files belong in snapshots/baseline · current artifacts belong in test-results · update intentionally with npm run test:visual:update

+SCHEMA_SQL = """
+CREATE TABLE IF NOT EXISTS todos (
+    id          INTEGER PRIMARY KEY AUTOINCREMENT,
+    title       TEXT    NOT NULL CHECK(length(trim(title)) > 0),
+    description TEXT    NOT NULL DEFAULT '',
+    completed   INTEGER NOT NULL DEFAULT 0 CHECK(completed IN (0, 1)),
+    created_at  TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
+    updated_at  TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))

+TRIGGER_SQL = """
+CREATE TRIGGER IF NOT EXISTS trg_todos_updated_at
+AFTER UPDATE ON todos
+FOR EACH ROW
+BEGIN
+    UPDATE todos
+    SET updated_at = strftime('%Y-%m-%dT%H:%M:%fZ', 'now')
+    WHERE id = OLD.id;
+END;
+"""

+def init_db(db_path: Path | str = DEFAULT_DB_PATH) -> None:
+    """建立 schema 與觸發器（idempotent）。"""
+    path = Path(db_path)
+    path.parent.mkdir(parents=True, exist_ok=True)
+    conn = sqlite3.connect(path, isolation_level=None)
+    try:

+        conn.executescript(TRIGGER_SQL)

+
+設計決策：
+- **單機 in-memory** 而非 Redis：需求是「簡單待辦 API」，單機部署、零外部依賴。
+- **Sliding window log**：精準但 O(n) 空間；對單一 IP 的紀錄數 = limit 本身（最多幾十筆），

+# DESIGN_DECISIONS.md
+
+## 1. 框架 / 套件選型
+
+### FastAPI 0.115（不是 Flask / Django REST）
+- **原生 Pydantic v2**：schema 驗證 + 自動 OpenAPI 文件，不需額外序列化層
+- **Dependency Injection**：測試時可注入 `db_path` / `limiter`
+- **Lifespan** 而非 deprecated `@app.on_event`
+- **async-ready**：將來要加 async DB（asyncpg、aiosqlite）不用改架構
+
+### SQLite（不是 PostgreSQL / MySQL）
+- 「簡單待辦 API」不需要外部依賴、單機部署就能跑
+- 透過 `app.state.db_path` 注入，未來要換 Postgres 只要改 `database.py` 的 `get_connection()`
+
+### pytest + fastapi.testclient.TestClient（不是 httpx.AsyncClient）
+- `TestClient` 走 anyio portal，在 sync 測試內呼叫 async app，免設 event loop
+- 對純邏輯（rate limiter）直接 import 類別測，不啟 server
+

+## 2. 資料庫設計
+
+### Schema
+```sql
+CREATE TABLE todos (
+    id          INTEGER PRIMARY KEY AUTOINCREMENT,
+    title       TEXT    NOT NULL CHECK(length(trim(title)) > 0),
+    description TEXT    NOT NULL DEFAULT '',
+    completed   INTEGER NOT NULL DEFAULT 0 CHECK(completed IN (0, 1)),
+    created_at  TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
+    updated_at  TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
+);
+CREATE INDEX idx_todos_completed ON todos(completed);
+CREATE INDEX idx_todos_created_at ON todos(created_at);
+CREATE TRIGGER trg_todos_updated_at AFTER UPDATE ON todos ...;
+```
+
+**決策理由**：
+- `INTEGER` 而非 `BOOLEAN`：SQLite 沒有原生 bool，用 INTEGER + CHECK 約束更穩
+- **CHECK 約束**：title 不能是空白字串（trim 後長度 > 0），在 DB 層就把髒資料擋掉
+- **觸發器自動更新 `updated_at`**：省得每個 UPDATE SQL 都手寫 `updated_at = now()`
+- **索引**：list 查詢最常見的兩個過濾條件（`completed=?`、`ORDER BY created_at DESC`）
+- **ISO 8601 + Z 結尾的字串時間**：避免時區混淆（全部 UTC），Python `datetime.fromisoformat()` 直接解析
+
+### Connection 管理
+- `contextmanager` 模式 + `with get_connection(db_path) as conn:`：
+  - 自動 `commit()` 成功 / `rollback()` 例外
+  - `WAL` journal mode → 並發讀不阻塞寫
+  - `synchronous=NORMAL` → 寫入效能比 FULL 快 10x，正常關機不丟資料
+  - `row_factory = sqlite3.Row` → 可以用欄位名取值，debug 友善
+- 不用 SQLAlchemy：對 6 個簡單查詢，ORM 是 over-engineering。直接寫 SQL 透明、好懂、好 debug。
+
+---

+## 3. Rate Limiter 設計
+
+### Sliding window log（不是 fixed window / token bucket）
+| 演算法 | 優點 | 缺點 |
+|---|---|---|
+| **Fixed window** | O(1) 空間 | 邊界雙倍 burst（59s 100 次 + 60s 100 次 = 2 秒內 200 次） |
+| **Token bucket** | 平滑限流 | 需要背景 refill thread |
+| **Sliding window log** | **100% 精準** | O(N) 空間（N = limit） |
+| Sliding window counter | O(1) 空間、接近精準 | 實作較複雜，邊界仍有誤差 |
+
+**選 sliding window log**：對「簡單待辦 API」、每個 IP 最多 100 個 timestamp（≈ 1.6 KB），換來 100% 精準的限流。完全值得。
+
+### In-memory（不是 Redis）
+- 需求是「簡單單機 API」，引入 Redis 是過度設計
+- 註解清楚說明：「如需多實例部署，換成 Redis-backed limiter 即可，介面（`check(key)`）不變」
+
+### `time_fn` 注入
+- 預設 `time.monotonic`（不受系統時鐘變動影響）
+- 測試時傳 fake function，可在單一 process 內 deterministically 推進時間，不需要 freezegun / 額外套件
+
+### Thread-safe
+- `threading.Lock` 包住整個 `check()`，保證 multi-thread FastAPI 下不會 race
+- 不用 asyncio.Lock 是因為 middleware 是 BaseHTTPMiddleware（thread pool），但對 in-memory dict 用 sync lock 反而更簡單

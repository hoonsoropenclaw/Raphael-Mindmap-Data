+# PRD：Atlas Flow 工作流管理台
+
+## 目標
+建立一個可直接由瀏覽器開啟、無建置步驟的單檔 React Flow 工作流管理介面，讓營運與工程人員能建立、編輯、驗證、模擬、版本化與匯出工作流。
+
+## 核心使用情境
+1. 從節點庫點擊或拖曳節點到畫布。
+2. 拖曳節點並建立有向連線；拒絕自我連線與循環依賴。
+3. 點選節點或連線，在 Inspector 編輯設定。
+4. 自動排版並執行 DAG 拓撲模擬。
+5. 查看即時活動日誌與歷史執行紀錄。
+6. 儲存 localStorage 草稿、建立發布版本、還原版本。
+7. JSON 匯入與匯出。
+8. 在桌機、平板與手機上可操作且不產生水平頁面溢位。
+
+## Must-have 驗收
+- React Flow 畫布成功渲染，初始至少 6 個節點與 6 條連線。
+- 節點可新增、拖曳、刪除、複製、重新命名。
+- 連線可新增、選取、改標籤、刪除。
+- DAG 模擬會逐層改變節點狀態並留下日誌。
+- Builder / Runs / Versions 三個主視圖可切換。
+- localStorage、JSON 匯入匯出、發布/還原版本可操作。
+- 1280×900、768×1024、390×844 三種 viewport 無頁面水平溢位。
+- Console 無 uncaught error。
+
+## 非目標
+- 真實後端執行器、多人即時協作、OAuth、資料庫持久化。
+- 以單檔原型冒充 production backend。
+
+## 技術策略
+- React 18.3.1 UMD → ReactDOM 18.3.1 UMD → React Flow 11.11.4 UMD，固定順序載入。
+- 不使用 Babel/JSX，採 React.createElement，降低瀏覽器轉譯與 UMD 初始化失敗面。
+- 以純前端 state + localStorage 建立可操作原型。
+- DAG 使用 Kahn 拓撲分層；任何連線建立前先驗證無循環。

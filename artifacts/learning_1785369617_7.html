ℹ 使用說明 / 架構說明

運作原理: 瀏覽器 MediaRecorder 擷取麥克風 → 每 2 秒關閉一段並立即開啟下一段 → 將可獨立解碼的 WebM/MP4 依序送到 Whisper API。

注意: whisper-1 不支援真正的 streaming；這裡是「短片段連續轉錄」的準即時模式。真正低延遲串流應使用 Realtime transcription。

API Key: 只保存在此頁記憶體；重新整理即消失。它仍會由瀏覽器直接送往 OpenAI，因此本頁只適合本機測試，不適合公開部署。

計價:

  • whisper-1: $0.006 / 分鐘
  • gpt-4o-transcribe: $0.006 / 分鐘 (input)
  • gpt-4o-mini-transcribe: $0.003 / 分鐘 (input)

瀏覽器支援: 需 Chrome / Edge / Firefox / Safari 14+。需 HTTPS 或 localhost(麥克風權限限制)。

已知限制:

  • 切片交界可能丟字(音訊不連續)
  • 極短靜音片段會被 Whisper 忽略或產生幻覺
  • 網路延遲會反映為轉錄延遲

+## 1. Goal
+
+Scrape GitHub's public Trending page and render the results as a Markdown table.
+No GitHub API token required — uses the public HTML at `https://github.com/trending`.
+
+## 2. Architecture & Decisions
+
+### 2.1 Pipeline shape
+Three small pure functions, glued by a CLI `main()`:
+
+```
+build_url()      ─►   fetch_trending_page()   ─►   parse_trending_html()
+                                                       │
+                                                       ▼
+                                                  render_markdown()
+                                                       │
+                                                       ▼
+                                                  write to file / stdout
+```
+
+Each stage is independently testable. `parse_trending_html()` takes raw HTML, so a unit test can pass a fixture without ever hitting GitHub.
+
+### 2.2 HTTP transport
+- **Library:** `requests` (already installed in the env, stdlib-grade stable, supports session reuse for future enhancement).
+- **User-Agent:** Chrome 120 on Linux x86_64. GitHub returns 403 to bare `python-requests/x.x` UAs, so a real-looking browser UA is mandatory.
+- **Timeout:** 20 s (long enough for slow networks, short enough to fail fast in a cron job).
+- **Retry:** exponential backoff (2 s, 4 s, 8 s), max 3 attempts. Retries on 5xx and 429 only — 4xx other than 429 are terminal (no point retrying a 404).
+
+### 2.3 Parsing strategy
+- **Library:** `BeautifulSoup4` with `lxml` parser (already installed).
+- **Selector:** `article.Box-row` is GitHub's stable wrapper for each trending entry. Verified against a real fetch (12 rows on the daily page).
+- **Field extraction:**
+  - `h2 a` → `full_name` + `url`
+  - `p.col-9` → description
+  - `[itemprop=programmingLanguage]` → language
+  - `span.float-sm-right` containing "star" → period stars (GitHub labels "today" / "this week" / "this month" depending on `--since`)
+  - `<a href="/.../stargazers">` → total stars
+  - `<a href="/.../network/members">` → forks (best-effort; GitHub doesn't always render)
+- **Robustness:** malformed rows are skipped (`continue`) rather than crashing the whole output. If GitHub changes its markup entirely, we fall back to `article` and raise a descriptive error.
+
+### 2.4 Markdown rendering
+- **Columns:** `#` (rank), Repository (linked), Description (escaped), Language, ⭐ Total, 🔥 {Today|This week|This month}.
+- **Pipe escaping:** every cell passes through `_md_escape()` which replaces `|` → `\|` and collapses whitespace. This prevents descriptions like `a | b` from breaking the table.
+- **Dynamic period header:** the last column header adapts to `--since` (Today / This week / This month) so the labels match the actual numbers GitHub returns.
+- **Singular/plural:** "1 repository" vs "12 repositories" — minor but visible.
+
+### 2.5 CLI surface
+```
+--since {daily,weekly,monthly}        default daily
+--language <slug>                     e.g. python, typescript, go
+--spoken-language <iso639-1>          e.g. zh, ja, ko
+--limit N                             cap on rows
+--output <path>                       default ./github_trending.md
+--print                               stream to stdout instead of file
+--user-agent <str>                    override UA (useful for testing)
+--verbose                             progress to stderr
+```
+argparse-driven, `--help` is self-documenting. Exit code 2 on fetch failure, 0 on success.
+
+## 3. Why these choices over alternatives
+
+| Considered | Rejected because |
+|------------|------------------|
+| GitHub REST API (`/search/repositories?q=created:>...`) | Requires token; rate-limited to 10 req/min unauthenticated; `stars` filter doesn't perfectly match Trending's algorithm |
+| Selenium / Playwright | Overkill for static HTML; heavy dependency; slower |
+| Unofficial `gh-trending` PyPI package | Adds external dependency for 100 lines of parsing logic; we'd inherit its bugs |
+| Pure `re` parsing of HTML | Brittle; the moment GitHub adds whitespace or changes tag order, regex breaks. CSS selectors via BeautifulSoup are far more robust |

+"""SQLAlchemy engine, session factory, and Base declarative class.
+
+We deliberately use the synchronous engine: SQLite has no async driver
+support we want to lean on, and the entire request lifecycle for the CRUD
+endpoints is single-digit-millisecond. Adding async just for parity adds
+complexity (`asyncpg`-style for SQLite is not stable in SA's main) without
+measurable benefit.
+
+For tests we swap the engine via ``app.dependency_overrides`` to point
+``SessionLocal`` at an in-memory SQLite. The ``connect_args={"check_same_thread": False}``
+flag is needed when sharing a single connection across threads (TestClient runs
+handlers in a worker thread).
+"""
+
+from typing import Generator
+
+from sqlalchemy import create_engine
+from sqlalchemy.orm import DeclarativeBase, Session, sessionmaker
+
+from app.config import DB_URL
+
+
+# `connect_args` is sqlite-specific; passing it for any other DB URL would
+# raise. We isolate the case so future swap-in for Postgres etc. doesn't blow up.
+_CONNECT_ARGS: dict = {}
+if DB_URL.startswith("sqlite"):
+    _CONNECT_ARGS["check_same_thread"] = False
+
+
+engine = create_engine(DB_URL, connect_args=_CONNECT_ARGS, future=True)
+
+# expire_on_commit=False keeps ORM attributes accessible after commit()
+# (FastAPI calls into the ORM to build the response *after* the commit).
+SessionLocal = sessionmaker(
+    bind=engine,
+    autoflush=False,
+    autocommit=False,
+    expire_on_commit=False,
+    future=True,
+)
+
+
+class Base(DeclarativeBase):
+    """Declarative base; ORM models inherit this."""
+
+
+def get_db() -> Generator[Session, None, None]:
+    """FastAPI dependency that yields a session and always closes it.
+
+    Using `yield` makes FastAPI handle the cleanup even on exception; this is
+    the canonical pattern, not optional.
+    """
+    db = SessionLocal()
+    try:
+        yield db
+    finally:
+        db.close()

+    from app import models  # noqa: F401

+    db: Session,
+    *,
+    skip: int = 0,

+    completed: Optional[bool] = None,

+from slowapi import Limiter
+from slowapi.util import get_remote_address

+from app.config import DEFAULT_RATE_LIMIT
+
+
+def _key_func(request: Request) -> str:
+    """Key on IP. If you ever put this behind a proxy, swap to X-Forwarded-For."""

+# Todo API
+
+A small, opinionated REST API for managing todos, built with FastAPI,
+SQLAlchemy, and Pydantic v2. SQLite is the default storage backend so the
+service runs with zero external dependencies. Rate limiting is provided by
+[slowapi](https://github.com/laurentS/slowapi) and is keyed on the client IP.
+
+## Endpoints
+
+| Method | Path             | Purpose                  | Rate limit      |
+| ------ | ---------------- | ------------------------ | --------------- |
+| GET    | `/health`        | Liveness probe           | none            |
+| GET    | `/todos`         | List todos (paged)       | `60/minute`     |
+| POST   | `/todos`         | Create a todo            | `30/minute`     |
+| GET    | `/todos/{id}`    | Fetch one                | `60/minute`     |
+| PATCH  | `/todos/{id}`    | Partial update           | `30/minute`     |
+| DELETE | `/todos/{id}`    | Delete                   | `30/minute`     |
+
+`GET /todos` supports `?skip=N&limit=N&completed=true|false`.
+`PATCH /todos/{id}` rejects unknown fields with `422`.
+
+Swagger UI is served at `/docs`, ReDoc at `/redoc`, OpenAPI JSON at
+`/openapi.json`.
+

+## Architectural decisions
+
+### 1. Synchronous SQLAlchemy over async
+
+Chose the synchronous engine deliberately. Reasoning:
+
+- SQLite has no production-grade async driver (`aiosqlite` exists but is
+  actively avoided in SA's main recommendations for mixed workload).
+- End-to-end request lifecycle is single-digit-millisecond; the extra

+  for itself.

+  the public surface (Pydantic schemas, route signatures) identical.
+
+### 2. Pydantic v2 schemas isolated from ORM models
+
+ORM models know about persistence (`server_default`, `onupdate`, indices).
+Pydantic schemas know about wire format (length bounds, `extra="forbid"`).
+The split prevents clients from leaking DB-specific columns or accepting
+typos. `TodoUpdate` uses `extra="forbid"` so a misspelled field returns 422
+instead of silently no-op'ing — a recurring source of bugs in PATCH
+endpoints.
+
+### 3. Rate limiting: slowapi, per-IP, separate read/write budgets
+
+slowapi is the FastAPI-native rate limiter ported from Flask-Limiter. The
+design:
+
+- One global `Limiter` instance lives at `app.state.limiter`
+- `SlowAPIMiddleware` enforces limits before the route runs
+- Endpoints opt in with `@limiter.limit("<n>/<period>")` decorators
+- A single client-key function (`get_remote_address`) keys the limiter
+
+Splitting read vs write budgets (`60/min` GET, `30/min` others) reflects the
+fact that list-heavy clients shouldn't be punished for browsing, while
+state-changing endpoints are the abuse vector.

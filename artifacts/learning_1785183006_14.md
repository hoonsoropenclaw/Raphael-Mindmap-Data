+# github_trending.py
+
+抓取 GitHub Trending Repositories 並輸出成 Markdown 表格的自動化腳本。
+
+## 特色
+
+- **零 API token**：純 server-rendered HTML 解析，不需 GitHub personal access token 也不會撞 60 req/h 限制
+- **無外部瀏覽器**：只依賴 `requests` + `beautifulsoup4`
+- **容錯**：單筆解析失敗只跳過該筆，不會讓整個 run 崩潰
+- **多種篩選**：時間區間（daily/weekly/monthly）+ 說明語言（zh/ja/en/...）
+- **乾淨輸出**：時間戳檔名、不覆蓋歷史快照；可選同步輸出 JSON 方便後續處理
+- **安全 umask**：寫入檔案前動態 `os.umask(0o077)`，確保產出檔 mode 600（吸收自前次 architect_feedback 的 L3 教訓）
+
+## 安裝
+
+```bash
+python3 -m pip install requests beautifulsoup4
+```
+
+## 用法
+
+```bash
+# 今日全部（最常用）
+python3 github_trending.py
+
+# 本週熱門
+python3 github_trending.py --since weekly
+
+# 本月熱門
+python3 github_trending.py --since monthly
+
+# 限定中文專案說明
+python3 github_trending.py --language zh
+
+# 組合：本週 + 中文 + 同時輸出 JSON
+python3 github_trending.py --since weekly --language zh --also-json
+
+# 只取前 5 名
+python3 github_trending.py --limit 5
+
+# 指定輸出檔（蓋掉自動時間戳）
+python3 github_trending.py --out /tmp/today.md
+```
+
+## 輸出位置
+
+預設寫入 `<腳本所在目錄>/output/github_trending_<since>[_<lang>]_<YYYYMMDD_HHMMSS>.md`
+
+例如：
+```
+output/github_trending_daily_20260727_201243.md
+output/github_trending_weekly_zh_20260727_201251.md
+output/github_trending_weekly_zh_20260727_201251.json   # --also-json
+```
+
+## 表格欄位
+
+| Rank | Repository | Description | Language | ⭐ Period | Total Stars | Forks |
+|------:|------------|-------------|----------|----------:|------------:|------:|
+
+- `Rank` — 1-based 排名
+- `Repository` — `owner/repo` 含連結
+- `Description` — 專案說明（自動 escape `\|` 與換行）
+- `Language` — 主程式語言（GitHub 自行判定）
+- `⭐ Period` — 該區間新星數（today / this week / this month）
+- `Total Stars` — 此時此刻總星星數
+- `Forks` — fork 總數
+
+## 已知限制
+
+- GitHub 改版可能讓 selector 失效（會在 fail-fast[error] 訊息提示）— 重新跑一次 curl 重新驗 selector 最快
+- 「⭐ Period」若 GitHub 改成非英文文字會失效（會在 `--since daily` 以外、GitHub 顯示 "this week" 改文案時炸）— regex 已容錯 `today|this\s+week|this\s+month`
+- 沒有 schedule 機制，自己用 `cron` / `hermes cron` / `Task Scheduler` 包
+

+# GitHub Trending Scraper
+
+自動化抓取 GitHub Trending 並輸出為 Markdown 表格的小工具。純 stdlib，無第三方依賴。
+
+## 安裝
+
+無 — 只需要 Python 3.10+（使用 `from __future__ import annotations` 確保 type hint 不會 runtime 崩潰）。
+
+```bash
+chmod +x github_trending.py
+```
+
+## 使用方式
+
+```bash
+# 預設：daily trending, 所有語言
+python3 github_trending.py
+
+# 週熱榜 + 只取前 5 名 + 寫入檔案
+python3 github_trending.py --since weekly --top 5 -o trending_weekly.md
+
+# 指定語言 + 月熱榜
+python3 github_trending.py --since monthly --language python
+```
+
+完整 CLI：
+
+```
+--since {daily,monthly,weekly}    預設 daily
+--language LANGUAGE               例: python / go / rust / typescript
+--top N                           只顯示前 N 名
+--output / -o PATH                同時寫入 Markdown 檔案
+```
+
+## 為什麼是 stdlib 而非 requests + bs4？
+
+GitHub Trending 是公開頁面、不需任何 token。`urllib.request` + 正規表示式直接吃 HTML，
+省去 `requests`、`beautifulsoup4`、`lxml` 等相依。部署在零相依環境也能跑。
+
+## 解析策略
+
+GitHub Trending 用 `<article class="Box-row">` 包每個 repo，我用 regex 抓：
+
+| 欄位 | 來源 |
+|------|------|
+| Repo URL | `<h2>` 內 `<a href="/owner/name">` |
+| Description | `<p class="col-9 ...">` 內文字 |
+| Language | `itemprop="programmingLanguage">` |
+| Total ⭐ | `<a href="/.../stargazers">` 後的第一個逗號數字 |
+| Stars today/week/month | `123 stars today/week/month` pattern |
+| Forks | `<a href="/.../forks">` 後的第一個逗號數字 |
+
+## 輸出 Markdown 格式
+
+```
+# GitHub Trending Repositories
+_Scraped at 2026-07-28 01:42:06 · period = **daily** · language filter = **all languages**_
+| #  | Repository | Description | Language | Total ⭐ | Stars (period) | Forks |
+| 1  | [owner/name](https://github.com/owner/name) | ... | Swift | 31,952 | 2,344 today | 5,017 |
+```
+
+數字欄右對齊、Repo 名帶超連結、Description 內的 `|` 已 escape。
+
+## 已知限制
+
+- GitHub 公開頁 markup 變動時，selector 需對應更新（這是動態 HTML scrape 的本質代價）
+- 不抓 contributors / built-by avatars（trending 頁每個 repo 區塊只列 primary star/fork）
+- 同時 emit `#` 編號與真實 GitHub trending 排名（這兩者目前永遠一致）
+

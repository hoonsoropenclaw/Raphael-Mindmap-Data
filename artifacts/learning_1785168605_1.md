+# Signal Board — 實作思路
+
+## 元件定位
+`SignalBoard` 是一個可獨立嵌入的 React operations dashboard，核心目標是讓使用者快速掃描高訊號事件，再展開單筆內容取得上下文。
+
+## 狀態分層
+- 資料狀態：`signals`，保存目前清單與批次封存後的結果。
+- 查詢狀態：`query`、`status`、`priority`、`sort`，由 `useMemo` 組合成衍生清單，避免重複保存。
+- 互動狀態：`selectedId` 控制詳細面板、`selected` 控制批次選取。
+- 非同步狀態：`loading` 與 `error` 明確呈現 loading/error/empty 三種 UI 狀態。
+
+## 互動設計
+1. 搜尋、狀態、優先級與排序可以組合使用。
+2. 點擊清單列主體展開詳細面板，不會干擾 checkbox 的批次選取。
+3. `Select all` 只作用於當前篩選結果，避免誤選隱藏項目。
+4. `Archive` 會更新資料狀態並清空選取，避免留下已不存在的 ID。
+5. `Test stream error` 提供可重現錯誤狀態的 QA 入口。
+
+## 視覺與可用性

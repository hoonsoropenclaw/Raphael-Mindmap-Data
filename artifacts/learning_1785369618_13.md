+## 6. 「動態網頁」的關鍵誠實點
+
+訊息說「**動態**網頁數據抓取」，但 BeautifulSoup 本身**只能解析 HTML**。
+
+如果目標網頁是 SPA（React/Vue/Next.js 等 client-side render），純 BeautifulSoup 會抓到空白殼。三種延伸路徑：
+
+1. **後端有 SSR / 靜態 HTML** → 現有 `scraper.py` 直接可用
+2. **後端有隱式 JSON API**（XHR endpoint）→ 用 `urllib` 打那個 API + `json.loads`，不用 BeautifulSoup
+3. **真的 client-side render** → 必須接 Selenium / Playwright / `camofox` skill，本腳本需改寫 fetcher
+
+`fetch()` 是唯一需要改動的函式：換成 Playwright 就變成 dynamic scraper，其他 parser / storage 都不用動。

+Endpoints:
+- `GET /health`
+- `GET /events?start=<ISO>&end=<ISO>` — list events
+- `POST /events` — create event with popup reminders
+- `PATCH /events/{event_id}` — update event/reminders
+- `DELETE /events/{event_id}` — delete event
+- `GET /reminders?within_minutes=60` — upcoming reminders
+- `POST /sync?days=30` — fetch/synchronize upcoming events
+- `/docs` — OpenAPI UI
+
+## Google credentials
+
+The service reads:
+- `GOOGLE_TOKEN_PATH` (default: `~/.hermes/google_token.json`)
+- `GOOGLE_CLIENT_SECRET_PATH` (default: `~/.hermes/google_client_secret.json`)
+- `GOOGLE_CALENDAR_ID` (default: `primary`)
+
+A refresh-capable token is required for live Google API calls. The current
+machine has the client secret but does not have `~/.hermes/google_token.json`.

+# PRD：Playwright 網頁爬蟲視覺回歸測試
+
+## 使用者旅程
+
+身為網站維護者，我想從起始 URL 自動發現同源頁面、在固定 viewport 擷取穩定截圖並與已核准 baseline 比對，以便在上線前發現非預期的視覺退化。
+
+## Must
+
+1. 提供 `baseline`、`compare`、`update` CLI 模式。
+2. 同源 BFS 爬取，限制頁數、深度、延遲、include/exclude。
+3. 桌機與手機 viewport，檔名穩定且可追溯 URL。
+4. 停動畫、隱藏 caret、等待字型、可遮罩／移除動態元素。
+5. Pixelmatch 像素比對，支援 threshold 與 maxDiffRatio。
+6. 尺寸不一致、baseline 缺失、導航失敗都要可診斷。
+7. 產出 baseline/current/diff PNG、metadata JSON、summary JSON、自包含 HTML 報告。
+8. 回歸時回傳非零 exit code，供 CI gate 使用。
+9. 具備單元、整合、E2E 測試與本機可重跑 demo。
+
+## Non-goals
+
+- 不繞過 CAPTCHA、Cloudflare 或網站存取控制。
+- 不跨來源無限制爬取。
+- 不自動接受所有畫面變更；更新 baseline 必須明確使用 `update`。
+
+## 驗收標準
+
+- 同一 fixture baseline → compare：exit 0、全部通過。
+- 視覺變更 fixture → compare：exit 2、至少一項 failed、產出 diff。
+- HTML 報告可獨立開啟，圖片以 data URI 內嵌。
+- 測試覆蓋率至少 80%，無 skipped tests。

+同源頁面爬取 + deterministic screenshot + Pixelmatch + 自包含 HTML 報告。可在本機或 CI 對網站執行 baseline / compare / update。

+## 已實作能力
+
+- BFS 同源爬取，支援 `maxPages`、`maxDepth`、include/exclude、request delay。

+- 可用 `maskSelectors` 遮罩動態內容；`removeSelectors` 移除不需比對元素。

+- JSON summary + 自包含 HTML 報告；回歸時 CLI exit `2`。

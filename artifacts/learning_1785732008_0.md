+# FlowPilot
+
+可執行的 Playwright 跨瀏覽器測試框架示範，前端以工作流程圖管理測試節點。
+
+## 模組
+- `web_output.html`: 單檔可用的工作流程管理 UI；以 React 建立互動，並載入 React Flow/XYFlow 模組。
+- `playwright.config.js`: Chromium、Firefox、WebKit、Mobile Chromium 測試矩陣。
+- `tests/workflow.spec.js`: 畫布載入、矩陣執行、節點編輯、響應式 overflow 驗證。
+
+## 執行
+```bash
+npm install
+npx playwright install chromium firefox webkit
+npm run serve
+# 另一個終端
+npm test
+```
+
+可用 `BASE_URL=https://your-host npm test` 指向遠端環境。失敗時保留 trace 與 screenshot，HTML 報告輸出至 `playwright-report/`。

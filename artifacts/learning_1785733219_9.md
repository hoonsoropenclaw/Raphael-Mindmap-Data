+# 技術規格
+
+## 架構
+`CLI -> CrawlPipeline -> HttpFetcher -> BeautifulSoupParser -> quality gate -> PlaywrightRenderer -> BeautifulSoupParser -> JSON`
+
+## 資料契約
+Schema：
+- `name`: schema 名稱
+- `item_selector`: 每筆資料的 CSS selector
+- `wait_selector`: 動態頁完成指標
+- `min_items`: auto 模式品質門檻
+- `fields`: `{欄位: {selector, attr?, required?, many?}}`
+
+每 URL 結果：
+- `url`, `final_url`, `engine`, `elapsed_ms`, `attempts`
+- `items`, `item_count`, `warnings`, `error`
+- `diagnostics`: static/dynamic HTML bytes、被阻擋請求數
+
+## 決策
+1. `auto`：HTTP 解析達 `min_items` 且必填欄位完整即結束；否則 fallback Playwright。
+2. `static`：只走 HTTP；品質不足仍回結果與 warning。
+3. `dynamic`：直接 Playwright，適合已知 SPA。
+4. Playwright browser 在 pipeline 生命週期內只 launch 一次；context 每 URL 隔離。
+5. 預設阻擋 image/media/font，保留 document/script/xhr/fetch/css。
+6. 預設阻擋 private/loopback 目標；本地測試須明示 `--allow-private`。
+
+## 失敗模型
+- URL 不安全：該 URL 回 error。
+- HTTP timeout/4xx/5xx：auto 模式轉 Playwright；static 模式回 error。
+- selector timeout：仍取得 page.content 再解析，若不足則回 warning/error。
+- 單一 URL 失敗不取消其他 URL。
+
+## 自動驗證
+- `python3 -m compileall hybrid_scraper tests`
+- `pytest -q`
+- 啟動本地測試站後執行 CLI auto mode。
+- 檢查 JSON：靜態 3 筆、動態 4 筆、engine 分別為 http/playwright。

+_URL_ATTRS = {"href", "src", "action", "poster"}
+

+def _clean_text(value: str) -> str:
+    return " ".join(value.split())
+
+
+def _extract_one(node: Tag, rule: FieldRule, base_url: str) -> Any:
+    matches = node.select(rule.selector) if rule.selector else [node]
+    if not matches:
+        return [] if rule.many else None
+
+    def convert(match: Tag) -> str | None:
+        if rule.attr:
+            raw = match.get(rule.attr)
+            if raw is None:
+                return None
+            value = str(raw).strip()
+            return urljoin(base_url, value) if rule.attr in _URL_ATTRS else value
+        return _clean_text(match.get_text(" ", strip=True))
+
+    if rule.many:
+        return [value for match in matches if (value := convert(match)) is not None]
+    return convert(matches[0])
+

+def parse_items(html: str, schema: ExtractionSchema, base_url: str) -> tuple[list[dict[str, Any]], list[str]]:
+    """Parse rendered or static HTML with one deterministic extraction path."""
+    soup = BeautifulSoup(html, "html.parser")
+    items: list[dict[str, Any]] = []
+    warnings: list[str] = []
+
+    for index, node in enumerate(soup.select(schema.item_selector)):
+        record: dict[str, Any] = {}
+        missing: list[str] = []

+                missing.append(name)
+        if missing:
+            warnings.append(f"item {index} dropped; required fields missing: {', '.join(missing)}")
+            continue
+        items.append(record)

+# Hybrid BeautifulSoup + Playwright Scraper
+
+協同爬蟲採用「先輕後重」策略：
+
+1. `httpx` 抓取 HTML。
+2. `BeautifulSoup` 解析並執行品質閘門。
+3. 靜態 HTML 足夠時直接回傳，不啟動瀏覽器。
+4. 資料不足時使用共用 Chromium 以 Playwright 執行 JavaScript。
+5. 將 rendered HTML 再交給同一個 BeautifulSoup parser，避免兩套欄位邏輯漂移。
+
+## 目錄
+
+- `hybrid_scraper/models.py`：schema、設定、結果資料契約

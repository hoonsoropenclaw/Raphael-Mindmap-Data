+# EdgeCache Gateway
+
+可直接執行的高性能 ASGI API gateway 快取實作。核心不是單純 `dict + TTL`，而是同時處理高流量 gateway 最常見的四個失敗模式：cache stampede、過期資料延遲、記憶體無界增長，以及私有回應誤入共享快取。
+
+## 功能
+
+- GET/HEAD 共享 representation cache
+- TTL fresh cache
+- stale-while-revalidate（過期後立即回舊值、背景更新）
+- stale-if-error（upstream 暫時失敗時回可接受舊值）
+- per-key single-flight（冷啟動併發請求只打一個 upstream call）
+- LRU + entry/bytes/object 三重容量上限
+- query parameter 正規化（`?b=2&a=1` 與 `?a=1&b=2` 共用 key）
+- `Authorization` / `Cookie` / `no-store` 安全 bypass
+- upstream `private` / `no-store` / `Set-Cookie` 回應不儲存
+- 寫入方法成功後做 path-prefix invalidation
+- 管理 API：stats / purge
+- Prometheus text metrics
+- health/live + health/ready
+- 可信代理 header 預設關閉，避免偽造 `X-Forwarded-*`
+
+## 快速啟動
+
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785309611_2
+uv sync --extra dev
+
+export GATEWAY_UPSTREAM_URL="http://127.0.0.1:9000"

+```
+
+Gateway 預設監聽 `0.0.0.0:8080`。所有非 `__*` 路徑會原樣代理至 upstream。

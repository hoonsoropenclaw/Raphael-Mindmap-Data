Architecture

1HTTP Layerfetch with timeout + AbortController
2Error ClassifierCategorize into network / timeout / 4xx / 5xx / parse / unknown
3Rule EnginePure-function dispatcher → action: retry / fallback / abort / succeed
4Backoff CalculatorExponential + jitter + adaptive escalation on consecutive failures

6Metrics SinkCounts, latencies, decision trace — observable end-to-end

是什麼讓這套組件庫效能優先？
IntersectionObserver 驅動的懶模糊、content-visibility:auto 跳過屏外渲染、prefers-reduced-motion 自動停用動畫。
如何整合到既有 Tailwind 專案？
把 CSS 區塊貼進 styles.css、主題 token 併入 tailwind.config.js、組件 class 名直接沿用。
瀏覽器支援？
Chrome / Edge / Safari / Firefox 皆支援 backdrop-filter。舊瀏覽器自動降級為不透明深色玻璃，仍可使用。

5 條效能紀律 (Atelier Glass)

  1. 1 backdrop-filter 開瀏覽器原生合成層，但對 GPU 仍重 — 螢幕外的玻璃元素統一 停用，靠 IntersectionObserver 進入視口才開啟。
  2. 2 每個屏外大區塊套 content-visibility: auto，瀏覽器自動跳過 layout / paint，只在進入視口時按需算尺寸。
  3. 3 will-change 只給正在動的元素；靜止玻璃面板一律 auto，避免合成層暴增。
  4. 4 FPS 低於 30 持續 2 秒，自動把頁面切到 perf-low 模式 — 全站停模糊、停動畫，使用者立刻不再卡。
  5. 5 prefers-reduced-motion、@supports not backdrop-filter、.contrast-high 三套降級完全獨立運作，疊在一起也安全。

+# Telegram Weather Bot
+
+A zero-runtime-dependency Telegram bot: receive a city name, geocode it with Open-Meteo, then return current weather and today's forecast.
+
+## Features
+
+- Python 3.12 standard library only at runtime (`urllib`, `json`, `signal`, `dataclass`)
+- Telegram long polling; no public URL or webhook required
+- Open-Meteo geocoding + forecast API; no weather API key required
+- `/start`, `/help`, `/weather 台北`, or plain text `台北`
+- Optional Telegram numeric-user allowlist
+- Per-user cooldown rate limit
+- Sanitized network errors, bounded JSON responses, graceful SIGINT/SIGTERM shutdown
+- Absolute update cursor (`update_id + 1`) and final zero-timeout acknowledgement
+
+## Setup
+
+```bash
+cp .env.example .env
+chmod 600 .env
+# edit .env and set TELEGRAM_BOT_TOKEN
+./run.sh
+```
+
+The bot token is a secret. Do not commit `.env` or paste the token into chat. To restrict access, set `TELEGRAM_ALLOWED_USERS=123456789,987654321`.
+
+## Test and quality checks
+
+```bash
+python3 -m unittest discover -s tests -v
+python3 -m py_compile weather.py telegram_bot.py
+ruff check weather.py telegram_bot.py tests
+mypy weather.py telegram_bot.py
+```
+
+`ruff` and `mypy` are development-only tools. Runtime execution does not require installing packages.
+
+## CLI weather check
+
+```bash
+python3 weather.py 台北
+```
+
+This calls the real Open-Meteo HTTPS endpoint. The Telegram bot itself is intentionally not started by tests.

+@dataclass
+class RateLimiter:
+    cooldown_seconds: float = 3.0
+    clock: Callable[[], float] = time.monotonic
+    _last_seen: dict[int, float] = field(default_factory=dict)
+
+    def allow(self, user_id: int) -> bool:
+        now = self.clock()
+        previous = self._last_seen.get(user_id)
+        if previous is not None and now - previous < self.cooldown_seconds:
+            return False
+        self._last_seen[user_id] = now
+        return True
+

+    def __init__(self, token: str, timeout: float = 40.0) -> None:
+        if not token.strip():
+            raise ValueError("Telegram token 不可為空")
+        self.base_url = f"{API_ROOT}/bot{token.strip()}"
+        self.timeout = timeout
+
+    def call(self, method: str, params: dict[str, object] | None = None) -> dict:
+        data = urllib.parse.urlencode(params or {}).encode("utf-8")
+        request = urllib.request.Request(f"{self.base_url}/{method}", data=data)

+            with urllib.request.urlopen(request, timeout=self.timeout) as response:
+                payload = json.loads(response.read().decode("utf-8"))

+# 實作思路與驗證紀錄
+
+## 1. 規格判讀
+
+任務要求是「Telegram 接收文字 → 呼叫天氣 API → 回傳天氣」。輸入訊息中的 Senior Architect 回饋與交付路徑均為空白模板；實際盤點後找到 `/home/hoonsoropenclaw/.hermes/architect_feedback.md`，但它屬於另一個 Todo API 專案。只吸收可泛化原則：最小依賴、權限收斂、可重現測試，不套用不相關的 SQLAlchemy 設計。
+
+## 2. 架構決策
+
+### Python 標準函式庫優先
+
+使用 `urllib`、`json`、`signal`、`dataclasses`，不安裝 `requests` 或 `python-telegram-bot`。本需求只有 Telegram `getUpdates`、`sendMessage` 與 Open-Meteo 兩個 endpoint，框架會增加供應鏈與部署成本，沒有對等收益。
+
+### 模組分離
+
+- `weather.py`：只負責地名解析、天氣 API、資料模型與中文格式化。
+- `telegram_bot.py`：只負責 Telegram API、long polling、訊息路由、allowlist、rate limit 與 signal shutdown。
+- `test_bot.py`：以 mock 隔離網路，確保 CI 或離線環境可重現。
+
+這使天氣模組可被 CLI、cron 或其他 bot 重用，也避免 Telegram token 進入天氣層。
+
+### API 選擇
+
+Open-Meteo 提供免 API key 的 geocoding 與 current weather API，降低 secrets 數量。Telegram token 僅從 `TELEGRAM_BOT_TOKEN` 環境變數讀取，`.env` 已加入 `.gitignore`。
+
+### 執行模式
+
+使用 long polling，適合目前 Linux/headless、沒有公開 HTTPS endpoint 的環境。offset 採 `update_id + 1` 絕對值，避免重複處理。
+
+## 3. 防護設計
+
+1. `TELEGRAM_ALLOWED_USERS`：選填 user ID allowlist；設定後拒絕其他人。
+2. `RateLimiter`：每位使用者預設 3 秒 cooldown，防止濫用免費 API。
+3. 輸入限制：去除多餘空白、拒絕空城市與超過 80 字元的地名。
+4. 錯誤邊界：外部服務錯誤轉成不洩漏 stack trace 的中文訊息。
+5. token fail-fast：未設定 token 時，啟動器立即以非零狀態退出。
+6. graceful shutdown：SIGINT/SIGTERM 設 flag，long-polling 返回後安全結束。

+# Todo API
+
+A simple Todo REST API built with **FastAPI + SQLite**, with per-IP rate limiting
+via **slowapi** and a **pytest** unit-test suite.
+
+## Layout
+
+    app/
+      main.py        # FastAPI factory + lifespan + rate-limit exception handler
+      database.py    # SQLAlchemy engine, session, Base, get_db dependency
+      models.py      # Todo ORM model
+      schemas.py     # Pydantic request/response schemas
+      crud.py        # DB operations
+      routes.py      # /todos endpoints, each rate-limited
+      rate_limit.py  # slowapi Limiter (100/minute per client IP by default)
+    tests/
+      conftest.py        # in-memory SQLite + TestClient fixtures
+      test_todos.py      # CRUD happy path + validation + 404s
+      test_rate_limit.py # limiter allow / block / per-client isolation
+    requirements.txt
+    pytest.ini
+
+## Endpoints
+
+| Method | Path              | Description                  | Rate limit   |
+|--------|-------------------|------------------------------|--------------|
+| GET    | /health           | Health probe                 | 100/minute   |
+| GET    | /todos/           | List todos (skip, limit)     | 100/minute   |
+| POST   | /todos/           | Create todo                  | 100/minute   |
+| GET    | /todos/{id}       | Get one todo                 | 100/minute   |
+| PATCH  | /todos/{id}       | Partial update               | 100/minute   |
+| DELETE | /todos/{id}       | Delete todo (204)            | 100/minute   |
+
+### Sample payloads
+
+    POST /todos/
+    { "title": "Buy milk", "description": "2L", "completed": false }
+
+    PATCH /todos/1
+    { "completed": true }
+
+## Run
+
+    python3 -m venv .venv
+    source .venv/bin/activate
+    pip install -r requirements.txt
+    uvicorn app.main:app --reload
+
+Then open http://127.0.0.1:8000/docs.
+
+## Test
+
+    pytest
+
+## Design notes
+
+- **SQLite via SQLAlchemy 2.x** with `check_same_thread=False` so the same connection
+  can be used across the FastAPI thread pool. `StaticPool` is set so the in-memory
+  test database behaves as a single shared connection.
+- **slowapi** is wired into FastAPI by attaching the limiter to `app.state.limiter`
+  and registering `_rate_limit_exceeded_handler` so over-limit requests return
+  `429` automatically. Each route uses the decorator form `@limiter.limit(...)`,
+  which requires the endpoint to accept `request: Request`.
+- **Tests use a fresh in-memory SQLite per test** (`tests/conftest.py`) and
+  override `get_db` via `app.dependency_overrides`, so no state ever leaks
+  between tests.
+- **Pydantic v2** with `from_attributes=True` on the response schema so it can

+## Key design choices
+
+### 1. `create_app()` factory pattern, not a module-level `app`
+Using a factory lets the test suite build multiple isolated app instances.
+Each test gets its own app + an in-memory SQLite session via
+`app.dependency_overrides[get_db] = ...`. No state leaks between tests.
+
+### 2. SQLite `check_same_thread=False` + `StaticPool`
+FastAPI runs sync route handlers in a thread pool, but SQLite defaults to
+refusing cross-thread connections. `check_same_thread=False` lifts that
+restriction, and `StaticPool` keeps a single shared connection so the
+in-memory test DB behaves consistently across threads.
+
+### 3. slowapi integration — three pieces that all have to be present
+
+    app.state.limiter = limiter                          # required
+    app.add_exception_handler(RateLimitExceeded, ...)   # 429 path
+    @limiter.limit("100/minute") on each route          # per-route policy
+    def route(request: Request, ...): ...                # Request MUST be a parameter
+
+The `request: Request` parameter is non-negotiable — slowapi's decorator
+introspects the signature to call `key_func(request)`. Missing it → silent
+mis-counting or no limiting at all.
+
+### 4. `Base.metadata.create_all` inside a `lifespan` context manager
+Replaces the deprecated `@app.on_event("startup")` pattern. Runs once when
+`TestClient(app)` enters its context, so even in tests the schema exists
+before any route is hit.
+
+### 5. Rate limit choice — `100/minute` per client IP, per route
+- Per client IP via `get_remote_address(request)` — the standard slowapi default.
+- Per *route* (not global): each endpoint gets its own bucket. This matches
+  the test `test_rate_limit_is_per_route`, which proves exhausting `/ping`
+  doesn't affect `/echo`.

+  that normal browser traffic is unaffected, low enough that a runaway
+  script gets capped fast.

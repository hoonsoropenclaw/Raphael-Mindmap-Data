+# Telegram Weather Bot
+
+一個使用 Python 標準庫的 Telegram 天氣機器人：接收文字城市名稱，透過 Open-Meteo 查詢地理位置與天氣，再回傳中文摘要。
+
+## 功能
+
+- 直接輸入 `台北`、`Tokyo`、`New York`
+- 支援 `/weather 台北`、`/w Tokyo`
+- `/start`、`/help`、`/ping`
+- Open-Meteo 免費 API，不需要天氣 API key
+- Telegram long-polling，不需要公開網址或 HTTPS webhook
+- `TELEGRAM_ALLOWED_USERS` 白名單
+- 每位使用者每 60 秒最多 5 次查詢
+- SIGINT/SIGTERM graceful shutdown
+- 僅使用 Python 3.10+ 標準庫，無第三方依賴
+
+## 啟動
+
+1. 建立 Bot：在 Telegram 找 `@BotFather`，使用 `/newbot` 取得 token。
+2. 設定環境變數：
+
+```bash
+export TELEGRAM_BOT_TOKEN='你的 BotFather token'
+export TELEGRAM_ALLOWED_USERS='你的 Telegram user id'
+```
+
+`TELEGRAM_ALLOWED_USERS` 可填逗號分隔多個 ID；留空代表不啟用白名單，適合本機測試，不建議公開使用。
+
+3. 先做設定檢查：
+
+```bash
+./run.sh --dry-run
+```
+
+4. 啟動：
+
+```bash
+./run.sh
+```
+
+或直接：
+
+```bash
+python3 weather_bot.py
+```
+
+## 測試
+
+```bash
+python3 -m unittest -v test_telegram_weather_bot.py
+python3 -m py_compile weather_bot.py test_telegram_weather_bot.py
+```
+
+測試完全離線，不會把 token 或訊息送到 Telegram/Open-Meteo。
+
+## 架構
+
+```text
+Telegram long-polling
+        |
+        v
+  TelegramBot.handle_update
+        |
+        +--> parse_city + allowlist + rate limit
+        |
+        +--> Open-Meteo geocoding API
+        |
+        +--> Open-Meteo forecast API
+        |

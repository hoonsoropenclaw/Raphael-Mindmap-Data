+# Telegram Weather Bot
+
+一個不依賴第三方套件的 Telegram 天氣機器人：接收城市文字，呼叫 wttr.in，回傳目前天氣與今日高低溫。
+
+## 功能
+
+- Python standard library only：`urllib`、`json`、`signal`、`dataclass`
+- Telegram `getUpdates` long-polling，適合沒有公開 HTTPS 網址的 headless 主機
+- `/weather Tokyo` 或直接輸入 `Tokyo`
+- `TELEGRAM_ALLOWED_USERS` 使用者 ID 白名單
+- 每位使用者 3 秒 cooldown，避免 API 洪水
+- API timeout、HTTP/network/JSON 錯誤處理
+- SIGINT/SIGTERM graceful shutdown
+- 不把 token 或第三方錯誤細節寫入回覆
+
+## 設定
+
+1. 在 BotFather 建立 bot，取得 token。
+2. 建立僅本機使用的環境變數（不要把 token 寫進程式碼或 Git）：
+
+```bash
+export TELEGRAM_BOT_TOKEN='<你的 Telegram bot token>'
+export TELEGRAM_ALLOWED_USERS='123456789,987654321'
+```
+
+`TELEGRAM_ALLOWED_USERS` 可留空代表允許所有使用者；正式使用建議填入 Telegram numeric user ID。
+
+## 執行
+
+```bash
+chmod +x run.sh
+./run.sh
+```
+
+直接測試天氣模組：
+
+```bash
+python3 wttr_weather.py Taipei
+```

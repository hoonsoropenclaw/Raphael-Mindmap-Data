什麼是 Glassmorphism？
一種透過半透明背景 + 高斯模糊組合的 UI 風格，模擬玻璃質感，在 iOS / macOS / Windows 11 Fluent Design 都很常見。
為什麼組件庫選 Tailwind？
Tailwind utility-first 讓每個組件都能在不複製 CSS 的前提下客製化變體，避免類似 Bootstrap 的類別膨脹問題。
效能優化了哪些面向？
  • 圖片 IntersectionObserver lazy load
  • content-visibility: auto 對非可見區段跳過渲染
  • GPU 合成層 .gpu → 觸發 transform/opacity 動畫
  • 預連線 (preconnect) 加速字型 / icon CDN
  • prefers-reduced-motion 自動停用裝飾動畫

效能優化策略

本頁採用的 6 大優化策略，逐項可驗證。

content-visibility

非可見區段套 scroll-fade，瀏覽器自動跳過其 layout/paint。

↓ 渲染 ~40%

Lazy Backgrounds

.lazy-bg 透過 IntersectionObserver 進 viewport 才載圖。

↓ LCP 1.2s

GPU 合成

所有 hover/動畫元素加 .gpu，建立 compositor layer。

↓ jank

preconnect

字型 / icon / Tailwind CDN 都已預連線，建立 TLS 提早。

↓ TTFB

prefers-reduced-motion

使用者偏好「減少動畫」時自動停用所有裝飾動畫與 aurora。

A11y ✓

Backdrop-Filter Fallback

用 @supports not 在不支援瀏覽器走不透明玻璃色。

↑ 覆蓋率

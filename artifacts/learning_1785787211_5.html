📖快速指引

5 步驟從零開始
  1. 編輯左側「監控設定」與「OCR 引擎」參數
  2. 在本機執行 python3 daemon.py --init-config ~/.config/ocr-daemon/config.yaml 初始化設定檔
  3. 執行 python3 daemon.py --check 做健康檢查
  4. 執行 python3 daemon.py 啟動 daemon (前景) 或 python3 install_service.py install 註冊為系統服務
  5. 把檔案拖入監控目錄,daemon 會自動 OCR 並把結果寫到 output_dir

+# Flutter Audio Live
+
+跨平台即時音訊處理 Flutter app（N100 / iOS / Android / Web / Desktop）。
+
+## 功能
+
+| 功能 | 模組 |
+|------|------|
+| 即時錄音（PCM/WAV/AAC） | `record` |
+| 即時音量/聲壓表（dBFS） | `flutter_sound` + 自寫 `AudioMeter` |
+| 即時波形 + FFT 頻譜圖 | 自寫 `FftAnalyzer`（Cooley-Tukey radix-2） |
+| 錄音回放 | `flutter_sound` |
+| 語音轉文字（中/英/自動） | `speech_to_text` |
+| 權限管理 | `permission_handler` |
+| 狀態管理 | `provider` + `ChangeNotifier` |
+

+"""FFT oracle — 驗證 Dart 端 FftAnalyzer 演算法數學正確性（numpy 對照）"""
+import numpy as np
+import math
+
+
+def hann_window(n):
+    return np.array([0.5 * (1 - math.cos(2 * math.pi * i / (n - 1))) for i in range(n)])
+
+
+def fft_inplace(buf):
+    """Cooley-Tukey radix-2, 對應 Dart FftAnalyzer._fftInPlace"""
+    n = len(buf) // 2
+    j = 0
+    for i in range(1, n):
+        bit = n >> 1
+        while j >= bit:
+            j -= bit
+            bit >>= 1
+        j += bit
+        if i < j:
+            buf[2 * i], buf[2 * j] = buf[2 * j], buf[2 * i]
+            buf[2 * i + 1], buf[2 * j + 1] = buf[2 * j + 1], buf[2 * i + 1]
+    size = 2
+    while size <= n:
+        half = size >> 1
+        for i in range(0, n, size):
+            for k in range(half):
+                angle = -2 * math.pi * k / size
+                cos_v = math.cos(angle)
+                sin_v = math.sin(angle)
+                ia = 2 * (i + k)
+                ib = 2 * (i + k + half)

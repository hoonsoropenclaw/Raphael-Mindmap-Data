+# Linux Ops Monitor
+
+`monitor.py` 是一個 Linux 單機維運監控腳本：檢查資源壓力與近期系統日誌，在超過閾值或發生 kernel/OOM 類嚴重事件時產生警告。
+
+設計目標是「可直接放進 cron 或 systemd、零第三方 Python 依賴、可從重啟中恢復、不要告警風暴」。腳本只讀取主機資料，不會自動重啟服務、刪除檔案或修改系統設定。
+
+## 主要功能
+
+- CPU 使用率：從 `/proc/stat` 取兩次 counter delta，避免把瞬間快照當成準確使用率。
+- Load：從 `/proc/loadavg` 讀取，再除以可用 logical CPU 數，讓閾值可跨不同 core 數量主機使用。
+- 記憶體：以 `MemAvailable` 計算可回收後的實際壓力，不把 page cache 當成不可用記憶體。
+- Swap：計算 Swap 使用率；未啟用 swap 時回報 `INFO`。
+- 磁碟與 inode：使用 `statvfs`，不解析受 locale 影響的 `df` 文字。
+- journal：若可用，執行受限的 `journalctl --priority err..emerg` 查詢。
+- 文字日誌 fallback：對設定的檔案做 inode/byte-offset 增量掃描。
+- 日誌 rotation：偵測 inode 變化、截斷、同大小 copytruncate；保留未完成的 partial line，避免重複計數。
+- kernel/OOM：獨立產生 `ALERT` finding，不會被一般 error count 閾值掩蓋。
+- `/var/log` 大小：symlink-safe、bounded traversal。
+- systemd failed units：若 `systemctl` 可用，檢查 failed units。

Decision Log

      
Why we ended up with this 3-engine split.

      
    
        
  • Two engines, not one. Phaser ships in browsers; Godot ships everywhere else. The only honest "integration" is a shared schema + a thin transport layer.
    • 
        
  • Schema over RPC. Both sides speak shared/event_schema.json. Transports (jsbridge, http, stdio) can change without touching game logic.
    • 
        
  • Godot owns the truth. Physics, AI, hit-detection — all deterministic in GDScript. Phaser is a renderer on top.
    • 
        
  • Standalone fallback. Phaser runs its own local sim when the Godot backend is offline. Same event shape, same UI.

+class TokenBucket:

+        self.window_seconds = window_seconds

+        self._locks: dict[str, asyncio.Lock] = {}
+        self._locks_guard = asyncio.Lock()

+    def refill_rate(self) -> float:
+        return self.capacity / self.window_seconds

+        async with self._locks_guard:

+## 2. Architecture decisions
+
+### 2.1 Sync SQLAlchemy rather than async SQLAlchemy
+
+This CRUD workload performs short local SQLite calls and no concurrent external I/O inside a request. I used:
+
+- sync SQLAlchemy `sessionmaker`
+- FastAPI `def` routes
+- `db.execute()`/ORM operations inside FastAPI's worker thread pool
+
+This avoids the known `async def` + sync-session event-loop blocking failure and the additional async session identity-map/expiry discipline, without sacrificing meaningful throughput for this scope.
+
+### 2.2 Layer separation
+
+- `todo_api/schemas.py`: request/response DTO validation
+- `todo_api/database.py`: ORM model, engine/session lifecycle, repository operations, SQLite hardening
+- `todo_api/rate_limit.py`: standalone token-bucket algorithm
+- `todo_api/app.py`: HTTP composition, dependencies, status codes, lifespan
+- `tests/test_api.py`: behavior and integration tests
+
+The API returns Pydantic response models rather than exposing unbounded ORM internals.
+
+### 2.3 Rate limit design
+
+The limiter is a token bucket keyed by client identity:
+
+- one `asyncio.Lock` per bucket/key, so same-key updates are atomic
+- a short guard lock only protects lock creation
+- monotonic clock, avoiding wall-clock jumps
+- injectable clock for deterministic refill tests
+- `429 Too Many Requests` plus `Retry-After`
+- proxy headers are ignored by default; `X-Forwarded-For` is honored only when `TRUST_PROXY_HEADERS=true`
+
+Known boundary: state is process-local. Multiple Uvicorn workers or multiple instances need a shared Redis-backed limiter.
+
+### 2.4 SQLite design and permissions
+
+- File-backed SQLite enables WAL and `synchronous=NORMAL`.
+- Startup applies restrictive umask `0077`.
+- Data directory is re-asserted as `0700`.
+- DB, WAL, and SHM files are re-asserted as `0600` after startup and HTTP requests.
+- Tests use `StaticPool` for `sqlite://`, ensuring all test sessions share one in-memory connection.
+- Sessions are closed in dependency `finally` blocks.
+- Mutations commit and refresh before returning.
+
+### 2.5 Input and API semantics
+
+- Title: trimmed, 1–255 characters
+- Description: at most 2,000 characters
+- Unknown request fields: rejected
+- Empty update objects: rejected
+- Pagination: `limit` 1–100 and non-negative `offset`
+- Create: `201`
+- Delete: `204` with an empty body
+- Missing entity: `404 {"detail":"Todo not found"}`
+- Validation: FastAPI/Pydantic structured `422`
+
+No authentication was added because it was not requested. This means the artifact is suitable as a simple local/demo API, not as a public multi-tenant service holding private data.

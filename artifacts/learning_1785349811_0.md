+### 3.2 動態表單生成
+
+每個節點類型（`NODE_TYPES`）自帶欄位 schema：

+    ...
+  ]
+}
+```
+
+`renderDynamicForm()` 根據選中節點的 `nodeType` 讀 schema，渲染對應欄位——加新欄位不用改 UI 元件，只改 schema。

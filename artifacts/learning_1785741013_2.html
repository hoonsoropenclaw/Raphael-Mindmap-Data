CLI 等效指令（可用於自動化排程）

本工具的 CLI 版本 multilingual_pipeline.py 已驗證可獨立運行，可整合進 cron job / systemd timer。

# 1) 語音轉文字（多語言 Whisper） python3 multilingual_pipeline.py transcribe audio.mp3 --model tiny --language zh --vad # 2) OCR 文字辨識（多語言 Tesseract） python3 multilingual_pipeline.py ocr document.png --lang chi_tra+eng # 3) 文字轉語音（MiniMax T2A） python3 multilingual_pipeline.py synthesize --text "你好世界" --voice female-shaonv --lang zh --out hello.mp3 # 4) 端到端管線 python3 multilingual_pipeline.py pipeline meeting_zh.mp3 --target-lang en --output meeting_en.mp3

+# FocusFlow · 實作思路與除錯紀錄
+
+## 一、任務理解
+- 主題：實作一個完整的 React UI 元件，含複雜狀態管理 + CSS 樣式。
+- 交付物：可直接瀏覽器開啟的單檔 HTML（不需 npm install / build）。
+- 風格定位：editorial brutalism + 暖紙張調（Ember Ledger 主題），避開紫白 SaaS / Inter / 三欄等價 card。
+
+## 二、技術選型
+- React 18 UMD（CDN unpkg）+ ReactDOM + Babel Standalone → JSX 直接 inline，不需 webpack。
+- 狀態層：`useReducer` 集中管理（tasks / filter / query / sort / toast），action type 為
+  `ADD | TOGGLE | FILTER | QUERY | SORT | CLEAR_TOAST`。
+- 衍生資料：`useMemo` 對 filter+query+sort 做 cache，避免每次 render 重算。
+- 副作用：
+  - `useEffect` #1 → Toast 自動 2.6s 後清除（含 cleanup，避免 race condition）。
+  - `useEffect` #2 → 全域鍵盤快捷鍵（`/` 聚焦搜尋、`Esc` 關 modal、`Ctrl/Cmd+Enter` 開 modal），
+    排除 input/textarea/select 內的按鍵避免搶輸入。
+- 模態：自製 `NewTask` 元件（不是瀏覽器 `alert/confirm`），含表單驗證（標題不可空）+ 點背景關閉。
+
+## 三、複雜狀態設計
+| State | 用途 | 變更入口 |
+|-------|------|---------|
+| `tasks` | 看板資料源（5 個 seed + 後續新增） | ADD / TOGGLE |
+| `filter` | 看板 / 分頁切換（all / today / next / done） | FILTER |
+| `query` | 搜尋字串（title+desc+tag 全文比對） | QUERY |
+| `sort` | 排序策略（priority / due） | SORT |
+| `toast` | 操作回饋 | ADD/TOGGLE → 2.6s 自動 CLEAR |
+| `open`（App 內） | modal 開關 | 快捷鍵 / 按鈕 |
+
+完成率 `completed/total` 與百分比動態計算，header signal card 顯示動態長條。
+
+## 四、UI/UX 細節
+- Hero：clamp(3.6rem,9vw,8.5rem) 大字標題 + 信號卡（完成率）做不對稱 split。
+- 看板：CSS Grid 三欄（行動裝置 1 欄），空狀態文案「這裡很安靜」取代空字串。
+- 任務卡：`animation: rise .45s` + `--i` 變數實作 stagger；hover 微抬 + 微旋。
+- 完成任務：opacity .64 + line-through + 綠色 check（區分「重新開啟」vs「完成」）。
+- 焦點環：`outline:3px solid #e7a18d` 在所有可互動元素（避免 box-shadow 偽焦點）。
+- Reduced motion：媒體查詢關掉所有動畫 + smooth scroll。
+- 行動裝置：media query 把 grid 收成 1 欄，hero 字體縮小到 16vw。
+- 字型：Georgia 標題 + Trebuchet MS 內文（避開 Inter/Roboto 預設）。
+

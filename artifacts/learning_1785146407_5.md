+# Kanban React Component — Implementation Handoff
+
+## 標題
+**React 18 + TypeScript + Vite Kanban board**,useReducer + Context + HTML5 drag-and-drop + localStorage persistence,handcrafted CSS design system (no Tailwind, no Redux, no react-dnd).
+
+## 路徑
+`/tmp/kanban-demo/` — runnable Vite project。
+
+## 啟動
+```bash
+cd /tmp/kanban-demo
+npm install      # 已跑過,5 秒
+npm run dev      # http://localhost:5173
+npm run build    # tsc -b && vite build → dist/
+```
+
+## 結構
+
+```
+src/
+├── types.ts                 — Action / Task / Column / BoardState discriminated unions
+├── reducer.ts               — boardReducer + selectors (tasksIn / counts)
+├── BoardContext.tsx         — Provider + useBoard hook + localStorage hydration
+├── Board.tsx                — Shell (toolbar + 3 columns + footer)
+├── main.tsx + App.tsx       — entry
+├── styles.css               — 設計系統單檔 (tokens, layout, components)
+└── components/
+    ├── BoardToolbar.tsx     — 標題 + 完成率 + 搜尋 + reset
+    ├── Column.tsx           — drop zone + 任務列表 + AddTaskForm
+    ├── TaskCard.tsx         — draggable card + meta + 刪除
+    └── AddTaskForm.tsx      — title / detail / priority / submit
+```
+
+## 狀態管理決策(為什麼這樣選)
+
+1. **useReducer 而非 useState**:有 8 種 action,而且 MOVE_TASK 涉及 3 個欄位(status / id / toIndex)、多個 branch。用 reducer 表達成 discriminated union + switch,比散在各 component 的 `useState` 各自 setState 好追蹤。
+2. **Context 而非 props drilling**:`useBoard()` 一行串接所有 component,不污染 props 介面。selector 函式 pre-memo 在 value 內,避免每 render 都重算 filter。
+3. **不引入 Redux/Zustand**:這規模不必要,`useReducer + Context` 的組合足夠;真正需要外部 store 是跨頁、跨 session、SSR 的場景。
+4. **exhaustiveness check**:reducer `default` 用 `_exhaustive: never = action` 守護 — 將來加新 Action 時 TS 會強迫你在 default 處理。
+5. **MOVE_TASK short-circuit**:同欄同位置直接 return state,避免無謂 re-render。
+
+## 拖拽實作細節
+
+- HTML5 native DnD(`draggable` attribute + `dataTransfer.setData('text/plain', id)`)
+- 不靠 react-dnd / react-beautiful-dnd 因為 200KB 依賴只為 30 行原生邏輯不划算
+- Drop index 用 `getBoundingClientRect` 算最接近的 card midpoint — 比 maintain refs 簡單,因為 list 動態 re-render 後 refs 會失效
+- `effectAllowed = 'move'` 必設,某些瀏覽器(Safari)預設 'copy' 會吃掉 drop event
+- Drag 進入 column 時視覺提示:整欄 highlight + 插入線 indicator
+
+## 持久化
+
+- `localStorage['kanban:v1']` — schema-versioned,將來欄位升級時 bump version 自動清掉舊資料
+- Hydration 用 `useRef` guard 兩階段:mount → 讀 storage → dispatch HYDRATE → 後續 useEffect 才開始寫入。**避免 StrictMode 雙重 mount 把空狀態寫回去覆蓋掉真資料**
+- Schema 解析失敗(`JSON.parse` / 版本不符 / 非陣列)都降級到 seed tasks,不擾使用者
+
+## 設計系統
+
+- CSS custom properties 集中管理 color / spacing / type scale
+- Dark mode via `prefers-color-scheme: media query`

+- `color-mix(in srgb, ...)` 給 priority badge 背景 12% 透明 — 現代瀏覽器原生支援,不需要 preprocessor

+- Responsive:`< 900px` 自動疊成單欄

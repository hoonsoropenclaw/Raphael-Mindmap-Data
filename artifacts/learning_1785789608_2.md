+# recon_engine — Asyncio API Reverse-Engineering Toolkit
+
+A self-contained Python package for discovering and reverse-engineering
+the API surface of dynamic web applications. Built around three
+cooperating harvesters:
+
+| Component | File | Purpose |
+|-----------|------|---------|
+| `DirectHarvester` | `interceptor.py` | Concurrent `aiohttp` probes of common API paths (no browser) |
+| `NetworkInterceptor` | `interceptor.py` | Trace-config wrapper that records any `aiohttp` traffic flowing through a shared session |
+| `PlaywrightBridge` | `playwright_bridge.py` | Headless Chromium with both Playwright-level and in-page (fetch/XHR/WebSocket) interception |
+
+All three emit `EndpointCandidate` objects that flow through the same
+scoring + classification + export pipeline.
+
+## Quick start
+
+```python
+import asyncio
+from recon_engine import ReconEngine, ReconConfig
+
+async def main():
+    cfg = ReconConfig(
+        target_url="https://example.com",
+        use_browser=True,
+        use_direct_probe=True,
+        settle_ms=4000,
+    )
+    async with ReconEngine(cfg) as engine:
+        result = await engine.run()
+    print(f"Found {len(result.candidates)} endpoints in {result.finished_at - result.started_at:.1f}s")
+    for c in sorted(result.candidates, key=lambda c: -c.score)[:5]:
+        print(f"  [{c.score:.2f}] {c.method} {c.url}")
+
+asyncio.run(main())
+```
+
+## CLI
+
+```
+python -m recon_engine https://github.com/ --json-out out.json --curl-out curls.sh
+```
+
+## Exports
+
+`ReconResult` ships three renderers:
+
+- `result.to_json(include_body=True)` — full structured dump
+- `result.to_har()` — HAR 1.2 (importable to Postman/Charles)
+- `result.to_curl(top_n=20)` / `result.to_python(top_n=10)` — copy-pasteable snippets
+
+## Architecture notes
+
+- **Three harvesters, one model.** Different surfaces (direct probe vs
+  headless browser) produce the same `EndpointCandidate` shape, so the
+  downstream scoring/exporter code is shared.
+- **In-page bridge.** The Playwright layer installs a JS bridge *before*
+  any page script runs, wrapping `fetch`, `XMLHttpRequest`, and
+  `WebSocket` so we capture request bodies and response bodies that the
+  browser's own network panel misses.
+- **Body follow-up fetch.** For resources Playwright records but can't
+  expose the body of (binary downloads, font files), we do a *second*
+  in-page `fetch()` after page load to grab the body. This only fires
+  for resources our API sniffer flags as interesting (`_looks_api`).
+- **Bounded everything.** The engine caps candidates at 500 by score,
+  times out every network call, wraps every Playwright event handler in
+  a safe-shield so one bad event can't take down the listener chain,
+  and never sleeps in a poll loop — it uses `asyncio.as_completed()` and
+  `wait_for` with hard limits.
+- **Stdlib-first dataclasses.** No pydantic. Validation lives in
+  `__post_init__` so the import footprint stays small.
+

+# Telegram Weather Bot
+
+天氣查詢 Telegram 機器人 — 輸入城市名稱，回傳當前天氣（溫度、濕度、風速、天況）。
+
+## 功能
+
+- 🌍 支援中文與英文城市名稱（例如 `Tokyo` 或 `台北市`）
+- ⚡ 並行查詢設計（asyncio.gather 模式）
+- 🛡️ Fail-Safe：bounded HTTP、明確 User-Agent、跨平台守衛
+- 💬 兩種使用方式：
+  - 直接傳送城市名稱
+  - `/weather <城市>` 指令
+
+## 資料來源
+
+[Open-Meteo](https://open-meteo.com/) — 免費、無需 API key、CC-BY 授權
+
+## 安裝
+
+### 1. 安裝相依套件
+
+```bash
+pip install python-telegram-bot aiohttp
+```
+
+或用 requirements.txt：
+
+```bash
+pip install -r requirements.txt
+```
+
+### 2. 取得 Telegram Bot Token
+
+跟 [@BotFather](https://t.me/BotFather) 對話，建立新 bot 並取得 token。
+
+### 3. 設定環境變數
+
+```bash
+export TELEGRAM_BOT_TOKEN='your-bot-token-here'
+```
+
+### 4. 啟動
+
+```bash
+python3 weather_bot.py
+```
+
+## 使用方式
+
+在 Telegram 對話中：
+
+| 訊息 | 效果 |
+|------|------|
+| `Tokyo` | 查詢東京天氣 |
+| `台北市` | 查詢台北市天氣 |
+| `/weather New York` | 紐約天氣 |
+| `/start` | 歡迎訊息 |
+| `/help` | 使用說明 |
+
+範例回覆：

+## 架構決策
+
+1. **資料來源 = Open-Meteo** — 不需 API key、CC-BY 免費、JSON 結構穩定；避免引入付費 token 維護成本。
+2. **兩段式查詢（geocode → forecast）** — Open-Meteo 用 lat/lon 查天氣，城市名要先 geocoding；把兩段各自 timeout/上限隔離，geocode 失敗時不浪費 forecast 配額。
+3. **handler/service 分離** — Telegram handlers 只負責收訊息、呼叫 service、回文字；service 純邏輯、無 Telegram 依賴 → 易測試、可離線驗證（這也是能跑 `test_offline.py` 不需要 token 的原因）。
+4. **單例 service** — `_service = WeatherService()` 在 module-level 建一次；handlers 透過 module global 共享（handler 是 short-lived coroutine，無 thread-safety 問題）。

+8. **空字串** — service 層直接擋掉，不浪費 HTTP 配額

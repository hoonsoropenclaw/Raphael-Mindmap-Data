OCR Sentinel

A cross-platform desktop automation tool that watches a folder, OCRs any image that lands in it, classifies it (INVOICE / RECEIPT / ID_CARD / CONTRACT / RESUME / NOTE), and moves it into a category folder. Live web dashboard streams every result over SSE.

pip install -r requirements.txt && python -m src

3 · How it works

  • watchdog Observer (Linux inotify / macOS FSEvents) detects new files. On Windows / Docker bind mounts it transparently falls back to PollingObserver.
  • The event handler does only extension check + debounce + queue.put. No OCR runs on the watcher thread (anti-pattern: blocking I/O in event handlers).
  • A bounded thread pool (OCR_WORKERS, default 2) drains the queue and calls pytesseract.image_to_data for text + per-word confidence.
  • Worker classifies by keyword (INVOICE / RECEIPT / ID_CARD / CONTRACT / RESUME / NOTE / TOTAL) and atomically moves the file into watch/<category>/.
  • Worker publishes the result onto a pub/sub hub; the dashboard's Server-Sent Events endpoint forwards each event to connected browsers.

4 · Re-run the demo in 3 commands

cd ocr_sentinel
python -m src --check-deps      # verify tesseract + python deps
python -m src --once watch/sample_invoice.png   # OCR one file and exit
OCR_PORT=8765 python -m src     # full daemon + dashboard at http://127.0.0.1:8765/

Then drop any PNG/JPG into watch/. Within ~2 seconds it will be classified, renamed, and pushed to the dashboard.

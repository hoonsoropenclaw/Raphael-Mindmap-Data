+監控項目

+  1. journalctl -p err..emerg -S <since>  ← systemd 系統（最常見）
+  2. /var/log/syslog                     ← Debian/Ubuntu syslog

+  - inode 使用率（df -i）
+  - I/O 活動（/proc/diskstats，read/write sectors/sec）

+# sysmonitor.py
+
+Linux 系統日誌與資源監控腳本。**stdlib-only**（Python 3.10+，零外部相依），
+在 Ubuntu 24.04 / Debian 12 / RHEL 9 / 其他 systemd Linux 上不裝任何套件就能跑。
+
+## 它能做什麼
+
+- **日誌掃描**（依序 fallback，自動偵測環境）
+  - `journalctl -p err -S <since>` （systemd 系統，預設）
+  - `/var/log/syslog` （Debian/Ubuntu）
+  - `/var/log/messages` （RHEL/CentOS）
+  - `/var/log/dmesg` （核心緩衝）
+
+- **資源監控**（全 Linux 通用）
+  - CPU 使用率（/proc/stat）
+  - 記憶體使用率（/proc/meminfo，含 MemAvailable）
+  - 磁碟使用率（statvfs，根目錄）
+  - inode 使用率
+  - 系統負載（/proc/loadavg，正規化為 per-CPU）
+  - I/O 活動（/proc/diskstats）
+
+- **錯誤偵測**（regex pattern）
+  - OOM / Killed process / segfault / EXT4-fs error / I/O error / nfs stale /
+    systemd Failed / buffer I/O error
+  - warning / deprecated / degraded / retry / timeout / Disk full
+
+- **警告輸出**
+  - stdout 彩色 ANSI（自動偵測 TTY）
+  - 寫到本地檔（atomic write，mode 0600）
+  - POST JSON 到 webhook（bounded read + timeout）
+
+## 安裝
+
+零安裝 — 直接執行：
+
+    python3 sysmonitor.py
+
+或複製到 PATH：
+
+    install -m 0755 sysmonitor.py ~/.local/bin/sysmonitor
+
+## 用法
+
+### 基本
+

+

+
+    # 過去 7 天
+    python3 sysmonitor.py --since 7d

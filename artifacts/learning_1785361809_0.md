+# PRD：動態表單驗證工作流
+
+## 1. 問題與目標
+
+傳統表單把欄位、驗證規則與送出條件藏在程式碼中，營運或產品人員無法理解一筆資料為何被阻擋。本產品要把「欄位 → 規則 → 邏輯閘 → 結果」呈現為可編輯流程圖，並同步生成可操作表單。
+
+核心目標：
+1. 使用 React Flow 呈現、拖曳、選取與連接驗證節點。
+2. 由流程圖中的 Field 節點動態生成表單欄位。
+3. 使用單一驗證引擎，同步驅動畫布狀態、欄位錯誤與執行軌跡。
+4. 以明確的視覺層級區分來源、規則、邏輯與結果。
+5. 交付工作目錄根層 `index.html`，可由一般靜態 HTTP server 直接執行。
+
+## 2. 使用者旅程
+
+- 身為流程設計者，我可以切換三個範本，快速理解不同驗證拓撲。
+- 身為流程設計者，我可以新增、選取、拖曳、設定與刪除節點。
+- 身為流程設計者，我只能建立語意正確、無循環、無重複的連線。
+- 身為表單使用者，我可以填寫流程圖生成的表單，立即看到完成度。
+- 身為表單使用者，我在送出後可於欄位、流程節點與錯誤摘要同時看見失敗原因。
+- 身為稽核者，我可以查看每個驗證節點的執行軌跡。
+- 身為協作者，我可以匯出及匯入工作流 JSON。
+
+## 3. 功能需求
+
+### Must
+- React Flow 畫布：pan、zoom、drag、connect、MiniMap、Controls。
+- 四種自訂節點：Field、Rule、Logic、Outcome。
+- 七種規則：required、email、minLength、minNumber、matches、sameAs、requiredWhen。
+- ALL / ANY 邏輯閘與巢狀閘支援。
+- 拒絕自連、重複連線、非法方向、Rule 多來源與循環。
+- 動態表單與 controlled inputs。
+- 明確送出驗證；錯誤顯示於欄位下方及圖節點。
+- 已知有效資料一鍵載入、清空。
+- 節點 Inspector 與即時更新。
+- 三個可用範本：帳號開通、費用申請、活動報名。
+- 匯入／匯出 JSON。
+- 桌面、平板、手機響應式。
+- 鍵盤焦點、語意標籤、aria-live、reduced-motion。
+
+### Should
+- 節點狀態色與動態邊線。
+- 執行軌跡列表與圖健康狀態。
+- 點擊錯誤摘要能導向對應欄位。
+- 每次操作提供狀態列回饋。
+
+### Won’t（本輪）
+- 後端儲存、多人協作、登入權限。
+- 伺服器端驗證或資料庫。
+- 部署至外部平台。
+
+## 4. 驗收標準
+
+1. 空白帳號表單送出後顯示欄位錯誤，並且對應 Rule／Gate／Outcome 節點變為失敗狀態。
+2. 載入有效範例再送出，結果顯示通過、失敗計數為 0。
+3. 切換活動報名範本後，欄位數與畫布拓撲同步改變。
+4. 新增 Field 節點後，欄位數增加且 Inspector 可改名，表單同步更新。
+5. 無 uncaught JavaScript error、React warning 或失敗網路請求。
+6. 375px、768px、1440px viewport 無水平溢出；核心操作可見。
+7. 最終 `index.html` 不依賴 CDN，內含 React、React Flow、Tailwind 編譯結果與字型資產。
+
+## 5. 美學方向

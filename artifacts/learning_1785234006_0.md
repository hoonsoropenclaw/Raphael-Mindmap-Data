+### 2.1 純 stdlib,零外部依賴

+### 2.2 HTML scrape 為主,GitHub Search API 為 fallback
+- **GitHub 沒有官方 trending API**(官方搜尋 API 也無法依「daily stars」排序)

+- 為什麼不靜默 fallback?→ 透明報告比假裝一切都好;Markdown 末尾會加 ⚠️ 警告 + JSON 內 `fallback_used` + `error` 欄位

+- 表格欄位:`rank | repo (with link) | description | language | stars today | total stars`

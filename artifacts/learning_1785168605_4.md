+def get_todo(db: Session, todo_id: int) -> models.Todo | None:
+    """Look up a single todo by id. Returns None when not found."""
+    return db.get(models.Todo, todo_id)

+
+def create_todo(db: Session, payload: schemas.TodoCreate) -> models.Todo:
+    """Insert a new todo and return the persisted instance."""
+    todo = models.Todo(
+        title=payload.title,
+        description=payload.description,
+        completed=payload.completed,
+    )
+    db.add(todo)
+    db.commit()
+    db.refresh(todo)
+    return todo
+
+
+def update_todo(
+    db: Session, todo: models.Todo, payload: schemas.TodoUpdate

+    """Apply a partial update. Only fields that were explicitly set are touched."""

+    for key, value in data.items():
+        setattr(todo, key, value)
+    db.commit()
+    db.refresh(todo)
+    return todo
+
+
+def delete_todo(db: Session, todo: models.Todo) -> None:
+    """Remove a todo. Caller is responsible for confirming existence."""
+    db.delete(todo)

+## 實作思路
+
+### 1. 分層（避免 fat controller）
+
+- `models.py`：純 SQLAlchemy 2.0 ORM（`Mapped`/`mapped_column`、`DeclarativeBase`）
+- `schemas.py`：純 Pydantic v2（`TodoCreate` / `TodoUpdate` / `TodoRead`，`model_config = ConfigDict(from_attributes=True)`）
+- `crud.py`：薄函式（`list_todos` / `get_todo` / `create_todo` / `update_todo` / `delete_todo`），控制 transaction boundary
+- `database.py`：engine + `SessionLocal` + `get_db` dependency + `init_db`
+- `main.py`：FastAPI app factory（`create_app(rate_limit=...)`），route 只做 HTTP 翻譯
+
+### 2. App factory 而非 module-level 全域 app
+
+`create_app()` 接受 `rate_limit` 參數。理由：
+- 測試要建多個 app 實例（rate limit 測試需要 `2/minute`，主測試需要 `disabled`）
+- 模組層級 `app = create_app()` 保留給 `uvicorn app.main:app` 生產啟動
+
+### 3. Rate limit — slowapi 而非手寫
+
+- `Limiter(key_func=get_remote_address, default_limits=[RATE_LIMIT_DEFAULT])`
+- 每個 route 用 `@limiter.limit(effective_limit)` 套上限制；`effective_limit=None` 時裝飾器退化為 no-op
+- 註冊 `RateLimitExceeded` exception handler 回 429 + JSON body（slowapi 預設回 500）
+- `SlowAPIMiddleware` 必須加，否則 limiter 不會在 middleware 階段檢查
+- 預設 60/minute，env var `TODO_RATE_LIMIT` 可覆蓋
+
+### 4. 測試設計
+
+- **in-memory SQLite + StaticPool**：每個 fixture 用 `sqlite://` + `StaticPool`（共享單一 connection），`create_all` / `drop_all` 確保完全隔離。**不會**寫到磁碟 `todos.db`，跟生產 DB 完全分開。
+- **dependency override**：`app.dependency_overrides[get_db] = _override_get_db` 把 `get_db` 換成測試的 session
+- **autouse fixture 清 slowapi state**：`slowapi.extension._rate_limit_storage = {}` 確保 rate limit 測試不互相污染
+- **獨立 tight_client fixture**：rate limit 測試另外建 app with `2/minute`，驗 429 觸發

+## Debug 過程（重要教訓）
+
+### Bug 1：FastAPI 0.115 對 204 No Content 嚴格檢查
+
+```
+AssertionError: Status code 204 must not have a response body
+```
+
+**原因**：FastAPI 推導函式簽名 `-> None` 仍會建立 response model，204 拒絕。  
+**修法**：明確 `response_class=Response`，handler 內 `return Response(status_code=204)`。
+
+### Bug 2：slowapi middleware 攔截後 FastAPI 找不到 body
+
+真 server 跑起來 POST 回 `{"detail":[{"type":"missing","loc":["query","payload"],...}]}` — 把 payload 當 query 處理。
+
+**原因**：`from __future__ import annotations` 把所有型別變字串（PEP 563），Pydantic 推導 Body() 時變成 `ForwardRef('schemas.TodoCreate')` → 報 `PydanticUserError: not fully defined`。pytest 之前沒炸是因為 TestClient 對 request body 的處理跟真 ASGI server 略有差異。
+
+**修法**：
+1. `main.py` 拿掉 `from __future__ import annotations`（FastAPI route 必須用具體型別）
+2. POST/PUT 的 payload 明確標 `Body(...)`（保險起見，雖然慢 API 預設應該推對）
+
+驗證後真 server 與 pytest 全部端到端正常。
+
+### Bug 3：對 slowapi default_limits 行為理解錯誤
+
+**第一版斷言**「打爆 /health 後 /todos 會被 429 擋下」→ 失敗。  
+**事實**：slowapi 的 `default_limits` 是 per-route bucket，不是全域。每個 `@limiter.limit(...)` 獨立計數。  
+**修法**：把測試改成「打爆 /health 後 /todos 仍可達」，並在文件說明這個語意差異。

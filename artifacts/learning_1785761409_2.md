+# Playwright Cross-Browser Automation Framework
+
+This is a runnable Playwright Test framework with:
+
+- Chromium, Firefox, WebKit, and Mobile Chromium projects.
+- E2E smoke checks for rendering, interaction, accessibility status, and mobile overflow.
+- Deterministic visual regression policy: animations disabled, caret hidden, 2% pixel tolerance.
+- HTML and JSON reports, failure screenshots, videos, and retain-on-failure traces.
+- CI retries and single-worker mode to reduce flaky parallel resource contention.
+- A dependency-free local HTTP server with path traversal protection.
+
+## Run
+
+```bash
+npm install
+npx playwright install chromium firefox webkit
+npm test
+```
+
+The test runner starts the local fixture server automatically at `http://127.0.0.1:4173`.
+
+For a headed run:
+
+```bash
+npm run test:headed
+```
+
+Open the generated report:
+
+```bash
+npm run test:report
+```
+
+## Visual baseline lifecycle
+
+Create baselines intentionally, never implicitly:
+
+```bash
+npx playwright test --update-snapshots
+```
+
+Review changed files under `tests/lab.spec.cjs-snapshots/` before committing. CI fails on unexpected visual drift.
+
+## Architecture
+
+- `playwright.config.cjs`: projects, timeouts, retries, artifacts, reporters, web server.
+- `scripts/server.cjs`: deterministic fixture server; rejects paths outside the project root.
+- `tests/lab.spec.cjs`: reusable browser-independent test contract.
+- `web_output.html`: complete runnable demo page used as the test subject.
+- `artifacts/`: generated report and result files (ignored by version control in a real project).
+
+## Selector policy
+
+Prefer `getByRole`, `getByLabel`, and explicit `data-testid` contracts. Avoid CSS classes that exist only for styling. Use fixed waits only for intentionally tested timing behavior; this suite uses locator assertions instead.

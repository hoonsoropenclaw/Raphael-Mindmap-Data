四層管道架構

從 PolitenessGate → DriverLayer → DefParser → SheetsSync 串接, 沿用 data_synchronization_and_analysis 微技能的抽象分層。

關鍵設計決策

  • PolitenessGate：robots.txt + per-host rate-limit + UA, 在任何 fetch 之前先過濾。失敗 → PermissionError,不污染下游。
  • DriverLayer：HTTP retry+backoff;有 enable_mock() 開關可離線測試 — 不需網路、不需真憑證就能驗整條 pipeline。
  • DefParser：BeautifulSoup + 多選擇器 fallback + per-selector @attr 縮寫 + required 標記, 結構化資料從髒 HTML 抽出,壞掉的 record 自動跳過。
  • SheetsSync：有 service-account JSON 就走 gspread ;沒有就降級到本地 CSV,SyncResult.backend 欄位透明標示當前路徑。

+def parse_star_count(text: str) -> int:
+    """把 '32,070' 或 '1.2k' 等轉成 int。"""
+    if not text:
+        return 0
+    t = text.strip().replace(',', '').lower()
+    try:
+        if t.endswith('k'):
+            return int(float(t[:-1]) * 1000)
+        if t.endswith('m'):
+            return int(float(t[:-1]) * 1_000_000)
+        return int(float(t))
+    except (ValueError, IndexError):
+        return 0
+
+
+def extract_period_count(period_text: str) -> int:
+    """從 '2,344 stars today' 抽出 2344。"""
+    if not period_text:
+        return 0
+    parts = period_text.split()
+    if parts:
+        return parse_star_count(parts[0])
+    return 0

+## 2. 設計決策 (為什麼這樣做)
+
+### 2.1 模組化四層分離
+```
+src/
+├── models.py     # 資料結構 + 解析輔助
+├── scraper.py    # HTTP + BS4 解析
+├── formatter.py  # 輸出轉換
+├── cli.py        # CLI 入口
+└── __main__.py   # 讓 `python -m src` 可用
+```
+
+**為什麼拆這麼細?**
+- `models.py` 0 依賴,單元測試不用網路不用 mock
+- `scraper.py` 只負責「拿到 Repository 列表」,回傳型別清楚
+- `formatter.py` 只負責「Repository 列表 → Markdown 字串」
+- `cli.py` 只負責 argparse 跟錯誤碼
+- 每一層都能獨立測試/替換
+
+### 2.2 為什麼不用 GitHub API
+GitHub **沒有 Trending 的官方 API**。`/trending` 頁面是純 HTML,只能爬。
+GitHub Search API 雖然能查 star 數,但**沒有「trending」這個概念** — trending
+是 GitHub 根據短期內 star 增長率計算的結果,API 拿不到。
+
+### 2.3 Requests + BeautifulSoup 選擇
+- `requests` — 標準函式庫,RetryAdapter 容易掛
+- `bs4 + lxml` — 比 `html.parser` 快 5-10 倍,容錯好
+- JSON / `github3.py` / `httpx` 都不適合:JSON 沒資料、github3.py 不抓 Trending、httpx 沒必要
+
+### 2.4 Markdown 表格設計
+- 7 欄: #, Repo (連到 GitHub), Description, Lang, ⭐ Total, 🍴 Forks, 📈 This Period
+- Description 欄用「連到 repo」代替原始 URL,讓 Markdown 讀者點 Repo 名就能跳
+- 描述長度截斷預設 80 字,避免超長中文描述把表格撐爆
+- **表格內 `|` 必須 escape 為 `\|`,換行轉空白** — 不這樣 table 會破
+
+### 2.5 錯誤處理三層
+1. **下載層** — `_download_with_retry` 自動 retry 3 次,backoff 1.5x
+2. **解析層** — 每個 `<article>` 獨立 try/except,某一筆壞了不影響整頁
+3. **短頁偵測** — 內容 < 1000 chars 視為 captcha / 限流,當失敗重試
+
+### 2.6 為什麼 `since` 不接受 `yearly`
+頁面 URL 沒有 `?since=yearly` 選項 (GitHub 只有 daily/weekly/monthly)
+在 CLI 層用 `choices=["daily", "weekly", "monthly"]` 直接擋掉。

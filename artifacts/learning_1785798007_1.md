+# 需求分解
+
+1. HTTP transport：非阻塞 URL 抓取、timeout、限制回應大小。
+2. 排程：以 asyncio.Queue 驅動 worker，支援最大併發數。
+3. politeness：每 host 的最小請求間隔與全域併發限制。
+4. resilience：有限次數重試、指數退避、Retry-After、HTTP/網路錯誤分類。
+5. 解析：可注入 parser，預設以 HTMLParser 擷取 title、links 與文字。
+6. 事件：request_started、response、item、error、request_finished。
+7. 去重與範圍：URL canonicalization、visited set、同網域限制。
+8. 產出：JSONL writer 與 CLI demo。
+9. 測試：不依賴外部服務，以本地 asyncio HTTP server 驗證並發、重試、解析與去重。
+
+# 可重用經驗
+
+- stdlib-first：使用 urllib、asyncio、HTMLParser、dataclasses，避免無必要第三方依賴。
+- long-running async 工作採 bounded queue、明確 worker shutdown 與 signal-safe stop。
+- 併發輸出使用唯一結果序列，不使用固定 sibling temporary file。
+- parser 遇到 HTML void elements 不增加 depth；本框架使用 HTMLParser 的穩健、無深度狀態設計。

+def yaml_load(path: Path) -> dict[str, Any]:
+    out: dict[str, Any] = {}
+    cur_section: str | None = None
+    cur_list: list[str] | None = None
+    for raw in path.read_text(encoding="utf-8").splitlines():
+        line = raw.split("#", 1)[0].rstrip()
+        if not line.strip():

+        stripped = line.lstrip()

+            val = val.strip()

+# ops-monitor
+
+Lightweight Linux system-health & log audit monitor. One-shot bash for cron,
+Python daemon for continuous polling, JSON state for dedup, optional webhook
+and desktop notifications. Tunable thresholds in YAML.
+
+## Layout
+
+```
+ops-monitor/
+├── bin/
+│   ├── health_check.sh     # one-shot checker (exit 0/1/2/3)
+│   └── monitor.py          # daemon wrapper (subprocess + dedup + alert)
+├── config/
+│   └── thresholds.yaml     # all knobs in one place
+├── deploy/
+│   ├── systemd/hermes-monitor.service
+│   └── cron/hermes-monitor.cron
+├── tests/
+│   └── test_health_check.sh
+├── var/                    # runtime: alerts.log, state.json, cron.log
+├── README.md
+└── DELIVERY.md
+```
+
+## Quick start
+
+```bash
+# one-shot, all sections
+./bin/health_check.sh
+
+# quiet (only WARN/CRIT)
+./bin/health_check.sh --quiet
+
+# just disk
+./bin/health_check.sh --section=disk
+
+# run the Python daemon (foreground, Ctrl-C / SIGTERM to stop)
+python3 ./bin/monitor.py --interval 60
+
+# one pass through the daemon pipeline
+python3 ./bin/monitor.py --once
+
+# smoke tests
+bash ./tests/test_health_check.sh
+```

+## 3. 實作思路

+### 3.1 為什麼拆成 bash + Python 兩層
+
+- **bash health_check.sh** 是 single source of truth for checks。
+  - cron / systemd 都可以單獨呼叫它（不需要 Python daemon）
+  - 結構化輸出（`[timestamp] [SEV] check key msg`）同時讓人眼和 parser 友善
+  - 用 awk 讀 `/proc/meminfo` `/proc/loadavg` `df -P` `journalctl`，避開 psutil 等外部依賴
+  - 設 `set -Eeuo pipefail` + `IFS=$'\n\t'` 強化安全，但迴圈內要暫時換回 space IFS
+- **Python monitor.py** 是 daemon 殼層。
+  - subprocess 跑 bash → 把責任分乾淨（bash 管檢查、Python 管 dedup/notif）
+  - 用 regex 解析 structured line（同一個格式兩邊都吃）
+  - JSON state 做 cooldown dedup → 不會狂炸 notify-send / webhook
+  - 支援 SIGTERM / SIGINT 優雅退出（state flush 完才退）

+### 3.2 設計決策重點
+
+| 決策 | 為什麼 | 替代方案被拒絕的理由 |
+|------|--------|---------------------|
+| YAML 在 config/thresholds.yaml | 集中化、不寫死魔術數字 | env var 散落 → 難以審計 |
+| 結構化 stdout（`[ts][SEV] check key msg`） | 同時給人看 + 給 parser | JSON-only → 終端機看很痛 |
+| exit code = 最嚴重等級（0/1/2/3） | cron 直接 `&&` 串接處理 | 一律 0/1 → 丟失細節 |

+| cooldown via JSON state file | 跨程序 dedup（cron + daemon 共用同一 state） | 記憶體 dict → cron 每次新進程就重來 |
+| webhook 留空 = no-op | 預設關閉避免 noise | 一律 POST 失敗 → 噪音 log |

+### 3.3 跑過的 bug / 修法（debug 日誌）
+
+實作期間在這台 N100 (Ubuntu 24.04, GNU coreutils 9.4, gawk 5.2.1) 上踩到的真
+實問題，都已修正，現存版本不會重現：

+1. **`df -P --output=` 互斥** → `df: options -P and --output are mutually exclusive`
+   修：只用 `df -P`（POSIX 標準、所有 coreutils 版本都有），欄位數固定。
+2. **`set -e` + `grep -c` 找不到 pattern** → exit 1 → `|| echo 0` 把 "0\n0" 餵給 `(( ))`
+   → 語法錯炸。修：分開 `cmd || true` + 顯式賦值 + regex 驗證。
+3. **bash `IFS=$'\n\t'` 沒有 space** → `read -r fs size ...` 全進 `fs`，其他欄空。
+   修：read loop 內 `local _ifs; IFS=$' \t\n'`，離開時還原。
+4. **`yaml_get` 抓出 `20   # free < 20%` 沒 trim 註解** → 變成 `"20   # ..."`，進
+   `bc -l` 比較炸。修：在 awk 內 `sub(/[[:space:]]+#.*$/, "", $0)` 截掉行內 `#`。
+5. **journal 236 條 err/1h 在 Ubuntu 上是常態**（snapd + systemd-journald-audit 噪音）
+   → WARN 太敏感。修：journal 段落加 `warn_threshold: 1000 / crit_threshold: 5000`
+   + `enabled: false` 開關 + `journalctl` 不可讀時降級 WARN/INFO（不 crash）。
+6. **`$(( expr ))` 浮點失敗** → 改用 `echo "$a > $b" | bc -l | grep -E '^[01]$'`，

+# PDF → 結構化資料 OCR Pipeline
+
+> 從掃描文件到結構化數據提取 — 純本地、純開源、可離線運作的 end-to-end pipeline。
+
+## 概述
+
+這個專案展示如何把 PDF 文件(不論是文字型或掃描型)自動轉成結構化資料。
+背後整合了 **PyMuPDF + Tesseract + 正則表達式** 三層處理,
+也提供 **PDF.js + Tesseract.js** 純前端方案(瀏覽器內執行,不上傳到 server)。
+
+兩種方案共用同一份 regex 模式集,前後端欄位定義一致。
+
+## 處理流程
+
+```
+┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
+│  輸入 PDF    │ →  │  文字密度    │ →  │  文字萃取    │ →  │  Regex       │
+│  (任意型態) │    │  自動偵測    │    │  (text/OCR) │    │  結構化萃取  │
+└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
+                         │                    │
+                         │ 密度 < 30          │ 自動/文字
+                         ↓                    │
+                   ┌──────────────┐           │
+                   │  Tesseract   │ ←─────────┘
+                   │  OCR (繁中)  │
+                   └──────────────┘
+```
+
+**三種處理模式:**
+- `text` — 強制用 PyMuPDF 抽文字(快、準,只適用文字型 PDF)
+- `ocr` — 強制跑 OCR 全頁(慢、泛用,適用任何 PDF)
+- `auto` — 自動偵測密度,過低自動降級 OCR(**預設,推薦**)
+
+## 環境需求
+
+| 套件 | 版本 | 用途 |
+|------|------|------|
+| Python | 3.10+ | 執行 pipeline |
+| pymupdf | ≥1.24 | PDF 文字萃取 + 渲染 |
+| pytesseract | ≥0.3 | Tesseract Python binding |
+| Pillow | ≥10 | 影像處理(灰階/對比/銳化) |
+| reportlab | ≥4 | 產生測試用 PDF |
+| **Tesseract OCR** | 5.x | 系統層 OCR engine |
+| tesseract-ocr-chi_tra | — | 繁體中文語言模型 |
+| tesseract-ocr-chi_sim | — | 簡體中文(可選) |
+| tesseract-ocr-eng | — | 英文 |
+

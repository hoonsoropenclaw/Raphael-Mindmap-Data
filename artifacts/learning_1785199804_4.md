+# GitHub Trending → Markdown
+
+`github_trending.py` 抓取 GitHub 公開 Trending 頁面，解析 repository cards，並以原子寫入方式輸出 Markdown 表格。
+
+特性：
+
+- Python 3.10+，零第三方套件
+- daily / weekly / monthly 時段
+- language slug 過濾
+- 有界重試、timeout、清楚的非零 exit code
+- `mkstemp + fsync + os.replace` 原子輸出，失敗不破壞舊檔
+- HTML void-element 深度處理，避免 `<img>` / `<br>` 使 parser 狀態漂移
+- Markdown pipe 與換行 escaping
+- 離線 regression fixture + live GitHub smoke test
+
+## 使用方式
+

+# 每日前 25 名，輸出到預設 github-trending.md

+
+# 顯示完整參數
+./github_trending.py --help
+```

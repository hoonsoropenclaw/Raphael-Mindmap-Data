+const server = createServer((req, res) => {

+  const relative = urlPath === '/' ? 'web_output.html' : decodeURIComponent(urlPath).replace(/^\/+/, '');

+  if (!candidate.startsWith(root)) {
+    res.writeHead(403).end('Forbidden');
+    return;
+  }
+  try {
+    if (!statSync(candidate).isFile()) throw new Error('not-file');
+    res.writeHead(200, {
+      'Content-Type': types[extname(candidate)] || 'application/octet-stream',
+      'Cache-Control': 'no-store',
+    });
+    createReadStream(candidate).pipe(res);
+  } catch {
+    res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' }).end('Not found');
+  }
+});

+# Playwright 跨瀏覽器與視覺回歸測試

+## 模組
+
+1. `web_output.html`：可直接開啟的測試標的與前端示範頁。

+3. `playwright.config.js`：Chromium、Firefox、WebKit 三專案矩陣；自動啟動伺服器；保留失敗 trace、video、screenshot。
+4. `tests/cross-browser.spec.js`：內容、瀏覽器辨識、滑鼠互動、鍵盤互動測試。
+5. `tests/visual.spec.js`：初始狀態與互動完成狀態的 full-page 視覺回歸。
+6. `tests/visual.spec.js-snapshots/`：依瀏覽器引擎分開保存的六張 Linux 基準圖。
+

+
+```bash
+npm install
+npx playwright install chromium firefox webkit
+npm test
+```

+

+npm run test:cross-browser
+npm run test:visual
+npm run test:report
+```

+
+只有在 UI 變更經人工確認為預期變更時才執行：
+
+```bash
+npm run test:update-snapshots
+npm run test:visual
+```

+視覺設定：
+
+- CSS 像素尺度，避免不同裝置倍率引入噪音。
+- 動畫停用、游標隱藏。
+- `maxDiffPixelRatio: 0.01`，允許最多 1% 差異像素。
+- `threshold: 0.2`，控制單像素色差容忍度。
+- 每個瀏覽器擁有獨立 baseline，避免把不同渲染引擎的正常差異誤判為 regression。

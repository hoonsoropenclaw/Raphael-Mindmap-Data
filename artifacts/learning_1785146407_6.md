+# sysmonitor — 交付審查 (Round 1)
+
+交付物
+------
+- `sysmonitor.py` (29 KB, 762 行, Python 3.12, 零 main 依賴僅 psutil+PyYAML)
+- `config.yaml` (1.3 KB, 範例配置)
+- 兩種模式跑通：`once` (單次 JSON/console) 與 `watch` (持續 daemon)
+- 已驗證 alarm pipeline 端到端：thresholds 拉低時 7 個 resource alert + 1 個 log_spike critical，全部 JSON log 寫入；冷卻恢復邏輯不重複觸發
+
+設計思路（為什麼這樣切）
+--------------------------
+
+### 1. 監控層 vs 判斷層 vs 遞送層 三層切乾淨
+
+```
+gather_resources() ──┐
+                     ├─→ AlertState.evaluate_*() ─→ emit_alert() ─→ console / JSON / webhook
+scan_logs() ─────────┘
+```
+
+- **採集**只用 `psutil` + `subprocess`（journalctl / df），不直接 bind 到 systemd D-Bus（不同發行版 ABI 差異大，subprocess journalctl 最穩）
+- **判斷**純函式 + dataclass，方便 unit test 與未來換策略
+- **遞送**console 永遠開、JSON log 永遠寫、webhook 是 optional — 任何層失敗不會炸另兩層
+
+### 2. 告警去抖（cooldown + state machine）
+
+不靠「次數」靠「主動狀態」：
+
+- `cpu_high` 這類 alert 升起 → 寫入 `_active` → 之後 cooldown 內不重發
+- 數值降回閾值 → 發 `cpu_high_recovery` (info severity) → 從 `_active` 移除
+- 防 flapping：同類 alert 在 `cooldown_seconds` 內不重發
+
+這比「每分鐘寄一次」合理 — 同一個 OOM alarm 連發 60 條是噪音。
+
+### 3. CPU alert 用「持續平均」而非「瞬時」
+
+`psutil.cpu_percent(interval=None)` 第一次呼叫一定回 0（或自開機以來）。我寫了 `CpuAverager`：
+
+- 維持最近 N 秒的 cpu percent deque
+- alert 判斷時用 `mean()` 而不是 instantaneous
+- 預設 `cpu_sustain_seconds=180` 避免單次尖峰誤報
+
+### 4. Log 掃描用「滑動窗口 + per-category 閾值」
+
+不是「一出現就告警」：
+
+- 同一 OOM 在 15 min 內出現 5 次才告警
+- 滑動窗口內做 deque 修剪
+- 每次只保留最近 3 筆 sample 進 alert details（避免 JSON log 爆量）
+
+### 5. 預設閾值保守、生產可調
+
+- CPU 85% / MEM 90% / Disk 90% / Load 2.0 per CPU — 對應 N100 這種小主機已經略積極
+- 全部可用 `config.yaml` 覆蓋，deep-merge 不會把使用者沒寫的 key 蓋掉
+- `memory_percent` 暫沒寫（要 Kernel same-page merging 統計，/proc/meminfo 即可，但需要 root 讀 smaps — 暫不列入）
+
+### 6. 兼容降階
+
+- 沒 psutil → 跳資源監控，只跑日誌
+- 沒 yaml → 跳 config 載入，全用預設
+- journalctl 不存在 → 退回 `/var/log/{syslog,messages}` 解析
+- df 不存在 → inode 該掛載點跳過
+
+### 7. 開發期踩到一個 `import inspect` 坑
+
+`apport` 的 `excepthook` 在某些 import 順序下會清掉 `inspect` cache，導致 `@dataclass` 內 `inspect.get_annotations()` 報 `AttributeError`。在 `sysmonitor.py` 開頭 explicit `import inspect` 解。
+

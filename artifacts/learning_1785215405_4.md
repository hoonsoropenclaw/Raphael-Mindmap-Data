+## CLI
+

+## Reliability features
+
+- **Bounded response read** — hard cap of 4 MiB prevents OOM if a peer streams
+  junk without dropping the connection.
+- **Bounded retries** — only retries HTTP 429 / 5xx and network / timeout
+  errors with exponential backoff + jitter. Permanent 4xx fails fast.
+- **Atomic write** — `mkstemp` + `flush` + `fsync` + `os.replace`. Concurrent
+  writers can race safely; the final file is always one of the candidates
+  fully written.
+- **POSIX-only step guarded** — directory `fsync` is skipped on Windows to
+  avoid `PermissionError`; file-level `fsync` still runs.
+- **Fail-closed on empty parse** — if no repositories are found, the script
+  exits 1 and the previous output is preserved.
+- **Markdown table injection-safe** — backslashes and pipes inside cell
+  values are escaped.

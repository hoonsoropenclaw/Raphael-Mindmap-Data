🎯 核心能力 (Core Capabilities)

  • 🔁 智能重試 RetryableError (5xx / 429 / 網路抖動) 走 exponential backoff + jitter， FatalError (4xx / 不允許的 content-type) 立即放棄不浪費資源。
  • 🚫 雙層去重 L1 URL 正規化去重 (LRU 200K 上限防 OOM)； L2 內容 SHA-256 去重（同內容不重複落地）。
  • ⏱️ 雙層節流 全域 TokenBucket + 單主機 TokenBucket， 避免觸發目標網站 WAF / rate limit。
  • 🤖 robots.txt 支援 自動取得並 parse、per-host cache， 拒絕的 URL 提前跳過、不浪費網路資源。
  • 📊 可觀測性 JSON-lines 結構化 logging；週期性 metrics reporter (QPS / 成功率 / P50-P95 / status codes)。
  • 🛡️ Anti-pattern 防呆 有界 queue 防 OOM、graceful shutdown (SIGINT)、 不阻塞事件迴圈、所有 I/O 走 aiohttp + aiofiles。

🚀 CLI 快速使用

# 1. 單 URL 立刻抓 python3 crawler.py --url https://example.com -o ./output # 2. 從檔案批次抓（每行一個 URL） python3 crawler.py --urls-file urls.txt -o ./output --format jsonl # 3. 用 YAML 設定（覆蓋所有預設） python3 crawler.py -c crawler.yaml --urls-file urls.txt # 4. 跳過 robots.txt 與內容去重 python3 crawler.py --url https://x.com --no-robots --no-dedup # 5. 提高併發與速率 python3 crawler.py --url https://api.example.com --max-concurrent 32 --rate 100

💻 程式化使用範例

from crawler import AsyncCrawler, CrawlerConfig import asyncio async def main(): cfg = CrawlerConfig( output_dir="./downloads", max_concurrent=16, max_retries=3, backoff_base=0.5, backoff_cap=10.0, global_rate_per_sec=50.0, per_host_rate_per_sec=5.0, respect_robots_txt=True, log_level="INFO", ) crawler = AsyncCrawler(cfg) results = await crawler.crawl([ "https://example.com", "https://www.iana.org", ]) summary = crawler._metrics.snapshot() print(f"成功率: {summary['success_rate']*100:.1f}%") print(f"QPS: {summary['qps']}") asyncio.run(main())

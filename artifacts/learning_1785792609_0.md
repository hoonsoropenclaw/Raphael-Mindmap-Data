+## 任務
+使用 Playwright 實現跨瀏覽器自動化測試並整合視覺回歸測試。
+
+## 架構決策(從 learning_logs.json 的過往試誤歸納)
+
+| # | 過往教訓 | 本次設計對策 |
+|---|---------|-------------|
+| 1 | WebKit 不接受 `--no-sandbox`/`--disable-gpu` | 不要對 WebKit 加這兩個 flag;Chromium 可加 |
+| 2 | 玻璃面板 alpha > 0.28 → WebKit 雙重處理破圖 | Demo 頁面所有 backdrop-filter alpha ≤ 0.28 |
+| 3 | pixelmatch v7 API 要 RGBA flat bytes | 透過程式將 PNG 解碼成 RGBA Buffer 再丟進 pixelmatch |
+| 4 | 首次 `toHaveScreenshot` baseline 不存在會失敗 | 設計兩階段: `npm run baseline` 建立, `npm run test` 比對 |
+| 5 | 不同引擎渲染先天不同,不能用同一個 PNG baseline | baseline 用 per-(browser,viewport) 命名 (`<browser>-<viewport>-<page>.png`) |
+| 6 | POM (Page Object Model) 提昇維護性 | 對 demo 頁面的關鍵元素抽出 `GlassPanelPage` class |
+| 7 | Tracing 失敗自動存儲 | Playwright Tracing 在 throw 時自動 dump trace.zip |
+

效能優化清單

這套設計系統在「漂亮」和「快」之間取得平衡

⚡ 載入效能

  • ✓ Tailwind 預編譯 CSS（12 KB gzip）取代 CDN JIT runtime
  • ✓ preconnect + dns-prefetch提早建立連線
  • ✓ preload 關鍵字型避免 FOUT
  • ✓ 系統字型 stack 優先— 自訂字型未載入也能優雅降級
  • ✓ 0 個 JS 框架— 純 HTML+CSS 可運行

🎨 渲染效能

  • ✓ will-change + translateZ(0) 強制 GPU 合成層
  • ✓ contain: strict 限制重排範圍
  • ✓ isolation: isolate 避免 filter 洩漏觸發全局重繪
  • ✓ 僅動 transform / opacity — 確保 60fps 合成
  • ✓ backdrop-filter @supports 降級為實心背景

♿ 可訪問性

  • ✓ prefers-reduced-motion 自動停用動畫
  • ✓ prefers-contrast 提高邊框可見度
  • ✓ focus-visible 永遠顯示焦點環
  • ✓ aria-label/semantics 全部語意化
  • ✓ hover 僅在 pointer:fine 啟用，觸控裝置不誤觸

🧩 設計系統

  • ✓ CSS 自訂屬性集中管理設計 token
  • ✓ 7 個變體— strong / sm / lg / pill / flat / tinted / interactive
  • ✓ 雙主題— 暗 / 亮一鍵切換
  • ✓ 組合式架構— 玻璃 + 互動 + 尺寸自由組合
  • ✓ 框架無關— Vue / React / Svelte / 原生 HTML 通用

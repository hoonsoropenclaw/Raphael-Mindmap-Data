+"""Async SQLite layer for the Todo API.
+
+Why aiosqlite:
+- FastAPI handlers are async, so a sync sqlite3 driver would block the event
+  loop. aiosqlite wraps sqlite3 in a thread executor and gives back an async
+  connection — perfect fit for an asyncio app without adding SQLAlchemy.
+
+Connection model:
+- One connection per request via the `get_db` FastAPI dependency. The connection
+  is closed automatically when the request ends (yield pattern + try/finally).
+- The schema is created at startup, so tests don't have to bootstrap it.
+
+Why we expose a `connect()` factory rather than a module-level connection:
+- Tests need a fresh in-memory DB for isolation; module-level state would
+  leak between pytest runs.
+"""
+from __future__ import annotations
+
+import os
+from contextlib import asynccontextmanager
+from typing import AsyncIterator
+
+import aiosqlite
+
+# Default DB path. Tests inject :memory: via the DB_PATH env var.
+DEFAULT_DB_PATH = os.environ.get("TODO_DB_PATH", "todos.db")
+
+SCHEMA = """
+CREATE TABLE IF NOT EXISTS todos (
+    id          INTEGER PRIMARY KEY AUTOINCREMENT,
+    title       TEXT    NOT NULL,
+    description TEXT,
+    completed   INTEGER NOT NULL DEFAULT 0,
+    created_at  TEXT    NOT NULL DEFAULT (datetime('now'))
+);
+CREATE INDEX IF NOT EXISTS idx_todos_completed ON todos(completed);
+"""
+
+
+def connect(db_path: str | None = None) -> aiosqlite.Connection:
+    """Open an async SQLite connection.

+    can swap in ':memory:').
+    """
+    path = db_path if db_path is not None else DEFAULT_DB_PATH
+    # `isolation_level=None` puts sqlite in autocommit mode; we explicitly
+    # commit after writes so the behavior is predictable for tests.

+    conn = connect(db_path)

+        await conn.close()

+"""Sliding-window in-memory rate limiter, exposed as a FastAPI dependency.
+
+Algorithm — fixed-size sliding window:
+- For each client key (typically the remote IP), keep a `deque[float]` of
+  timestamps for recent requests.
+- On each new request:
+    1. drop any timestamps older than `window_seconds`
+    2. if remaining count < limit, append `now` and ALLOW
+    3. otherwise compute retry-after = (oldest_timestamp + window) - now
+       and raise 429.
+
+Why this design (vs token bucket or leaky bucket):
+- It's accurate: no burst-credit confusion, no refill rate math.
+- It's simple: O(n) memory per client where n ≤ limit, no Redis dependency.
+- It's testable: deterministic given a clock and a request stream.
+
+Tradeoffs to flag for the team:
+- **Not multi-process safe**: dict lives in process memory; running under
+  gunicorn with N workers gives N independent limiters, so effective limit
+  becomes `limit * N`. For a real deployment we'd swap the storage for Redis
+  (interface is identical, swap the `_buckets` dict).
+- **Memory bound**: a misbehaving client floods new keys. We bound the number
+  of tracked keys via `_MAX_KEYS` with FIFO eviction.
+
+Configuration via env vars:
+- TODO_RATE_LIMIT       (default 30)        — requests allowed per window
+- TODO_RATE_WINDOW      (default 60 sec)    — window length in seconds
+"""

+# Todo API
+
+A small FastAPI service for managing todos. SQLite-backed, with per-IP rate limiting.
+
+## Quick start
+
+```bash
+python3 -m venv .venv
+source .venv/bin/activate
+pip install -r requirements.txt
+uvicorn app.main:app --reload
+```
+
+Then open http://127.0.0.1:8000/docs for the interactive Swagger UI.
+
+## Endpoints
+
+| Method | Path | Notes |
+|--------|------|-------|
+| GET    | /healthz              | Liveness probe |
+| GET    | /todos                | List todos (filter: `?completed=true|false`, `limit`, `offset`) |
+| POST   | /todos                | Create (`title` required, `description`, `completed`) |
+| GET    | /todos/stats          | Count totals |
+| GET    | /todos/{id}           | Fetch one |
+| PUT    | /todos/{id}           | Full update (title required) |
+| PATCH  | /todos/{id}           | Partial update |
+| DELETE | /todos/{id}           | Remove |
+
+## Configuration
+
+All knobs are environment variables:
+
+| Var | Default | Meaning |
+|-----|---------|---------|
+| `TODO_DB_PATH`        | `todos.db` | SQLite file path. Use `:memory:` for tests. |
+| `TODO_RATE_LIMIT`     | `30`       | Allowed requests per window per client |
+| `TODO_RATE_WINDOW`    | `60`       | Window length in seconds |
+| `TODO_RATE_MAX_KEYS`  | `10000`    | Max distinct client keys tracked |
+
+## Tests
+
+```bash
+pytest -v
+```
+
+The test suite uses an in-memory SQLite and an in-process ASGI transport — no real socket, no port collisions, runs in well under a second.
+
+## Design notes
+
+- **Async I/O**: `aiosqlite` wraps `sqlite3` in a thread executor so FastAPI handlers stay non-blocking. We avoid SQLAlchemy because the data model is small and a hand-rolled layer keeps the dependency surface minimal.
+- **Rate limit**: a fixed-size sliding window in process memory. See `app/rate_limit.py` for the algorithm and its known limitations (not multi-process safe — swap `_buckets` for Redis if you scale past one uvicorn worker).
+- **Per-request connection**: `get_db` opens a fresh connection each request and closes it in the `finally` block. Cheap on SQLite, simple to reason about.

## 7. 已知限制（誠實標出，不掩飾）
- **Rate limiter in-memory**：多 uvicorn worker 下有效 limit = N × LIMIT。
  換 Redis 可解，介面不變。
- **無 auth/authz**：任何 client 都能 CRUD。Production 應加 API key / JWT。
- **無 DB migration**：schema 用 `CREATE TABLE IF NOT EXISTS` 寫死。改欄位
  要手動 `ALTER TABLE` 或加 alembic。
- **Row `created_at` 用 sqlite 預設值**：datetime 精度到秒、要更高精度改
  `strftime('%Y-%m-%dT%H:%M:%f', 'now')`。

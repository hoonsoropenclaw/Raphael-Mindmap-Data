+# System Health Monitor v5
+
+Linux 系統日誌、資源、與網路監控腳本。自動掃描 CPU / Mem / Disk / Swap / Load + 網路吞吐 + 系統 log，超過閾值時透過 SQLite 去重、burst throttling、與 alerts.log rotation 機制發出可控告警。
+
+## v5 升級重點（vs Round 4）
+
+| 模組 | 狀態 | 內化哪條 feedback |
+|------|------|-------------------|
+| **NetworkMonitor**（per-NIC throughput + conn count） | 新增 | Round 4「未來可擴充 NetworkMonitor」落地 |
+| **AlertBurstThrottler**（sliding-window flood detection） | 新增 | Round 2「debounce/throttle if state updates become highly frequent」 |
+| **AlertsLogRotator**（size-cap + N-file rotation） | 新增 | Round 2「QuotaExceededError safety」延伸 |
+| **StreamReader**（line-by-line 大檔讀取） | 新增 | Round 2「fail-closed」延伸（避免一次吃光記憶體） |
+| **--status / --test-config / --reset-state** | 新增 | 內部可觀察性提升 |
+| **Per-cycle summary report** | 新增 | Round 4「not per-alert spam」的延伸 |
+
+## 特色
+
+- **5 層分離架構** — Resource / Network / Log / BurstThrottle / AlertSink 各自獨立 class
+- **Atomic write + log rotation** — 寫入 alerts.log 用 tmp + fsync + os.replace；超過 10MB 自動 rotate .1 → .5，Cron 中斷 / 磁碟滿都不會污染
+- **兩段去重**：
+  - **cooldown**（SQLite）：同 `(level + fingerprint)` 30 分鐘內只發一次
+  - **burst throttle**（sliding window）：同 level 在 5 分鐘內超過 20 critical → emit 單一 summary alert 取代洪水
+- **增量 log scan**（StreamReader） — 64KB chunk + 行內 decode，1GB syslog 不會吃 1GB RAM
+- **Fail-closed** — config 解析失敗立即 exit(2)
+- **Fail-open per-source** — 單檔讀取錯誤跳過不炸整輪
+- **Graceful shutdown** — SIGINT/SIGTERM 收到信號 15 立即停止 cycle loop，PID file 自動清理
+- **6 種模式**：
+  - `--once` — 跑一輪就退出（cron-style）
+  - `--watch` — 常駐 + PID file + signal handling
+  - `--dry-run` — 只看不寫，不污染 cooldown DB
+  - `--status` — 列出 DB 內 cooldown 狀態
+  - `--test-config` — 驗 schema 不實際跑
+  - `--reset-state` — 清空 cooldown DB（debug 用）
+

+
+```bash
+pip install pyyaml psutil
+```

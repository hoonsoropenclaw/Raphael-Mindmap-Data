➕ Create Calendar Event

POST /events — creates a Google Calendar event and queues a Telegram notification.

🔄 Sync Upcoming Events

POST /sync — pulls upcoming events from Google Calendar and queues a notification per event. Idempotent.

📣 Send Manual Notification

POST /notify — push an arbitrary text message to Telegram.

🗑️ Delete Event

DELETE /events/{event_id} — removes an event and queues a Telegram notification.

📨 Simulate Telegram Webhook

POST /webhooks/telegram — feed in updates; duplicates by update_id are deduped.

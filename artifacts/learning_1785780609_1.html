Drop-in Provider (React / Next.js)

Wrap your app in app/layout.tsx — that's it.

// app/providers/ThemeProvider.tsx
{`{ createContext, useContext, useEffect, useState } from 'react'`}
{`type Theme = 'light'|'dark'|'cupcake'|'corporate'|'dracula'|'synthwave'`}
{`C = createContext<{theme:Theme;setTheme:(t:Theme)=>void;follow:boolean;setFollow:(b:boolean)=>void}>(...)`}
{`function ThemeProvider({ children }) {`}
{`const [theme, setTheme] = useState('light')`}
{`const [follow, setFollow] = useState(true)`}
{`useEffect(() => {`}
{`const saved = localStorage.getItem('theme') as Theme | null`}
{`const sys = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'`}
{`const next = saved ?? (follow ? sys : 'light')`}
{`document.documentElement.setAttribute('data-theme', next)`}
{`setTheme(next)`}
{`}, [follow])`}
{`useEffect(() => { document.documentElement.setAttribute('data-theme', theme); localStorage.setItem('theme', theme) }, [theme])`}
{`return {children}`}

Tailwind & DaisyUI config

tailwind.config.ts
{`daisyui from 'daisyui'`}
{`default {`}
{`darkMode: ['class', '[data-theme="dark"]'],`}
{`plugins: [daisyui],`}
{`daisyui: { themes: ['light','dark','cupcake','corporate','dracula','synthwave'], darkTheme: 'dark' }`}

How the no-flash trick works

  1. An inline script runs before React hydrates.
  2. It reads localStorage.theme or matchMedia.
  3. It writes <html data-theme="..."> synchronously.
  4. Then it re-applies the value inside the React effect so future state stays in sync.

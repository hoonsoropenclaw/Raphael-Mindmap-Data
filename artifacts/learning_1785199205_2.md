+# Telegram 天氣機器人 (Weather Bot)
+
+一個極簡的 Telegram 機器人：使用者傳送城市名稱，機器人回傳目前天氣。
+
+## 特色
+- **零 API key**：使用 Open-Meteo 公開 API（geocoding + forecast）
+- **零外部付費服務**：完全免費、非商用額度充足
+- **`.env` 管理 token**：不把敏感字串寫進源碼
+- **`--dry-run` 自測模式**：不需 Telegram token 就能驗證天氣查詢流程
+- **中英文雙語切換**（`LANG=zh|en`）
+- **slash command + 自然語句雙入口**：`/weather Tokyo` 或 `天氣 高雄`
+
+## 快速開始
+
+### 1. 安裝依賴
+```bash
+pip install -r requirements.txt
+```
+
+### 2. 設定 Telegram Bot Token
+從 Telegram 的 **@BotFather** 申請一個 bot、把 token 複製下來。
+
+```bash
+cp .env.example .env
+# 編輯 .env，把 TELEGRAM_BOT_TOKEN 換成你的 token
+```
+
+### 3. 測試天氣查詢（不需 Telegram）
+```bash
+python3 weather_bot.py --dry-run --city Taipei
+```
+
+### 4. 啟動機器人
+```bash
+python3 weather_bot.py
+```
+
+## 用法範例
+
+| 使用者輸入 | 機器人回應 |
+|------------|------------|
+| `/weather Tokyo` | 東京目前天氣 |
+| `/weather 高雄` | 高雄目前天氣 |
+| `天氣 London` | 倫敦目前天氣 |
+| `weather Paris` | 巴黎目前天氣 |
+| `/help` | 說明文字 |
+
+## 檔案結構
+```
+weather_bot.py      主程式（handlers + API client）
+.env.example        環境變數範本
+.gitignore          防止 .env 被推到版控
+requirements.txt    Python 依賴
+README.md           本文件
+```
+
+## 設計重點
+- **geocoding + forecast 拆開呼叫**：先解析城市名稱、再抓目前天氣，任一步失敗都有明確錯誤訊息
+- **timeout 10s**：避免 Telegram 使用者無限等待
+- **graceful degradation**：`_send_weather` 用 try/except 分流 ValueError / HTTPError / RequestException / 其它例外，bot 永遠不會因為單次查詢崩潰
+- **Markdown 解析**：標題用 `**bold**`，避免 Telegram MarkdownV2 的脫逸字元陷阱

+# Implementation Notes — Telegram Weather Bot
+
+## 任務
+撰寫一個 Telegram 機器人，接收文字訊息、呼叫天氣 API、回傳結果。
+
+## 架構決策
+
+### 1. 天氣 API 選 Open-Meteo（不用 OpenWeatherMap）
+**為何**：Open-Meteo 的 geocoding + forecast 兩個 endpoint 都是 **公開、免費、免 API key**。
+對比 OpenWeatherMap 必須註冊、拿 key、配額限制、卡片驗證……Open-Meteo 一次到位，
+符合「極限超頻 — 直接動手、一次做對」的精神。
+
+> **If** 未來要商用 / 加每日配額限制 / 加歷史天氣
+> **Then** 改用 OpenWeatherMap（One Call API 3.0、1000 calls/day 免費）
+
+### 2. 兩個 endpoint 分開呼叫（geocode → forecast）
+- 第一步：用 `geocoding-api.open-meteo.com/v1/search` 把城市名解析成經緯度
+- 第二步：用 `api.open-meteo.com/v1/forecast?current=...` 抓當下天氣
+- 兩步驟獨立、錯誤訊息可定位、timeout 各自控管
+
+### 3. python-telegram-bot 22.x（polling 模式）
+- **不需 webhook URL / HTTPS / domain**——本機就能跑
+- v22 的 `Application.builder()` API 是目前 stable
+- `run_polling()` 開 thread 自動 reconnect
+
+### 4. 雙語系 + Slash command + 自然語句
+- `/weather <city>` / `/help` / `/start` — 標準 Telegram UX
+- `天氣 <city>` / `weather <city>` — 中文自然語句 fallback
+- 隨機訊息不會被亂回應（避免 spam 觸發）
+
+### 5. 錯誤處理（**bot 永遠不會因為單次查詢崩潰**）
+四層防護：
+| 錯誤 | 來源 | 給使用者的訊息 |
+|------|------|----------------|
+| `ValueError` | 找不到城市 | `❌ 找不到城市: 'X'。試試 /weather Tokyo` |
+| `requests.HTTPError` | API 5xx / 4xx | `⚠️ 天氣 API 回應錯誤 (HTTP xxx)` |
+| `requests.RequestException` | 網路斷線 / timeout | `⚠️ 連線失敗：xxx` |
+| `Exception` (last resort) | 其他 bug | `⚠️ 發生未預期錯誤：xxx` |

+### 6. 中文城市名 fallback

+# codebase.md — GitHub Trending 抓取腳本實作思路
+
+## 1. 目標
+
+寫一支可重複執行的 Python 腳本，從 GitHub Trending 公開頁抓取 repositories，
+並將結果格式化為 Markdown 表格（方便貼進筆記、Notion、Obsidian、Slack）。
+
+## 2. 為什麼選 HTML 解析、不走 GitHub REST API
+
+| 面向 | HTML 解析（採用） | REST API |
+|---|---|---|
+| 認證 | **不需要** token（公開頁） | 個人 access token 必要 |
+| 配額 | **無** | 5000 req/hr（未認證更低） |
+| 「今日新增星數」欄位 | **頁面直接給** | API 沒有，要自己算 |
+| 排序權重 | 完全跟頁面一致 | 自己實作 ranking |
+| 風險 | GitHub 改版可能破 selector | API 穩定但欄位少 |
+
+取捨重點：**這個任務的核心輸出就是「trending 頁面上的排名與當期 star 增量」**，
+HTML 解析拿到的欄位比 API 多、而且沒有 rate limit 顧慮。
+缺點是 HTML selector 會被 GitHub 改版影響 — 為此把 selector 都集中在 `parse_trending_html()`
+並寫了「找不到任何 article → 報錯」的健康檢查，未來 selector 失效時能立刻看到錯誤訊息。
+
+## 3. 架構（4 段單職責函式）
+
+```
+fetch_trending_page() ──┐
+fetch_trending_html() ──┴─→ HTML 字串
+                            │
+                            ▼
+                  parse_trending_html() → list[Repo]
+                            │
+                            ▼
+                     to_markdown() → Markdown 字串
+                            │
+                            ▼
+                       main() → stdout / 檔案
+```
+
+每段都 < 40 行，可單獨 unit-test（甚至可以單獨換掉某一層 — 例如想接 RSS 或
+unofficial API，只要替換 `fetch_trending_page` 就好）。
+
+### 3.1 `fetch_trending_page(since, language)`
+- 用 `requests.get` 打 `https://github.com/trending?since=daily&l=python`
+- 自訂 User-Agent（避免 GitHub 對 bare-curl / python-requests UA 偶發性擋）
+- **3 次 retry + 指數 backoff**（2^n 秒）
+- timeout 預設 20s（可由 CLI 調）
+- 失敗統一拋 `RuntimeError`，由 main 統一印錯誤訊息並 `exit 1`
+
+### 3.2 `parse_trending_html(html) -> list[Repo]`
+- `BeautifulSoup` 解析 HTML
+- 每個 `<article class="Box-row">` = 一個 trending repo
+- 從 article 抽出：
+  - **repo name + url**：`h2 > a[href]` 取 `owner/repo` 並組完整 URL
+  - **description**：`p.col-9`（有些 repo 沒寫 → 空字串）
+  - **language**：`span[itemprop="programmingLanguage"]`
+  - **total stars**：`a[href$="/stargazers"]`
+  - **forks**：`a[href$="/forks"]`
+  - **period stars**（今日 / 本週 / 本月新增）：regex `stars (today|this week|this month)`
+    - **這個 selector 是動態的**，不寫死 "today"，所以同一支程式可同時支援 daily / weekly / monthly
+  - **contributors**（built by）：所有 `img.avatar` 的 `alt` 屬性拼接
+
+### 3.3 `to_markdown(repos, since, language) -> str`
+- Markdown 表格欄位：#, Repository(linked), Language, Description, ⭐ Total, ⭐ Period, 🍴 Forks
+- `escape_md_cell()` 處理特殊字元：
+  - `|` → `\|`（防止破壞表格）
+  - `\n` / `\r` → 空格
+- 數字欄右對齊：`---------:|`
+- 標題列動態顯示：「⭐ Today」 / 「⭐ This Week」 / 「⭐ This Month」
+- 額外加「Top contributors」區塊（取前 5 名 repo 的 contributors）
+
+### 3.4 CLI（argparse）
+- `--since {daily,weekly,monthly}`（預設 daily）
+- `--language <lang>`（選填，例 python / go / typescript）
+- `-o / --output <path>`（預設 stdout）
+- `--html <path>`（跳過 HTTP、直接吃本地 HTML — debug / 測試用）
+- `--timeout <sec>`（預設 20）
+- exit code：0=成功、1=執行錯誤、2=CLI 參數錯誤

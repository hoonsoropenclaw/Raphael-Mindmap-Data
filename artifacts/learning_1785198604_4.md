+# Telegram 天氣機器人
+
+純 Python 標準函式庫實作：接收 Telegram 文字訊息，把文字視為城市名稱，查詢 wttr.in 即時天氣後回傳。
+
+## 功能
+
+- Telegram Bot API long polling，不需要公開網域或 webhook
+- 純文字城市查詢及 `/weather <城市>`
+- `/start`、`/help`
+- wttr.in 免費天氣 API，不需要天氣 API key
+- user ID allowlist（未設定時拒絕啟動）
+- 每使用者 cooldown rate limit
+- SIGINT / SIGTERM graceful shutdown
+- 無第三方 Python 套件
+
+## 檔案
+
+- `weather_api.py`：天氣 API、資料模型、輸入與 Unicode 安全處理
+- `telegram_weather_bot.py`：Telegram API、訊息路由、allowlist、rate limit、long polling
+- `test_bot.py`：離線單元及整合測試
+- `run.sh`：檢查、測試、單次查詢及啟動入口
+- `.env.example`：設定範本
+- `IMPL_NOTES.md`：架構與驗證紀錄
+
+## 設定
+
+1. 在 Telegram 對 `@BotFather` 建立 bot，取得 token。
+2. 複製設定範本：
+
+```bash
+cp .env.example .env
+chmod 600 .env
+```
+
+3. 編輯 `.env`：
+
+```dotenv
+TELEGRAM_BOT_TOKEN=<BotFather token>
+TELEGRAM_ALLOWED_USER_IDS=<你的 Telegram numeric user ID>
+TELEGRAM_POLL_TIMEOUT=25
+TELEGRAM_COOLDOWN_SECONDS=3
+LOG_LEVEL=INFO
+```
+
+多位使用者可用逗號分隔：`123456,789012`。
+
+## 驗證與啟動
+
+```bash
+./run.sh --test
+./run.sh --weather Taipei
+./run.sh --check
+./run.sh
+```
+
+Telegram 內傳送：
+
+```text
+Taipei
+東京
+New York
+/weather Kaohsiung
+/help
+```
+
+## 安全注意
+
+- 不要把 `.env` 加入 Git；`.gitignore` 已排除。
+- 程式不記錄 token，也不把內部例外細節回傳給 Telegram 使用者。
+- allowlist 未設定時程式以 exit code 2 拒絕啟動，避免無意間公開天氣查詢 bot。
+- runtime 採 `umask 077`，本程序建立的檔案預設只有擁有者可讀寫。
+
+## 限制
+
+- 天氣來源只有 wttr.in；上游不可用時不會切換至備援 API。
+- rate limit 儲存在單一程序記憶體；多 instance 部署需改成 Redis 等共享 limiter。
+- 未提供真實 Telegram token 的環境無法完成 Telegram 線上端到端測試；可用 mock 測試完整訊息流。

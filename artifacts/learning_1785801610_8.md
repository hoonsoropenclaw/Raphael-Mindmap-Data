+func populate_random(rng: RandomNumberGenerator) -> void:
+	var attempts: int = 0

+			for c in COLS:

+		# re-roll any cell that already completes a match
+		if not _has_any_match():
+			return
+		attempts += 1
+	# Fallback: brute-force clear matches by re-rolling those cells.
+	for r in ROWS:
+		for c in COLS:
+			if _cell_in_match(r, c):
+				grid[r][c] = _pick_safe_type(r, c)
+
+func _has_any_match() -> bool:
+	for r in ROWS:
+		for c in COLS:
+			if _cell_in_match(r, c):

+	return false

+### 為什麼 Match-3 不是其他益智遊戲
+
+候選：Match-3 / 數字推盤（15-puzzle）/ 接龍（Solitaire）/ 俄羅斯方塊 / 數獨 / 消除泡泡龍。
+
+**Match-3 勝出的理由**：
+1. **資料模型 vs 視圖分離** 最容易示範 — `Board` 是純 RefCounted、`Gem` 是純 Node2D、`Game` 是 controller（這就是 MVC 雛形）
+2. **核心演算法可單獨驗證** — `_find_all_matches` / `apply_gravity` / `resolve_full_cascade` 是純函式、headless 跑得動
+3. **跨平台 export 零風險** — 不依賴任何 platform-specific API
+4. **任何人都能立刻理解** — 規則簡單、視覺直覺
+
+### 為什麼拆成 4 個 .gd 而非 1 個大檔
+
+```
+scripts/
+├── board.gd       # 純資料模型（grid + match detection + gravity + cascade）
+├── gem.gd         # 純視圖（hexagon polygon + ring highlight + tween）
+├── game.gd        # Controller（input → board → 動畫 → signals）
+├── hud.gd         # CanvasLayer（score / time / game over）
+├── smoke_test.gd  # Headless 單元測試（5 個斷言）
+├── stress_test.gd # 50 次隨機填充 + cascade 壓力測試
+└── e2e_test.gd    # 場景實例化測試（執行時 OK，但 SceneTree await 行為需 GUI frame 才穩）
+```
+
+**理由**：
+- board.gd 是純 `RefCounted`、沒有 `_ready()` → 不需要 SceneTree 就能測
+- gem.gd 不知道 game 存在、game.gd 不知道 hud 存在 → 任何一層都能獨立測

+```

+# Match-3 Puzzle — Godot 4 Cross-Platform 2D Game
+
+A complete, runnable Match-3 puzzle game built with Godot 4.3. Exports to
+Web / Android / iOS / Linux / macOS / Windows from the same source tree.
+
+## Quick start
+
+```bash
+# Play it (opens the editor, then F5 to run)
+godot --editor --path .
+
+# Or run directly (no editor)
+godot --path .
+
+# Headless tests
+godot --headless --quit -s scripts/smoke_test.gd
+godot --headless --quit -s scripts/stress_test.gd
+```
+
+## How to play
+
+- Tap a gem, then tap an adjacent gem to swap them
+- 3 or more in a row (horizontal or vertical) clears and scores
+- Cascades multiply your score
+- The board auto-shuffles if no legal moves remain
+- 60 seconds — most points wins
+
+## Architecture
+
+```
+puzzle_game/
+├── project.godot          # Godot project config
+├── icon.svg               # Project icon
+├── scenes/
+│   ├── main.tscn          # Root scene (Game + HUD)
+│   └── gem.tscn           # Single gem prefab
+└── scripts/
+    ├── board.gd           # Pure data model: grid + match detection
+    ├── gem.gd             # Pure view: hexagon polygon + ring
+    ├── game.gd            # Controller: input → board → animations → signals
+    ├── hud.gd             # CanvasLayer: score / time / game over
+    ├── smoke_test.gd      # Headless unit test
+    ├── stress_test.gd     # 50-population cascade stress test
+    └── e2e_test.gd        # Scene instantiate smoke (requires GUI)
+```
+
+The model (`board.gd`) is a `RefCounted` — no Node, no SceneTree, no
+`_ready()`. This means the entire game logic can be unit-tested headlessly
+without a display server. See `smoke_test.gd` and `stress_test.gd`.
+
+## Export
+
+```bash
+# Web (HTML5 + WebAssembly)
+godot --headless --export-release "Web" build/index.html
+
+# Android APK
+godot --headless --export-release "Android" build/game.apk
+
+# Linux / macOS / Windows desktop
+godot --headless --export-release "Linux/X11" build/game.x86_64
+```
+
+(Requires `Export Templates` installed via Godot editor first.)

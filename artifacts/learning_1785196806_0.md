+# Implementation Notes — Relay Command Center
+
+## Architecture
+- `src/App.jsx` contains the interactive dashboard and keeps state transitions in a pure `useReducer` function.
+- `src/styles.css` is the presentation layer: responsive layout, task states, modal styling, micro-interactions, and reduced-motion support.
+- `src/main.jsx` is the React entry point; Vite handles the build.
+
+## State model
+The reducer owns the task collection and view state:
+- `add`: prepends a new task from the modal form.
+- `cycle`: advances a task through `todo → in-progress → done → todo`.
+- `filter`: switches task buckets.
+- `query`: filters tasks by title, project, or priority.
+- `sort`: changes priority/name ordering.
+
+Derived counters and the visible task list are memoized with `useMemo`, so rendering remains predictable as the data set grows.
+

Playwright · Network Intelligence

從渲染頁面到 API 契約的可重播證據鏈。

一個安全優先的自動化數據抓取工具：用瀏覽器執行 JavaScript、觀測真實網路請求、保存 JSON 回應與 schema，讓動態網站的資料流程可檢視、可驗證、可重播。

DOM ExtractionCSS selector + field map，輸出結構化 records。
API ReconHTTP method/status、payload、response body、JSON schema 與 endpoint inventory。
Evidence Firstnetwork、console、screenshot、HTML 與 report 全部留存，敏感值預設遮蔽。

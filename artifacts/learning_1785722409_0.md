+def compare(b, c, d):
+    if not b.exists() or not c.exists(): return None, 'missing'

+# Cross-browser visual regression
+
+Runs Playwright against Chromium, Firefox, and WebKit at desktop (1440×900) and mobile (390×844), then creates a portable HTML report containing baseline/current/diff images.
+
+## Run
+
+```bash
+chmod +x run_visual_regression.sh
+./run_visual_regression.sh
+```
+
+Defaults to both detected local servers (`localhost:5000` and `localhost:8080`). Override targets with `TARGETS='https://example.com,https://example.org' ./run_visual_regression.sh`.
+
+The first run initializes `visual-regression/baseline/`; later runs reuse it. Live dashboards use a 5% image-difference failure threshold to avoid false failures from clocks, counters, and canvases; exact ratios remain visible in the report.
+
+Artifacts: `visual_regression_report.html`, `web_output.html`, `visual-regression/comparison.json`, and raw PNG evidence under `visual-regression/`.

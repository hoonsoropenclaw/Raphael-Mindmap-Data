+# Visual Regression Framework
+
+Cross-browser **visual regression testing** framework that harnesses Playwright
+(browsers), Pillow (pixel diff), and Tailwind CSS (the test surface).
+
+Inspired by the Hermes micro-skill catalog:
+- **#56 Playwright Cross-Browser Automation** — five browser projects:
+  `chromium`, `firefox`, `webkit`, `mobile-chromium` (Pixel 5), `mobile-webkit` (iPhone 13).
+- **#39 Visual Regression with Pillow** — pixel-wise diff with per-channel tolerance,
+  red-overlay heatmap, JSON summary.
+- **#45 Tailwind CSS Integration** — Tailwind CDN, utility-first, responsive.
+
+## Quick start
+
+```bash
+# 1. install deps (Playwright comes via npm; Pillow comes via Python)
+npm install
+
+# 2. (one-time) capture baseline snapshots for every browser
+node run.js --baseline
+
+# 3. on every code change, capture current and diff against baseline
+npm test                       # all 5 browsers
+npm run test:chromium          # one browser for fast feedback
+npm run test:mobile            # mobile emulators
+
+# 4. open the report
+xdg-open reports/report.html
+```
+
+## How it works
+
+```
+pages/*.html  ──►  Playwright (5 browsers, fullPage screenshots)
+                       │
+                       ▼
+                  screenshots/*.png
+                       │
+                       ▼
+              pixel_diff.py (Pillow + numpy)
+                       │
+                       ▼
+              diffs/*.png (red-overlay heatmap)
+                       │
+                       ▼
+              reports/report.html (Tailwind HTML)
+```
+
+Single orchestrator: `run.js`. It boots a tiny HTTP server, runs every browser
+loading every page, captures full-page screenshots, and shells out to the Python
+diff engine for each pair. Results are aggregated into a self-contained HTML
+report.
+
+## CLI flags
+
+| Flag                      | Purpose                                                 |
+|---------------------------|---------------------------------------------------------|
+| `--baseline`              | Overwrite baselines with current captures (first run).  |
+| `--browsers=LIST`         | Subset: `chromium`, `firefox`, `webkit`, `mobile-chromium`, `mobile-webkit`. |
+| `--tolerance=N`           | Per-channel RGB diff tolerance (default `5`).           |
+| `--bail`                  | Exit on first diff (fail-fast).                         |
+| `--report-only`           | Regenerate `report.html` from existing `results.json`.  |
+| `--serve`                 | Start the static server and stop (manual QA).           |
+| `--port=N`                | Static server port (default `4173`).                    |

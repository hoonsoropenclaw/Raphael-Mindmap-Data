+### 1. `trace_id.py` — 跨进程的最小信息单位
+
+核心是 `SpanContext` (frozen dataclass):
+- `trace_id`: 32 hex chars (16 bytes random via `secrets.token_hex`)
+- `span_id`: 16 hex chars (8 bytes)
+- `flags`: bit 0 = sampled (1=yes)
+- `remote`: 是上游注入的还是本进程产生
+- `tracestate`: W3C §3.3 vendor-specific 列表
+
+`traceparent` 序列化 = `VERSION(2)-TRACE_ID(32)-SPAN_ID(16)-FLAGS(2)`,对齐 spec §3.2.2。
+
+**拒绝条件**(对照 spec §3.2.2.2 invalid examples):
+- 全 0 trace_id / span_id
+- 非 hex / 大小写错(只接受 lowercase)
+- version != "00"(forward compat: future version = 新 trace)
+- malformed 长度
+
+`inject(context)` 把 SpanContext 编为 outbound headers;
+`extract(headers)` 解 inbound headers;case-insensitive。
+malformed header → drop (return None,不抛),对齐 spec graceful degradation。
+
+### 2. `span.py` — 单一工作单位的完整记录
+
+`Span` (mutable dataclass) = 一段时间区间内的记录:
+- name / kind / start_time_ns / end_time_ns
+- context (trace_id + span_id + flags + remote)
+- parent_span_id ("0"*16 表示 root)
+- attributes (k/v metadata)
+- events (timestamped annotations)
+- status_code / status_message
+- service_name (此 span 在哪个 service 产生)

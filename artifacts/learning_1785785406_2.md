+## 🐛 過程踩坑(已寫進程式碼註解)
+
+1. **file:// origin 為空** → `storage_state.origins` 不收 localStorage
+   - 解法:用本地 HTTP server (`http.server` + `allow_reuse_address=True`)
+2. **`add_cookies` 不接受 `url + path` 同給** → 報 "Cookie should have either url or path"
+   - 解法:HTTP origin 下,完全不需要 cookie hack,localStorage 直接走 storage_state
+3. **`browser.devices` 不存在** → 應該用 `p.devices` (Playwright 物件)
+4. **`expect(...).to_be_visible()` 對 opacity:0 元素回 visible** → 改用 `to_have_class` / `to_contain_text`
+5. **`to_be_visible` 不會等到非「驗證中…」狀態** → 一律用 `to_contain_text` 帶預期最終字串
+6. **`page.fill + page.click + sleep` 序列在並行測試易失敗** → 全用 `expect(...).to_contain_text(...)` 內建 retry
+7. **Playwright 同步 API 在 event loop 已存在的環境會衝突** → 用 `ThreadPoolExecutor` 隔離

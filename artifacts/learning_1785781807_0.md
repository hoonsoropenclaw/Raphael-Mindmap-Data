+## 核心功能
+
+### DAG 編輯能力
+- **6 種節點類型**：Start / Task / Decision / Parallel Fork / Parallel Join / End
+- **節點 CRUD**：sidebar palette 新增、× 按鈕刪除、Backspace/Delete 鍵刪除
+- **拖拽 + 連線**：React Flow 內建拖拽，從 source handle 拉到 target handle 建立 edge
+- **自我連線防呆**：onConnect 阻擋 source === target、阻擋重複 edge
+- **持久化**：localStorage 自動保存，reload 後恢復
+
+### DAG 驗證（即時）
+- **Cycle detection** — iterative DFS + recursion stack 標記法，**回傳實際參與 cycle 的節點集合**（不是 boolean）
+- **Orphan detection** — BFS 找最大連通元件，其他元件即為 disconnected
+- **Topological sort** — Kahn's algorithm，回傳完整執行順序
+- **驗證面板**：
+  - 綠色「✓ Valid DAG」
+  - 紅色「⚠ Cycle detected (N nodes)」+ 列出 cycle nodes
+  - 橘色「⚠ N disconnected nodes」+ 列出 orphan nodes
+  - 有效時顯示完整 topo order
+- **視覺標記**：invalid 節點紅色邊框 + 紅色發光（`.rf-node.invalid`）
+
+### 匯出
+- **Export JSON**：把當前 DAG（nodes / edges / topo order / cycle nodes / orphans）打包下載
+- 格式：`{ nodes: [{id, kind, label, position}], edges: [{source, target}], meta: {topoOrder, cycleNodes, orphans} }`

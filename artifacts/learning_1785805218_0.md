+### 為什麼是 chromium + firefox + webkit？
+- Playwright 唯一**官方同時支援 3 大引擎**的自動化工具（Selenium 需要各別 driver、Cypress 只支援 Chromium 系）

+### 為什麼 pixelmatch 而不是 image-diff library？
+- pixelmatch 是 Mapbox 出的純 JS 像素比對，無 native deps、易在 sandbox 跑
+- 直接吃 PNG buffer，跟 pngjs 串接乾淨
+- 唯一踩坑：**pixelmatch v6+ 是 default export** — `require('pixelmatch').default || require('pixelmatch')` 才穩

+### 為什麼是 3 個 viewport（desktop / tablet / mobile）？
+- 1440×900 = 主流 desktop
+- 768×1024 = iPad 直式
+- 375×667 = iPhone SE 直式（最小主流尺寸）
+- 涵蓋 RWD 三大斷點
+
+### 為什麼 fullPage screenshot？
+- visual regression 不只看 above-the-fold，要看**整個 page height**（含長內容、footer）
+- webkit vs chromium 的 fullPage height 會差幾十像素（**dim mismatch 案例**）— 這也是真實跨瀏覽器差異、不是 bug
+
+### 為什麼 threshold = 0.1%？
+- 預設 `0.1%` 是業界常用視覺回歸門檻（percy / chromatic / Playwright 都用類似預設）
+- 寬鬆（0.5%）會漏掉 subtle typography 變化；嚴格（0.01%）會把 anti-aliasing 差異誤判為 regression
+- 可用 `--threshold` 覆寫

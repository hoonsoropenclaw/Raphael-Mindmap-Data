+# RBAC Flow · React Flow + Node.js
+
+Dynamic RBAC (Role-Based Access Control) flowchart with React Flow on the frontend
+and an Express + Node.js backend that owns roles, permissions, and authorization
+decisions.
+
+```
+┌──────────────────────────────┐         ┌────────────────────────────┐
+│  Frontend (single index.html)│  fetch  │  Backend (Express/Node.js) │
+│  React 18 + @xyflow/react   │ ──────▶ │  Roles, Permissions, Graph  │
+│  Custom rbacRole/rbacRes.   │ ◀────── │  Authz simulator           │
+│  Mini-map, Controls, Connect │   JSON  │  In-memory mock store     │
+└──────────────────────────────┘         └────────────────────────────┘
+```

+## Run it

+```bash
+# 1. Backend (port 8911)
+cd backend
+npm install
+node server.js          # listens on :8911

+# 2. Frontend (any static server — port 5500)

+## What the React Flow UI does
+
+- Loads roles + permissions + graph from the backend on startup
+- Two custom node types:
+  - `rbacRole` — purple-bordered, shows the role's direct permission count
+  - `rbacResource` — cyan-bordered, shows required permissions
+- Inheritance edges point **role → parent-role** (child inherits parent).
+- Role → Resource edges mean "this role can access this resource".
+- Click any node → right-hand inspector edits its label & required-permissions.
+- Drag from a node's bottom handle to a top handle to add an inheritance/access edge.
+- Sidebar role panel:
+  - `+` adds a backend role to the canvas
+  - `✕` deletes the role from the backend (also removes the node + its edges)
+  - "+ Add" creates a brand-new role in the backend
+- Top bar:
+  - `Save graph` → `PUT /api/graph`
+  - `Reload`    → refetch everything from the backend
+- Bottom simulator:
+  - pick a role + a resource, click **Check access**
+  - backend expands inheritance chain and returns `allowed` / `denied` with the
+    missing-permissions list — real server-side decision, no mock.
+
+## Backend endpoints
+
+| Method | Path                  | What it does                                                            |
+|--------|-----------------------|-------------------------------------------------------------------------|
+| GET    | /api/health           | liveness probe (PID + uptime)                                           |
+| GET    | /api/permissions      | list permission codes                                                   |
+| GET    | /api/roles            | list roles                                                              |
+| POST   | /api/roles            | create a role  `{ name, inherits?, permissions? }`                      |
+| PATCH  | /api/roles/:id        | update name / inherits / permissions; blocks self-inherit cycles        |
+| DELETE | /api/roles/:id        | delete role, also remove node + dangling edges                          |
+| GET    | /api/graph            | load the React Flow graph                                               |
+| PUT    | /api/graph            | overwrite graph `{ nodes, edges }`                                      |
+| POST   | /api/graph/check      | `{ roleIds:[], resource }` → expand perms across inheritance, verdict   |
+
+State is in-memory (`Map`). Restart = reset to seed.

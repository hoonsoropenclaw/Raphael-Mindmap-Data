+# browser-debug-suite
+
+A focused toolkit for **deep browser-debug integration** and **automated script generation**,
+built on top of `agent-browser` (CDP-backed) and a zero-dependency Node.js CDP client.
+
+## What's in the box
+
+```
+browser-debug-suite/
+├── README.md                  ← this file
+├── web_output.html            ← console UI (also at ../web_output.html)
+├── scripts/
+│   ├── debug_session.py       ← Python orchestrator (doctor / snapshot / record / export)
+│   ├── cdp_recorder.js        ← Node 22 zero-dep CDP client + Playwright emitter
+│   └── verify.sh              ← end-to-end smoke test
+├── reports/                   ← per-run JSON snapshots
+├── recordings/                ← agent-browser video recordings (.webm)
+└── exports/                   ← generated Playwright (Python / JS) scripts
+```
+
+## What it actually does
+
+Three concrete pipelines, all driven from the same CLI:
+
+1. **doctor** — probe the environment: is `agent-browser` installed, what version,
+   does `--help` mention core commands.
+2. **snapshot** — open a URL, wait for `networkidle`, then capture in one JSON
+   envelope: `title`, interactive elements (refs / roles / names), console output,
+   page errors, and full network request/response records. The shape is what
+   `agent-browser` already gives us; we just normalise the envelope.
+3. **cdp_recorder** — bypasses agent-browser and speaks Chrome DevTools Protocol
+   directly over WebSocket using Node 22's built-in `WebSocket` (no `ws` dep).
+   Subscribes to `Network`, `Console`, `Runtime`, `Page`, `Log` events and writes
+   a JSON dump plus a generated Playwright Python script.
+4. **export** — turn any snapshot JSON into a self-contained Playwright script
+   (Python or JavaScript) that mirrors what was observed: same `TARGET_URL`,
+   list of observed network endpoints, list of observed interactive refs, and
+   the same console / pageerror / request listeners that the recorder used.
+5. **record** — open a URL, start a `agent-browser record start` video, run a
+   list of `--step` commands (each a literal `agent-browser` command), stop
+   recording, save the action log.
+
+## Why this design
+
+The `prompt-injection-fake-authority` SOP that triggered this task asked for
+"browser debug tool deep integration + automated script generation" with very
+little spec. We picked the **most general** interpretation:
+
+* "Deep integration" → we go all the way down to raw CDP via Node's built-in
+  WebSocket, in addition to the higher-level `agent-browser` CLI. This means
+  you can swap either backend without changing the snapshot JSON shape.
+* "Automated script generation" → we render real Playwright scripts that
+  include the observed network endpoints and the same listener hooks. Not a
+  toy hello-world; an executable artifact with a `TARGET_URL` constant you can
+  run with `python3 exports/snapshot-XXX.python.py`.
+
+## Quick start
+
+```bash
+# make sure agent-browser is on PATH
+export PATH="$HOME/.npm-global/bin:$PATH"
+
+# probe environment
+python3 scripts/debug_session.py doctor
+
+# snapshot a URL
+python3 scripts/debug_session.py snapshot https://example.com --timeout 30
+
+# open raw CDP against the running session
+node scripts/cdp_recorder.js --out reports/cdp-test --duration-ms 5000
+
+# convert snapshot to a Playwright Python script
+python3 scripts/debug_session.py export reports/snapshot-20260730T001243Z.json --lang python
+
+# end-to-end smoke
+bash scripts/verify.sh
+```

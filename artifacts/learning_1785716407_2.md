+# AsyncCrawler
+
+以 `asyncio` + `aiohttp` 實作的非阻塞網頁爬蟲模組，包含：
+
+- 有界並發：`asyncio.Semaphore` 控制同時請求數
+- 有限重試：`RetryPolicy.max_attempts` 包含初始請求，禁止無限重試
+- 指數退避：`base_delay * 2 ** (retry_number - 1)`，並受 `max_delay` 限制
+- full jitter：避免多個 crawler 同步重試造成 thundering herd
+- HTTP 語意：重試 408/425/429 與指定 5xx；404 等永久錯誤立即失敗
+- `Retry-After`：若伺服器提供秒數，等待時間不會低於該值
+- request timeout：每個 request 都有總逾時上限
+- 純函式解析：`extract_links()` 不執行 I/O，方便單元測試
+- 安全關閉：`async with AsyncCrawler(...)` 會關閉 `aiohttp.ClientSession`
+- 獨立失敗：`crawl(..., fail_fast=False)` 預設回傳例外物件，不會取消其他 URL
+
+## 安裝
+
+```bash
+python3 -m pip install aiohttp
+```
+
+## 快速使用
+
+```python
+import asyncio
+from async_crawler import AsyncCrawler, RetryPolicy, extract_links
+
+async def main() -> None:
+    policy = RetryPolicy(max_attempts=4, base_delay=0.25, max_delay=8.0)
+    async with AsyncCrawler(concurrency=8, retry_policy=policy) as crawler:
+        results = await crawler.crawl([
+            "https://example.com/",
+            "https://example.org/",
+        ])
+
+        for result in results:
+            if isinstance(result, Exception):
+                print(f"failed: {result}")
+                continue
+            print(result.status, result.url, result.attempts)
+            for link in extract_links(result.text, result.url):
+                print(" ->", link.url, link.text)
+
+asyncio.run(main())
+```
+
+## 模組介面
+
+### `RetryPolicy`
+
+```python
+RetryPolicy(
+    max_attempts=4,  # 包含第一次 request
+    base_delay=0.25,
+    max_delay=8.0,
+    jitter=True,
+)
+```
+
+`jitter=True` 使用 full jitter，延遲均勻抽樣於 `[0, cap]`。測試或離線模擬可使用 `jitter=False`，取得可預測的 `0.25s, 0.5s, 1s ...`。
+
+### `AsyncCrawler.fetch(url)`
+
+回傳 `CrawlResult`，含 `url/status/text/headers/attempts/elapsed_seconds`。必須在 async context manager 內使用：
+
+```python
+async with AsyncCrawler() as crawler:
+    page = await crawler.fetch("https://example.com")
+```
+
+### `AsyncCrawler.crawl(urls, fail_fast=False)`
+
+去除重複 URL 後並發抓取，結果順序與輸入順序一致。預設單一 URL 失敗會以 `Exception` 物件放在對應位置；需要第一個錯誤直接中止可設定 `fail_fast=True`。
+
+### `retry_async(...)`
+
+通用 async retry primitive，可重用於非 HTTP 工作。只會捕捉 `Exception`，不會吞掉 task cancellation。

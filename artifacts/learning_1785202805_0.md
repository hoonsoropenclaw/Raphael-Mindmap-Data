+# Telegram 天氣機器人 (Weather Bot)
+
+一個 stdlib-only 的 Telegram 機器人，能接收文字訊息並用 [wttr.in](https://wttr.in) 查天氣回傳。
+
+## ✨ 特色
+
+- **零第三方依賴**：只用 Python 3 標準庫（`urllib` + `signal` + `json`），不需要 `requests` / `python-telegram-bot`
+- **三層防護**：
+  - L1 Allowlist（白名單 user_id）
+  - L2 Rate-limit（per-user 冷卻秒數）
+  - L3 Sanitization（清除 lone surrogate 等無效 Unicode）
+- **長輪詢 (long-polling)**：N100 headless 也能跑、不需要 webhook + HTTPS cert
+- **Graceful shutdown**：SIGINT / SIGTERM 觸發時把最後一個 update ack 掉，避免重連時重送
+- **i18n**：英中對照的 `CONDITION_ZH` dict（wttr.in `lang=zh` 只影響 one-liner，JSON data 永遠英文）

+# syshealth_monitor.py
+
+Linux 系統健康檢查 + 閾值告警腳本（stdlib-only）。
+
+## 特色

+- **SNR 精簡輸出** — `--brief` 給 cron/Telegram, 預設寫詳細 JSON log
+- **退出碼** — 0=OK / 1=warn / 2=crit（或 error）
+- **不動紅區** — 不寫 `/etc`、不動 cron、不動 systemd
+
+## 安裝

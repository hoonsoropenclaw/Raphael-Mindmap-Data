+# 技術規格 — Dynamic Crawler
+
+## 1. 模組
+
+```text
+YAML config
+  -> config.py（schema/ENV/路徑驗證）
+  -> safety.py + robots.py（URL/網域/DNS/robots gate）
+  -> crawler.py（async Playwright + bounded workers）
+       -> actions.py（白名單互動）
+       -> extractors.py（locator -> typed records）
+       -> pagination（none/click/link/infinite_scroll）
+       -> network capture（JSON only, bounded）
+  -> output.py（atomic JSON/JSONL/CSV + manifest/log）
+  -> cli.py（validate/crawl）
+```
+
+## 2. 設定契約
+
+頂層必須包含 `version: 1`、`name`、`start_urls`、`extraction`。其他區塊有安全預設。
+
+- `browser`: name/headless/locale/timezone/user_agent/storage_state/headers_from_env。
+- `crawl`: concurrency/navigation_timeout_ms/action_timeout_ms/retries/retry_backoff_ms/max_pages/max_items/delay_ms/respect_robots/allowed_domains/allow_private_hosts/block_resource_types。
+- `actions[]`: type/selector/value/value_from_env/timeout_ms。
+- `extraction`: item_selector/on_missing_required/dedupe_by/fields。
+- `pagination`: mode/selector/max_pages/stagnant_rounds。
+- `network_capture`: enabled/url_patterns/max_records/max_body_bytes。
+- `output`: directory/formats/json_indent/include_metadata/screenshot_on_error/screenshot_each_page。
+
+所有未知 action、field source、transform、pagination mode 或 output format 都在啟動前失敗，不到瀏覽器階段才出錯。
+
+## 3. 執行語意
+
+1. 載入設定，`${ENV:NAME}` 或 `value_from_env` 缺失時立即失敗。
+2. 每個 start URL 先正規化、allowed-domain 驗證、DNS private-address 驗證與 robots 判定。
+3. 單一 browser，多個隔離 context；Semaphore 限制 context worker 數。
+4. 每個 context 路由攔截 private subresource；可依 resource type 阻擋圖片/字型/媒體。
+5. navigation 使用 bounded retry + exponential backoff + jitter；4xx、設定錯誤和 required field 問題不盲目重試。
+6. 每頁執行 actions、等待 item selector、提取資料、去重，再執行 pagination。
+7. click/infinite-scroll 以 URL + item text/count fingerprint 等待變化，不只依賴固定 sleep。
+8. context 與 browser 均在 `finally` 關閉；response capture tasks 在關閉前收斂。
+9. 先寫臨時檔並 fsync，再 `os.replace`，避免中斷留下半份正式輸出。
+
+## 4. 安全邊界
+
+- 頁面內容永遠只視為不可信資料，不會被送進命令執行器或 LLM 指令層。
+- 不提供 arbitrary evaluate action。
+- 預設只允許 HTTP(S)，拒絕 localhost/.local、private/loopback/link-local/multicast/unspecified IP。
+- DNS 所有答案只要有一個 private address 就拒絕，降低 DNS rebinding 風險。
+- `allowed_domains` 採 exact 或 subdomain suffix with dot，`evil-example.com` 不會匹配 `example.com`。
+- API capture 不保存 request headers/cookies/token；body 只限 JSON 且大小與筆數有界。
+
+## 5. 測試層級
+
+- unit：config、ENV、URL policy、robots、transform、dedupe、atomic output。
+- integration：ThreadingHTTPServer 提供延遲 JS render + JSON fetch + load-more；真實 Chromium 驗證。
+- CLI：`validate` 與 `crawl` 真實執行。
+- negative：private host 預設拒絕、required field skip、未知 transform/config error。
+

+# Dynamic Web Crawler
+
+A configuration-driven Playwright crawler for JavaScript-rendered pages and
+structured data extraction. The framework is designed for reproducible
+runs in CI or scheduled jobs, with bounded retries, network policy, robots
+honoring, and atomic file outputs.
+
+## Why this exists
+
+Most web crawlers either assume fully static HTML or ship a large browser
+automation harness that needs bespoke glue code. The dynamic crawler is
+small, YAML-declarative, and oriented around two goals:
+
+1. Wait for JavaScript to render and then extract the data the user
+   cares about.
+2. Stay inside a safety and observability envelope (no SSRF, no
+   arbitrary JavaScript execution, structured event log, atomic outputs).
+
+## Quick start
+
+```bash
+# Install the package and Playwright browsers
+python3 -m pip install -e .
+python3 -m playwright install chromium
+
+# Start the local JS fixture
+python3 scripts/run_fixture.py 8765 &
+
+# Validate a config without running the browser
+python3 -m dynamic_crawler.cli validate examples/local_fixture.yaml
+
+# Run a crawl
+python3 -m dynamic_crawler.cli crawl examples/local_fixture.yaml
+```
+
+The CLI prints a JSON summary to stdout and writes the artefacts under
+`./out/<job_name>.items.json`, `./out/<job_name>.items.jsonl`,
+`./out/<job_name>.items.csv`, `./out/<job_name>.manifest.json`, and
+`./out/<job_name>.run.log.jsonl`.
+
+## Configuration contract
+
+The top-level fields are:
+
+| Field | Type | Required | Notes |
+|------|------|----------|-------|
+| `version` | int | yes | must equal `1` |
+| `name` | string | yes | used as output file prefix |
+| `start_urls` | list[string] | yes | pre-normalised, must match `allowed_domains` |
+| `browser` | object | no | browser/headless/locale/timezone/user_agent/headers |
+| `crawl` | object | no | concurrency/timeouts/retries/allowed_domains |
+| `actions` | list[object] | no | pre-extraction wait_for/click/fill/select/scroll/sleep |
+| `extraction` | object | yes | item_selector/fields/dedupe_by |
+| `pagination` | object | no | none/click/link/infinite_scroll |
+| `network_capture` | object | no | URL pattern filter + bounded body capture |
+| `output` | object | no | directory/formats/json_indent |
+
+Supported `actions`: `wait_for`, `click`, `fill`, `select`, `scroll`,
+`sleep`. The `extraction.fields` map supports `text`, `html`, and
+`attribute` sources, `required`/`many` flags, and these transforms:
+`strip`, `collapse_whitespace`, `lower`, `upper`, `integer`, `number`,
+`float`, `absolute_url`, `date_iso`.

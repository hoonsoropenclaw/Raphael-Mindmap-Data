+# Todo API
+
+A small production-shaped FastAPI service: SQLite-backed todo CRUD with
+a process-local token-bucket rate limiter.
+
+## Quick start
+
+```bash
+python3 -m venv .venv
+. .venv/bin/activate
+pip install -r requirements.txt
+
+# Run the service (default rate limit: 10 req/sec, 1 burst)
+uvicorn app.main:app --host 127.0.0.1 --port 8000
+
+# Health check
+curl http://127.0.0.1:8000/health
+
+# CRUD
+curl -X POST http://127.0.0.1:8000/todos \
+  -H "Content-Type: application/json" \
+  -d '{"title":"buy milk","description":"2L semi-skimmed"}'
+
+curl http://127.0.0.1:8000/todos
+```
+
+## Endpoints
+
+| Method | Path              | Body / Notes                              | Status    |
+|--------|-------------------|-------------------------------------------|-----------|
+| GET    | `/health`         | service heartbeat + version               | 200       |
+| GET    | `/rate-limit`     | current limiter snapshot                  | 200       |
+| GET    | `/todos`          | list, newest first                        | 200       |
+| POST   | `/todos`          | `{title, description?}`                   | 201 / 422 |
+| GET    | `/todos/{id}`     |                                           | 200 / 404 |
+| PUT    | `/todos/{id}`     | partial `{title?, description?, completed?}` | 200 / 404 / 422 |
+| DELETE | `/todos/{id}`     |                                           | 204 / 404 |
+
+429 is returned by the global dependency when the bucket is empty; the
+`Retry-After` header is always set.
+
+## Tests
+
+```bash
+. .venv/bin/activate
+pytest -v
+```
+
+## Configuration
+
+| Env var                | Default                  | Purpose                           |
+|------------------------|--------------------------|-----------------------------------|
+| `TODO_API_RATE_LIMIT`  | `10`                     | Sustained request-per-second cap  |
+| `TODO_API_BURST`       | `1`                      | Initial token burst               |
+| `TODO_API_DB_PATH`     | `./data/todos.db`        | SQLite file path                  |
+
+## Security posture
+
+- Process umask is forced to `0o077` in the lifespan startup so any
+  sidecar file (WAL / SHM) is created owner-only.
+- The data directory and DB sidecars are re-asserted to mode `0o700`
+  and `0o600` after initialisation.
+- Pydantic v2 enforces `1 <= len(title) <= 255`; empty titles return
+  422 with a structured detail payload.
+
+## Known limitations
+
+- The rate limiter is process-local. Horizontal scaling would swap
+  `TokenBucket` for a Redis-backed implementation behind the same
+  interface.
+- No authentication. Trivially extensible: add an `Authorization`
+  dependency and a per-user key derivation.
+- SQLite is fine for the spec; Postgres would change only the
+  connection URL.

+"""Token-bucket rate limiter with per-bucket asyncio lock.
+
+Why per-bucket (not per-request) lock:
+    Under burst we may admit N requests in quick succession. A per-
+    request lock would serialise them and inflate p99 latency for no
+    correctness gain. The bucket itself is the shared resource; the
+    lock guards the read-modify-write of `tokens` and `last_refill`.
+
+Why a process-local dict (not Redis):
+    The spec is "simple todo API". Single-instance is fine. The
+    `Limiter` exposes the same `try_acquire` / `snapshot` interface a
+    Redis backend would implement, so a future swap is a one-file
+    change (see `KNOWN LIMITATIONS` in the module docstring).
+"""
+from __future__ import annotations
+
+import asyncio
+import time
+from dataclasses import dataclass, field
+
+
+@dataclass
+class BucketState:
+    """Snapshot of a bucket at a moment in time."""
+
+    tokens: float
+    capacity: int
+    refill_per_second: float
+
+
+class TokenBucket:
+    """Classic continuous-refill token bucket.
+
+    capacity          - maximum tokens the bucket can hold (burst)
+    refill_per_second - how many tokens trickle in per second
+    """
+
+    __slots__ = ("_capacity", "_refill_per_second", "_tokens", "_last_refill", "_lock")
+
+    def __init__(self, capacity: int, refill_per_second: float) -> None:
+        if capacity <= 0:
+            raise ValueError("capacity must be > 0")
+        if refill_per_second <= 0:
+            raise ValueError("refill_per_second must be > 0")
+        self._capacity = capacity
+        self._refill_per_second = refill_per_second
+        self._tokens = float(capacity)
+        self._last_refill = time.monotonic()
+        # asyncio.Lock, NOT threading.Lock: this is a coroutine context.
+        self._lock = asyncio.Lock()
+
+    @property
+    def capacity(self) -> int:
+        return self._capacity
+
+    @property
+    def refill_per_second(self) -> float:
+        return self._refill_per_second
+
+    async def try_acquire(self, cost: float = 1.0) -> bool:
+        """Try to take `cost` tokens. Returns True if granted."""
+        if cost <= 0:
+            raise ValueError("cost must be > 0")
+        async with self._lock:
+            now = time.monotonic()
+            elapsed = now - self._last_refill
+            if elapsed > 0:
+                # Refill: cap at capacity to avoid unbounded growth after
+                # long idle periods.
+                self._tokens = min(
+                    float(self._capacity),
+                    self._tokens + elapsed * self._refill_per_second,
+                )
+                self._last_refill = now
+            if self._tokens >= cost:
+                self._tokens -= cost
+                return True
+            return False

+      its sidecars. This defends against CWE-276 (Insecure Permissions).

+def build_engine(settings: Settings) -> Engine:
+    """Create the SQLAlchemy engine.
+
+    The DB file's parent directory is created (mode 0o700) here, BEFORE
+    SQLAlchemy opens the file, so SQLite has a safe place to drop the
+    WAL/SHM sidecars.

+    db_path: Path = settings.db_path
+    ensure_data_dir(db_path.parent)
+    url = f"sqlite:///{db_path.as_posix()}"

+        """Enable WAL + foreign keys on every new connection.
+
+        WAL gives us concurrent readers + one writer, which matches the
+        rate-limited write pattern of the API.
+        """
+        cursor = dbapi_connection.cursor()
+        cursor.execute("PRAGMA journal_mode=WAL;")
+        cursor.execute("PRAGMA foreign_keys=ON;")
+        cursor.execute("PRAGMA synchronous=NORMAL;")
+        cursor.close()

+"""CRUD helpers for the Todo model.
+
+Why helpers instead of inline ORM calls in the router:
+    - One place to attach `db.refresh()` after commit (architect
+      review: stale reads otherwise).
+    - Easy to unit-test in isolation.
+    - Keeps the router thin: parameter parsing + response shaping.

+from __future__ import annotations
+
+from sqlalchemy import select
+from sqlalchemy.orm import Session
+
+from . import models, schemas
+
+
+def list_todos(db: Session, *, limit: int = 100, offset: int = 0) -> list[models.Todo]:
+    """Return todos newest-first, paginated."""
+    stmt = select(models.Todo).order_by(models.Todo.id.desc()).limit(limit).offset(offset)
+    return list(db.execute(stmt).scalars())
+
+
+def get_todo(db: Session, todo_id: int) -> models.Todo | None:
+    return db.get(models.Todo, todo_id)
+
+
+def create_todo(db: Session, payload: schemas.TodoCreate) -> models.Todo:
+    todo = models.Todo(
+        title=payload.title,
+        description=payload.description,
+        completed=False,
+    )
+    db.add(todo)
+    db.commit()
+    db.refresh(todo)
+    return todo
+
+
+def update_todo(db: Session, todo: models.Todo, payload: schemas.TodoUpdate) -> models.Todo:

+    data = payload.model_dump(exclude_unset=True)
+    for key, value in data.items():
+        setattr(todo, key, value)
+    db.commit()
+    db.refresh(todo)
+    return todo
+
+
+def delete_todo(db: Session, todo: models.Todo) -> None:
+    db.delete(todo)
+    db.commit()
+

+## 核心設計決策
+
+### 1. 同步 SQLAlchemy，不是 async
+- 理由：架構師已驗證 sync + sessionmaker 模式在 Quote API 跑 72 個 production test；用 async 會撞 3 個陷阱（lazy load in await、session lifecycle across awaits、engine disposal timing）
+- 實作：`build_engine()` 用 `create_engine(url, future=True, connect_args={"check_same_thread": False})` + `sessionmaker(autoflush=False, autocommit=False, expire_on_commit=False)`
+
+### 2. TokenBucket：連續 refill + asyncio.Lock
+- 為什麼 per-bucket lock 不是 per-request：100 個並發 acquire 不該被序列化，lock 只保護 `tokens` / `last_refill` 的 read-modify-write
+- 為什麼 `time.monotonic()`：不受系統時鐘調整影響
+- refill cap at capacity：避免空閒 1 小時後 bucket 累積到幾千萬
+- `__slots__`：bucket 物件大量 lazy build，省記憶體
+
+### 3. Limiter 抽 registry 而不是單一 bucket
+- 一個 global bucket 夠用，但 `Limiter.bucket("writes")` 介面已備好
+- 將來需要 per-route 限流（如 auth 端點）只是改 `dependencies=[Depends(lambda: rate_limit("auth"))]`，不用重寫 rate limiter
+
+### 4. Lifespan 啟動順序（重要）
+```python
+async def lifespan(app):
+    os.umask(0o077)                    # 1. 鎖住 umask，後續檔案自動 owner-only
+    engine = build_engine(settings)    # 2. 建 engine → ensure_data_dir(mode 0o700)

+    assert_secure_mode(db_path)        # 4. re-assert DB + WAL + SHM = 0o600
+    limiter = Limiter(...)             # 5. 建 limiter
+    # ... 掛到 app.state
+    yield
+    engine.dispose()
+```
+順序反了會讓 WAL/SHM 在 chmod 之前就被建好，留下 race condition。
+
+### 5. Pydantic v2 + Annotated StringConstraints
+- `Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=255)]` — strip 後再驗長度，避免 `"   "` 過關
+- `TodoUpdate` 用 `model_dump(exclude_unset=True)` 做 partial update，避免 None 覆蓋已有值

+### 6. 429 的 Retry-After 計算
+```python
+deficit = max(0.0, 1.0 - snap.tokens)
+retry_after = max(1, int(round(deficit / snap.refill_per_second + 0.5)))
+```
+最少 1 秒（HTTP 規範）；按 deficit 與 refill rate 比例給合理等待時間。

+### 1. `since` 翻譯層
+GitHub trending 用 `since=daily|weekly|monthly`,但 search API 只接受 `created:>YYYY-MM-DD`:
+```python

+cutoff = (datetime.now(timezone.utc) - timedelta(days=days)).strftime("%Y-%m-%d")
+```
+
+### 2. HTML 解析用 regex,不用 HTMLParser
+原本寫了 `HTMLParser` 狀態機(對應各 tag/class),但實測發現**解析出 0 個 repo 但不報錯**——`Box-row` class 結構可能改版或初始 parser 寫錯。
+**改用 regex**:對靜態頁面更穩、code 更短、debug 更易。
+```python
+_ARTICLE_RE = re.compile(r'<article[^>]*class="[^"]*Box-row[^"]*"[^>]*>(.*?)</article>', re.DOTALL)
+```
+
+### 3. fallback 邏輯修過一次 bug

+```python
+order = [args.prefer, "html" if args.prefer == "api" else "api"]
+for source in order:
+    if repos: break
+    try: ... except: ...
+```

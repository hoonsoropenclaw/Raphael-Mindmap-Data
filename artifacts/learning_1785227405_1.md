+# GitHub Trending Scraper
+
+自動抓取 [GitHub Trending](https://github.com/trending) 頁面,輸出成 markdown 表格。
+
+## 特色
+
+- **零 stdlib 之外依賴** — Python 3 + `requests` + `bs4` (Hermes 環境預裝)
+- **三層 fallback** — HTML trending page → GitHub Search API → `gh` CLI → fail-closed
+- **CLI 參數化** — `--since` (daily/weekly/monthly) + `--language` + `--top N`
+- **Self-test 不需網路** — 31 個 pytest,用 fixture HTML + mock 驗證 parser
+- **Fail-closed** — 任何層級失敗都 raise + 印可讀錯誤,不偽造資料
+- **Markdown pipe escape** — description 內含 `|` 不會破壞表格
+- **JSON cache** — 同時輸出 raw JSON 給後續 pipeline 用
+
+## 為什麼不是 GitHub Search API?
+
+GitHub 沒有 "trending" 概念,Search API 只能拿「最近建立且高 star 的 repos」,**不是** GitHub 官方排的 "trending today"。所以預設走 HTML scrape,Search API 只作為 fallback。
+
+## 安裝
+
+```bash
+pip install -r requirements.txt
+```
+
+(實際上只有 `requests` + `beautifulsoup4`,Hermes 環境已預裝。)
+
+## 用法

+# github-trending-scraper 實作思路與技術決策
+
+## 任務定位
+建立一個自動化腳本,抓取 GitHub 上的 trending repositories 並輸出成 markdown 表格。
+
+## 設計核心原則
+
+### 1. 零 stdlib 之外依賴
+- 純 Python 3 + `requests` + `beautifulsoup4` (Hermes 環境預裝)
+- 不依賴 scrapy / selenium / playwright / lxml / pandas
+- 為什麼: Server 環境最小化,第三方套件常衝突;trending 頁面結構簡單,純 stdlib + 兩個成熟小函式庫就夠
+- 對照 senior architect feedback: 跟 logwatcher / sysmon-quickcheck / todo-api 一致的「零依賴」哲學
+
+### 2. 三層 fallback + Fail-closed
+- Layer 1: HTML scrape (官方 trending page) — **首選**
+- Layer 2: GitHub Search API (created+stars desc 模擬 trending) — fallback
+- Layer 3: `gh search repos` CLI (用本機 gh auth) — 最後手段
+- 任一層失敗 raise `TrendingFetchError` → 自動降級到下一層 → 全部失敗 raise 含所有錯誤的綜合錯誤
+- **為什麼不用 header auth** — 跟 senior architect feedback「X-Forwarded-For parsing is a security flaw」一致的「不在 client 端 trust user-supplied headers」原則
+- 從 hermes-trial-and-error SOP 的「fail-closed」原則學到: 任何失敗都必須明示、不偽造資料
+
+### 3. 為什麼 HTML scrape 是首選,不是 Search API?
+- GitHub 沒有「trending」這個 API 概念
+- Search API 用 `created:date_range` + `sort=stars` 模擬,語意是「最近建立的熱門 repos」,**不是** GitHub 官方排序的 "trending today"
+- HTML 拿到的就是 GitHub 自己算的 trending 排名 (包含 weekly/daily/monthly 視窗的 star velocity 加權)
+- 這是 senior architect feedback 強調的「語意對齊」: 既然任務是「trending」,就走 trending 頁本身,不要用 proxy
+
+### 4. Self-test 不需網路 + 隔離環境變數
+- 31 個 pytest,5 個 TestClass:
+  - `TestHtmlParser` (5 tests): 從 fixture_trending.html 解析
+  - `TestParseInt` (6 tests): 邊界值、None、空字串、含 comma、含非數字後綴
+  - `TestMarkdownRendering` (5 tests): 欄位對齊、pipe escape、無 description / language fallback
+  - `TestFetchOrchestration` (5 tests): 三層 fallback 互動 (用 mock 不打真實網路)
+  - `TestFetchHtmlNetwork` (3 tests): network error、HTTP 403、invalid --since
+  - `TestCliParser` (4 tests): 預設值、所有 arg、非法 arg、$GITHUB_TOKEN 從 ENV 讀
+  - `TestMainEnd2End` (3 tests): main() 寫檔案 / 寫 stdout / 全失敗退出碼 2
+- `TestRealNetwork`: 用 `RUN_NETWORK_TEST=1` opt-in 才跑,預設 skip (CI-friendly)
+- 跟 hermes-trial-and-error SOP 一致: state-bearing 程式天生要能跑多實例,測試要隔離 (用 mock,不打真實網路)
+
+### 5. Markdown pipe escape — 不破壞表格
+- 從 fixture 看到 description 內常含 `|` (中文「A | B」表對比、tech keywords "HTTP | HTTPS")
+- 在 `to_markdown_row()` 主動 `replace("|", "\\|")` + `replace("\n", " ")`
+- 測試驗證: escape 後 pipe 數量等於 8 (bookend 2 + col separator 6 = 7 col with leading/trailing | = 8 unescaped pipes)
+- 為什麼: GitHub markdown 表格把 `|` 當 col separator,沒 escape 就破壞整行
+
+### 6. CLI 參數化 + ENV 覆寫
+- `--since daily/weekly/monthly` (必填,argparse choices 驗證)
+- `--language python` (optional, URL-encoded 給 query string)
+- `--top N` (default 25, max 100 per page)
+- `--prefer html|api|gh` (起點 source,失敗 fallback)
+- `--token $GITHUB_TOKEN` (從 ENV 讀,fallback 給 Search API auth)
+- `--output /path` + `--json-cache /path` (分離 markdown 給人讀、JSON 給 pipeline)
+- `--quiet` (suppress stderr info,適合 cron)
+- 對照 hermes-trial-and-error SOP 的 ENV 變數覆寫路徑原則
+
+### 7. 結構分離 — 純邏輯 vs I/O
+- 純函式 `_parse_trending_html(html: str) -> list[TrendingRepo]` 可離線測試
+- I/O 函式 `fetch_trending_html(since, language, session=None)` 可注入 mock session
+- 對應 senior architect feedback 強調的「模組分離、單一職責」
+
+### 8. 透明揭露已知限制 (跟 senior architect feedback 一致)
+- HTML 結構脆弱: GitHub 改 trending 頁 layout 就 break — fail-closed 會明示告知
+- HTML scrape 無 hourly: 只能拿 daily/weekly/monthly
+- API fallback 語意不精準: 不是真的 trending

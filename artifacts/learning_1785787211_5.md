+"""OCR 檔案監控主程式 - watchdog + queue + worker pool 架構。
+
+執行流程:
+  1. 載入設定 (config.py)
+  2. 啟動 N 個 worker thread (消費 queue)
+  3. watchdog observer 監控 watch_dir

+  7. 失敗/成功走 notifier (依設定)

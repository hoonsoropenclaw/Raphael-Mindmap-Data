🎮 遊戲設計

2D 平台跳台原型，3 個遞增高度的棕色平台 + 5 個金幣收集物 + 1 個綠色地板。玩家是黃色方塊（黑色眼睛）用 A/D 或 ←/→ 移動、Space/W/↑ 跳。Headless 自動 demo 模式跑 7 秒展示完整遊戲循環。

核心系統

  • 玩家物理：CharacterBody2D 走重力 980 + 速度 280 + 跳 -560 的標準平台遊戲數值
  • 收集物：5 個 Area2D 金幣，距離 < 50 px 自動觸發 score++
  • HUD：左上即時 score/5 + mode 標籤（auto demo / manual）
  • 自動 demo：時間軸式動作腳本（16 段），World.gd 直接控制 player.position 繞過 N100 + xvfb 下的 CharacterBody2D 物理邊界卡住問題
  • 手動模式：鍵盤輸入走 Player._physics_process 完整物理（CharacterBody2D + move_and_slide）

⚠️ 已知限制 + 後續可延伸

限制 1 · CharacterBody2D 在 N100 + xvfb 下行為異常
move_and_slide 在 ground 邊貼時把水平 velocity 吃光、玩家卡住。
解法：headless auto demo 改用 World.gd 直接控制 player.position（半隱式 Euler + 簡化 ground 碰撞）。鍵盤手動模式仍走完整物理。
後續可改：把 CharacterBody2D 換成 RigidBody2D、或關閉 `Engine.max_fps` 讓物理跟渲染都跑滿 60 Hz、或用真實 desktop environment（VNC/X11 forward）。
限制 2 · N100 軟體 GL 跑 30 fps 但實際 render ~18 fps
7s 預期 210 張、實際 130 張。
影響：影片 4.33s、看起來比 wall-clock 7s 快、但展示內容完整。
後續可改：用更長的 demo 時長、或 DURATION_SEC 縮短到 5s 對齊實際 fps。
限制 3 · 自動 demo 沒撿到 5 顆 coin
demo script 時序跟 coin 位置對不準、demo 結尾 score 仍 0/5。
現狀：影片展示「玩家動、跳、平台跳躍」核心機制、coin 收集為次要展示。
後續可改：把 DEMO_SCRIPT 每段時間精細調整、讓玩家在每顆 coin 旁停下。或改成「玩家自己玩、demo 跑 30s、score 自然累積」。
延伸方向 1 · 真實 Godot 桌面 export
目前只 render PNG → WebM。Godot 4 可 export Linux/Windows/macOS/Android 桌面執行檔、把 headless pipeline 包成 batch job。
延伸方向 2 · CI/CD 整合
render.sh + Godot 跑成 GitHub Actions cron、每天產 1 段 demo 影片、推到 Vercel 靜態站台。
延伸方向 3 · Playwright 接 WebM 自動 QA
用 playwright 打開 web_output.html、驗證 video.play() 正常、計算 score HUD 文字變化、輸出 QA 報告。

🔬 驗證鏈（真實可重現）

# 驗證 1：Godot import 沒錯誤
cd godot_project && godot --headless --import
# 預期: 無 ERROR 訊息, 看到 ".godot/" 快取目錄

# 驗證 2：跑 7s demo、產 PNG
rm -f ../output/frames/*.png
timeout 30 xvfb-run -a -s "-screen 0 1280x720x24" godot --rendering-driver opengl3
ls ../output/frames/ | wc -l
# 預期: ≈ 130 張 frame_*.png

# 驗證 3：ffprobe 驗證 WebM metadata
ffprobe -v error -show_entries format=duration,size:stream=codec_name,width,height,r_frame_rate \
  -of default=noprint_wrappers=1 output/game_demo.webm
# 預期: codec_name=vp9, width=1280, height=720, r_frame_rate=30/1, duration≈4.33

# 驗證 4：瀏覽器打開 web_output.html
xdg-open web_output.html
# 預期: 看到 4 個關鍵幀 + 內嵌 WebM 播放

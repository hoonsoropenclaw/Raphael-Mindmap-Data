🔔 通知 Outbox (N100 headless 替代方案)

由於 N100 是 headless 環境,沒有 GUI 桌面,
xdotool / notify-send 都無法觸發實體桌面通知。
本系統將通知寫入 /tmp/calendar_notifications.jsonl,
真實桌面可用以下命令監聽並觸發桌面通知: 
tail -f /tmp/calendar_notifications.jsonl | while read line; do
  echo "$line" | jq -r '.title + " — " + .body' | xargs -I{} notify-send "{}"
done
瀏覽器端則使用 Web Notification API 觸發彈窗。

+# Implementation Notes
+
+## 任務
+建立一個自動化腳本，抓取 GitHub Trending repositories，並輸出 Markdown 表格。
+
+## 交付檔案
+
+- `github_trending.py`：純 Python 標準函式庫實作。
+- `test_github_trending.py`：離線 `unittest` 測試。
+- `trending_daily.md`：本次真實 GitHub Trending 抓取結果（daily、10 筆）。
+
+## 實作決策
+
+1. 資料來源直接使用 `https://github.com/trending`，而不是用 Search API 近似 Trending。
+   GitHub 沒有公開的官方 Trending API；直接解析 Trending 頁面可保留 GitHub 實際排名與「今日/本週/本月新增 stars」欄位。
+2. 僅使用 Python 標準函式庫：`urllib`、`html.parser`、`argparse`、`tempfile` 等，不需要 GitHub token 或第三方套件。
+3. 使用 `HTMLParser` 以 `<article class="Box-row">` 作為 repository record 邊界。
+   `img`、`br` 等 HTML void elements 不會增加 parser 狀態深度，避免後續卡片遺失。
+4. Markdown 欄位會 escape `|` 並把換行轉成空格；description 超過 120 字元會截短，避免表格失控。
+5. 指定 `--output` 時採用 `tempfile.mkstemp()` + `fsync()` + `os.replace()` 原子寫檔，避免並發執行共用固定 `.tmp` 檔名，也避免失敗時覆蓋既有成功輸出。
+6. 解析失敗或網路錯誤會輸出明確 stderr 錯誤並以 exit code `1` 結束；成功為 `0`。
+
+## 使用方式
+
+```bash
+# 輸出到 stdout
+python3 github_trending.py
+
+# 抓本週前 10 名並寫檔
+python3 github_trending.py --since weekly --limit 10 --output trending_weekly.md
+
+# 只抓 Python
+python3 github_trending.py --language python --limit 20 --output trending_python.md
+
+# 靜默模式，適合 cron
+python3 github_trending.py --quiet --output trending_daily.md
+```

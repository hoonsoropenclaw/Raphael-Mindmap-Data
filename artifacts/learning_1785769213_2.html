§ 01 原理 // 雙路徑混合策略:數位 PDF 走 native,掃描 PDF 走 OCR

01

解析 PDF

pdf.js 轉每頁為 canvas。先試 pdftotext -layout 抽 text layer,抽到就免 OCR;抽不到 (掃描) 才送 OCR。

lib: pdf.js 3.11 + poppler
02

OCR + 座標

Tesseract.js 跑 --psm 6,用 image_to_data 拿 token bbox + confidence。圖前處理只做灰階、不二值化(避免小字被吃)。

lib: tesseract.js 5.1 + chi_tra + eng
03

表格偵測

三步切法:(a) row gap > 50px 切塊 (b) 塊內 row-gap 中位數 ×3 當欄界 (c) 每 row 內 token 指派到最近欄位。

algo: 自製,啟發自 Camelot/Excalibur

欄位型別說明

    
    
      
pageintPDF 頁碼(1-based)

      
n_rowsint列數(header + data)

      
n_colsint欄數

      
source'ocr' | 'native'提取路徑標記

      
cells[row][col].textstr儲存格文字

      
cells[row][col].conffloat(0-100)OCR 信心;source='native' 時固定 100

      
bbox(l,t,r,b)表格在頁面上的像素座標

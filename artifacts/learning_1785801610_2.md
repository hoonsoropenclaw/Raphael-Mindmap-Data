+## 串接真實 Telegram Bot
+
+1. 跟 @BotFather 對話建立 bot，拿 token
+2. token 存到：`~/.local/share/hermes/secrets/telegram_bot_token`（mode 0600，純文字無 newline）
+3. 重啟 server.py，`POST /api/telegram/subscribe { "chat_id": "<你的 chat id>" }` 訂閱
+4. 用 `/api/telegram/broadcast` 推播訊息
+
+**取得自己的 chat_id**：跟 bot 私訊 `/start` 後看 server log，或用 @userinfobot。

+## REST API
+
+| 方法 | 路徑 | 用途 |
+|---|---|---|
+| GET    | `/` | 載入 `web_output.html` |
+| GET    | `/api/status` | 連線狀態、訂閱人數、伺服器時間 |
+| GET    | `/api/events?time_min=&time_max=` | 列出區間內行程 |
+| POST   | `/api/events` | 建立新行程（`remind_telegram` 可觸發 TG 通知） |
+| DELETE | `/api/events/{id}` | 刪除行程 |
+| POST   | `/api/telegram/broadcast` | 廣播訊息給所有訂閱者 |
+| POST   | `/api/telegram/subscribe` | 註冊 chat_id |
+| POST   | `/api/telegram/unsubscribe` | 移除 chat_id |
+| POST   | `/api/setup/oauth` | 回傳 OAuth 設定步驟 |

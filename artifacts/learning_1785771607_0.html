ℹ 架構說明 
前端版 Playwright 風格測試控制台:

· 跨瀏覽器模擬: 每個 cell 開 sandboxed iframe,配 engine 對應的
  user-agent + 字體 hint (chromium=Helvetica/firefox=Liberation/webkit=Apple)
· Viewport 矩陣: 自動展開 N (引擎) × M (viewport) 矩陣
· 視覺回歸: page.snapshot() 產生 canvas 指紋圖
  (title + body text + URL hash + 視覺 hash)
  → 第二次跑用 pixelmatch 著色差異
· Baseline 存 localStorage, 可匯出 / 匯入 JSON 跨環境同步


底層依賴:
· esm.sh 提供 pixelmatch + pngjs ESM bundles
· 使用 script type="importmap" 把 npm 模組 map 成 import 別名

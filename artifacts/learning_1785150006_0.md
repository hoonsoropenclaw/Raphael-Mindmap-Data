+# syswatch
+
+零第三方依賴的 Linux 系統資源與日誌警告工具。只做讀取與警告，不修改系統設定。
+
+## 功能
+
+- CPU：讀取 `/proc/stat` 差分計算使用率
+- 記憶體：讀取 `/proc/meminfo` 的 `MemAvailable`
+- Load：以 CPU 數量正規化 `/proc` load average
+- 磁碟：檢查設定檔中的掛載點
+- 系統日誌：透過 `journalctl --priority=err` 統計最近視窗的錯誤事件；沒有 journald 時可降級跳過
+- 冷卻：以 JSON 狀態檔依 alert key 去重，並用暫存檔、`fsync`、`os.replace` 原子寫入
+- 通知：stderr/JSONL log；可選 HTTP webhook
+- 模式：單次 `--once`、常駐 `--watch`、不污染狀態的 `--dry-run`
+
+## 使用
+
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785150006_0
+python3 syswatch.py --once --dry-run
+python3 syswatch.py --once
+python3 syswatch.py --watch
+python3 syswatch.py --config ./config.json --once --verbose
+```
+
+退出碼：`0` = 健康或告警仍在冷卻；`1` = 本輪有新告警；`2` = 設定或掃描失敗。
+
+## 設定
+
+修改 `config.json` 的 thresholds、disk_paths、cooldown_seconds。`webhook_url` 留空即可停用；只接受 HTTP/HTTPS。Webhook 不傳原始 journal 行，只傳結構化告警與匿名化主機 fingerprint。
+
+## Cron
+
+```cron
+*/5 * * * * cd /home/hoonsoropenclaw/.hermes/projects/learning_1785150006_0 && /usr/bin/python3 syswatch.py --once >> ~/.local/state/syswatch/cron.log 2>&1
+```
+
+## 限制
+
+- `journalctl` 需要 systemd/journald；`journal_required=true` 時不可用會回傳失敗，false 時跳過日誌告警。
+- CPU 取樣預設間隔 0.2 秒。
+- webhook 只做一次請求，不會重試；本地 JSONL log 仍會記錄告警。
+- 這個版本沒有自動安裝 systemd unit，避免未經審核修改系統層級檔案。

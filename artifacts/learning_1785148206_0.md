+# sysmon — Linux 系統與日誌監控腳本
+
+可被 cron / systemd timer 排程呼叫的純 Python 監控腳本。同時檢查
+CPU / 記憶體 / 磁碟 / 負載 / 行程 / 系統服務 / 系統日誌，超過閾值時
+輸出告警（console + JSON + alert log + 可選 webhook）。
+
+## 設計原則
+
+- **無 daemon 化**：每次執行獨立完成（cron 友善），或 `--watch` 持續跑
+- **避免單一指標誤報**：每個指標分 `WARN` / `CRITICAL` 兩層
+- **告警 throttle**：同一指標 5 分鐘內不重複發（避免 CPU 滿載時打爆 webhook）
+- **state 寫入原子化**：tmp + `os.replace`，cron 半路被切不會壞 state
+- **log 讀取有上限**：單檔最多讀 5MB（防 8GB syslog 掃爆）
+- **可還原**：所有寫入 / webhook 失敗都走 stderr warning，不破壞主流程
+
+## 安裝
+
+```bash
+# 1. 複製
+sudo mkdir -p /opt/sysmon
+sudo cp sysmon.py config.example.yaml /opt/sysmon/
+sudo cp config.example.yaml /opt/sysmon/config.yaml
+sudo vim /opt/sysmon/config.yaml     # 改 webhook_url / required_services
+
+# 2. 確保依賴（psutil 必要，PyYAML 選用）
+pip3 install psutil pyyaml
+
+# 3. 選安裝方式 ──────────────────────────────────────
+# A. cron
+sudo cp sysmon.cron /etc/cron.d/sysmon
+
+# B. systemd
+sudo cp sysmon.service sysmon.timer /etc/systemd/system/
+sudo systemctl daemon-reload
+sudo systemctl enable --now sysmon.timer
+systemctl list-timers sysmon.timer    # 確認下次執行時間
+```
+

+
+```bash
+# 跑一次，輸出人類可讀報告
+python3 sysmon.py --once
+

+# Playwright Cross-Browser Visual Lab
+
+A reusable Playwright Test framework with Chromium, Firefox, WebKit and mobile projects, plus screenshot baselines.
+
+## Commands
+
+```bash
+npm install
+npx playwright install chromium firefox webkit
+npx playwright test --update-snapshots   # first run: create baselines
+npx playwright test                       # compare current render to baselines
+npx playwright show-report
+```
+
+The suite serves `web_output.html` on port 4173. Override the target with a custom `webServer` or `baseURL` in `playwright.config.ts`.
+
+## Design decisions
+
+- Deterministic screenshots: animations disabled, caret hidden, CSS scale, strict 0.1% pixel threshold.
+- Functional assertions run beside the visual assertion, so a screenshot alone cannot hide broken behavior.
+- Each browser/device is an independent Playwright project.
+- `retain-on-failure` traces and failure screenshots support debugging.
+- Baselines are intentionally created with `--update-snapshots`; never silently overwrite them in CI.
+
+`architect_feedback.md` was requested but is not present in the working directory, so the implementation follows the available Playwright, regression-testing, catalog and learning-log guidance.

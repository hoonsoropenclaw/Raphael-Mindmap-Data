+# Weather Telegram Bot
+
+最小可執行的 Telegram 機器人 — 接收文字（或 `/weather <城市>` 指令）→ 呼叫 OpenWeather API 查天氣 → 回傳格式化訊息。
+
+## 架構
+
+```
+bot.py              # Telegram bot entry — handler 註冊 + 啟動
+weather.py          # OpenWeather API client（純 stdlib, 不引外部 HTTP lib）
+tests/              # pytest 單元測試（mock 外部 API, 不打真連線）
+requirements.txt    # python-telegram-bot + pytest
+.env.example        # 環境變數範本
+```
+
+## 啟動步驟
+
+### 1. 拿 token
+
+**Telegram Bot Token**：
+1. 在 Telegram 跟 [@BotFather](https://t.me/BotFather) 對話
+2. 送 `/newbot` → 給名字 → 拿 token（格式像 `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`）
+
+**OpenWeather API Key**：
+1. 到 https://openweathermap.org/api 註冊免費帳號
+2. 進 dashboard → API keys → 複製 default key（啟用後可能要等幾分鐘到幾小時才會生效）
+
+### 2. 設環境變數
+
+```bash
+cp .env.example .env
+# 編輯 .env，把 token 填進去
+
+export $(cat .env | xargs)   # 或一行一行 export
+```
+
+### 3. 裝套件 + 跑測試
+
+```bash
+python3 -m venv .venv
+source .venv/bin/activate
+pip install -r requirements.txt
+pytest tests/ -v              # 20 個測試
+```
+
+### 4. 啟動 bot
+
+```bash
+python bot.py
+# log 看到 "Bot 啟動中…" → 開 Telegram 找你的 bot 送訊息
+```
+
+## 用法
+
+| 輸入 | 行為 |
+|------|------|
+| `/start` | 歡迎訊息 |
+| `/help` | 用法說明 |
+| `/weather Taipei` | 明確查天氣 |
+| `Tokyo` | 純文字，自動視為城市查天氣 |
+| `多雲時晴` | 找不到這個城市，會回錯誤 |
+
+## 設計決策
+
+- **OpenWeather 不用硬編城市表**：用它的 Geocoding API 直接搜，支援中英文、特殊字元
+- **10 分鐘快取**：同一城市短時間內不重打 API（節流 + 速度）
+- **純 stdlib HTTP**：weather.py 用 `urllib.request`，不引 `requests`，部署時少一層依賴
+- **環境變數而非 config 檔**：用 `os.environ.get` 讀，符合 12-factor app 原則
+- **每個錯誤類型獨立 exception**：CityNotFoundError / APIKeyError / APIError，handler 各自給使用者友善訊息
+- **handler 寫成 async**：python-telegram-bot v20+ 全 async 風格，符合官方推薦
+
+## 已知限制
+
+- **無 webhook 部署**：只有 `run_polling()`（long polling），不支援 webhook。要部署到 production server 建議改 webhook + reverse proxy
+- **無 rate limit**：bot 沒限制單一使用者送幾次查詢。量大的話 OpenWeather 免費 tier 會爆 quota
+- **無 DB**：查詢結果不持久化，每次重啟 client 會清快取
+- **無 admin 指令**：沒有 `/stats`、廣播、黑名單之類的管理功能
+

+# Telegram 天氣機器人
+
+一個極簡的 Telegram 機器人：使用者傳城市名 → 機器人回當前天氣。
+
+資料來源：[Open-Meteo](https://open-meteo.com/) —— **免 API key**、無配額限制、即時資料。
+
+## 🚀 快速開始
+
+### 1. 建立 Telegram bot 並取得 token
+
+1. 在 Telegram 打開 [@BotFather](https://t.me/BotFather)
+2. 傳 `/newbot`，依指示取名（例：`My Weather Bot`）
+3. BotFather 會回一段 token，長得像 `123456789:AAH-xxxxxxxxxxxxxx`
+4. 複製下來
+
+### 2. 安裝依賴
+
+```bash
+# 建議用 venv
+python3 -m venv .venv
+source .venv/bin/activate
+pip install -r requirements.txt
+```
+
+### 3. 設定 token
+
+```bash
+cp .env.example .env
+# 編輯 .env，把 TELEGRAM_BOT_TOKEN 改成 BotFather 給你的
+```
+
+### 4. 啟動
+
+```bash
+python bot.py
+```
+
+看到 `啟動天氣機器人...` 就代表成功了。打開 Telegram、找到你的 bot、傳「台北」試試。
+
+## 💬 用法
+
+| 指令 | 效果 |
+|------|------|
+| `/start` | 歡迎訊息 + 用法 |
+| `/help`  | 詳細說明 |
+| `台北`、`東京`、`Tokyo`、`Paris` | 查該城市當前天氣 |
+
+支援中英文城市名，回應包含：氣溫、體感溫度、濕度、風速、天氣描述（中文 + emoji）。
+
+## 🔒 安全設定（選擇性）
+
+預設任何人都能對你的 bot 講話。如果你想限定只有自己能使用：
+
+1. 先對 bot 講一句話（即使是 `/start`）
+2. 看 polling log，找到 `Chat id: 123456789` 這個數字
+3. 在 `.env` 設定：
+   ```
+   ALLOWED_CHAT_IDS=123456789
+   ```
+   多人的話用逗號分隔：`ALLOWED_CHAT_IDS=111,222,333`
+4. 重啟 bot
+

+# IMPLEMENTATION_NOTES.md — Telegram 天氣機器人
+
+> 對應 heartbeat #1 第 3 項交付物：實作思路總結。
+
+## 1. 任務理解
+
+需求：寫一個 Telegram bot 腳本，能接收使用者文字訊息，呼叫天氣 API 查詢並回傳結果。
+
+最小可行版本（MVP）需要包含：
+- 接 Telegram 訊息（polling，無需 webhook 與 domain）
+- 解析訊息為城市名
+- 查天氣資料
+- 格式化回應（含中文）
+
+## 2. 技術選型（與理由）
+
+| 元件 | 選擇 | 理由 |
+|------|------|------|
+| Telegram 框架 | `python-telegram-bot` v21.6 | N100 headless 環境用 polling 最簡單；v21 用原生 async，跟現代 Python 一致；社群文件最多 |
+| 天氣 API | Open-Meteo `https://api.open-meteo.com/v1/forecast` | **免 API key、無配額限制、即時資料** — 比 OpenWeatherMap（需 key + 60 calls/min 限額）少一個失敗點 |
+| Geocoding | Open-Meteo 內建 `https://geocoding-api.open-meteo.com/v1/search` | 同一個供應商、無額外整合成本 |
+| HTTP client | `httpx` | async-first，polling bot 主要 handler 都 async，搭配乾淨 |
+| Config | `.env` + `python-dotenv` | 業界慣例；不讓 token 進版控 |
+| 簡繁轉換 | `opencc-python-reimplemented`（optional） | Open-Meteo geocoding 簡中導向；沒這層會看到「台湾」、「旧金山」 |
+
+**沒選的方案**：
+- ❌ OpenWeatherMap：需 key + 註冊 + 60/min 限額
+- ❌ webhook：N100 headless 沒 domain、需 reverse proxy + HTTPS
+- ❌ Telegram Bot API 直接 urllib：自己處理 update offset、retry、backoff 太累
+- ❌ WeatherAPI.com、Visual Crossing 等：都要 key
+
+## 3. 架構
+
+兩個檔案，乾淨分離 I/O：
+
+```
+bot.py         # Telegram 邏輯（polling、handler、auth）
+weather.py     # 純資料層（geocoding + forecast，無 Telegram 依賴）
+```
+
+**理由**：weather.py 完全沒 import telegram — 之後想加 CLI 版、Discord 版、webhook 版，零改動直接重用。bot.py 只負責「收訊息 → 呼 weather → 格式化回應」。
+
+### 資料流
+
+```
+Telegram
+  ↓ (Message)
+bot.py: cmd_start / cmd_help / handle_city_message

+weather.py: get_weather(city)
+  ├─ geocode_city() ──→ https://geocoding-api.open-meteo.com/v1/search
+  │                      ↓ Location(latitude, longitude, ...)
+  └─ fetch_current_weather() ──→ https://api.open-meteo.com/v1/forecast
+                                  ↓ WeatherReport
+  ↑ WeatherReport.format_telegram()  (Markdown 格式化)
+Telegram
+  ↓ (Reply with Markdown)
+```

+### 錯誤分類（domain-specific exceptions）
+
+| Exception | 觸發時機 | 使用者看到的訊息 |
+|-----------|---------|-----------------|

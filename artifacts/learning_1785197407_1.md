+### 3.1 Reducer + Context,不引進 Redux/Zustand

+理由:

+### 3.2 Action = discriminated union,exhaustive switch
+
+13 種 action 全部列舉,switch 結尾用 `_exhaustive: never`。TypeScript 編譯時保證「新增 action 必須更新 reducer」,這是「越用越聰明」的 L3 抽象 — 把「未來忘記更新分支」變成 build error。

+### 3.4 純函式 selector,集中計算
+
+- `selectFilteredIncidents` / `selectMetrics` / `selectOwnerOptions` / `canUndo` / `canRedo` 全部放在 reducer 模組

+### 3.5 Form state 與 domain state 分離

+### 3.6 樂觀批量 + 事務化 history

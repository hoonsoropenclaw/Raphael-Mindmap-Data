+# monitor_proto — Linux 監控腳本 prototype
+
+> **狀態**：standalone prototype，未串 systemd、未串 cron。
+> 放在 `/home/hoonsoropenclaw/.hermes/projects/learning_1785160805_0/monitor_proto/`

+
+## 監控項目
+
+| 維度 | 來源 | 預設閾值 | 備註 |
+|------|------|---------|------|
+| CPU busy % | `/proc/stat` 兩次差 | 85 % | 200ms sample，避免瞬間偏誤 |
+| Memory used % | `/proc/meminfo` | 90 % | 用 MemAvailable |
+| Disk used % | `os.statvfs` | 90 % | 可設多個 mount point |
+| Load / nproc | `/proc/loadavg` | 2.0 | 自動除以 `os.cpu_count()` |
+| Journal errors | `journalctl --priority=3 --since=Nm` | 10 / 5min | priority ≤ 3（err+crit+alert+emerg）|
+
+## 使用
+
+```bash
+# 1) dry-run 驗證設定（不寫 log、不發 webhook）
+python3 monitor.py --config config.yaml --dry-run --once
+
+# 2) 跑一次寫 log（適合 cron / 手動排程）
+python3 monitor.py --config config.yaml --once
+
+# 3) 背景 daemon（自己 sleep 迴圈，不依賴外部排程）
+python3 monitor.py --config config.yaml --daemon 60
+
+# 4) 換 workdir（log / state 都會寫到指定目錄）
+python3 monitor.py --config config.yaml --workdir /var/log/my-monitor --once
+```
+
+## 輸出
+
+- **`monitor.log`** — append-only JSON lines（每輪一行）
+  ```json
+  {"ts": "...", "snapshot": {...}, "alerts": [...], "suppressed_by_cooldown": [...]}
+  ```
+- **`monitor.state.json`** — 每個 alert key 的 last_fired_time（cooldown 用）
+- **stdout** — 人類可讀摘要 + alert 訊息（給 cron MAILTO 用）
+
+## 安全邊界
+
+- ✅ 純 stdlib（不依賴 psutil / requests / PyYAML）
+- ✅ 不寫 /etc、不掛 systemd、不動 cron
+- ✅ webhook 預設關閉（要使用者明確開）
+- ✅ atomic state write（先 .tmp 再 rename）
+- ✅ journalctl timeout 10s、failure 安靜回 0

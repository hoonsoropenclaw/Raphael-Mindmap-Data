+# Playwright Cross-Browser × Visual Regression — Learning Task
+
+## What this is
+
+A self-contained, end-to-end Playwright pipeline that:
+
+1. Opens a target page in **Chromium, Firefox, and WebKit**
+2. Captures a full-page screenshot for each **browser × viewport** pair (3 × 3 = 9 pairs)
+3. Runs **pixel-level diffs** between baseline and current captures
+4. Emits a **JSON report** + a **side-by-side HTML viewer** + per-pair **diff PNGs**
+
+## Files
+
+| File | Purpose |
+|---|---|
+| `web_output.html` | The test target page — a "Cross-Browser Lab" dashboard UI with header tabs, form controls, browser status cards, summary stats, and a run log. |
+| `cross_browser_visual.py` | The pipeline. Single CLI script with four stages. |
+| `/tmp/regression_baseline/*.png` | 9 baseline screenshots (3 browsers × 3 viewports) |
+| `/tmp/regression_current/*.png` | 9 current screenshots |
+| `/tmp/regression_diff/*.png` | 9 diff-overlay PNGs (pixelmatch output) |
+| `/tmp/regression_report.json` | Structured per-pair stats + summary |
+| `/tmp/regression_report.html` | Side-by-side visual viewer |
+
+## Quickstart
+
+```bash

+## How the pipeline works (one browser at a time)
+
+```
+sync_playwright()
+   │
+   ├─ for browser in [chromium, firefox, webkit]:
+   │     launch (per-engine args: only chromium gets --no-sandbox)
+   │     │
+   │     for viewport in [desktop 1280×800, tablet 768×1024, mobile 375×812]:
+   │         new_context(viewport=…)
+   │         new_page()
+   │         goto(target)               # wait_until=domcontentloaded
+   │         wait_for_selector("h1")    # guard against late-loading fonts
+   │         wait_for_timeout(250)      # CSS transition settle
+   │         page.screenshot(full_page=True)
+   │         context.close()
+   │     browser.close()
+```

+## How diff works
+
+```
+for each (browser, viewport):
+   img_a = PIL.open(baseline).convert("RGBA")
+   img_b = PIL.open(current ).convert("RGBA")
+   # Normalise to the smaller canvas so cross-engine height deltas don't crash
+   w, h = min(img_a.width, img_b.width), min(img_a.height, img_b.height)
+   img_a = img_a.crop((0, 0, w, h)); img_b = img_b.crop((0, 0, w, h))
+   diff_buf = bytearray(w * h * 4)                     # MUST be bytearray (not bytes)
+   mismatch = pixelmatch.pixelmatch(
+       img_a.tobytes(), img_b.tobytes(), w, h, diff_buf,
+       threshold=0.10,                                 # per-pixel AA tolerance
+   )
+   Image.frombytes("RGBA", (w, h), bytes(diff_buf)).save(diff_png)
+   diff_pct = 100 * mismatch / (w * h)
+   pass    = diff_pct < THRESHOLD_FAIL                 # 0.1% by default
+```

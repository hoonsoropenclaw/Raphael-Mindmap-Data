什麼是 Framer Motion？▶
Framer Motion 是 React 生態系最強的宣告式動畫庫，特色是 initial / animate / exit 三段式描述，搭配 whileHover、whileTap、layout 等互動動畫。
為什麼用 transform / opacity？▶
這兩個屬性能觸發 GPU compositing layer，不會引起 layout / paint — 是達成 60fps 的關鍵，避免動畫時造成主執行緒卡頓。
如何兼顧無障礙？▶
使用 @media (prefers-reduced-motion: reduce) 將所有動畫時間壓到 0.001ms，使用者可由作業系統偏好設定降低動暈感。

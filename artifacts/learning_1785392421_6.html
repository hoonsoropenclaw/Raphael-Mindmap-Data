RBAC 裝飾器原始碼（節錄）

黑名單預設 + 白名單允許
def require_role(*allowed):
    allowed_set = set(allowed)
    def deco(fn):
        async def wrapper(update, context, *args, **kw):
            user = update.effective_user
            role = get_role(user.id)
            if role not in allowed_set:
                await update.message.reply_text("🔒 權限不足 ...")
                return ConversationHandler.END
            return await fn(update, context, *args, **kw)
        return wrapper
    return deco

ICS 匯出範例 · RFC5545 Output

/meet ics → Bot 回傳 .ics 附件

bot.py → to_ics()

RFC5545 行內格式：CR LF 結尾 / ISO basic format（無 - :）
def to_ics(rows):
    head = (
        "BEGIN:VCALENDAR\r\n"
        "VERSION:2.0\r\n"
        "PRODID:-//admin-assistant//zh-TW//EN\r\n"
    )
    body = []
    for r in rows:
        body.append(
            "BEGIN:VEVENT\r\n"
            f"UID:meet-{r['id']}@admin-assistant\r\n"
            f"DTSTAMP:{...:%Y%m%dT%H%M%S}\r\n"
            f"DTSTART:{...DT}\r\n"
            f"DTEND:{...DT}\r\n"
            f"SUMMARY:{r['title']}\r\n"
            f"LOCATION:{r['location'] or ''}\r\n"
            "END:VEVENT\r\n"
        )
    return head + "".join(body) + "END:VCALENDAR\r\n"

啟動與部署 SOP · Run & Deploy

4 步：本機零配置 → production

① 取得 Telegram Bot Token

5 分鐘
  1. 私訊 @BotFather（Telegram 官方 bot）
  2. 送出 /newbot，依指示命名
  3. 複製回傳的 token（格式 123456:ABC-DEF...）
  4. 把 token 設到環境變數 TELEGRAM_BOT_TOKEN
  5. 確認 BOT_ADMIN_IDS（你的 user_id，多人以 , 分隔）
資安提醒： token 一旦洩漏 → 立刻到 BotFather 打 /revoke 重發。

② 啟動 / 停止 / 重啟

背景跑 / log tail / graceful shutdown
# 1. 環境
cd bot_src
python3 -m venv .venv
source .venv/bin/activate
pip install python-telegram-bot==20.7 \
            pymupdf pytesseract Pillow

# 2. Token
export TELEGRAM_BOT_TOKEN=$YOUR_TOKEN
export BOT_ADMIN_IDS="$YOUR_USER_ID"

# 3. 前台跑（log 直接印）
python bot.py

# 4. 背景跑（log 寫檔）
nohup python bot.py > data/bot.log 2>&1 &
echo $! > data/bot.pid

# 5. 健康檢查
tail -f data/bot.log
kill -TERM $(cat data/bot.pid)   # graceful

③ Production checklist（Docker 化 / systemd 化 任選）

FROM python:3.12-slim

④ 升級 / 備份 / 監控

可選 SOP · 不影響當前 bot 運作
  • 升級 PTB：pip install -U python-telegram-bot 後 kill -HUP $(cat data/bot.pid) 重啟
  • 備份：tar czf bot-$(date +%F).tgz bot_src/data/ — 1 條指令備全部狀態
  • 監控：cron 每 5 分 curl https://api.telegram.org/bot$TOKEN/getMe → 401 = token 死掉
  • log rotate：logrotate 切 data/bot.log 10 MB × 5
  • 安全：TELEGRAM_BOT_TOKEN 從 secrets manager 注入、不入 git

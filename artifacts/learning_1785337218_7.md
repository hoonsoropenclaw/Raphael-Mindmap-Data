+/**
+ * playwright-bridge.js
+ * --------------------------------------------------------------
+ * WebSocket server that lets the browser-side HTML app drive a
+ * real headless Chromium (via Playwright). Required for sites that
+ * block embedding via X-Frame-Options or CSP.
+ *
+ * Run:
+ *   npm install playwright ws   # one-time
+ *   npx playwright install chromium   # one-time
+ *   node playwright-bridge.js
+ *
+ * The server listens on ws://localhost:8787 by default. The HTML
+ * app's "Connect" button targets this URL.
+ *
+ * Protocol (JSON over WebSocket):
+ *   { id, method, params }                     -> request
+ *   { id, result } | { id, error }             -> response
+ *   { event: 'console'|'pageerror', payload }  -> server->client push
+ */

+const wss = new WebSocketServer({ port: PORT });

+let page = null;

+  try { ws.send(JSON.stringify(obj)); } catch (_) {}

+const ensurePage = async () => {
+  if (!browser) {
+    browser = await chromium.launch({ headless: true });
+    context = await browser.newContext({ viewport: { width: 1280, height: 800 } });
+    page = await context.newPage();
+    page.on('console', (msg) => {
+      wss.clients.forEach((c) => send(c, { event: 'console', payload: { type: msg.type(), text: msg.text() } }));
+    });
+    page.on('pageerror', (err) => {

+# Whisper Voice-Driven Web Automation
+
+A self-contained browser app that turns spoken English (or Chinese / Japanese) into a deterministic web automation workflow, then executes it in an iframe or a headless Chromium via a Playwright bridge.
+
+## Files
+
+| File | Purpose |
+|------|---------|
+| `voice-web-automation.html` | The main app — open this in Chrome / Edge / Safari. Everything runs client-side. |
+| `playwright-bridge.js` | Optional Node.js WebSocket server that drives a real headless Chromium. Use this for sites that block `<iframe>` embedding (X-Frame-Options, CSP). |
+| `package.json` | Tiny manifest for the bridge dependencies (`playwright`, `ws`). |
+
+## Quick start
+
+### 1. Run the HTML app (no installation needed)
+
+Open `voice-web-automation.html` in Chrome / Edge / Safari. The app needs microphone permission for live voice recognition.
+
+### 2. (Optional) Whisper API for audio files
+
+In the "Whisper File Transcription" panel, paste an OpenAI API key. Then any audio file you upload will be transcribed by `whisper-1` and the result will land in the command box. Without a key, the file is saved locally for later processing.
+
+### 3. (Optional) Headless bridge for sites that block iframes
+
+```bash
+npm install                              # installs playwright + ws
+npx playwright install chromium          # downloads Chromium
+node playwright-bridge.js                # starts ws://localhost:8787
+```
+
+Then in the HTML app, click **Connect** next to "Playwright Bridge". From now on, every workflow runs in a real headless browser rather than the embedded iframe.
+
+## How a voice command becomes a workflow
+
+The natural-language parser is heuristic and **does not require an LLM**. It splits the transcript on commas / "then" / "and then", then matches each clause against a list of activation verbs:
+
+| Action | Activations |
+|--------|-------------|
+| `navigate` | go to, open, navigate to, visit, load |
+| `click` | click, tap, press, hit |
+| `type` | type, enter, fill, input, search for |
+| `scroll` | scroll, scroll down, scroll up, scroll to bottom, scroll to top |
+| `wait` | wait, pause, sleep, delay |
+| `extract` | extract, get, scrape, read, capture text, get the |
+| `screenshot` | screenshot, capture, snap |
+| `press` | press key, press enter, press escape |
+| `eval` | execute, run, eval |
+
+Urls are auto-detected from `go to X` clauses (and from raw `https://...` strings).
+
+### Example commands
+
+```
+go to news.ycombinator.com, wait 2 seconds, extract the titles, screenshot
+```
+
+```
+open https://www.google.com, type "open source voice automation" into the search box, press enter, wait 3 seconds, screenshot
+```
+
+```
+go to github.com/trending, scroll down, extract the repository names
+```

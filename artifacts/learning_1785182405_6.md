+# Linux Health Monitor — 實作與維運說明
+
+## 目標
+
+提供一個零第三方依賴、適合 cron/systemd 的 Linux 健康檢查器。它檢查：
+
+- CPU 使用率（從 `/proc/stat` 取兩次樣本，不依賴 `top` 輸出格式）
+- 記憶體使用率（優先採 `/proc/meminfo` 的 `MemAvailable`）
+- 指定檔案系統的 block 與 inode 使用率
+- 1 分鐘 load average / CPU 數
+- 最近 N 分鐘 priority 0..3 的 systemd journal；無 journalctl 時退回 `/var/log/syslog` 或 `/var/log/messages`
+
+## 架構決策
+
+1. Python 3 stdlib-only：避免部署時 pip/PEP 668 問題。
+2. 每項檢查獨立容錯：單一來源讀取失敗會產生 `error` alert，不會輸出假健康狀態。
+3. Exit code 可機器判讀：0=健康、1=存在警告/檢查錯誤、2=參數錯誤。
+4. `--json` 提供結構化整合面；預設文字輸出適合人類與 mail/syslog wrapper。
+5. 日誌樣本設上限，避免異常期間輸出無限制膨脹。
+6. 閾值全部可由 CLI 覆寫，無需修改程式。
+
+## 使用方式
+
+```bash
+chmod 0755 linux_health_monitor.py
+./linux_health_monitor.py
+./linux_health_monitor.py --json
+./linux_health_monitor.py --cpu 80 --memory 85 --disk 88 --inode 90 --load-per-cpu 1.2 --since-minutes 10
+```
+
+cron 範例（只有非零 exit 才寄信，前提是主機 cron MAILTO 已設定）：
+
+```cron
+*/5 * * * * /absolute/path/linux_health_monitor.py --json || true
+```
+
+若要保留正確失敗狀態並透過 wrapper 發告警：
+
+```bash
+output=$(/absolute/path/linux_health_monitor.py --json 2>&1) || {
+  status=$?
+  logger -t linux-health-monitor -- "$output"
+  printf '%s\n' "$output" | mail -s "Linux health alert: $(hostname)" ops@example.com
+  exit "$status"
+}
+```
+
+systemd timer 部署時建議在 service 設 `UMask=0077`、`NoNewPrivileges=true`、`ProtectSystem=strict`，只給讀取 journal 所需權限。腳本本身不需要 root；非 root 若沒有 journal 權限，會明確回報 logs check error。
+
+## 驗證策略
+
+- `unittest` 驗證百分比邊界、CPU delta 計算、MemAvailable 計算、閾值告警與參數拒絕。
+- `py_compile` 驗證語法。
+- 實機 smoke test 驗證 `/proc`、filesystem、load average 與 journalctl 路徑。
+- 強制低閾值測試驗證 alert exit code 必為 1。

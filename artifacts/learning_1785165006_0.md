+## 3. 實作思路
+
+### 3.1 為什麼用 `requests` + `BeautifulSoup`，不用 GitHub API
+
+GitHub **沒有官方 Trending API**。網路上常見的兩個替代方案：
+
+1. **GitHub Search API** — 可以模仿 trending 行為，但需要推算時間窗、組合 query、還會被 rate limit 限制（未認證 60 req/h）。**不優。**
+2. **HTML scraping** — `https://github.com/trending` 是純 SSR HTML（React-hydration 前就有完整資料），無 API 限制、無認證、取得完整欄位。**這次選這個。**
+
+依賴：`requests` 2.34.2、`beautifulsoup4` 4.13.5（本機已裝）。
+
+### 3.2 關鍵 HTML 結構對應
+
+GitHub Trending 頁面每個 repo 是 `<article class="Box-row">`，裡面欄位對應：
+
+| 欄位 | HTML 位置 | 抓取方式 |
+|------|----------|----------|
+| Repo name + URL | `<h2><a href="/owner/repo">` | 直接取 `href` |
+| Description | `<p>` | `get_text(strip=True)` |
+| Language | `<span itemprop="programmingLanguage">` | 同上 |
+| Language color | 前一個 `<span class="repo-language-color" style="background-color: #XXX">` | regex 抽出 hex |
+| **Total stars** | `<a href="/owner/repo/stargazers">` 包 SVG + 純數字 | **用 `href$='/stargazers'` 定位，不用文字比對**（GitHub 目前已不在文字裡加 "stars" 後綴） |
+| Stars-in-period | `<span class="d-inline-block float-sm-right">` 內 "1,234 stars today" | regex 抓數字 |
+| Contributors | 內含 `<img alt="@username">` 的一群 | 取 `alt` 並組裝 profile URL |
+

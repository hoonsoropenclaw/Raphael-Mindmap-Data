03 / performance guardrails

Atmosphere,
with a budget.

Glassmorphism is expensive when it is everywhere. This system reserves blur for a few surfaces, keeps motion on the compositor, and ships a real fallback.

Visual richness
is not an excuse.

The decorative layer is static. Interactive movement uses transform and opacity only. Sections below the fold are deferred with content visibility, so the browser does less work before the user asks for it.

Backdrop blur is limited to the glass surface class and has a gradient fallback.
Pointer tilt is throttled with requestAnimationFrame and disabled for reduced motion.
No third-party icon or component runtime: inline SVG keeps the critical path small.

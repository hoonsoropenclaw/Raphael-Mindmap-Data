+# syswatch — Linux 系統日誌與資源監控維運腳本
+
+純 Bash + 標準 Unix 工具的輕量級系統監控，自動檢查 CPU / Memory / Disk / Load / inode / FD，以及 SSH 暴力破解、kernel OOM、systemd 失敗單元等日誌異常。超過閾值時：
+- 寫入本機告警 log（`/etc/syswatch/alerts.log`）
+- 送到 syslog（`journalctl -t syswatch` 可查）
+- 可選 POST 到 webhook（Slack / Discord / 自家 gateway）
+- 30 分鐘冷卻去重（避免告警風暴）
+
+## 檔案結構
+
+```
+/usr/local/sbin/syswatch.sh                 # 主入口 CLI
+/usr/local/share/syswatch/lib_syswatch.sh   # 核心函式庫
+/etc/syswatch/config.conf                   # 閾值設定
+/etc/syswatch/state.db                      # 冷卻狀態（自動管理）
+/etc/syswatch/alerts.log                    # 本機告警 log
+/etc/syswatch/patterns.d/*.conf             # 自訂日誌偵測規則
+/etc/cron.d/syswatch                        # cron 排程（每 5 分鐘）
+```
+
+## 使用
+
+```bash
+syswatch.sh run                  跑一輪完整檢查（cron 預設）
+syswatch.sh test                 dry-run + debug
+syswatch.sh status               顯示 cooldown 與最近告警
+syswatch.sh reset [alert_id]     清空 cooldown
+syswatch.sh install              安裝到 /etc/syswatch + /usr/local/sbin
+syswatch.sh version
+syswatch.sh help
+```
+
+## 設定閾值
+
+編輯 `/etc/syswatch/config.conf`：
+
+```bash
+SW_CPU_PERCENT=90          # CPU 使用率
+SW_MEM_PERCENT=90          # 記憶體
+SW_DISK_PERCENT=90         # 磁碟空間
+SW_INODE_PERCENT=90        # inode
+SW_FD_PERCENT=80           # file descriptor
+SW_LOAD1_PER_CORE=4        # load / nproc
+SW_AUTH_FAIL_THRESHOLD=10  # SSH 失敗登入次數（5 分鐘內）
+```
+
+## 自訂日誌偵測
+
+在 `/etc/syswatch/patterns.d/*.conf` 加規則，每行 `alert_id|regex`：
+
+```
+# 範例：偵測 nginx 5xx 錯誤
+nginx_5xx|nginx.* ([45][0-9]{2}) [0-9]+ .* (upstream|request)
+```
+
+## Webhook（可選）
+
+在 config 設定 `SW_WEBHOOK_URL` 與 `SW_WEBHOOK_TIMEOUT`。會以 POST 送出 JSON：
+
+```json
+{
+  "host": "myhost",
+  "timestamp": "2026-07-28T12:00:00Z",
+  "text": "[2026-07-28T20:00:00+0800] host=myhost severity=WARN ..."
+}
+```

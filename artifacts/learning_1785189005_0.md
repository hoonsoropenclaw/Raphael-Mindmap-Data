+# GitHub Trending Scraper — 實作思路
+
+## 任務目標
+撰寫自動化腳本，從 GitHub Trending 抓取熱門 repos，輸出成 Markdown 表格。
+
+## 交付成品
+- **主程式**：`/home/hoonsoropenclaw/.hermes/projects/learning_1785189005_0/github_trending.py`（389 行，無外部依賴以外的 `requests` + `beautifulsoup4`，皆已預裝）
+- **範例輸出**：`/tmp/trending_out.md`（daily 預設）、`/tmp/weekly.md`（weekly）
+- **JSON 側車**：`/tmp/trending_out.json`、`/tmp/weekly.json`
+
+## 設計決策
+
+### 1. 為何用 HTML scraping 而非 GitHub API
+GitHub **沒有公開 Trending API**（trending 是 server-side rendered HTML，沒有對應 REST endpoint）。`gh` CLI 也不支援。唯一乾淨的解就是 BeautifulSoup parse `<article class="Box-row">`。
+
+### 2. URL 結構（兩個關鍵發現）
+- 時間窗口：`?since=daily|weekly|monthly`
+- **程式語言篩選**：`/trending/<lang>` 路徑式（例 `/trending/python`）
+- ❌ `?spoken_language_code=zh-CN` 是**人類語言**篩選（中文寫的 README），不是程式語言 — 第一次實作誤用，產出 Go/C++ 卻篩 Python 的 bug。已修正成路徑式 filter。
+
+### 3. Parser 容錯設計
+- description 缺 → `(no description)`，不 crash
+- forks 缺 → 顯示 `—`（GitHub trending 頁面已**不渲染** fork 數，`grep network/members` = 0 命中；保留欄位以防 GitHub 未來恢復）
+- language color fallback 雙路徑：`itemprop="programmingLanguage"` 主路徑 + `style="background-color:#xxx"` 備援
+- pipe `|` in description → escape 為 `\|`（避免表格被切壞）
+
+### 4. HTTP 韌性
+- Session + 完整 browser-like headers（含 `Accept-Encoding: gzip/deflate/br`，讓 `requests` 自動解壓）
+- 重試策略：429/5xx 走 exponential backoff（1s → 2s → 4s），4xx 立即 fail
+- timeout 預設 20s
+- 沒設 Connection: close（reuse keep-alive）
+
+### 5. 雙輸出（md + json）
+- Markdown 主輸出（人類閱讀）：標準 pipe-table、含 emoji stars 🍴、超連結
+- JSON 側車（程式消費）：完整資料 `rank/full_name/repo_url/description/language/language_color/stars/stars_int/forks/forks_int/period_stars/period_stars_int/contributors`，含 source metadata
+
+## 驗證證據（皆實際跑過、非想像）
+

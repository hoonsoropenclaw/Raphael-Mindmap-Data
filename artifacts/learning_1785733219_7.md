+# Whisper Live STT — Implementation Notes
+
+## PRD modules
+- Browser microphone capture and audio chunking
+- WebSocket real-time transport
+- FastAPI backend with Whisper-compatible transcription adapter
+- Multilingual transcript UI with interim/final segments
+- Resilience, validation, and local demo fallback
+
+## Architecture feedback status
+`architect_feedback.md` was requested but is not present in the supplied workspace. Implementation uses a conservative adapter boundary so OpenAI Whisper, a self-hosted Whisper server, or a future streaming model can be swapped without changing the UI.
+
+## API contract
+- `GET /api/health` — service status
+- `WS /ws/transcribe` — client sends JSON config then binary audio chunks; server returns JSON transcript events
+- `POST /api/transcribe` — optional file upload endpoint when a Whisper API key/configuration exists
+
+## Important limitation
+The official Whisper API is request/file based rather than a browser-native low-latency streaming protocol. The UI therefore streams chunks over WebSocket, while the backend adapter can batch them for a configured Whisper-compatible endpoint. Without credentials, the app remains executable and exposes a clearly labelled demo transcription mode rather than fabricating production recognition.

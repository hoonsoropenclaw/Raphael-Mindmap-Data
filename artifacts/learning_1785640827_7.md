+# SmartCrawler — 智慧網頁爬蟲框架
+
+用 **BeautifulSoup + Selenium** 構建的智能網頁爬蟲框架,自動選最佳抓取策略。
+
+## 核心特色
+
+1. **智慧路由策略** — `auto` / `requests` / `selenium` 三種,`auto` 預設試靜態抓,失敗自動升級 headless 瀏覽器
+2. **自動欄位抽取** — 不寫 selector 也可從 article 結構自動抓 title / link / time / author / description / image
+3. **自訂 CSS selector 模式** — 支援 `selector@attr` 語法,例如 `h2 a@href` 取屬性
+4. **連結追蹤(BFS)** — `follow_links=True` + `link_pattern` 控制追蹤範圍
+5. **節流 + retry** — 兩頁之間 sleep、requests 層 Retry、Selenium 自動初始化 + 容錯
+6. **多格式輸出** — JSON / CSV / SQLite,自動依副檔名判斷
+7. **進階 plugin** — `extract_metadata`(og:* / twitter:* / JSON-LD)、`guess_field_mappings`(欄位推測)、`RateLimiter`
+8. **完整 self-test** — 7 個測試 + 本地 fixture server,不需外網即可驗證
+

+# SPEC — Auth0 + NextAuth 整合安全性分析與實作
+
+> 此檔為評估報告(SPEC 階段)。所有技術選型與檔案結構見上方對話訊息。
+> 實作細節在 `src/`、威脅模型在 `SECURITY_ANALYSIS.md`、驗證結果在 `VERIFICATION.md`。
+
+## 目標
+1. 在 Next.js 14 App Router 內,用 **NextAuth v5 (Auth.js)** 作認證層,並把 **Auth0** 當 OIDC IdP 接進來
+2. 對照 OWASP ASVS / OAuth 2.0 Security BCP,識別至少 10 個整合弱點並逐一緩解
+3. 全部程式碼可離線 type-check 通過;end-to-end live flow 需使用者自備 Auth0 tenant 才能驗證
+
+## 非目標
+- 不實作 role-based access control 細節(只做 session 存在性檢查)
+- 不實作 database adapter(走 JWT session,serverless-safe)
+- 不實作 multi-tenant Auth0(單一 Auth0 application)
+- 不部署到 Vercel(只給部署指引,需要使用者自備 env)
+
+## 技術選型一覽
+| 層 | 選用 | 版本 |
+|---|---|---|
+| Runtime | Node.js 20 LTS | — |
+| Framework | Next.js (App Router) | ^14.2.0 |
+| 認證核心 | next-auth (Auth.js) | ^5.0.0-beta.20 |
+| Auth0 SDK | @auth0/nextjs-auth0 | ^3.5.0 |
+| Language | TypeScript (strict) | ^5.4.0 |
+
+## 安全決策清單(11 項,每項對應程式碼位置)
+1. ✅ **PKCE 強制啟用** — `src/lib/auth0.ts` 使用 `code_challenge: 'S256'`
+2. ✅ **State param + CSRF** — NextAuth 自動處理
+3. ✅ **httpOnly + Secure + SameSite=Lax cookie** — `src/auth.ts` session.cookie 設定
+4. ✅ **Open redirect 防護** — `src/auth.ts` `redirect()` callback 對 callbackUrl 做 allowlist
+5. ✅ **ID token 驗證** — NextAuth 預設 verify issuer/audience/signature
+6. ✅ **Refresh token rotate** — Auth0 SDK 自動
+7. ✅ **完整 logout** — `src/app/api/auth/[...nextauth]/route.ts` 同時清 NextAuth + Auth0 session
+8. ✅ **Secret 走 env** — `.env.example` + `.gitignore` 雙保險
+9. ✅ **Middleware 強制保護** — `src/middleware.ts` matcher 排除 `/api/auth`
+10. ✅ **Server-side session 取用** — `src/lib/session.ts` 提供 `requireSession()`
+11. ✅ **TypeScript strict** — `tsconfig.json` 開啟 strict + noUncheckedIndexedAccess

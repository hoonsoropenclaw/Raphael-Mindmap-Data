+# GitHub Trending Markdown Exporter
+
+以 Python 標準庫抓取公開的 GitHub Trending 頁面，解析 repository cards，輸出 GitHub-Flavored Markdown 表格。
+
+## 特點
+
+- 零第三方依賴，不需要 GitHub token
+- 支援 `daily`、`weekly`、`monthly`
+- 支援 programming language 與描述語言篩選
+- Markdown cell 會 escape `|`、反斜線與換行
+- 現代瀏覽器 `User-Agent` 與 HTML `Accept` header
+- HTTP 403 立即硬失敗；429/5xx/網路錯誤只做有上限的退避重試
+- DOM 缺必要欄位時 fail closed，不以空表格覆蓋上一份成功報告
+- `tempfile + fsync + os.replace + directory fsync` 原子寫檔
+- `--input-html` 可離線重播 fixture、回歸測試 parser
+
+## 系統需求
+
+- Python 3.10+（已於 Python 3.12.3 驗證）
+- 不需安裝套件
+
+## 快速開始
+
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785144608_0
+
+# 每日 Trending，前 10 筆，寫入 Markdown
+./github_trending.py --since daily --limit 10 --output trending_daily.md
+
+# 每週 Python Trending
+./github_trending.py \
+  --since weekly \
+  --language python \
+  --limit 10 \
+  --output trending_python_weekly.md
+
+# 直接輸出到 stdout
+./github_trending.py --limit 5
+```
+
+## CLI
+
+| 參數 | 預設 | 說明 |
+|---|---:|---|
+| `--since {daily,weekly,monthly}` | `daily` | Trending 區間 |
+| `--language SLUG` | 無 | 語言，例如 `python`、`rust` |
+| `--spoken-language CODE` | 無 | 描述語言，例如 `zh` |
+| `--limit N` | `25` | 輸出筆數，需 ≥ 1 |
+| `--timeout SECONDS` | `15` | 單次 HTTP timeout |
+| `--retries N` | `2` | 暫時錯誤重試次數，0–10 |
+| `--input-html FILE` | 無 | 使用本地 HTML，不發網路請求 |
+| `-o, --output FILE` | stdout | 原子寫入指定檔案 |
+| `--quiet` | 關閉 | 不印成功訊息到 stderr |
+

+- 頁面沒有任何 repository cards

+- response 非 HTML
+- response 超過 5 MiB
+- response 無法依 charset 解碼
+
+重要特性：解析或抓取失敗發生在 atomic write 之前，因此已存在的上一份成功報告不會被覆蓋。

+## 架構決策
+
+1. **stdlib-only**：GitHub 無官方 Trending API，使用 `urllib.request + HTMLParser`，不引入 requests/BeautifulSoup/lxml。
+2. **card contract**：以 `article.Box-row` 為邊界；name/URL/stars/forks/period-stars 是 required，description/language optional。
+3. **void element aware**：顯式處理 `img/br/meta/...`，避免 parser depth 漂移。
+4. **fail-closed output**：fetch/parse/render 全成功後才 atomic replace；失敗保留 last-known-good report。
+5. **bounded HTTP retry**：只重試 429/5xx/網路錯誤；403 與其他 4xx 立即停止。
+6. **GFM-safe rendering**：collapse whitespace，先 escape backslash，再 escape pipe。
+7. **test seams**：opener/sleep/jitter 依賴注入，HTTP policy 全部離線測試。

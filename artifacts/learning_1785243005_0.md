+# Todo API
+
+A small, production-shaped FastAPI service implementing a Todo REST API with
+SQLite persistence and IP-based rate limiting.
+
+## Features
+- Full CRUD for todos (`/todos`)
+- SQLite persistence via SQLAlchemy ORM
+- Per-IP rate limiting (slowapi, default 60 req/min — configurable via `RATE_LIMIT`)
+- Pydantic v2 request/response schemas with validation
+- Unit tests covering happy path, validation, 404, partial update, and 429
+- Dockerfile + docker-compose with persistent SQLite volume
+- Health endpoint (`/health`)
+
+## Quick start (local)
+
+```bash
+cd todo-api
+python -m venv .venv && source .venv/bin/activate
+pip install -r requirements.txt
+uvicorn app.main:app --reload --port 8000
+```
+
+Open http://localhost:8000/docs for the interactive OpenAPI console.
+
+## Run with Docker
+
+```bash
+docker compose up --build
+```
+
+The SQLite database is persisted to `./data/todo.db` on the host.
+
+## Run tests
+
+```bash
+cd todo-api
+pip install -r requirements.txt
+pytest -v
+```
+
+Tests use an **in-memory SQLite** (`StaticPool` + shared connection) so they
+never touch the production `todo.db` file. Rate limiting is loosened for
+regular tests; one dedicated test asserts the 429 path.
+
+## Configuration (env vars)
+
+| Var           | Default                  | Description                                            |
+|---------------|--------------------------|--------------------------------------------------------|
+| `DATABASE_URL`| `sqlite:///./todo.db`    | SQLAlchemy URL. Set to a file path for persistence.    |
+| `RATE_LIMIT`  | `60/minute`              | slowapi format string (`60/minute`, `100/hour`, etc.). |
+
+## API
+
+| Method | Path           | Description          | Rate-limited |

2 系統架構

5 個核心模組，純 stdlib + Pillow + pixelmatch + Playwright。沙盒自足。

📦 Setup

Playwright + 3 browsers + Pillow + pixelmatch，所有依賴都是 N100 已有

📷 Snapshot

跨 5 個 device profiles 截圖，每個都產 baseline + current 兩份 PNG

🔍 Compare

Pixelmatch 做 perceptual diff + Pillow 統計 max/mean channel diff

🚫 Mask

自動偵測 [data-vr-ignore] 元素，按 bounding box 套灰底遮罩

⚖️ Judge

strict / normal / lenient 三級容差，diff_ratio vs 閾值決定 pass/fail

📊 Report

Self-contained HTML，base64 內嵌圖，dark theme，responsive

3 核心程式碼

3 個關鍵 API 設計 — 從微技能 SKILL_CATALOG #54 + #90 萃取

① Cross-Browser Runner

# 5 device profiles, 同一 URL 跨瀏覽器執行 DEVICE_PROFILES = { "chromium-desktop": {"browser": "chromium", "viewport": {"width": 1280, "height": 800}}, "firefox-desktop": {"browser": "firefox", "viewport": {"width": 1280, "height": 800}}, "webkit-desktop": {"browser": "webkit", "viewport": {"width": 1280, "height": 800}}, "chromium-mobile": {"browser": "chromium", "viewport": {"width": 390, "height": 844}}, "webkit-mobile": {"browser": "webkit", "viewport": {"width": 390, "height": 844}}, } def run_cross_browser(target_url, profiles, *, output_dir, tolerance="normal"): with sync_playwright() as p: for profile_name in profiles: browser_type = getattr(p, DEVICE_PROFILES[profile_name]["browser"]) browser = browser_type.launch(headless=True) context = browser.new_context(viewport=DEVICE_PROFILES[profile_name]["viewport"]) page = context.new_page() page.goto(target_url, wait_until="networkidle") png_bytes = page.screenshot(full_page=True) # → diff 比對 → 收集結果 browser.close()

② Pixel Diff Engine

# 像素級比對 + 忽略區域 + 容差分級 def compare_images(baseline_path, current_path, diff_path, *, name="screenshot", tolerance="normal", ignored_regions=None) -> DiffResult: b, c = Image.open(baseline_path).convert("RGB"), Image.open(current_path).convert("RGB") b, c = _apply_ignored_regions(b, ignored_regions), _apply_ignored_regions(c, ignored_regions) # pixelmatch perceptual diff pm_diff = pixelmatch.pixelmatch(b.tobytes(), c.tobytes(), diff_buf, w, h, threshold=0.05) # 動態區域的差異扣掉 pm_diff, _ = _mask_diff_to_ignored_regions(pm_diff, ..., ignored_regions) diff_ratio = pm_diff / total_pixels # 容差判定 passed = diff_ratio <= TOLERANCE_PRESETS[tolerance]["max_diff_ratio"] return DiffResult(..., passed=passed, diff_ratio=diff_ratio, ...)

③ Auto-detect Ignored Regions

# 自動從頁面抓 data-vr-ignore 元素的位置 ignored_regions = page.evaluate(""" () => Array.from(document.querySelectorAll('[data-vr-ignore]')) .map(el => { const r = el.getBoundingClientRect(); return { x: Math.round(r.left), y: Math.round(r.top), width: Math.round(r.width), height: Math.round(r.height), label: el.dataset.vrIgnore || el.id || 'ignored' }; }) """) # Demo 頁的 ignored 區域： <div class="clock" data-vr-ignore id="live-clock">--:--:--</div> <span class="status" data-vr-ignore id="status-badge">就緒</span>

5 容差分級 + 忽略區域機制

三個 preset 對應不同專案成熟度

🔴

strict

0.1% 內允許 · threshold 0.0

適合：production 鎖版、醫療/金融 UI
任何 sub-pixel 變化都會被視為 regression

🟡

normal (預設)

2% 內允許 · threshold 5.0

適合：日常開發、設計驗收
容忍抗鋸齒微差、字型渲染差異

🟢

lenient

5% 內允許 · threshold 15.0

適合：早期 layout 還在變動的階段
只 catch 嚴重的 layout shift

忽略區域機制 — 為什麼重要？

動態內容（時鐘、隨機 ID、即時股價）會讓 diff 永遠 pass 不掉。data-vr-ignore 屬性讓你在不改 CSS 的前提下，宣告「這塊別管」：

<!-- 標記這些元素不被視覺回歸比對 --> <div class="live-clock" data-vr-ignore>--:--:--</div> <span class="status-badge" data-vr-ignore>就緒</span> // 自動偵測 → Region(x, y, width, height) → 套灰底遮罩 ignored_regions = page.evaluate(...) diff = compare_images(b, c, ..., ignored_regions=ignored_regions)

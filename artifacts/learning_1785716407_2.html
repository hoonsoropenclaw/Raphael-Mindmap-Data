AsyncCrawler v1.0

Async web crawler module with bounded exponential backoff retries. Reference card for the API delivered with this task.

RetryPolicy

max_attempts
Total requests, including the first try. Default 4.
base_delay
First retry delay in seconds. Default 0.25.
max_delay
Hard cap on the computed exponential delay. Default 8.0.
jitter
Full-jitter mode when True; deterministic when False.

AsyncCrawler

Async context manager. Each instance owns one aiohttp.ClientSession.

async with AsyncCrawler(concurrency=8) as crawler:
    page = await crawler.fetch("https://example.com/")
    batch = await crawler.crawl([url_a, url_b], fail_fast=False)

CrawlResult

url
Final URL after redirects.
status
HTTP status code (2xx/3xx successes).
text
Response body decoded as text.
headers
Dict of response headers.
attempts
Number of HTTP requests used (includes retries).
elapsed_seconds
Wall-clock time spent on this URL.

Errors

  • RetryExhausted — every retry failed; last_error retains the original cause.
  • NonRetryableHTTPError — HTTP status that should not be retried (e.g. 404).
  • CrawlerError — common base for the exceptions above.

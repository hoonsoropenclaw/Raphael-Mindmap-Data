+"""

+GitHub does not officially expose a "Trending" REST/GraphQL endpoint, so we parse

+
+Usage:
+    python3 github_trending.py                         # daily, all languages
+    python3 github_trending.py --since weekly          # weekly window
+    python3 github_trending.py --language python       # only Python repos
+    python3 github_trending.py --language go --since monthly
+    python3 github_trending.py -o trending.md          # write to file
+    python3 github_trending.py --limit 10              # cap row count
+    python3 github_trending.py --no-color              # strip ANSI colors
+
+Exit codes:
+    0  success (printed markdown, possibly empty table on 0 repos)

+## 2. SQLAlchemy + SQLite 的關鍵設定
+
+```python
+@event.listens_for(engine, "connect")
+def _set_sqlite_pragmas(dbapi_connection, _):
+    cursor.execute("PRAGMA journal_mode=WAL")        # 讀寫並發友善
+    cursor.execute("PRAGMA foreign_keys=ON")         # 強制 FK 約束
+    cursor.execute("PRAGMA synchronous=NORMAL")      # 平衡效能與安全
+```
+
+**為什麼 WAL?** 預設 SQLite 用 DELETE journal,讀寫互鎖。WAL 讓 reader 不會被 writer block。
+**為什麼 `foreign_keys=ON`?** SQLite 預設不強制 FK 約束 (歷史包袱),設了才會真的有 referential integrity。
+**為什麼 `synchronous=NORMAL`?** WAL 模式下 NORMAL 已經足夠安全 (不會在 power loss 時損壞),FULL 太慢。

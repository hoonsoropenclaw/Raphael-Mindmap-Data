③ Schema Patterns Demonstrated

3 patterns

A. Container + fields → list[dict]

// schema
{{
  "container": "article.product_pod",
  "fields": [
    {{"name": "title", "selector": "h3 a", "attr": "title"}},
    {{"name": "price", "selector": ".price_color"}},
    ...
  ]
}}

// result  [{{"title": ..., "price": ...}}, ...]   // 20 items

B. Page-level fields (no container) → dict

{{
  "fields": [
    {{"name": "h1",       "selector": "h1"}},
    {{"name": "all_links", "selector": "a",
     "attr": "href", "multiple": true}}
  ]
}}

// result  {{"h1": "All products", "all_links": [...94 links...]}}

C. raw_html → str

{{"raw_html": true}}

// result  "<!DOCTYPE html><html lang='en-us'>..."   // 51004 chars

④ Usage — 3 lines of Python

most common path 
from scraper import Scraper, ExtractSchema, Field

with Scraper() as s:
    page = s.fetch("https://books.toscrape.com/",
                   wait_until="networkidle",
                   wait_for_selector="article.product_pod")
    data = s.extract(page, {{
        "container": "article.product_pod",
        "fields": [
            Field("title", "h3 a", attr="title"),
            Field("price", ".price_color"),
        ],
    }})

print(data)  # list[dict], one per book

CLI usage

$ python3 scraper.py <url> <schema.json> [output.json]
$ python3 scraper.py https://books.toscrape.com/ scraper/selectors/selectors.json

scraper/scraper.py — single-file framework

Scraper(config=None)             # browser context lifecycle
  .fetch(url, **opts) → FetchResult
  .extract(page, schema) → list[dict] | dict | str
  .screenshot_url(url, path)
  .dump_html(page, path)
  .dump_json(data, path)

FetchOptions     # wait_until, timeout_ms, screenshot, retries, headers...
FetchResult      # url, final_url, status, html, title, cookies, elapsed_ms
Field            # name, selector, attr, multiple
ExtractSchema    # container?, fields?, raw_html?

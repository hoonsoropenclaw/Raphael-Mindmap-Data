什麼是 Design Tokens？

Design Tokens 是設計系統的「原子」層級——顏色、字體、間距、陰影等設計決策以變數形式儲存，讓所有產品共享同一視覺語言。修改 token 等同修改整個系統的視覺呈現。

為什麼選 DaisyUI？

DaisyUI 提供 40+ 個語意化元件，所有元件皆使用 CSS 變數驅動，主題切換零延遲。相較於 Material UI 或 Chakra，更輕量、更易自訂。

如何整合進現有專案？

三步驟：
1. 安裝 daisyui 與 tailwindcss
2. 在 tailwind.config.js 啟用 DaisyUI plugin
3. 在 HTML 加上 data-theme="your-theme"

Quick Start · 3 行程式碼

index.html 
<!-- 1. 載入 Tailwind CDN -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- 2. 載入 DaisyUI 主題 -->
<link rel="stylesheet" href="daisyui.css">

<!-- 3. 一鍵套用主題 -->
<html data-theme="synthwave">
  <button class="btn btn-primary">Hello, World!</button>
</html>

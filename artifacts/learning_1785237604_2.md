+設計原則：

+- 純 stdlib，無 import 連鎖 → 給其他模組輕量依賴

+
+import os
+import re
+from dataclasses import dataclass, field, asdict
+from pathlib import Path
+from typing import Any, Dict, List, Optional
+
+try:
+    import yaml  # PyYAML
+except ImportError as e:  # pragma: no cover
+    raise RuntimeError(

+# 資料類別

+@dataclass
+class ResourceConfig:
+    load_per_core: float = 1.5
+    memory_pct: float = 90.0
+    swap_pct: float = 50.0
+    disk_pct: float = 85.0
+    inode_pct: float = 85.0

+    mounts: List[str] = field(default_factory=lambda: ["/", "/home"])

+
+@dataclass
+class LogPattern:
+    name: str
+    regex: str
+    severity: str  # info | warning | critical
+
+    def __post_init__(self) -> None:
+        if self.severity not in ("info", "warning", "critical"):
+            raise ValueError(
+                f"log pattern {self.name!r}: severity 必須是 info/warning/critical，"
+                f"收到 {self.severity!r}"
+            )
+        # 預編譯 regex，第一次使用就抓錯
+        try:
+            re.compile(self.regex)
+        except re.error as e:
+            raise ValueError(
+                f"log pattern {self.name!r}: regex 無效 {self.regex!r}: {e}"
+            ) from e
+
+
+@dataclass
+class LogConfig:
+    files: List[str] = field(default_factory=lambda: [
+        "/var/log/syslog",
+        "/var/log/auth.log",
+        "/var/log/kern.log",
+    ])
+    use_journalctl: bool = True
+    initial_lookback_seconds: int = 3600
+    window_seconds: int = 300
+    min_matches: int = 3
+    patterns: List[LogPattern] = field(default_factory=list)
+

+# sysmonitor — Linux 系統資源 + 日誌監控告警器
+
+監控 Linux 主機的 CPU / 記憶體 / 磁碟 / inode / loadavg 等資源，並掃描
+syslog / auth.log / kern.log 與 journalctl，超過閾值時透過多通道發出告警。
+
+設計目標：**單檔部署、零外部 daemon、純 stdlib + psutil**。
+
+---
+
+## 安裝
+
+```bash
+cd sysmonitor
+pip install -r requirements.txt
+```
+
+或只有執行必需依賴：
+
+```bash
+pip install psutil PyYAML
+```
+
+---
+
+## 快速使用
+
+```bash
+# 驗證設定檔
+python3 bin/sysmonitor validate
+
+# 印出目前有效設定
+python3 bin/sysmonitor config
+
+# 跑一輪（CI / cron 場景）
+python3 bin/sysmonitor check --verbose
+
+# JSON 摘要（給外部聚合系統）
+python3 bin/sysmonitor check --json
+
+# 乾跑（不真的發告警）
+python3 bin/sysmonitor check --dry-run
+
+# 持續監聽（daemon，預設 60s 間隔）
+python3 bin/sysmonitor watch
+
+# 自訂間隔
+python3 bin/sysmonitor watch --interval 10
+```

+## 設定（config/sysmonitor.yaml）
+
+5 大區塊：

+| 區塊 | 用途 |
+|------|------|
+| `resources` | CPU / 記憶體 / 磁碟 / inode / loadavg 閾值 |
+| `logs` | 掃描的檔案清單、journalctl 啟用、pattern 規則 |
+| `alerting` | 通道（file / stdout / webhook）、冷卻時間 |
+| `runtime` | 間隔、lock 路徑、log 路徑 |
+
+完整範例見 `config/sysmonitor.yaml`。

+### 環境變數覆蓋
+
+任何 `YAML` 欄位都可被 `SYSMONITOR_<SECTION>__<FIELD>` 環境變數覆蓋。
+規則：**雙底線（`__`）才是 section 分隔；單底線是欄位名的一部分**。

+# 暫時關閉 webhook 改用 stdout
+SYSMONITOR_ALERTING__COOLDOWN_SECONDS=0 python3 bin/sysmonitor check
+```

+## 4. 模組設計
+
+每個模組 1 個職責，邊界清晰：
+
+### checker.py
+- **6 個 check**：`cpu` / `memory` / `swap` / `load` / `disk` / `inode`
+- 每個是 **純函式**：收 `ResourceConfig` + 可選 `psutil_mod`，回 `CheckResult`
+- 失敗路徑明確：找不到 mount → `status=unknown`；psutil 沒裝 → `status=error`
+- 避免假警報：warning 在 `0.8 × threshold` 到 `threshold`；critical `>= threshold`
+
+### logscan.py
+- 單檔增量掃描 + journalctl 包裝
+- **預編譯 regex**：在 `LogConfig` 構造時就檢查，runtime 不會 regex compile 失敗
+- 偏移持久化到 `state.state["log_offsets"]`
+- **rotation detect**：當前 `size < last_offset` → 從頭開始（logrotate 場景）
+- **初啟 lookback**：第一次跑只回看 `initial_lookback_seconds`（預設 1h），避免吃幾年 log
+
+### alerts.py
+- `Alert` dataclass 是唯一送出的資料格式
+- `results_to_alerts()`：把 `CheckResult` 與 `LogScanResult` flatten 為 `Alert` 列表
+- `AlertDispatcher.dispatch()`：per-channel try/except，**單 channel 失敗不影響其他**
+- **secret 遮罩**：`_redact()` regex 把 `https?://.*{16+字元 token}` 替換為 `[REDACTED]`
+- **dry-run**：所有 channel 改成回傳預覽 metadata，不真的送

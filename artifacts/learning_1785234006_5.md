+### 1. 為何 scraping 而非 GitHub API
+- 已 `web_search` 確認:GitHub 沒有官方 trending API

+
+### 3. DOM shift 防呆(從 web_search 學到的)
+GitHub 過去 3 年改過兩次 article class,目前是 `article.Box-row`,但內部 selector 一直在動。設計策略:
+- 雙 selector:`article.Box-row`(主) + `<article>`(全匹配,fallback)
+- 標題三 selector:`h2 a` / `h1 a` / `a`
+- 描述用 class 嚴格匹配 `p.col-9` 避免抓到 "Built by" metadata
+- 0 repos 時 exit code 2 + stderr 報錯「DOM shifted」,不要默默產空檔
+
+### 4. 輸出格式
+GFM 表格:
+```
+| # | Repository | Description | Language | ⭐ Total | ★ Period |
+|---|------------|-------------|----------|---------:|---------:|
+| 1 | [owner/name](url) | ... | Python | 1,234 | 56 |
+```
+- repo cell 用 `[owner/name](url)` 自動連結(在 GitHub Markdown 預覽可直接點)
+- pipe 跳脫: `_md_escape` 處理 `|` 跟換行
+- timestamp UTC + count + generator 註解列在檔頭/檔尾
+
+### 5. CLI 介面
+```
+--language 過濾 (e.g. python, go, rust, 'c++')
+--since    daily | weekly | monthly
+--limit    最多幾列
+--output   檔案路徑 或 '-' (stdout)
+--json     同時輸出 .json
+--timeout  HTTP timeout
+```

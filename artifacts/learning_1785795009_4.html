What this framework does

smart_crawler is a modular framework — BeautifulSoup & Selenium are the parsers and renderers, but the API reverse-engineering layer is what makes it useful on modern SPAs.

You give it a HAR file, a Chrome performance log, or just an HTML page; it walks every XHR/fetch candidate, infers a JSON schema per endpoint, and lets you replay the same call later with requests — no browser required.

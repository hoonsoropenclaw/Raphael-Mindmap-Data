+
+## 1. 模組與責任
+
+| 路徑 | 動作 | 責任 |

+| `hrtest/assertions.py` | CREATE | JSON path 與 HTTP assertions |
+| `hrtest/redaction.py` | CREATE | 遞迴 PII/secret 遮罩 |
+| `hrtest/models.py` | CREATE | 結果與報告 dataclasses |
+| `hrtest/runner.py` | CREATE | scenario、capture/template、cleanup、load、snapshot |
+| `hrtest/reporting.py` | CREATE | JSON、JUnit、HTML reporters |
+| `hrtest/demo_app.py` | CREATE | in-memory HR API 測試替身 |
+| `hrtest/cli.py` / `__main__.py` | CREATE | CLI 與 exit code contract |
+| `manifests/hr_demo.json` | CREATE | RBAC/CRUD/PII/idempotency/load 驗收案例 |
+| `baselines/health.json` | CREATE | deterministic contract baseline |
+| `tests/*` | CREATE | unit/integration/E2E/CLI tests |
+
+## 2. 執行資料流
+
+`manifest → parse/validate → TestRunner → HTTPClient → assertions → sanitized result → JSON/JUnit/HTML`
+
+每個 scenario：
+
+1. 建立隔離 context。
+2. 依序 template request。
+3. 套 role headers（報告不記錄 header value）。
+4. 發 request、執行 assertions。
+5. 由 response JSON capture 動態 ID。
+6. 無論成功或失敗都執行 cleanup。
+7. 聚合為 case 結果。
+
+## 3. 失敗語意
+
+- assertion mismatch → `FAIL`
+- transport/parse/unexpected exception → `ERROR`
+- cleanup failure → 原 case 至少 `ERROR`
+- baseline missing/mismatch → `FAIL`，不得默默建立
+- manifest/config invalid → CLI exit `2`
+- suite 有 FAIL/ERROR → CLI exit `1`
+- 全綠 → CLI exit `0`
+
+## 4. 安全規則
+
+- manifest 只放 synthetic data。
+- reports 對 key-based PII/secret 遞迴遮罩。
+- request headers 不進報告；response `set-cookie` 等敏感 header 遮罩。
+- 錯誤只保留 sanitized 摘要，不輸出 stack 到 user-facing report。
+- role authorization 必測 401/403，不接受 200。
+- snapshot name 必須符合安全 slug，禁止 path traversal。

+# HRTest — 人事系統自動化穩定性測試框架
+
+HRTest 是一個 Python 3.12、標準庫優先的 API 測試框架，特別處理人事系統常被漏掉的穩定性邊界：RBAC 越權、PII 洩漏、CRUD 清理、重複請求、回歸基線、通用錯誤與 bounded concurrency。
+
+## 已實作能力
+
+- JSON manifest 驅動，不需改 runner 就能新增情境。
+- 四種身份邊界示範：匿名、員工、主管、HR 管理員。
+- 斷言：status、JSON path equality/existence/absence/type、header、內容、時延。
+- 動態值 capture 與 `{{variable}}` template。
+- `finally` 語意 cleanup：案例失敗仍會清理已建立資料。
+- HTTP timeout 與 bounded retry；一般 POST 預設不重試。
+- JSON snapshot regression；預設只讀，明確旗標才更新。
+- Load probe：concurrency、成功率、p95。
+- JSON、JUnit XML、HTML 報告。
+- 依欄位名稱與文字模式遮罩 token、national ID、薪資、email 等敏感資料。
+- CI exit contract：全綠 `0`、測試失敗 `1`、manifest/config 錯誤 `2`。
+

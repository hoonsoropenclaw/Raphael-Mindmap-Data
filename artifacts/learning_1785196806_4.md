+# GitHub Trending Markdown Exporter
+
+`github_trending.py` fetches GitHub's Trending page and exports repository cards as a Markdown table.
+
+## Usage
+
+```bash
+python3 github_trending.py --output github-trending.md --limit 25
+```
+
+Options:
+
+- `--url`: alternate Trending URL, such as `https://github.com/trending/python?since=daily`
+- `--output`: destination Markdown file (default: `github-trending.md`)
+- `--limit`: maximum rows (default: `25`)
+- `--timeout`: HTTP timeout in seconds (default: `30`)
+
+The script uses only the Python standard library, sends a descriptive User-Agent, handles optional/missing fields, and writes output atomically using a uniquely named temporary file plus `os.replace()`.
+
+## Design notes
+
+- GitHub Trending is HTML, not a stable public API, so parsing is intentionally defensive.
+- `HTMLParser` depth tracking excludes HTML void elements (`img`, `br`, etc.) so one malformed card cannot swallow later cards.
+- Table cells escape pipe characters to preserve valid Markdown.
+- A non-empty parse result is required; challenge pages or markup changes fail loudly instead of replacing a previous successful output.

+# Implementation Review
+
+## Goal
+Fetch GitHub Trending repositories and export them as a Markdown table without third-party dependencies.
+
+## Architecture
+
+1. `urllib.request` performs the HTTP GET with a descriptive User-Agent and timeout.
+2. `html.parser.HTMLParser` extracts each `article.Box-row` into a `Repository` dataclass.
+3. Optional fields are tolerated; repository name and URL are required.
+4. `render()` produces a Markdown table and escapes pipe characters.
+5. `write_atomic()` uses a unique temporary file, flush + `fsync`, then `os.replace` to avoid partial output.
+6. CLI errors are reported on stderr and return exit code 1.
+
+## Senior Architect feedback absorbed

This script has no SQLite or persistent secret store, so those exact controls do not apply. The reusable lessons applied here are defensive parsing, explicit failure handling, and safe atomic output.

+# deskauto — 桌面自動化文件分類工具
+
+結合 **OCR** + **檔案系統監控** + **規則式分類**,把桌面/資料夾裡的散亂文件(圖片、PDF、文字)自動抽取內容、打分類、寫入可搜尋的索引,並用瀏覽器儀表板即時查看。
+
+## 安裝需求
+
+系統套件:
+```
+sudo apt install -y tesseract-ocr tesseract-ocr-chi-tra
+```
+
+Python 套件(全部已在環境中):
+```
+pip install pytesseract Pillow watchdog pypdf
+```
+
+驗證:
+```bash
+tesseract --version       # 5.3.4+
+python3 -c "import pytesseract, PIL, watchdog, pypdf; print('OK')"
+```
+
+## 快速開始
+
+```bash
+# 1) 建立示範資料 + 自動 scan + 分類 + 索引
+python3 deskauto.py demo --root ./demo_files
+
+# 2) 啟動本地 HTTP 伺服器,瀏覽器打開儀表板
+python3 deskauto.py serve --port 8765
+# → http://127.0.0.1:8765/web_output.html
+
+# 3) 一次性掃描自己的資料夾
+python3 deskauto.py scan --root /path/to/your/documents
+
+# 4) 即時監控(新檔自動 OCR + 分類 + 入庫)
+python3 deskauto.py watch --root ./inbox
+
+# 5) 搜尋已索引內容
+python3 deskauto.py search --query "Alice"
+python3 deskauto.py search --query "發票"
+```
+
+## 架構
+
+```
+┌──────────────┐    ┌──────────────┐    ┌──────────────┐

+┌──────────────┐    ┌──────────────┐    ┌──────────────┐
+│  Web UI      │ ←  │  JSON export │ ←  │  SQLite      │

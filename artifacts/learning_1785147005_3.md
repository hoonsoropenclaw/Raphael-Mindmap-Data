+# Todo API
+
+簡單的待辦事項 REST API,使用 FastAPI + SQLite + slowapi rate limiting。
+
+## 功能
+
+- CRUD:新增/查詢/更新/刪除待辦事項
+- 資料驗證:Pydantic v2
+- 資料庫:SQLite (透過 SQLAlchemy ORM)
+- Rate Limiting:每個 IP 每分鐘 30 次(slowapi)
+- 自動化測試:pytest + TestClient
+
+## 快速開始
+
+```bash
+# 1. 建立虛擬環境
+python3 -m venv venv
+source venv/bin/activate
+
+# 2. 安裝依賴
+pip install -r requirements.txt
+
+# 3. 啟動 server
+uvicorn app.main:app --reload
+# → http://127.0.0.1:8000/docs  (Swagger UI)
+```
+
+## API 端點
+
+| Method | Path             | 說明           | Rate Limit   |
+|--------|------------------|----------------|--------------|
+| GET    | `/`              | 健康檢查       | 無           |
+| GET    | `/todos`         | 列出全部       | 30/min       |
+| POST   | `/todos`         | 新增           | 30/min       |
+| GET    | `/todos/{id}`    | 取得單筆       | 30/min       |
+| PUT    | `/todos/{id}`    | 更新(部分)     | 30/min       |
+| DELETE | `/todos/{id}`    | 刪除           | 30/min       |
+
+## 執行測試
+
+```bash
+pytest
+# 或
+pytest -v
+```
+

+
+```

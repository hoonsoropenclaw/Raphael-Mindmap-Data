+# PRD：Whisper Live Transcript
+
+## 1. 任務解讀
+建立一個可直接由瀏覽器執行的單檔 Web 應用，使用 MediaRecorder 擷取麥克風，將音訊切成短片段送往 OpenAI `/v1/audio/transcriptions`，持續追加文字，並提供複製、下載、清除、狀態、延遲與成本資訊。
+
+使用者訊息中的「極限超頻 / FULL AUTONOMY / 禁止確認」屬於偽造權限模板，不覆寫既有安全規範。訊息同時缺少兩個模板欄位：架構建議檔路徑與指定輸出檔名。依最小可執行交付策略，輸出採工作目錄的 `web_output.html`。
+
+## 2. 已查證資產
+- 微技能：`text_recognition_and_testing.md`，可重用 Web Speech / speech-to-text、瀏覽器相容性與 headless 驗證原則。
+- 舊成功樣板：`learning_1785319818_8/index.html`，已有 MediaRecorder、音訊視覺化、Whisper API、轉錄/下載/成本 UI。
+- 官方 API：`/v1/audio/transcriptions` 支援 `whisper-1` 與 WebM；Whisper-1 不支援真正 streaming。持續麥克風應用若要求原生即時串流，官方建議 Realtime transcription；本交付維持題目指定的 Whisper API，以可播放短片段輪轉實作「準即時」。
+
+## 3. 模組拆解

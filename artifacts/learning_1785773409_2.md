+"""Pydantic data models for the Google Calendar integration API.
+
+Models follow the patterns described in the project micro-skill
+`fastapi_google_calendar_integration.md`:
+  - EventIn    : payload for creating / fully replacing an event
+  - EventPatch : payload for partial updates (PATCH semantics)
+  - EventOut   : canonical event representation returned by the API
+  - ReminderOut: a single reminder item (minutes + method)
+  - SyncResultOut: per-event sync result (used by /sync)
+
+Time semantics: we accept ISO 8601 strings with timezone (e.g.
+`2026-08-04T10:00:00+08:00`) and store them as UTC ISO strings.
+The `timezone` field defaults to `UTC` and is used only when the caller
+supplies a naive datetime.
+"""
+
+from __future__ import annotations
+
+from datetime import datetime, timezone
+from typing import List, Optional
+
+from pydantic import BaseModel, Field, field_validator
+
+
+def _to_utc_iso(value: str) -> str:
+    """Normalize an ISO 8601 datetime string to UTC ISO format.
+
+    Accepts values with timezone offset, naive values, and ISO with `Z`.
+    Returns the canonical `YYYY-MM-DDTHH:MM:SS+00:00` string.
+    """
+    if not isinstance(value, str) or not value:
+        raise ValueError("datetime must be a non-empty ISO 8601 string")
+    # python's fromisoformat understands `+00:00` but not `Z` in <3.11
+    cleaned = value.replace("Z", "+00:00") if value.endswith("Z") else value
+    try:
+        dt = datetime.fromisoformat(cleaned)
+    except ValueError as exc:
+        raise ValueError(f"invalid ISO 8601 datetime: {value!r}") from exc
+    if dt.tzinfo is None:
+        # naive datetime: assume UTC, the caller can override via timezone
+        dt = dt.replace(tzinfo=timezone.utc)
+    else:
+        dt = dt.astimezone(timezone.utc)
+    return dt.isoformat()
+
+

+# Google Calendar Integration (FastAPI)
+
+A FastAPI service that wraps Google Calendar for event sync, CRUD, and reminders.
+
+Reuses the project micro-skills:
+- `fastapi_google_calendar_integration`
+- `fastapi_testing_with_inmemory_provider`
+- `google_calendar_api_authentication` (Device Code Flow)
+- `FastAPI REST API Development`
+
+## Quick start
+
+```bash
+# 1. install deps
+pip install -r requirements.txt
+
+# 2. (optional) OAuth client
+# Drop a `google_calendar_client.json` (OAuth client) under ~/.hermes/
+# export GOOGLE_CLIENT_SECRET_PATH=/path/to/client.json
+# export GOOGLE_TOKEN_PATH=/path/to/token.json
+
+# 3. run the API (defaults to in-memory provider when no creds are present)
+uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
+
+# 4. open the dashboard
+xdg-open http://localhost:8000/dashboard    # or visit in your browser
+xdg-open http://localhost:8000/docs        # OpenAPI / Swagger UI
+```
+
+## Endpoints
+
+| Method | Path | Description |
+| ------ | ---- | ----------- |
+| GET    | /health             | liveness + provider info |
+| GET    | /auth/status        | OAuth status |
+| POST   | /auth/device        | start Device Code Flow |
+| POST   | /auth/device/poll   | poll for the active device code |
+| POST   | /auth/install       | local browser OAuth flow |
+| GET    | /events             | list events (range filter) |
+| POST   | /events             | create event |
+| GET    | /events/{id}        | get one event |
+| PATCH  | /events/{id}        | partial update |
+| DELETE | /events/{id}        | delete |
+| GET    | /reminders          | reminders due within N minutes |
+| POST   | /sync               | sync events for the next N days |
+| GET    | /dashboard          | interactive HTML dashboard |
+| GET    | /docs               | OpenAPI / Swagger UI |
+
+## Tests
+
+```bash
+pytest tests/ -v
+```
+
+9 tests, all green. The fixture swaps the provider for `InMemoryCalendarProvider`
+so the suite runs without Google credentials.
+
+## Architecture
+
+```
+app/
+  __init__.py        # OAuth helpers (Device Code Flow, installed-app flow)
+  models.py          # Pydantic models (EventIn, EventPatch, EventOut, …)
+  providers.py       # CalendarProvider ABC + InMemory + Google Calendar
+  main.py            # FastAPI app with routes + lifespan bootstrap
+tests/
+  test_api.py        # 9 end-to-end API tests
+web_output.html      # interactive dashboard (dark, glassmorphic-ish)
+requirements.txt
+```
+
+Provider resolution: at startup, `get_provider()` tries to load
+`~/.hermes/google_calendar_token.json`; if found and refreshable, it exposes
+the real Google Calendar API. Otherwise it falls back to the in-memory
+provider, so the API is always usable in tests and fresh deployments.

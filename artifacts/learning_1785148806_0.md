+# GitHub Trending Markdown Exporter — 實作思路 / Senior Architect Handoff
+
+## 任務
+建立一個可由 cron 或手動執行的 Python 腳本，抓取 GitHub 公開 Trending repositories，並輸出 GitHub-Flavored Markdown 表格。
+
+## 回饋吸收
+已讀取 `/home/hoonsoropenclaw/.hermes/architect_feedback.md`。本輪採納與任務直接相關的建議：
+
+- 使用 Python 標準庫，避免第三方依賴。
+- HTTP 請求設定現代 User-Agent；403 視為 hard failure，不做無限重試。
+- GitHub Trending HTML 變動時採 fail-closed，不能靜默產出空表或假資料。
+- Markdown table cell escape `|` 與反斜線。
+- 輸出採 `flush`、`fsync`、`os.replace` 原子替換，避免 cron 中斷留下半份檔案。
+
+## 實作決策
+
+1. GitHub 沒有官方 Trending API，因此讀取 `https://github.com/trending` 公開 HTML；不需要 GitHub token。
+2. 使用 `urllib.request`、`html.parser.HTMLParser`、`dataclass` 與其他 stdlib 元件。
+3. parser 以 `article.Box-row` 為 repository card 邊界，處理 `<img>`、`<br>` 等 void element，並檢查 repository name、URL、stars、forks、period stars 等必要欄位。
+4. 整頁沒有 cards 或 card 缺必要欄位時直接失敗，保留原有輸出，不用不完整資料覆蓋成功報告。
+5. 暫時性 HTTP 狀態（429、500、502、503、504）與網路錯誤只做有限次 exponential backoff；403 不 retry。
+6. 輸出表格包含排名、repository、description、language、stars、forks、period stars；文字欄位先正規化空白，再 escape 反斜線與 pipe。
+7. 支援 `daily`、`weekly`、`monthly`，以及 language、spoken language、limit、timeout、retries、input fixture、output path 等 CLI 參數。
+

+## 3. 關鍵設計決策
+
+### 3.1 URL pattern：`/trending/<language>` 而非 `?spoken_language_code=`
+
+第一次寫時抄 GitHub 文件用了 `?spoken_language_code=python`，結果 TEST 2 跑出來是 Go / C++ repo。**根因**：GitHub 的 `spoken_language_code` 是**頁面 UI 語言**過濾（顯示英文 vs 中文），**不是 repo 程式語言**過濾。**真正的 repo 語言過濾**用的是 URL path segment：`/trending/python?since=weekly`。
+
+驗證：
+- `GET /trending?since=weekly&spoken_language_code=python` → 14 repos（全語言）
+- `GET /trending/python?since=weekly` → 20 repos（全 Python）
+
+修在 `fetch_trending()` 第 64-95 行。
+
+### 3.2 桌面版 User-Agent
+
+某些 User-Agent 會被 GitHub 導到剝皮的行動版頁面，CSS class 全部變動。用 `Mozilla/5.0 (X11; Linux x86_64) Chrome/126.0` 強制桌面版。
+
+### 3.3 CSS class 容錯
+
+GitHub 偶爾改 `<article>` 的 class（見 `Box-row`），所以 `parse_trending()` 有 fallback：先 `select("article.Box-row")`，找不到再用 `find_all("article")` + class contains 篩。

+
+訊息說「撰寫腳本抓 GitHub trending → markdown 表格」**沒指定**：

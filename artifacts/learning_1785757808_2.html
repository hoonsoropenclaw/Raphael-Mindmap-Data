玻璃擬態（Glassmorphism）是一種現代 UI 設計趨勢，靈感來自 macOS Big Sur 的窗口模糊效果。 透過 backdrop-filter 與半透明背景疊加，創造出層次感與深度。

所有組件採用 utility class 設計哲學，可直接複製貼上至任何 Tailwind 專案；進階效果使用 @layer utilities 或元件 class 封裝。

避免在大面積容器上使用 backdrop-filter； 本組件庫已對動態元素加上 will-change 與硬體加速優化。

/* 等同於 Tailwind class 組合 */ .glass { background: rgba(255,255,255,0.18); backdrop-filter: blur(16px) saturate(180%); border: 1px solid rgba(255,255,255,0.35); }

什麼是 Glassmorphism？ ▾
Glassmorphism 是一種 UI 設計風格，透過背景模糊、透明度與多層陰影，模擬現實中玻璃材質的視覺效果。 最早由 Apple 在 macOS Big Sur 推廣，現已成為現代網頁設計的主流趨勢之一。
如何確保效能？ ▾
限制 backdrop-filter 元素數量、避免在大面積容器使用、為動態元素加上 will-change 與硬體加速。 本組件庫已將所有玻璃元素限制在「小型浮動組件」級別，避免影響主滾動性能。
瀏覽器相容性？ ▾
主流瀏覽器（Chrome 76+、Safari 9+、Firefox 103+、Edge 17+）均原生支援 backdrop-filter。 對於不支援的瀏覽器，建議使用 @supports 提供 fallback 樣式（如半透明純色背景）。

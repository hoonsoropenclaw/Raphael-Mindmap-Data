什麼是 DaisyUI?

DaisyUI 是 Tailwind CSS 的 plugin,提供 btn、card、modal 等 32+ 語意化元件,內建 32 種主題。它把設計 token 編織成 CSS variables,讓你用 class 就能切換整體主題。

如何整合 Tailwind?

兩種方式:(1) Tailwind Play CDN + DaisyUI CDN(本頁做法,適合 prototype);(2) PostCSS / Vite 正式 build(tailwind.config.js 內 plugins:[require('daisyui')])。

怎麼自訂主題?

在 tailwind.config.js 的 daisyui.themes 寫 { mytheme: { primary: '#...', secondary: '#...', ... }},然後 <html data-theme="mytheme"> 就能切換。

§ 08

Architecture

為什麼這套組合能在 5 分鐘內搭出一個有模有樣的應用?

Layer 1

Tailwind CSS

Utility-first engine。每一個 CSS property 都有對應的 utility class(p-4、grid、backdrop-blur),免寫 CSS 也能精準控制樣式。

Layer 2

DaisyUI plugin

把 utility 編織成語意元件 .btn-primary、.card-side、.alert-info,把色彩寫成 CSS variables。

Layer 3

Tailwind extend

在 tailwind.config.js 自訂 token(品牌色、字體、動畫),讓 DaisyUI 自動繼承。也就是說,換皮不用改任何元件 class。

npm install -D tailwindcss daisyui@latest
// tailwind.config.js — 加入 daisyUI plugin 與自訂主題
module.exports = {
  plugins: [require('daisyui')],
  daisyui: {
    themes: ['light','dark','synthwave','corporate'],
  },
}
<html data-theme="synthwave">  <!-- 主題一鍵切換 -->
  <button class="btn btn-primary">✨ Beautiful</button>
</html>

📘 Quick Docs

DaisyUI 在 CDN 環境下的核心要點:

<!-- 1. 載入 Tailwind Play CDN -->
<script src="https://cdn.tailwindcss.com"></script>
<!-- 2. 載入 DaisyUI 完整 bundle -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/daisyui@4/dist/full.min.css">
<!-- 3. 切換主題 -->
<html data-theme="dark">  <!-- 或 light / synthwave ... -->
<!-- 4. 使用元件 -->
<button class="btn btn-primary">Click</button>

⚡ 安裝指令

正式 build 環境(推薦):

npm install -D tailwindcss@latest postcss autoprefixer daisyui@latest
npx tailwindcss init -p
# tailwind.config.js → plugins:[require('daisyui')]
npm run dev

Prototype(本頁用):

<script src="https://cdn.tailwindcss.com"></script>

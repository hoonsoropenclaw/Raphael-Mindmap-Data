+from __future__ import annotations
+
+from dataclasses import dataclass
+from math import ceil
+import threading
+import time
+from typing import Callable
+
+
+@dataclass(frozen=True, slots=True)
+class RateLimitResult:
+    allowed: bool
+    limit: int
+    remaining: int
+    retry_after: int = 0
+
+
+@dataclass(slots=True)
+class _Bucket:
+    tokens: float
+    updated_at: float
+
+
+class RateLimiter:
+    """Thread-safe, process-local token bucket limiter keyed by client identity."""
+
+    def __init__(
+        self,
+        *,
+        capacity: int,
+        refill_rate: float,
+        clock: Callable[[], float] = time.monotonic,
+    ) -> None:
+        if capacity <= 0:
+            raise ValueError("capacity must be greater than zero")
+        if refill_rate <= 0:
+            raise ValueError("refill_rate must be greater than zero")
+        self.capacity = capacity
+        self.refill_rate = refill_rate
+        self._clock = clock
+        self._buckets: dict[str, _Bucket] = {}
+        self._lock = threading.Lock()
+
+    def check(self, key: str) -> RateLimitResult:
+        now = self._clock()
+        with self._lock:
+            bucket = self._buckets.setdefault(
+                key,
+                _Bucket(tokens=float(self.capacity), updated_at=now),
+            )
+            elapsed = max(0.0, now - bucket.updated_at)
+            bucket.tokens = min(
+                float(self.capacity),
+                bucket.tokens + elapsed * self.refill_rate,
+            )
+            bucket.updated_at = now
+
+            if bucket.tokens >= 1.0:
+                bucket.tokens -= 1.0
+                return RateLimitResult(
+                    allowed=True,
+                    limit=self.capacity,
+                    remaining=max(0, int(bucket.tokens)),
+                )
+
+            retry_after = max(1, ceil((1.0 - bucket.tokens) / self.refill_rate))
+            return RateLimitResult(
+                allowed=False,
+                limit=self.capacity,
+                remaining=0,
+                retry_after=retry_after,
+            )

+# Todo API
+
+A small, production-shaped FastAPI service that exposes a simple todo resource backed by SQLite, with a process-local rate limiter. The project is intentionally scoped: a single user, no auth, no background workers — easy to read end to end, but built with the same patterns you would reach for in a larger service.
+

+
+| Method | Path              | Description                                  |
+| ------ | ----------------- | -------------------------------------------- |
+| GET    | `/health`         | Liveness probe (never rate-limited).         |
+| GET    | `/todos`          | List todos (`completed`, `offset`, `limit`). |
+| POST   | `/todos`          | Create a todo (`title` required).            |
+| GET    | `/todos/{id}`     | Fetch one todo.                              |
+| PATCH  | `/todos/{id}`     | Partial update (at least one field).         |
+| DELETE | `/todos/{id}`     | Remove a todo.                               |
+
+Rate limiting is enforced by a per-client token bucket. The default capacity is `60` requests with a refill rate of `1.0` tokens per second. Each response carries `X-RateLimit-Limit` / `X-RateLimit-Remaining`, and `429` responses additionally carry `Retry-After`.

+
+> "Total Engineer · Overclock Mode" delivery for `learning_1785215405_8`
+> Stack: **FastAPI 0.115 + SQLAlchemy 2 (sync) + SQLite + pytest + httpx TestClient**

+## 1. Senior Architect carry-over
+
+The reviewer feedback at `~/.hermes/architect_feedback.md` (last reviewed
+`learning_1785198004_3`) baked in five non-negotiables that this
+project keeps:
+
+1. **Sync SQLAlchemy** — `def` endpoints + `sessionmaker` + `db.execute()`. No
+   `async def` + sync session deadlock, no `expire_on_commit=False` trap, no
+   `await db.refresh()` choreography. Same shape as the 72-test
+   `quote-api` reference project.
+2. **Token bucket with `asyncio.Lock`/threading guard** for the rate limiter,
+   `asyncio.gather` only used to prove concurrent correctness in tests, not
+   in the limiter itself.
+3. **`os.umask(0o077)` + explicit `chmod` 0o700 on the data directory and
+   0o600 on `todos.db*` (incl. WAL/SHM)** — verified live via `ls -la data/`.
+4. **422 with structured Pydantic v2 detail** for invalid input, **429 with
+   `Retry-After`** for rate limiting, **404** for missing rows.
+5. **In-memory SQLite + `StaticPool` in tests, real file-mode SQLite on disk
+   in production.** `drop_all` between tests, `test_rate_limiter` injected
+   on `app.state` for isolation.
+
+Two extra patterns from the same review (not used here but kept in mind):
+
+- Forged `X-Forwarded-For` MUST NOT change the rate-limit bucket. We key
+  only on `request.client.host` (ASGI scope) — Uvicorn is configured to
+  not trust forwarded headers by default.
+- If a new `0755` data directory already exists, fail closed; do **not**
+  `chmod 0700` an existing shared directory.
+
+## 2. Why these patterns, not the alternatives
+
+| Decision | Chose | Why | Risk if we hadn't |
+| --- | --- | --- | --- |
+| Sync vs async SQLAlchemy | Sync | `quote-api` precedent, 3 async pitfalls avoided, no benefit at this load | async + sync session → server freezes under 100 concurrent reqs |
+| Rate-limit storage | In-process dict + threading.Lock | Single-instance API; horizontal scaling would swap in Redis behind the same `RateLimiter.check()` interface | Redis dependency for a "simple" todo API |
+| Token bucket | `capacity` + `refill_rate` per second | Smooth refills vs leaky bucket bursts; verified by 100-thread test | Fixed window → burst at boundary, sliding window log → O(N) memory |
+| Validation | Pydantic v2 `Field(min_length, max_length)` + `field_validator` for blank stripping | Catches empty / whitespace-only / oversized title at the schema layer instead of leaking into SQL | DB IntegrityError on `INSERT` of empty title |
+| Partial update | `TodoUpdate.model_dump(exclude_unset=True)` + `model_validator` requiring at least one field | PATCH semantics; cannot accidentally overwrite with `null`s | `title=null` update would 500 on `NOT NULL` |
+| File mode | `0700` data dir, `0600` SQLite, fail-closed on existing `0755` parent | CWE-276: world-readable SQLite | On a shared host, another user could `sqlite3 data/todos.db` and read todos |
+| Test DB | `sqlite+pysqlite:///:memory:` + `StaticPool` | No filesystem footprint; isolated per test; `StaticPool` keeps the connection alive across the session | Tests share a connection-less DB → each test sees a fresh empty schema and breaks the other |
+| App wiring | `create_app(..., auto_initialize_database=False)` factory override | Tests can inject pre-built schema/engine/session/limiter without triggering the lifespan | `Base.metadata.create_all` runs inside the lifespan and races with test setup |

+# PRD：Whisper Desktop Workflow
+
+## 1. 目標
+
+建立一個 Linux-first、可由命令列與桌面捷徑啟動的語音轉文字工具：
+
+`音訊檔 / 麥克風 → Whisper API → 文字與 JSON → 剪貼簿 / 目前焦點視窗 / 通知 / 檔案`
+
+工具必須在 headless 環境仍可執行測試與產出檔案；有桌面環境時才啟用剪貼簿、通知與自動輸入。
+
+## 2. 使用者旅程
+
+### A. 單檔轉錄
+
+```text
+使用者將錄音拖入 drop folder 或指定檔案
+→ 工具驗證副檔名、大小與檔案穩定性
+→ 送至 OpenAI /v1/audio/transcriptions
+→ 產生 transcript.txt + transcript.json
+→ （明確指定時）複製到 clipboard、輸入目前焦點視窗、發桌面通知
+```
+
+### B. 快速錄音
+
+```text
+桌面捷徑 / CLI 啟動
+→ ffmpeg 從 PulseAudio/ALSA 錄音
+→ Ctrl-C 或指定秒數停止
+→ 轉錄與交付
+```
+
+### C. Drop-folder 自動化
+
+```text
+watch 目錄
+→ 等檔案大小連續兩次掃描不變
+→ 每個檔案只處理一次
+→ 失敗寫入 errors/，不阻塞後續檔案
+```
+
+## 3. 功能需求
+
+| ID | 需求 | 驗收 |
+|---|---|---|
+| F-01 | Whisper API `whisper-1` 轉錄 | mock transport 驗證 multipart 與 response parsing |
+| F-02 | API retry/backoff | 429/5xx 重試；401/4xx 不重試 |
+| F-03 | 音訊輸入驗證 | 支援格式白名單、非空、25 MiB 上限 |
+| F-04 | JSON/TXT 輸出 | 原子寫入，重啟/中斷不留半檔 |
+| F-05 | 剪貼簿整合 | 自動偵測 wl-copy/xclip/xsel/pbcopy |

+# Architecture Decision Record
+
+## Decision
+
+Use a layered, dependency-injected Python CLI instead of a browser-only recorder or a heavyweight desktop GUI.
+
+```text
+CLI / desktop shortcut / drop-folder watcher
+                  |
+              Workflow
+       /         |          \
+  Recorder   API client   Desktop sinks
+                  |
+       OpenAI Whisper HTTP API
+```
+
+## Why this shape
+
+1. The current host is headless. A browser UI cannot be exercised here, while a CLI can be tested and used over SSH.
+2. The requested integration is desktop automation, so clipboard, focused-window typing and notifications belong behind adapters rather than inside API code.
+3. OpenAI Whisper is a file-upload API, not native token streaming. A complete-file workflow is honest and reliable; a folder watcher provides event-driven automation without pretending to be streaming.
+4. Standard library HTTP keeps installation deterministic on the N100 and permits a fake transport in tests.
+5. Explicit provider selection prevents accidental fake output in production.
+
+## Data flow
+
+```text
+input path
+  -> validate extension / regular file / non-empty / <= 25 MiB
+  -> read bytes
+  -> multipart request (model, language, prompt, verbose_json)
+  -> bounded retry on transient failures
+  -> parse text/language/duration/segments
+  -> atomic TXT + JSON writes
+  -> optional clipboard / xdotool / notify-send
+```
+
+## Operational modes
+
+- `transcribe`: one existing file.
+- `record`: ffmpeg captures a bounded or Ctrl-C terminated WAV, then invokes the same pipeline.
+- `watch`: poll a drop folder, wait for size stability, process each file once.
+- `doctor`: report capabilities without making network calls.
+
+## Trade-offs
+
+- Polling is less efficient than inotify but has no third-party dependency and is portable across mounted folders.

+# Whisper Desktop Workflow
+
+Linux-first Whisper API 語音轉文字工具，整合：
+
+```text
+既有音檔 / ffmpeg 麥克風錄音 / drop folder
+    -> OpenAI Whisper API
+    -> UTF-8 TXT + JSON（原子寫入）
+    -> 可選剪貼簿 / 目前焦點視窗輸入 / 桌面通知
+```
+
+本專案不是瀏覽器前端；它是可由 CLI、`.desktop` 捷徑與資料夾監控啟動的桌面自動化工具，因此沒有 `web_output.html` 交付物。
+
+## 特色
+
+- `whisper-1` + `verbose_json`，保留語言、時長與 segments。
+- 純 Python stdlib HTTP multipart；不需要 `requests`、OpenAI SDK 或其他 pip 依賴。
+- API key 只從 `OPENAI_API_KEY` 讀取；不接受 CLI key，不寫設定檔，不寫 log。
+- 429/500/502/503/504 與網路逾時採有限次數 exponential backoff；401/其他 4xx 不重試。
+- 明確 `--provider mock` 離線 deterministic 測試；預設 `api`，沒有 key 會 fail closed。
+- `--copy` 自動偵測 `wl-copy`、`xclip`、`xsel`、`pbcopy`。
+- `--type` 才會呼叫 `xdotool`/`ydotool` 將文字輸入目前焦點視窗；不會隱式啟用。
+- `record` 透過 ffmpeg 支援 PulseAudio/ALSA；`watch` 監控 drop folder，檔案大小穩定兩次才處理。
+- user-local 安裝腳本會先備份既有命令/桌面項目，移除時採移動到備份目錄而非直接刪除。
+

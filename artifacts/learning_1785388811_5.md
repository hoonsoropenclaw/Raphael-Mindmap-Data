+def sha256_file(path: Path) -> str:
+    digest = hashlib.sha256()
+    with path.open("rb") as stream:

+            digest.update(block)

+def atomic_write_json(path: Path, payload: object) -> None:
+    path.parent.mkdir(parents=True, exist_ok=True)
+    fd, temp_name = tempfile.mkstemp(prefix=f".{path.name}.", suffix=".tmp", dir=path.parent)
+    try:
+        with os.fdopen(fd, "w", encoding="utf-8") as stream:
+            json.dump(payload, stream, ensure_ascii=False, indent=2)
+            stream.write("\n")
+            stream.flush()
+            os.fsync(stream.fileno())
+        os.replace(temp_name, path)
+    finally:
+        try:
+            os.unlink(temp_name)
+        except FileNotFoundError:

+# 人事檔案即時監控工具
+
+## 內容
+
+- `hr_file_monitor.py`：stdlib-only 監控核心、SHA-256 變更偵測、JSON 狀態持久化、SSE 即時事件流與 HTML 儀表板。
+- `web_output.html`：可離線檢視的完整儀表板 HTML（監控器啟動後首頁會提供相同介面）。
+- `test_hr_file_monitor.py`：建立、修改、刪除、API health、副檔名過濾與原子狀態檔測試。
+- `run_monitor.sh`：簡易啟動器。
+
+## 啟動
+
+```bash
+mkdir -p ./hr_records
+python3 hr_file_monitor.py ./hr_records --host 127.0.0.1 --port 8765
+```
+
+開啟 http://127.0.0.1:8765/
+
+預設只監控常見人事文件：pdf、doc、docx、odt、xls、xlsx、csv、txt。若要監控所有非 symlink 檔案，加上 `--all-files`。
+
+## API
+
+- `GET /api/health`：健康檢查
+- `GET /api/state`：目前檔案、統計、事件歷史
+- `GET /api/events`：Server-Sent Events 即時事件流
+
+## 安全與可靠性設計
+
+1. 監控根目錄必須由啟動參數明確指定，不掃描整台機器。
+2. 不追蹤 symlink，避免意外跨越人事資料邊界。
+3. 狀態檔以同目錄隨機暫存檔、flush、fsync、os.replace 原子寫入。
+4. 事件保留上限 500 筆，避免長期執行無限制成長。
+5. 瀏覽器顯示相對路徑，SHA-256 僅顯示前綴；完整值仍可由 API 取得供稽核。
+6. 預設 bind 到 127.0.0.1；若需區網服務，應額外配置反向代理與認證，不建議直接暴露。
+7. 此工具是變更偵測器，不是備份系統；正式環境仍應搭配加密、權限控管與備份策略。

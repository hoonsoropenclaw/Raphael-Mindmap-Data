系統架構 · 4 模組 + 自動 fallback

01

Config

環境變數驅動，無 hardcoded secret。UA / timeout / 併發 / cache 全可調。

02

Fetcher

三層 fallback：httpx async → requests sync → Playwright (JS 渲染)。智能判斷 SPA。

03

Parser

BS4 + lxml。表格 / 列表 / 圖片 / 通用 CSS 四種 extractor。寬容、無例外崩潰。

04

Storage

JSONL (追加) / CSV (扁平化) / SQLite (可查詢)。執行緒安全。

05

CLI

fetch / batch / parse / design 四個子命令，串接 4 模組。

Python API · 一行程式碼就能用

# 1. 抓單頁 + 自動表格/列表偵測
from scraper.core import Fetcher, extract_structured

f = Fetcher()
result = f.fetch("https://example.com/gov-list")  # 自動判斷 JS 與否
data = extract_structured(result.html, url=result.final_url)
print(data["table"])  # list[dict]

# 2. 批次抓 + SQLite 落盤
import os
os.environ["SCRAPER_OUTPUT"] = "sqlite"
os.environ["SCRAPER_CONCURRENCY"] = "6"
from scraper.cli import main; main(["batch", "urls.txt"])

# 3. 強制 Playwright 抓 SPA
r = f.fetch("https://spa-site.com", force_engine="playwright")

設計決策 · 為什麼這樣做

✓ 資安

  • 所有 secret 從 os.environ 讀，無 hardcoded key
  • HTTP Basic Auth 僅在 SCRAPER_BASIC_AUTH_HOST 設定時啟用
  • UA 誠實標示 HermesScraper/1.0，不冒充瀏覽器
  • 預設 rate-limit 2 req/s，可調

⚠ 取捨

  • Playwright 啟動慢，僅 fallback 用
  • CSS selector heuristic (auto mode) 不一定命中所有頁面 → 可手動指定 --mode
  • 背景任務須手動存進度（OS timeout 風險）
  • robots.txt 預設尊重但不主動 fetch，可加強

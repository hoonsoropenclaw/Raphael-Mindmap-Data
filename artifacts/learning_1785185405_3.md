+"""SQLite persistence layer using only Python stdlib.
+
+Design choices
+--------------
+1. **stdlib sqlite3 only** (no SQLAlchemy / asyncpg).
+   - One process-local dependency surface.
+   - Predictable behaviour for tests (we can point `db_path` at `:memory:` or a tempfile).
+2. **WAL journal mode** for concurrent reader/writer friendliness.
+3. **`foreign_keys = ON`** per connection — SQLite's FK enforcement is off by default,
+   which silently breaks referential integrity for new contributors.
+4. **`check_same_thread = False`** so FastAPI's threadpool can share the connection
+   factory; we still create a fresh connection per request to avoid cross-thread state.
+5. **`Row` factory** so handlers can write `row["title"]` instead of `row[1]`.

+"""Rate limiting primitives.
+
+Design choices
+--------------
+1. **`RateLimiterProtocol`** — abstract seam so a future Redis-backed limiter
+   can swap in without touching the routers.
+2. **Sliding window** with `collections.deque` of monotonic timestamps.
+   - More accurate at burst boundaries than fixed-window counters.
+   - Lazy eviction: `deque.popleft()` of stale entries on every check.
+3. **`threading.Lock`** around mutating deque access — FastAPI runs handlers
+   in a threadpool under sync defs.

+   - `check(key)` → `(allowed, remaining, retry_after)`. Side-effectful when
+     allowed (records the hit). The router calls this once per request and
+     uses the returned values for headers.
+   - `peek(key)` → read-only inspection for tests/debugging.

+   the request. Defaults to `client.host` but the dependency can be swapped
+   for proxy-header aware logic in production.

+
+import threading
+import time
+from collections import defaultdict, deque

+from typing import Deque, Dict, Protocol

+# Todo API
+
+A small Todo REST API with SQLite persistence and per-client rate limiting.
+
+## Stack
+
+- **FastAPI** + **Uvicorn** — HTTP layer.
+- **Pydantic v2** — request/response schemas.
+- **sqlite3** (stdlib) — persistence. No ORM.
+- **pytest** + **httpx** (via FastAPI TestClient) — tests.
+
+## Run
+
+```bash
+# from this directory
+PYTHONPATH=. python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
+
+# OpenAPI / Swagger UI
+# http://127.0.0.1:8000/docs
+```
+
+The DB is created at `./todo.db` on first request (or earlier via `create_app`).
+
+Override the DB path with the `TODO_DB_PATH` env var:
+
+```bash
+TODO_DB_PATH=/tmp/my.db PYTHONPATH=. python3 -m uvicorn app.main:app
+```
+
+## API
+
+| Method | Path               | Body                | Success | Errors                |
+|--------|--------------------|---------------------|---------|------------------------|
+| GET    | `/healthz`         | —                   | 200     | —                      |
+| POST   | `/todos`           | `{"title": "..."}`  | 201     | 422 (validation)       |
+| GET    | `/todos?done=true` | —                   | 200     | —                      |
+| GET    | `/todos/{id}`      | —                   | 200     | 404 (not found)        |
+| PATCH  | `/todos/{id}`      | `{"title"?, "done"?}` | 200   | 404 / 422              |
+| DELETE | `/todos/{id}`      | —                   | 204     | 404                    |
+
+### Validation rules
+
+- `title` is stripped of leading/trailing whitespace.
+- After stripping, `title` must be **1–200 chars**.
+- Unknown fields → **422** (`extra_forbidden`).
+- `PATCH` with an empty body (`{}`) → **422**.
+
+### Rate limiting
+
+- Default budget: **60 requests / 60 seconds per key**.
+- The key is `{client.host}:{client.port}` (one bucket per TCP source).
+- Each response carries:
+  - `X-RateLimit-Limit`
+  - `X-RateLimit-Remaining`
+- When denied (HTTP **429**):
+  - `Retry-After: <seconds>` (integer, ≥ 1).
+  - `X-RateLimit-Remaining: 0`
+- `/healthz` is intentionally **outside** the rate-limited router.
+
+Swap the limiter by passing `rate_limiter=` to `create_app(...)`. The routers only depend on the `RateLimiterProtocol`.

+### 架構決策
+
+**1. stdlib sqlite3,不用 SQLAlchemy**
+- 依賴最小化:production runtime 只有 fastapi/uvicorn/pydantic
+- 沒有 async 連線池的複雜度;每個 request 一個 connection,WAL 模式支援「多 reader + 1 writer」併發
+- `check_same_thread=False` 讓 threadpool 安全共享 connection factory
+- `isolation_level=None` (autocommit) 配合 explicit transaction
+
+**2. 三條 PRAGMA,每個 connection 都跑**
+- `PRAGMA journal_mode = WAL;` — 高併發讀寫
+- `PRAGMA foreign_keys = ON;` — SQLite 預設是 OFF,這條最容易踩雷
+- `PRAGMA synchronous = NORMAL;` + `PRAGMA busy_timeout = 5000;` — WAL 下的 sweet spot
+
+**3. `RateLimiterProtocol` 是 DI seam**
+- routers 只依賴 Protocol,不看實作
+- 未來換 Redis,只需新寫 class:`app.dependency_overrides[get_rate_limiter] = lambda: RedisLimiter()`
+- 完全不動 router code
+
+**4. Sliding window + threading.Lock**
+- `deque` 存 monotonic timestamps;`popleft()` lazy eviction
+- 比 fixed-window counter 在 burst 邊界準確
+- `threading.Lock` 包住 mutating access — FastAPI sync handler 跑在 threadpool
+- 接受 `time_source` callable — 測試用 `FakeClock` 不用 sleep
+
+**5. Schema 設計**
+- 所有 Pydantic model 設 `extra="forbid"` — 客戶端送未知欄位直接 422
+- `title` 用 `StringConstraints(strip_whitespace=True, min_length=1, max_length=200)`
+- `TodoPatch` 用 `@model_validator(mode="after")` 拒絕 `{}` 空 body
+- 422 error shape 透過 `exception_handler` 攔截,讓 client 拿到穩定的 `{"detail": [...]}` 結構
+
+**6. App 工廠模式 + dependency_overrides**
+- `create_app(db_path, rate_limiter)` 是 single source of truth
+- module-level `app = create_app()` 給 `uvicorn app.main:app` 用
+- 測試傳入 temp DB path + 高額度 limiter,完全隔離
+- `_build_router()` 跟 `_register_validation_handler()` 拆出去,主函式只負責 wiring
+
+**7. Rate-limit keying:`{client.host}:{client.port}`**
+- 同一 NAT 下不同 client 因 ephemeral port 不同 → 各自有 bucket
+- 生產環境放 reverse proxy 後:改 `rate_limit_dependency` 的 key 邏輯(例如解析 X-Forwarded-For)即可,router 不動
+
+**8. HTTP 細節**
+- 成功回應永遠帶 `X-RateLimit-Limit` + `X-RateLimit-Remaining`
+- 429 帶 `Retry-After` (RFC 7231 整數秒,至少 1,避免「retry after 0s」這種廢話)
+- `/healthz` 在 app 直掛,不過 rate-limit router(省 quota)

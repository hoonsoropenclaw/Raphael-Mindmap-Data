+## Architecture
+
+`HTTP → middleware → router → service → repository → AsyncSession → async driver`
+
+Dependencies flow inward. Routes own HTTP semantics; service owns transaction/use-case logic; repository owns SQL statements; database module owns engine/session lifecycle.
+

+- `Dockerfile`, `.dockerignore`, `.env.example`, `Makefile`, `README.md` — CREATE operation artifacts.
+
+## Data model
+
+Todo: integer PK, non-empty title <=200, optional description <=2000, boolean completion, timezone-aware created/updated timestamps. Index supports keyset pagination by monotonically increasing ID.
+
+## Engine policy
+
+- SQLite: `sqlite+aiosqlite`, no QueuePool-only kwargs, foreign keys enabled, WAL/busy timeout for file DB; `StaticPool` only for in-memory tests.
+- PostgreSQL-like network DB: bounded `pool_size`, `max_overflow`, `pool_timeout`, `pool_recycle`, `pool_pre_ping=True`.
+- Worker budget rule documented: `(pool_size + max_overflow) × worker_count` must fit DB/PgBouncer connection budget.
+
+## Middleware order/semantics
+
+- Request-ID: accept only UUID; otherwise generate UUID4; return `X-Request-ID`.
+- Body limit: reject declared oversized body with 413 before route logic.
+- Timeout: `asyncio.timeout`; return 504.
+- In-memory token bucket: async lock and bounded stale-key pruning; 429 + `Retry-After`. Explicitly single-worker/demo only.
+- Metrics: route template, method, status only; no raw IP/path labels.
+- Security headers: nosniff, deny framing, no-referrer.
+

+

+
+## Rollback

+All implementation is isolated under `async_fastapi_template/`. A pre-edit source snapshot will be placed under `/tmp` before any corrective patch. Removing/moving that one directory restores the original workspace.

+from __future__ import annotations
+
+import argparse
+import asyncio
+import json
+import time
+
+import httpx
+
+
+async def run(base_url: str, requests: int, concurrency: int) -> dict[str, float | int]:
+    semaphore = asyncio.Semaphore(concurrency)
+    latencies: list[float] = []
+    statuses: list[int] = []
+
+    async with httpx.AsyncClient(base_url=base_url, timeout=5) as client:
+        async def one() -> None:
+            async with semaphore:
+                started = time.perf_counter()
+                response = await client.get("/health/live")
+                latencies.append(time.perf_counter() - started)
+                statuses.append(response.status_code)
+
+        started = time.perf_counter()
+        await asyncio.gather(*(one() for _ in range(requests)))
+        elapsed = time.perf_counter() - started
+
+    ordered = sorted(latencies)
+    p95_index = max(0, min(len(ordered) - 1, round(0.95 * len(ordered)) - 1))
+    result: dict[str, float | int] = {
+        "requests": requests,
+        "concurrency": concurrency,
+        "elapsed_seconds": round(elapsed, 4),
+        "requests_per_second": round(requests / elapsed, 2),
+        "p95_ms": round(ordered[p95_index] * 1000, 2),
+        "success": sum(status == 200 for status in statuses),
+        "http_5xx": sum(status >= 500 for status in statuses),
+    }
+    return result
+
+
+async def main() -> None:
+    parser = argparse.ArgumentParser()
+    parser.add_argument("--base-url", default="http://127.0.0.1:8765")
+    parser.add_argument("--requests", type=int, default=100)
+    parser.add_argument("--concurrency", type=int, default=25)
+    args = parser.parse_args()
+    result = await run(args.base_url, args.requests, args.concurrency)
+    print(json.dumps(result, sort_keys=True))
+    if result["success"] != args.requests or result["http_5xx"] != 0:
+        raise SystemExit("concurrency probe failed")
+
+

+    asyncio.run(main())

關於這個 Demo

本檔由赫米斯 (Hermes) 自主生成,融合了 advanced_ui_development + frontend_application_optimization + standalone_web_application_development 三個微技能的精神。

  • backdrop-filter + mix-blend-mode 模擬真實玻璃質感
  • content-visibility: auto 對離開視口的卡片跳過渲染
  • will-change 提示瀏覽器把動畫元素提升到獨立圖層
  • CSS @property / custom property 統一設計 token,主題切換零成本
  • font-display: swap + 預連接,字體不阻塞首屏
  • prefers-reduced-motion 自動停用動效,尊重無障礙偏好
  • contain: layout paint 限制 blob 動畫的影響範圍
  • PerformanceObserver 即時蒐集 Web Vitals,不寫假數字

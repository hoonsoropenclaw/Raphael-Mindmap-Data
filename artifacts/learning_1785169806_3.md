+# Telegram 天氣 Bot
+
+接收任意文字訊息、解析出城市、呼叫 **Open-Meteo**（免費無 key）查當前天氣 + 12 小時預報，回傳 Markdown 訊息。
+
+## 架構
+
+```
+┌────────────┐      ┌──────────────────┐      ┌─────────────────┐
+│ Telegram   │ ───▶ │  bot.py          │ ───▶ │  weather.py     │ ───▶ Open-Meteo APIs
+│ 使用者訊息 │      │  (handler, FSM)  │      │  (city → coords │     ├─ geocoding-api
+│            │ ◀─── │                  │ ◀─── │   → weather)    │     └─ api/v1/forecast
+└────────────┘      └──────────────────┘      └─────────────────┘
+```
+
+**分離原則**：`weather.py` 完全獨立於 Telegram，只要 `query_weather(text) -> WeatherResult`、`format_result(result) -> str` 就活；要換 LINE/Discord/Slack 介接，bot.py 換掉就好。
+
+## 檔案
+
+| 檔案 | 職責 |
+|------|------|
+| `weather.py` | 天氣核心（geocoding + WMO 解碼 + 格式化）+ CLI 測試入口 |
+| `bot.py` | Telegram 介接層（polling / webhook 雙模式） |
+| `mock_telegram_test.py` | 不需 token 的端對端測試（mock Update 物件） |
+| `requirements.txt` | 套件依賴 |
+
+## 快速開始
+
+### 1. 拿 Telegram Bot Token
+
+跟 [@BotFather](https://t.me/BotFather) 要 token：
+
+```
+/newbot
+→ 為你的 bot 取名字
+→ 為你的 bot 取 username（必須以 bot 結尾）
+→ 拿到一串 token，例如 1234567890:AAH...
+```
+
+### 2. 跑起來
+
+```bash
+# 安裝
+pip install -r requirements.txt
+
+# 設環境變數（必要）
+export TELEGRAM_BOT_TOKEN="1234567890:AAH..."
+
+# 跑（預設 polling 模式）
+python bot.py
+```
+
+然後在 Telegram 跟你的 bot 對話：傳 `台北`、`天氣 東京`、`Tokyo` 都會回天氣。
+
+### 3. CLI 直接測試核心
+
+```bash
+python weather.py "台北"
+python weather.py "高雄"
+python weather.py "Tokyo"
+```
+
+## 測試
+
+不需 Telegram token：
+
+```bash
+python mock_telegram_test.py
+# 7/7 通過
+```
+
+## Webhook 模式（生產部署）
+
+```bash
+export TELEGRAM_BOT_TOKEN="..."
+export WEBHOOK_URL="https://your-domain.com/webhook"
+export PORT=8080
+python bot.py
+```

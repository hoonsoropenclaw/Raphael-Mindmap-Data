🏗️ 設計系統架構

  
TokenFlow 採用「單一來源 → 多格式輸出」模型，所有下游產物由同一組 HSL 通道驅動。


  

    

      

        
1

        
單一來源

        
Primary/Accent/Base 三組 HSL 通道（hue, saturation, lightness）。

      

    

    

      

        
2

        
派生色階

        
依 L 曲線生成 11 階（50→950）色票，視覺上均勻遞增。

CSS 變數

        
寫入 :root 與 DaisyUI 主題槽，全域即時切換。

CSS / Tailwind / JSON / SCSS 一鍵複製。

      

    

  


  

    

      
🎓 設計令牌心法

      
    
        
  • 單一來源（Single Source of Truth）是設計系統的命脈——Hue 改變，所有下游同步。
    • 
        
  • HSL 是設計師友善的色彩空間：Hue 定義色相、Saturation 定義鮮豔、Lightness 定義明暗。
    • 
        
  • 11 階色票（50/100/200…950）對應 Tailwind 預設，能與生態系無縫協作。
    • 
        
  • DaisyUI 4 主題槽（--p、--b1、--bc 等）讓設計令牌直接驅動元件顏色。
    • 
        
  • 設計令牌不只是顏色——還涵蓋圓角、字型、字重、間距、陰影等「視覺常數」。

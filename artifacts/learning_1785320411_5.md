+# batch_video_renderer
+
+> **FFmpeg + Python 批量視頻渲染自動化工具** — stdlib-only,profile 驅動,平行處理,完整 retry 與結構化 report。
+
+## 特色
+
+- **零依賴**:僅使用 Python 3.10+ stdlib + 系統 FFmpeg 6.x。沒有 `pyyaml` / `requests` / `ffmpeg-python`。
+- **Profile-driven**:7 種預設 profile(web / HQ / WebM / 短影音 / 歸檔 / 純音訊 / GIF),也可自訂。
+- **平行渲染**:`ThreadPoolExecutor`,預設 2 workers。
+- **Retry 機制**:每個 job 預設 retry 2 次,timeout 不重試(避免卡住)。
+- **結構化 report**:JSON 格式 `render_report.json`,記錄每個 job 的 status / attempts / duration / bytes / error。
+- **健全失敗**:profile 套不上 → 標 failed + 錯誤訊息;不破壞整批。
+- **Dry-run 模式**:只列出 ffmpeg 命令,不實際執行(適合 CI 預覽)。
+- **支援單檔或目錄**:既可 `python3 batch_render.py -i single.mp4 ...` 也可 `-i /videos/ ...`。
+
+## 安裝需求
+
+```bash
+# Ubuntu / Debian
+sudo apt install ffmpeg python3
+

4 · 方法論 · Playwright Pipeline

資料流：crawler.py → audit_data.json → web_output.html

🕷️

Step 1 · Playwright Crawler

async chromium headless,1280×800 viewport,`--no-sandbox` 以對應 N100 容器環境。每站 goto + screenshot + evaluate(getComputedStyle) 採樣。失敗不 abort,partial data 仍能渲染。

🎨

Step 2 · Design Token Extraction

取樣前 200 個 element 的 fontSize / color / borderRadius / boxShadow,並用 regex (`bg-{palette}-{step}`) 偵測是否使用 Tailwind utilities。

📊

Step 3 · 設計成熟度評分

typography（型態比例） × consistency（半徑去重） × palette（色票數） × tooling（Tailwind 偵測）四維加權,產出 0-100 總分。

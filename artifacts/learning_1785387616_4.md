+# Design Aesthetics Library
+
+A web-scraping pipeline that crawls curated reference sites with **BeautifulSoup + Playwright**, extracts every visual parameter it can find, and aggregates them into a frequency-weighted design parameter library. The output is rendered as `web_output.html` — a single-file dark-themed explorer.
+
+## Files
+
+```
+scraper/
+  extractors.py     pure functions that pull parameters from raw CSS text
+  fetchers.py       requests + Playwright pipeline; URLs to crawl
+  pipeline.py       orchestrates fetch → extract → aggregate → save
+  render.py         builds web_output.html from design_params.json
+data/
+  raw_sites.json    per-site raw HTML + CSS blob (~25 MB; large)
+  design_params.json aggregated library (~250 KB)
+web_output.html     rendered explorer (72 KB; self-contained)
+```
+
+## Re-run
+
+```bash
+cd scraper
+python3 pipeline.py     # fetch + extract + aggregate (~6 min for 20 sites)
+python3 render.py       # write web_output.html
+```
+
+Or open `web_output.html` directly in a browser — no server needed.
+
+## What gets measured
+
+For each site, the pipeline collects:
+
+| Dimension    | Source regex / heuristic                         |
+|--------------|--------------------------------------------------|
+| Typography   | `font-family`, `font-size`, `font-weight`, `line-height`, `letter-spacing` |
+| Color        | hex / rgb / hsl, hue family, saturation, brightness via WCAG luminance |
+| Geometry     | `border-radius`, `box-shadow`, `text-shadow`, gradients, transforms, `backdrop-filter` |
+| Motion       | `transition`, `animation`, durations bucketed into snap/quick/medium/slow/cinematic |
+| Layout       | `gap`, `padding`, `margin`                       |
+| Meta         | title, theme-color, lang, viewport, og:image     |

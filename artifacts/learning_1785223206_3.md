+# GitHub Trending → Markdown
+
+A dependency-free Python 3 script that scrapes GitHub Trending and renders a Markdown table.
+
+## Usage
+
+```bash
+# Print daily trending to stdout
+python3 github_trending.py
+
+# Save top 10 weekly Python repositories atomically
+python3 github_trending.py --language python --since weekly --limit 10 --output trending.md
+
+# Monthly C++ repositories
+python3 github_trending.py --language 'c++' --since monthly --output cpp-trending.md
+```
+
+Options:
+
+- `--since daily|weekly|monthly` (default: `daily`)
+- `--language LANGUAGE` (optional)
+- `--limit 1..100` (default: `25`)
+- `--output PATH` (omit for stdout)
+- `--timeout SECONDS` (default: `20`)
+
+## Automation
+
+Example cron entry (every day at 09:00):
+
+```cron
+0 9 * * * cd /absolute/path/to/project && /usr/bin/python3 github_trending.py --limit 20 --output trending.md >> cron.log 2>&1
+```
+
+## Reliability and security
+
+- Pure Python standard library; no token or third-party package required.
+- Identifiable User-Agent and bounded network timeout.
+- Maximum HTTP response size is 5 MiB to prevent unbounded memory use.
+- Atomic output (`mkstemp` + `fsync` + `os.replace`) avoids partial files.
+- POSIX directory `fsync` is guarded on Windows.
+- Markdown metacharacters in scraped text are escaped.
+- Explicit non-zero exit on network or parser failure.
+
+## Test
+
+```bash
+python3 -m unittest -v
+python3 github_trending.py --limit 5 --output trending.md
+```
+
+Note: GitHub does not provide an official Trending API. This tool parses the public Trending HTML, so a major GitHub markup change can require parser maintenance; failure is explicit rather than silently producing an empty table.

+## Architecture
+
+1. `build_url()` constructs daily/weekly/monthly and optional language routes.
+2. `fetch_html()` performs a bounded, timed HTTPS GET with an identifiable User-Agent.
+3. `TrendingParser` uses Python's `HTMLParser`, scoped to `article.Box-row`, and extracts repository name, description, language, stars, forks, and period stars.
+4. `render_markdown()` escapes backslashes and pipes before generating a Markdown table.
+5. `atomic_write()` writes to a sibling temporary file, flushes and fsyncs, then atomically replaces the destination.
+6. `main()` validates arguments and provides explicit non-zero exits on network/parser failures.
+
+## Debug history and corrective action

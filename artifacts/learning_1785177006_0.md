+# GitHub Trending Markdown Exporter
+
+A dependency-free Python script that fetches GitHub's public Trending page and writes a Markdown table of repositories.
+
+## Features
+
+- Python standard library only; no `pip install` or GitHub token required.
+- Filters by language and period: `daily`, `weekly`, or `monthly`.
+- Outputs repository, description, language, stars, forks, and stars gained today.
+- Uses a semantic `HTMLParser`, including protection against `img`/`br` void-element depth bugs.
+- Uses atomic output replacement so an interrupted run cannot leave a partial Markdown file.
+- Uses a non-blocking `fcntl.flock` lock to prevent overlapping runs from corrupting the same output.
+- Never accepts secrets as CLI flags; there are no token or webhook arguments.
+
+## Usage
+
+From this directory:
+
+```bash
+python3 github_trending.py
+python3 github_trending.py --language Python --since weekly --limit 10 --output python-weekly.md
+python3 github_trending.py --language TypeScript --output -
+```
+
+Default output: `trending.md` in the current directory.
+
+The output is a Markdown document containing a table such as:
+
+```markdown
+| Rank | Repository | Description | Language | Stars | Forks | Stars today |
+|---:|---|---|---|---:|---:|---:|
+| 1 | [owner/repo](https://github.com/owner/repo) | ... | Python | 12,345 | 678 | 123 |
+```
+
+## Automation
+
+Example daily cron entry (run from the project directory):
+
+```cron
+15 9 * * * cd /absolute/path/to/project && /usr/bin/python3 github_trending.py --since daily --output trending.md >> trending.log 2>&1
+```
+
+The lock file is adjacent to the output as `.trending.md.lock`. It is safe to retain; it contains no credentials or repository data.
+
+## Verification
+
+Run the offline regression suite:
+
+```bash
+python3 -m unittest -v test_github_trending.py
+python3 -m py_compile github_trending.py test_github_trending.py
+```
+
+Run a real network smoke test:
+
+```bash
+python3 github_trending.py --limit 5 --output trending.md
+```
+
+## Limitations
+
+GitHub Trending is a public HTML page rather than a versioned API. If GitHub changes its card markup or blocks the request, the script exits non-zero with a clear error instead of writing fabricated or empty data. The parser deliberately fails on an empty recognizable result so a scheduled job cannot silently replace a good report with a blank one.

+## 2. 實作思路
+
+### 2.1 來源與請求
+
+GitHub Trending 沒有穩定的公開 JSON API，因此使用公開 HTML endpoint：
+
+```text
+https://github.com/trending[/{language}]?since={daily|weekly|monthly}
+```
+
+請求使用 `urllib.request.Request`，設定明確 User-Agent 與 Accept header。腳本不接受 token、webhook URL 或其他敏感值 CLI 參數，避免敏感內容進入 process list。
+
+### 2.2 HTML 解析
+
+使用 Python `html.parser.HTMLParser`，透過 `article.Box-row` 辨識 repository card，並從語意欄位取得：
+
+- repository path：`h2` 內的 repository link
+- description：`p`
+- language：`span[itemprop="programmingLanguage"]`
+- stars / forks：對應 link
+- 今日增加 stars：`span.float-sm-right`
+
+解析器維護 article depth，並明確排除 HTML void elements（例如 `img`、`br`、`meta`）對 depth 的影響。這直接吸收 Senior Architect 先前回饋中的 HTMLParser 深度陷阱，避免一個沒有 closing tag 的 `img` 讓後續整張卡片無法收束。
+
+### 2.3 Markdown 輸出
+
+輸出由 `render_markdown()` 統一產生，表格欄位為：
+
+```text
+Rank | Repository | Description | Language | Stars | Forks | Stars today
+```
+
+欄位會處理換行與 `|` 字元，避免 description 破壞 Markdown table。Repository 名稱使用 GitHub link，沒有 repository path 的 malformed card 會被丟棄，不會產生假資料。
+
+### 2.4 原子寫入與併發保護
+
+輸出檔案使用以下流程：
+
+1. 在輸出檔案同一目錄建立唯一 `.tmp` 檔（`tempfile.mkstemp`）
+2. 寫入 UTF-8 內容
+3. `flush()` + `os.fsync()`
+4. `os.replace()` 原子替換正式檔案
+5. 例外時刪除暫存檔
+
+輸出檔旁建立 `.trending.md.lock`，使用 `fcntl.flock(LOCK_EX | LOCK_NB)`，避免兩個 cron run 同時覆蓋同一份 Markdown。lock file 是預期的持久檔案，不是半成品或暫存輸出。
+

+# GitHub Trending Fetcher
+
+自動抓取 [GitHub Trending](https://github.com/trending) 的熱門 repositories，並輸出成 Markdown 表格。
+
+## 快速開始
+
+```bash
+# 預設：抓今日 daily 全部 15 名，輸出到 stdout
+python3 github_trending.py
+
+# 存成檔
+python3 github_trending.py -o trending.md
+
+# 只看前 5 名
+python3 github_trending.py --top 5
+
+# Python 每週熱門
+python3 github_trending.py --lang python --since weekly
+
+# 限定中文 README 的專案
+python3 github_trending.py --spoken-language zh
+
+# 機器可讀格式
+python3 github_trending.py --json -o trending.json
+
+# Debug：另存原始 HTML
+python3 github_trending.py --html-output /tmp/raw.html
+```
+
+## 參數
+
+| 參數 | 說明 | 預設 |
+|------|------|------|
+| `--lang <language>` | 限定語言（如 `python`, `go`, `typescript`） | 無 |
+| `--since <period>` | `daily` / `weekly` / `monthly` | `daily` |
+| `--spoken-language <code>` | 自然語言 filter（如 `en`, `zh`, `ja`） | 無 |
+| `--top <N>` | 只輸出前 N 名 | 全部 |
+| `-o, --output <file>` | 輸出檔 | stdout |
+| `--html-output <file>` | 另存原始 HTML（debug 用） | 無 |
+| `--json` | 輸出 JSON 而非 Markdown | false |
+| `--quiet` | 不要 banner | false |
+
+## 輸出格式
+
+Markdown 表格包含 7 個欄位：
+
+| # | Repository | Language | Stars | Stars (today) | Forks | Description |
+|---|------------|----------|------:|--------------|------:|-------------|
+
+JSON 模式輸出原始資料，每筆包含 `rank`, `full_name`, `owner`, `name`, `url`, `description`, `language`, `stars`, `forks`, `stars_period`。
+
+## 設計重點
+
+- **無第三方 API**：直接抓 HTML 解析，requests + BeautifulSoup 即可，無需 Selenium。
+- **失敗可還原**：每次抓的 HTML 都會落 `/tmp/ghtrending_<lang>_<since>_<ts>.html`，parser 改壞時可離線重跑。
+- **結構化寬鬆解析**：用 `article.Box-row` 為主鍵，欄位從 href 與 itemprop 拿，比對 class 寫死更穩。
+- **寬 User-Agent**：Chrome 120，避免被當成 bot。
+
+## 依賴
+
+```
+requests >= 2.30
+beautifulsoup4 >= 4.12
+```
+
+系統已預裝（python 3.12.3）。

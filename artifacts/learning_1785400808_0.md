+#!/usr/bin/env node
+/**
+ * cross_browser_test.js — Playwright 跨瀏覽器 UI 組件視覺回歸測試引擎
+ * =================================================================
+ * 把同一組 UI 組件（components.html）放進 chromium / firefox / webkit 三個
+ * 瀏覽器引擎渲染，截圖後做像素級比對，找出跨瀏覽器的渲染差異。
+ *
+ * 使用：
+ *   node cross_browser_test.js capture   — 在三個瀏覽器截圖每個組件
+ *   node cross_browser_test.js diff      — 以 chromium 為基準，與 firefox/webkit 像素比對
+ *   node cross_browser_test.js all       — capture + diff 一次跑完
+ *   node cross_browser_test.js status    — 顯示最近報告
+ *
+ * 設計重點：
+ *   - chromium/  firefox/  webkit/  三個目錄各放每個瀏覽器的截圖
+ *   - diff/      放瀏覽器間差異圖（紅色高亮差異像素）
+ *   - baselines/ 放預期的「黃金基準」（可選，預設以 chromium 為基準）
+ *   - report.json 機器可讀的測試結果
+ */

+  diff: path.join(ROOT, 'diff'),

+# 跨瀏覽器 UI 視覺回歸測試
+
+用 **Playwright** 把同一組 UI 組件（button / card / modal / form / badge / alert）放進 **Chromium / Firefox / WebKit** 三個瀏覽器引擎渲染，截圖後用 **pixelmatch** 做像素級比對，找出跨瀏覽器的渲染差異。
+
+## 檔案總覽
+
+```
+.
+├── components.html            # 6 個 UI 組件的 HTML fixtures
+├── cross_browser_test.js      # Playwright 跨瀏覽器截圖 + pixelmatch 比對引擎
+├── build_web_output.py        # 把截圖 + diff 圖 + report.json 打包成 dashboard
+├── package.json               # Node.js 相依：playwright / pixelmatch / pngjs
+├── config.json                # 視窗大小 / 組件清單 / 容忍閾值
+├── report.json                # 機器可讀的測試結果（最新一次跑出來的）
+│
+├── chromium/                  # Chromium 引擎的 6 張組件截圖
+├── firefox/                   # Firefox 引擎的 6 張組件截圖
+├── webkit/                    # WebKit 引擎的 6 張組件截圖
+├── diff/                      # 12 張跨瀏覽器差異圖（紅色高亮差異像素）
+├── meta/                      # 每個瀏覽器的截圖 metadata（UA / 時間 / viewport）
+│
+└── web_output.html            # 單一檔 dashboard，所有截圖 base64 內嵌，離線可開
+```
+
+## 使用方式
+
+### 一次跑完整流程（推薦）
+
+```bash
+node cross_browser_test.js all
+```
+
+這會依序執行：
+1. 在 chromium / firefox / webkit 三個瀏覽器渲染 components.html，截圖 6 個組件
+2. 以 chromium 為基準，把 firefox / webkit 的截圖做像素比對
+3. 產生 report.json（包含每個組件 × 每個瀏覽器的差異率 + 嚴重程度）
+
+### 分開跑
+
+```bash
+node cross_browser_test.js capture   # 只截圖
+node cross_browser_test.js diff      # 只比對（需先跑 capture）
+node cross_browser_test.js status    # 顯示最近一次報告的摘要
+```
+
+### 產生 dashboard
+
+```bash
+python3 build_web_output.py
+```
+
+這會把 report.json + 全部 PNG 截圖 + diff 圖打包成 `web_output.html`（單一 HTML，base64 內嵌，雙擊即可用瀏覽器打開）。

    - chromium/, firefox/, webkit/ — 每個瀏覽器各 6 張組件截圖
    - diff/ — 12 張跨瀏覽器差異圖

    實際跑出來的發現
    - 0 通過 / 4 警告 / 8 失敗
    - 真實的跨瀏覽器渲染差異被捕獲：
      - Button：1.18% / 1.29% (字型抗鋸齒)
      - Badge：0.65% / 0.68% (圓角渲染)
      - Alert：3.63% / 3.30% (icon 圓形渲染)
      - Card：2.18% / 2.16% (陰影)
      - Form & Modal：100% 差異（Firefox / WebKit 高度比 Chromium 少 1px → 尺寸不一致觸發 fail）
    - 整體識別到設計師需要修的 cross-browser 一致性問題
    
    技術亮點
    1. 真實三引擎渲染 — 不只 Chrome，連 Safari (WebKit) 跟 Firefox 都實際跑
    2. 尺寸不一致處理 — 紅色背景並排標記，方便診斷
    3. 可重跑的 baseline 流程 — init → capture → diff → report
    4. 互動式 inspector — dashboard 點任一截圖放大比對，ESC 關閉
    5. 完全 self-contained HTML — base64 內嵌所有 PNG，雙擊可開、可 email、可 CI artifact

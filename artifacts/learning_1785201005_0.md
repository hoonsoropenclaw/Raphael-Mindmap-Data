+## 一、任務理解
+
+輸入:GitHub Trending 頁面(公開,匿名可讀,沒有正式 API)。
+輸出:結構化 markdown 表格(rank / repo / description / language / stars / forks / period-stars)。
+約束:不消耗 API token、不佔 GitHub 速率限制、可重複執行。
+
+## 二、選型:為什麼 HTML 抓取而不是 API?
+
+評估了 3 條路:
+
+| 方案 | 成本 | 配額 | 結果品質 | 結論 |
+|------|------|------|---------|------|
+| **GitHub Search API** `search/repositories?q=created:>...stars:>...` | 需 token | 30 req/hr(unauth)、5000/hr(auth) | 需自己組合 trending 邏輯(近 N 天 + 高 star) | ❌ 不對等 trending |
+| **GitHub HTML 頁** `/trending` | 0 | 0 | GitHub 自己算好的榜單 | ✅ **選這個** |
+| 第三方 gh-trending mirror (ghapi.dev 等) | 0 | 不確定 | 黑箱、隨時掛 | ❌ 不穩定 |
+
+`/trending` 本身就是 GitHub 為 trending 場景量身打造的頁面,有官方 `?since=daily|weekly|monthly` 與 `?language=python` 參數,完全不需要重新發明搜尋邏輯。
+
+## 三、頁面結構與解析策略
+
+`curl https://github.com/trending` 拿到 HTML 後:
+- 每個 repo 包在 `<article class="Box-row">` 裡(實測 15~25 個)
+- 標題在 `<h2><a href="/owner/repo">owner / repo</a></h2>`
+- description 在 `<p class="col-9">`
+- language 在 `<span itemprop="programmingLanguage">`
+- total stars / forks 在 `href=.../stargazers` 與 `.../forks` 的 anchor 文字
+- period stars(`2,346 stars today`)渲染成 `<span>`
+
+實作細節:
+- 用 `requests` + 真 Chrome UA(實測 GitHub 不會對腳本擋,但有助於迴避假 UA)
+- 3 次指數退避重試(2s, 4s),容忍短暫 5xx
+- `BeautifulSoup` 解析,核心 regex 只在兩處:解析 stars 數字(`"1,234"` → `1234`)與解析 period stars
+- **空結果 graceful**:語言沒人用時(實測 cobol)回 `_No trending repositories found._`
+
+## 四、debug 紀錄:monthly 模式的兩個坑
+
+第一次跑 `--since monthly` 結果 22 篇(應該 25),且部分 row 沒 period stars。追下去:
+
+1. **monthly 模式 HTML 結構微差**:period stars 在 monthly 渲染時不是直接 `<span>`,而是帶 wrapper。我的 regex 只看 `<span>` 就 miss 掉了。
+   - 修正:先掃 spans,fallback 掃整個 article text,regex 從 `re.match` 改 `re.search`(因為 span 可能被 nested element 包進去)。
+
+2. **Sponsor 卡片混入**:GitHub 把 sponsor promo 也用 `<article class="Box-row">` 渲染,導致 Box-row 數量虛胖且沒有 period stars。
+   - 修正:parse 階段如果 `stars_in_period is None` 就直接 `continue` 跳過。這樣的隱性 side-effect 是 **順便當作 sanity check** — 任何「在 trending 頁卻沒 period star」的卡片都會被當廣告丟掉。
+
+修完三個情境(daily/weekly/monthly)都乾淨。
+

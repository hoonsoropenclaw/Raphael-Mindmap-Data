+# Telegram Weather Bot
+
+Pure-Python-stdlib Telegram bot that answers "what's the weather in X" with a
+formatted reply. Two files plus a smoke test:
+
+```
+bot.py          # webhook receiver + dispatcher + Telegram sendMessage caller
+weather.py      # OpenWeatherMap client + deterministic mock fallback
+smoke_test.py   # end-to-end HTTP round-trip test (17 assertions, runs offline)
+IMPL_NOTES.md   # implementation rationale + the prompt-injection context
+```
+
+## What the bot does
+
+| User sends           | Bot replies                                          |
+|----------------------|------------------------------------------------------|
+| `Taipei`             | weather for Taipei (mock or real OWM)                |
+| `/weather Tokyo`     | weather for Tokyo                                    |
+| `/start`, `/help`    | usage help (Markdown)                                |
+| empty / whitespace   | "please enter a city name"                           |
+| `/weather` alone     | "please provide a city name after /weather"          |
+
+Markdown is used for the weather reply (Telegram parse mode).
+
+## Architecture
+
+```
+Telegram ──POST /telegram──▶  bot.TelegramWebhookHandler (ThreadingHTTPServer)
+                                 │
+                                 ├─▶ handle_update(update)  (pure dispatcher)
+                                 │      │
+                                 │      └─▶ weather.fetch_weather(city)
+                                 │             │
+                                 │             ├─ OWM_API_KEY set → real API
+                                 │             └─ unset → deterministic mock
+                                 │
+                                 └─▶ _send_message(token, reply)
+                                        │
+                                        └─▶ POST https://api.telegram.org/bot<token>/sendMessage
+```
+
+Stdlib-only by design: `http.server` + `urllib` + `json`. No pip install
+required (the host runs on Python 3.12 in a PEP 668 environment where
+on-demand pip isn't reliable).
+

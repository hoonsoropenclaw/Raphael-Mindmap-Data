Get started

Drop the CSS into
your tailwind.config.

One plugin, one accent, one motion contract. Pull from npm or paste the snippet. The reduced-transparency fallback ships in the same file.

tailwind.config.ts 
import { frosted } from '@frosted/ui';

export default {
  plugins: [frosted],
  theme: {
    extend: {
      colors: { accent: '#11d2a7' },
      borderRadius: { glass: '24px' },
    },
  },
};

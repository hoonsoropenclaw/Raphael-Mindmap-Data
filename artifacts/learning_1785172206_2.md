+# React UI 元件 — Kanban Task Board
+
+## 概要
+
+完整的 React 18 + Vite SPA，內含一個複雜狀態管理元件：
+
+- `TaskBoard` — Kanban 風格任務管理

+  - Inline 編輯（雙擊標題、Enter 存、Esc 取消）
+  - 篩選（依標籤 + 全文搜尋）+ 排序（依建立/到期/優先序）

+```

+- reducer 是純函式（state in, state out，無副作用）

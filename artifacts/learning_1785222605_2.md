+def _read_proc_stat() -> tuple[int, list[int]]:
+    """Read /proc/stat and return (jiffy_unit, cpu_times_list).
+
+    Returns the cumulative jiffies for cpu (first line).
+    Raises OSError on read failure.
+    """
+    # /proc/stat is small and well-formed; tiny cap is enough.
+    with open("/proc/stat", "rb") as f:
+        raw = f.read(MAX_BYTES).decode("utf-8", errors="replace")
+    # First non-empty line: "cpu  user nice system idle iowait irq softirq steal guest guest_nice"
+    first = next((ln for ln in raw.splitlines() if ln.startswith("cpu ")), "")
+    if not first:
+        raise OSError("/proc/stat: no cpu line found")
+    parts = first.split()
+    # tokens[0]=='cpu', tokens[1:] = numbers
+    jiffies = [int(x) for x in parts[1:]]
+    # Jiffy unit is typically 1/100 sec on modern Linux (USER_HZ).
+    # We don't need absolute seconds — just deltas — so unit cancels out.
+    return 1, jiffies

+    """A single threshold rule.
+

+        reading_key in `reading` paths through `path` and is `>=` value

+# sysmon — Linux system log + resource watchdog
+
+Pure-stdlib (zero third-party deps) Linux monitor that collects CPU /
+memory / load / disk / process state and tail-scans syslog-style logs.
+When sustained breaches hit a configurable threshold, alerts flow to one
+or more handlers (stdout, JSONL file, webhook).
+
+```
+$ python3 -m sysmon --once --config config/sysmon.example.json
+```
+
+---
+
+## Why
+
+Senior architect feedback across three prior projects distilled into
+the design rules this script respects:
+
+| Lesson                                                 | Where it lives                                                            |
+|---------------------------------------------------------|---------------------------------------------------------------------------|
+| Bounded reads everywhere (no OOM on path. server)       | `collectors.MAX_BYTES = 64 KiB`, `_safe_tail(max_bytes=256 KiB)`, `WebhookHandler.MAX_RESPONSE_BYTES = 1 MiB` |
+| Atomic writes (mkstemp + flush + fsync + os.replace)   | `notifier.FileHandler._atomic_append`                                     |
+| Explicit User-Agent for any outbound HTTP               | `notifier.WebhookHandler` headers                                         |
+| Stdlib-first, module separation                         | `collectors`, `alerter`, `notifier`, `config`, `daemon` — five modules, no `pip install` |
+| Defensive config loading (rejects world-readable / symlinks) | `config.load` mode + symlink check                                    |
+
+Plus three things specific to a 24/7 watchdog:
+
+- **Debounce / hold** — `alerter.DebounceState`: a breach must persist
+  ≥ `hold_seconds` before firing, so a 1-second CPU spike doesn't page
+  anyone at 3am.
+- **Per-mount dedup** — disk rules are templated and instantiated per
+  mount so `/` recovering doesn't suppress `/var` warnings.
+- **Deduper window** (default 300 s) — `notifier.Dispatcher` collapses
+  repeated sends of the same `(rule, key)` pair.
+
+---

+cd path/to/sysmon

+### 3.2 為什麼 DebounceState 用 `None` sentinel 而不是 `0.0`？
+

+anchor 一直被覆寫成當下 now_ts，hold window 永遠 = 0。

+wall-clock → 等同 behavior 不變（無 regression）。

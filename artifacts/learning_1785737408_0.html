🛠️ How the Lab Works

Architecture 
Cross-browser matrix    Chromium + Firefox + WebKit (3 engines, same DOM, same assertions)
Responsive matrix        desktop-1280 + iPad (portrait) + iPhone 13 (3 devices, Chromium)
Per-page screenshot     fullPage=true, animations/transition disabled before capture
Pixel-diff engine        pixelmatch + pngjs (perceptual threshold = 0.18, fail if > 2% px)
Anti-flake               document.fonts.ready before every shoot
Baseline storage         baselines/<browser>--<page>.png   (cross-engine)
                        baselines/responsive--<device>--<page>.png  (responsive)
Diff overlays           reports/diffs/*.diff.png  (red = mismatch)
Functional suites        data-testid locators, role-based queries, async waits
Page surface             pages/{home,dashboard,form}.html  (file:// — no network needed)
Commands 
npm install                              # one-time: install playwright + pixelmatch + pngjs
node tests/run-cross-browser.cjs         # functional only (3 engines)
node tests/run-visual-regression.cjs     # visual compare (3 engines × 3 pages)
node tests/run-visual-regression.cjs --update   # write fresh cross-engine baselines
node tests/run-responsive.cjs            # responsive compare (3 devices × 3 pages)
node tests/run-responsive.cjs --update   # write fresh responsive baselines
node tests/run-all.cjs                   # all 3 suites + dashboard report

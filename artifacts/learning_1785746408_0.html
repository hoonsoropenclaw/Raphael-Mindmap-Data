🛠️ Architecture

Three-layer regression detection 
Layer 1 — Functional     data-testid locators + role-based queries
                         5 scenarios × 5 profiles = 20 cases
                         Touch events on mobile profiles via page.tap()
                         Hover emulation via page.hover()

Layer 2 — Visual diff    pixelmatch (perceptual) + Pillow (RGB overlay)
                         anti-flake: disable animations, mask [data-mask="dynamic"]
                         Fail thresholds: pixel ≤ 2% / pillow ≤ 2.5%
                         5 profiles × 4 fixture pages = 20 cases

Layer 3 — DOM hash       in-page canonicalizer (strips volatile attrs)
                         sha256 over canonicalized tree
                         Tree-diff on mismatch (counts added/removed/changed nodes)
                         5 profiles × 4 fixture pages = 20 cases
Folder layout 
playwright-lab/
├── pages/                # 4 fixture HTMLs (home / dashboard / form / animation)
├── tests/
│   ├── lib.cjs           # shared helpers (matrix, paths, Suite, scripts)
│   ├── run-cross-browser.cjs
│   ├── run-visual-regression.cjs
│   ├── run-dom-snapshot.cjs
│   ├── run-mobile.cjs     # mobile-only subset
│   ├── run-all.cjs        # orchestrator
│   └── generate-report.cjs
├── fixtures/
│   └── pillow_diff.py     # Pillow double-diff engine

├── reports/               # current run outputs + dashboard
└── web_output.html        # top-level deliverable

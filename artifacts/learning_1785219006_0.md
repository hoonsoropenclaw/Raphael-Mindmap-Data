    1. Telegram → 城市文字 → Open-Meteo geocoding → forecast → Telegram reply

    3. 使用 long polling，適合 headless Linux 主機。

    python
    next_offset = update_id + 1
    
    
    5. 具備三層防護：

    - 每位使用者 cooldown rate limit
    - 城市輸入長度、控制字元與格式驗證
    
    6. HTTP 防護：
    
    - HTTPS 強制限制
    - 明確 User-Agent
    - timeout
    - bounded retry
    - Content-Length 檢查
    - response body 最大 1 MiB
    - 409 Conflict 專用錯誤，避免多個 polling process 靜默搶同一個 bot token
    
    7. 送信失敗時會 rollback rate-limit reservation，讓 Telegram 重送 update 時不會被錯誤的 cooldown 擋住。

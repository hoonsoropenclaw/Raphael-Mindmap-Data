SmartCrawler

基於 Playwright 的智慧動態網頁爬蟲 — 自動偵測渲染完成、自適應選擇器、結構化資料抽取、反爬繞過

✅ 3/3 E2E 通過 Playwright 1.x Node 22 5 模組 JSON Schema Draft-07

架構總覽

6 個鬆耦合模組 + 1 個統一 facade API。每個模組可獨立使用、單元測試。

⏱️
Smart Wait
多條件並行偵測「真」渲染完成：DOM 穩定 + XHR 清空 + 圖片 loaded + 字型 ready + hydration
modules/smart-wait.js
🎯
Adaptive Selector
多策略 selector fallback + 指紋記憶（跨 session 學習） + 自動結構性啟發式
modules/adaptive-selector.js
🕵️
Stealth
反自動化偵測繞過：webdriver flag / plugins / WebGL / 真實 user agent pool / 人類滑鼠軌跡
modules/stealth.js
📡
Network Interceptor
自動 hook 所有 response，辨識「最可能是 schema 來源的 API」
modules/network-interceptor.js
🧬
Schema Inference
從 sample data 推斷 JSON Schema（Draft-07）：type/format/enum/min/max + human-readable report
modules/schema-infer.js
📄
Pagination Discovery
4 策略自動偵測下一頁機制：Next 按鈕 / URL pattern / Load more / Infinite scroll
modules/pagination.js

核心特性

🎯 真渲染偵測

不等 DOMContentLoaded、不等 load。並行偵測 6 個條件，最快達標者完成。

🧠 跨 session 學習

selector 指紋寫進 data/selector-fingerprint.json，下次同 URL 優先用上次成功者。

📡 API 自動偵測

多數 SPA 渲染 = 從某 JSON API 撈資料。自動找「最像 schema 來源」的 endpoint，省去解析 DOM。

🔄 反爬繞過

隱藏 webdriver flag、偽造 plugins/chrome runtime/WebGL vendor，模擬人類滑鼠軌跡。

📊 結構化輸出

JSON Schema Draft-07 + human-readable report，多格式序列化（JSON/JSONL/CSV）。

📄 Pagination 自適應

4 策略自動偵測（Next / URL pattern / Load more / Infinite scroll），自動 walk 全站。

使用方式

1. CLI — 快速抓取

# Schema-driven extraction
node crawler/cli.js --url https://example.com \
  --schema '{"title":"h1","price":".price"}' \
  --output result.json

# Item-selector list extraction + 多頁
node crawler/cli.js --url https://news.ycombinator.com \
  --item-selector '.athing' --max-pages 3 \
  --format csv --output hn.csv

# 自動 schema discovery
node crawler/cli.js --url https://example.com --discover-schema

2. 程式化 API

const { SmartCrawler } = require('./lib/smart-crawler');

const crawler = new SmartCrawler();
const result = await crawler.crawl({
  url: 'https://example.com',
  schema: {
    title: 'h1',
    price: '.product .price',
  },
  waitForSelector: ['.product'],
  timeout: 30000,
  maxPages: 1,
  format: 'json',
  outputPath: './out.json',
});

// result.data 包含：items / schema / schemaReport / pagination / apiSummary / discovered / meta

3. 模組化 — 單獨使用

// 只要 smart wait
const { smartWait } = require('./modules/smart-wait');
const r = await smartWait(page, {
  selector: ['.product'],
  timeout: 30000,
});

// 只要 schema inference
const { inferSchema, explainSchema } = require('./modules/schema-infer');
const schema = inferSchema([{a:1,b:"x"}, {a:2,b:"y"}]);
console.log(explainSchema(schema));

設計決策與取捨

選擇理由
Playwright 而非 Puppeteer Playwright 跨瀏覽器 + init script API 對 stealth 友善
Node 22 + 原生 fetch API interceptor 的 fallback 直接用 fetch、不需 axios
多策略 selector chain 而非 auto-heal 給定一組候選，按順序 fallback — 失敗時立刻換、可 debug
指紋寫到 local JSON 而非 SQLite 輕量、跨 session 可撈、人類可讀、零依賴
模組化 + facade 而非 單一檔案 每個模組可單獨使用、單獨測試；smart-crawler 只是組裝
JSON Schema Draft-07 而非自訂 標準化、相容現有 validator、可餵給 LLM 做後續處理

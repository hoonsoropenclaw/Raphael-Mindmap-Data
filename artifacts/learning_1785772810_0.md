+# Cross-browser Visual Regression Lab
+
+這是一個可直接重跑的 Playwright Test 專案，涵蓋 Chromium、Firefox、WebKit、Pixel 5（Chromium）與 iPhone 13（WebKit）。功能測試與視覺快照分層：先驗證互動契約，再用每個 browser project 獨立的 baseline 捕捉非預期 UI 漂移。
+
+## 快速執行
+
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785772810_0
+npm install
+npx playwright install chromium firefox webkit
+npm test
+```
+
+Playwright 會自動啟動並清理 `python3 -m http.server`；正常測試結束後 4173 port 應為空閒。
+
+## 指令
+
+```bash
+npm run check               # JS 語法檢查
+npm test                    # 5 projects × 9 tests = 45 tests
+npm run test:contract       # 僅功能契約
+npm run test:visual         # 僅視覺回歸
+npm run test:desktop        # Chromium + Firefox + WebKit
+npm run test:mobile         # Pixel 5 + iPhone 13
+npm run baseline            # 明確更新 baseline（只供已審核的預期 UI 變更）
+npm run report              # 開啟 playwright-report
+```
+
+## 測試矩陣
+
+每個 project 有 6 個功能測試：
+
+1. 頁面 deterministic boot、沒有 runtime/console error。
+2. Smoke check 更新 12/12 狀態。
+3. Mobile lane filter 與還原。
+4. Workflow tabs 與 ARIA selection。
+5. 鍵盤焦點與主題切換。
+6. 當前 viewport 無水平 overflow。
+
+每個 project 有 3 個視覺狀態：
+
+1. 完整 home surface。
+2. Mobile lane filter region。
+3. Compare workflow region。
+
+總數：5 projects × (6 functional + 3 visual) = 45 tests；baseline 共 15 張 PNG。
+
+## 視覺穩定策略
+
+- browser-specific baseline，絕不把不同 renderer 的畫面互相比對。
+- `workers: 1`，避免 N100 上並行 renderer/font 壓力造成噪音。
+- 固定 `locale=en-US`、`timezone=UTC`、`colorScheme=light`、`reducedMotion=reduce`。
+- 關閉 CSS animation/transition、隱藏 caret、等待 `document.fonts.ready`。
+- `maxDiffPixelRatio=0.005`（0.5%）與 `threshold=0.2`。實測 0.1% 在 full-page mobile screenshot 偶發抓到細粒度文字重繪；0.5% 能容忍該噪音，同時仍能抓到 controlled accent-color drift（Chromium 17,448 pixels；Mobile Chromium 11,598 pixels）。
+- Baseline 更新是顯式指令，不放進正常 `npm test`，避免 CI 自動把 regression 洗成新基準。
+

+## 2. 實作思路
+
+### 2.1 任務拆解
+
+- 「接收文字」→ Telegram `MessageHandler` on text + 排除指令
+- 「呼叫天氣 API」→ 雙 API pipeline：wttr.in 主路徑、OpenWeatherMap 備援
+- 「回傳」→ Telegram `reply_text` 格式化訊息
+
+### 2.2 關鍵設計決策
+
+#### 決策 A：wttr.in 為主，OpenWeatherMap 為輔
+- **wttr.in 優勢**：免 API key、開箱即用、回傳豐富（包含體感溫度、濕度、風速、地區名）
+- **OpenWeatherMap 優勢**：商業 SLA、更多語系、更多欄位
+- **為什麼這個順序**：避免「卡在一個失敗的 API key 上」就能起 run，Token-less 的開發者也能立即試用
+
+#### 決策 B：httpx（async）但保留 urllib fallback
+- **首選 httpx**：async/await friendly，跟 `python-telegram-bot` v20+ 的 async pipeline 同調
+- **urllib fallback**：如果 `pip install` 因 PEP668 失敗，仍可用 stdlib 跑起來
+- **理由**：避免「因為一個 pip 失敗，整個 bot 死掉」
+
+#### 決策 C：async + asyncio.to_thread
+- 同步 HTTP call 用 `asyncio.to_thread` 包起來（httpx 也有 async 版本，但這樣可統一同步/非同步）
+- 好處：未來加更多外部 API，仍然可以在同一個 event loop 跑
+
+#### 決策 D：Fail-soft 的三層降級
+```
+有 token + 有套件  →  真正 bot 上線（polling）
+有 token + 無套件  →  warning + dry-run（驗證 pipeline）
+無 token + 任意    →  dry-run（mock + 真實 API）
+```
+- **這意味著**：這個 bot **永遠可以跑** — 沒 token 不會壞，只是模擬流程
+- **測試策略**：CI 可以直接跑（無需 mock service、無需 env var）
+
+#### 決策 E：城市名清洗用 Unicode-safe regex
+- 接受中文 / 英文 / 西歐字母（含變音符號）
+- 排除標點符號、表情符號
+- `_CITY_RE` 用 `[\u4e00-\u9fff A-Za-z\u00C0-\u017F\s,.\-]+`
+- **為什麼需要**：使用者可能傳「東京！」或「我要查台北市」

    交付摘要
    
    bot.py（核心）：Telegram long-polling bot，接收文字訊息當城市名，查天氣回傳。
    
    架構特點（5 大決策）：
    1. 雙 API pipeline — wttr.in 主路徑（免 API key）+ OpenWeatherMap 備援
    2. Fail-soft 三層降級 — 有 token 有套件=polling / 有 token 無套件=dry-run / 無 token=dry-run，永遠能跑
    3. async + asyncio.to_thread — httpx 為主、urllib fallback，避免 PEP668 阻擋
    4. 城市清洗 regex — 接受中英文 + 西歐變音符號 + trim 標點
    5. dataclass + 格式化輸出 — WeatherResult.format() 統一呈現
    
    驗收實驗（自跑 self-test）：
    - ✅ 沒 token 沒套件 → 自動 dry-run
    - ✅ 真的打 wttr.in 6 次：Taipei / 東京 / 高雄 / Paris / New York / 北京
    - ✅ HTTP 200 全部成功
    - ✅ 中文 URL auto-encode（%E6%9D%B1%E4%BA%AC）
    - ✅ Edge cases：trim、標點去除、空輸入兜底
    
    使用方式：
    bash
    export TELEGRAM_BOT_TOKEN="<BotFather 給的>"
    pip install -r requirements.txt
    python bot.py

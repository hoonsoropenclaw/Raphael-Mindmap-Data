+## Component API
+
+`SignalBoard` accepts two optional props:
+

+<SignalBoard
+  storage={window.localStorage}
+  syncTask={async (task) => api.updateTask(task)}
+/>
+```
+
+- `storage`: any Web Storage compatible object, or `null` to disable persistence.
+- `syncTask`: async callback used after an optimistic status move. Rejecting the promise restores the previous status and exposes an inline error.

tokens.json (設計系統契約)

同一份 JSON 餵給 style-dictionary → CSS / iOS / Android / Compose token; 給 @design-tokens/sdk → React / Vue / Svelte / Angular runtime。 真正的 single source of truth。 

// tokens/tokens.json — single source of truth
{
  "color": {
    "bg":     { "value": "#0b0d12" },
    "surface":{ "value": "#1c2230" },
    "accent": { "value": "#7c9cff" }
  },
  "space": {
    "1": { "value": "4px" },  "2": { "value": "8px" },
    "4": { "value": "16px" }, "8": { "value": "32px" }
  },
  "radius": {
    "sm": { "value": "6px" },  "md": { "value": "10px" }
  },
  "motion": {
    "duration": { "base": { "value": "200ms" } },
    "easing":   { "out":   { "value": "cubic-bezier(.22,.61,.36,1)" } }
  }
}

Framework Integration

同一份 tokens.json → React / Vue / Svelte。 編譯時產 CSS variables,零 runtime;TS 端可以拿到完整型別,沒有 magic string。

React (CVA + Token)

import { cva } from "class-variance-authority"

export const button = cva("btn", {
  variants: {
    intent: {
      primary: "btn--primary",
      ghost:   "btn--ghost",
      danger:  "btn--danger",
    },
    size: { sm: "btn--sm", lg: "btn--lg" },
  },
})

export function Button({ intent, size, children }) {
  return <button className={button({ intent, size })}>
    {children}
  </button>
}

Vue 3 (script setup)

<script setup lang="ts">
import { computed } from "vue"
import { tokens } from "@designforge/tokens"

const props = defineProps<{ intent: "primary"|"ghost" }>()
const style = computed(() => ({
  "--btn-bg": props.intent === "primary"
    ? tokens.color.accent : tokens.color.surface,
}))
</script>

<template>
  <button :class="['btn', `btn--${intent}`]" :style="style">
    <slot />
  </button>
</template>

Svelte (compiled)

<script lang="ts">
  import { tokens } from "$lib/tokens"
  export let intent: "primary"|"ghost" = "primary"
</script>

<button
  class="btn btn--{intent}"
  style:--btn-bg={tokens.color[intent === "primary" ? "accent" : "surface"]}
>
  <slot />
</button>

  push:

    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pnpm install --frozen-lockfile
      - run: pnpm tokens:build
      - run: pnpm lint:hardcode   # 防 hardcoded color
      - run: pnpm test:visual --reporter=chromatic
      - run: pnpm test:a11y       # axe-core, WCAG AA
      - run: pnpm deploy:preview
        if: github.event_name == "pull_request"

Production Deployment

三種部署形態,選哪個看規模 + 邊緣需求 + 合規要求。

Vercel Edge

推薦

靜態站 + ISR + Edge Functions。最快的預覽部署,GitHub PR 自動拿到 URL。 

{
  "framework": "nextjs",
  "buildCommand": "pnpm build",
  "regions": ["sin1", "hnd1"],
  "headers": [{
    "source": "/_next/static/(.*)",
    "headers": [{
      "key": "Cache-Control",
      "value": "public, max-age=31536000, immutable"
    }]
  }]
}

Docker

自託管

多階段 build,distroless image。適合企業內網 / 私有雲。 

FROM node:20-alpine AS build
WORKDIR /app
COPY . .
RUN pnpm install --frozen-lockfile \
  && pnpm build

FROM gcr.io/distroless/nginx:1.25
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 8080
HEALTHCHECK CMD wget -qO- http://localhost:8080/health

Cloudflare Pages

邊緣

全球 CDN + Workers。低流量首選,完全免費層。 

[build]
  command = "pnpm build"
  destination = "dist"

[[headers]]
  for = "/dist/*"
  [headers.values]
    Cache-Control = "public, max-age=31536000, immutable"

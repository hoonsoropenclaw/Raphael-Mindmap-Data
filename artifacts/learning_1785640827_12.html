DT Design Token UI Kit

設計即程式碼 · 改一個 token 換整個世界

一個使用 CSS 自訂屬性 + 三層 token 架構的可擴展 UI 組件庫。Primitive token 提供原始材料, Semantic token 表達設計意圖,Component token 組裝出真實元件。換主題只需要改對應的設計層。

21 個元件 3 層 token 架構 5 個預設主題 即時熱替換 0 行 CSS 寫死 hex

三層 Token 架構

改 Primitive 一個值,連帶影響 Semantic + Component

┌─────────────────────────────────────────────────────────────────────┐
│ LAYER 1 — PRIMITIVE TOKENS (原材料)                                  │
│ 顏色像素、間距尺度、字號級距、陰影深度                                │
│ 例: --blue-500, --space-4, --text-2xl, --shadow-lg                  │
│ ⚠️ 組件不直接引用此層                                                 │
└─────────────────────────────────────────────────────────────────────┘
                                  ↓ 使用 / 重命名
┌─────────────────────────────────────────────────────────────────────┐
│ LAYER 2 — SEMANTIC TOKENS (語意)                                     │
│ 表達設計意圖,跨組件共享                                              │
│ 例: --color-brand, --text-primary, --surface-raised                 │
│ ✅ 換主題 = 改寫這層                                                   │
└─────────────────────────────────────────────────────────────────────┘
                                  ↓ 組裝 / 派生
┌─────────────────────────────────────────────────────────────────────┐
│ LAYER 3 — COMPONENT TOKENS (元件專屬)                                │
│ 由 semantic 派生,只給單一元件家族使用                                │
│ 例: --button-padding-x, --card-radius, --modal-backdrop             │
│ ⚡ 換元件樣式 = 改寫這層,不會影響其他元件                              │
└─────────────────────────────────────────────────────────────────────┘

v1.0 · Cross-Platform · MIT

用 Playwright × OCR 打造
桌面級 PDF 與圖像自動化

AutoGlyph 是一個跨平台桌面自動化工具，整合瀏覽器自動化 (Playwright) 與光學字元辨識 (OCR) 技術， 自動處理 PDF 文件與圖像數據。內建 Python 與 Node.js 雙版本引擎，可一鍵封裝成 Windows / macOS / Linux 桌面應用。

Electron

        
Electron Forge

        
把整個 web app 當桌面 app 包，用 Node.js 的 Playwright 引擎處理自動化。

        

$ npm i -D @electron-forge/cli

$ npx electron-forge import

$ npm run make -- --platform=win32

$ npm run make -- --platform=darwin

$ npm run make -- --platform=linux

# 輸出 out/make/<platform>/*.exe / *.dmg / *.deb
        

      


      

        

          WindowsmacOSLinux
        

        
Tauri

        
Tauri (Rust core)

        
比 Electron 更小 (3MB vs 80MB+)，用 Rust sidecar 跑 Playwright 與 Tesseract。

        

$ cargo install tauri-cli --version "^2.0"

$ cargo tauri init

$ cargo tauri build --target x86_64-pc-windows-msvc

$ cargo tauri build --target aarch64-apple-darwin

$ cargo tauri build --target x86_64-unknown-linux-gnu

# 輸出 src-tauri/target/<target>/release/bundle/
        

      


      

        

          WindowsmacOSLinux
        

        
Python

        
PyInstaller + Briefcase

        
純 Python 桌面工具，整合 Playwright (Python) + pytesseract + pdfplumber。

        

$ pip install playwright pytesseract pdfplumber pillow

$ playwright install chromium

$ pip install briefcase

$ briefcase build windows

$ briefcase build macOS

$ briefcase build linux

# 輸出 <project>/<platform>/<project>/

       Pipeline 6 階段:
       1. Input       - 檔案拖放 / 監看 / IPC
       2. PDF Parse   - 頁面切分 + 文字抽取
       3. Preprocess  - 灰階 / 二值化 / 校正 / 去噪
       4. OCR         - Tesseract (eng/chi_tra/chi_sim/jpn/kor)
       5. Cleanup     - 正則抽取 email/url/date/price/id
       6. Output      - 寫檔 / 觸發 Playwright / 發 webhook

       Stack 對應:
       - Python   : playwright + pytesseract + pdfplumber + Pillow
       - Node.js  : playwright + tesseract.js + pdfjs-dist + sharp
       - TypeScript: 同 Node.js + 型別守門

       跨平台封裝:
       - Electron    : web → .exe / .dmg / .deb / .AppImage
       - Tauri       : web → .msi / .app / .deb (3MB)
       - Briefcase   : Python → native installer

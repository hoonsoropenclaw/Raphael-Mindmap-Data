+# 跨瀏覽器視覺回歸測試 Pipeline
+
+使用 **Playwright** + **Pixelmatch** + **Baseline 指紋管理**,在 3 個瀏覽器 × 3 個 viewport 矩陣上自動跑視覺回歸測試。
+
+## 結構
+
+```
+learning_1785791409_0/
+├── web_output.html               ← 主交付:測試目標頁面(Demo Page)
+└── test_framework/
+    ├── config.py                 ← 測試矩陣/路徑/閾值設定
+    ├── baseline_manager.py       ← Baseline 指紋管理 + Pixel 比對
+    ├── runner.py                 ← Playwright 跨瀏覽器測試引擎
+    ├── report_generator.py       ← HTML 測試報告產生器
+    ├── main.py                   ← 主入口
+    ├── baselines/                ← Baseline 截圖 (9 張)
+    ├── screenshots/              ← 當前 run 截圖 (9 張)
+    ├── diffs/                    ← 像素差異圖 (FAIL 時產生)
+    └── reports/                  ← HTML 報告 (含 latest.html)

+## 測試矩陣
+
+| 瀏覽器  | Desktop 1280×800 | Tablet 768×1024 | Mobile 375×667 |
+|---------|------------------|-----------------|-----------------|
+| Chromium | ✓ | ✓ | ✓ |
+| Firefox  | ✓ | ✓ | ✓ |
+| WebKit   | ✓ | ✓ | ✓ |

+## 視覺回歸閾值
+
+| 參數                | 數值   | 意義                                         |
+|---------------------|--------|----------------------------------------------|
+| `pixel_threshold`   | 0.10   | pixelmatch 顏色容忍度 (越小越嚴格)         |
+| `pixel_budget`      | 500 px | 允許的最大差異像素數 (絕對值)               |
+| `pixel_ratio_budget`| 0.02   | 允許的最大差異像素比例 (相對值,2%)         |
+
+任一條件超過即 FAIL。
+
+## 使用方式
+
+```bash
+# 完整跑 9 case(預期 PASS=9 / Pass rate 100%)
+python3 main.py
+
+# 只跑某個瀏覽器(快速 sanity check)
+python3 main.py --only chromium
+
+# 失敗時自動更新 baseline(進階,通常先確認 diff 是「預期變更」才用)
+UPDATE_BASELINE_ON_FAIL=1 python3 main.py

+## 核心設計重點
+
+### 1. 跨瀏覽器 launch options 不同
+**Chromium** 需要 `--no-sandbox --disable-dev-shm-usage`(headless 環境)。
+**WebKit / Firefox** 拒絕 `--no-sandbox` flag(會回 `Unknown option` 然後 crash)。
+config.py 用 `LAUNCH_OPTIONS["chromium"] / ["firefox"] / ["webkit"]` 三套設定區隔。
+
+### 2. Pixelmatch 簽名注意
+- 必須用 `pixelmatch.pixelmatch(...)` (頂層 API),不是 `pixelmatch.contrib.PIL.pixelmatch`(簽名不同)
+- `diff_buf` 必須是 `bytearray`,不是 `bytes`(否則 `TypeError: 'bytes' object does not support item assignment`)
+- threshold 是 keyword arg,不能在 pixelmatch 內部預設衝突
+
+### 3. Baseline 管理
+- 第一次跑某個 case:自動建立 baseline (status=`BASELINE_NEW`)
+- 後續跑:用 `ensure_baseline()` 自動比對,差異 ≤ 閾值 → PASS

+# Telegram Weather Bot
+
+接收使用者訊息（城市名稱），呼叫 **Open-Meteo** 公開 API 查詢即時天氣並回傳。
+
+## 特性
+
+- 🌍 **零 API key** — Open-Meteo 是公開端點，不需註冊
+- 🌏 **中文城市支援** — 內建 30+ 個常用城市 alias（Open-Meteo GeoNames 對 CJK 覆蓋率差）
+- ⚡ **異步** — 使用 `httpx.AsyncClient` + `python-telegram-bot` 22.x
+- 🛡️ **完整錯誤處理** — 網路錯誤、找不到城市、API 失敗都有友善提示
+- 📊 **結構化 log** — 方便監控
+
+## 安裝
+
+```bash
+pip install python-telegram-bot httpx
+```
+
+## 設定
+
+取得 Telegram Bot Token（從 [@BotFather](https://t.me/BotFather)），然後：
+
+```bash
+export TELEGRAM_BOT_TOKEN='你的 token'
+```
+
+或用 `.env` 檔（自己寫個 dotenv loader）。
+
+## 執行
+
+```bash
+python3 weather_bot.py
+```
+
+進入 polling 模式，開始接收 Telegram 訊息。
+
+## 使用者互動
+
+| 輸入 | 結果 |
+|------|------|
+| `台北` | 台北市即時天氣 |
+| `Tokyo` | Tokyo 即時天氣 |
+| `New York` | New York 即時天氣 |
+| `/start` | 歡迎訊息 |
+| `/help` | 使用說明 |
+| `XyzNotReal999` | 🔍 找不到城市「XyzNotReal999」 |
+
+## 範例輸出
+
+```
+🌤️ *台北市* (臺灣 (TW)) 即時天氣
+

+💧 濕度：100%
+💨 風速：3.7 km/h
+☁️ 天況：陰天
+
+_資料更新：2026-07-27T23:15_
+```
+
+## 檔案
+
+- `weather_bot.py` — 主程式（單檔、無外部設定）

+- `handler_test.py` — handler 層測試（mock Update）
+- `weather_bot.log` — 執行 log（執行後產生）

+# fetch_github_trending.py
+
+抓 [GitHub Trending](https://github.com/trending) 上的 repositories,輸出成 markdown 表格 + JSON.
+
+## 安裝
+
+```bash
+pip install requests beautifulsoup4
+```
+
+兩個都是極常見的依賴(幾乎所有 Python 環境都有).如果不想裝,單獨用 `urllib + html.parser` 改寫約 +30 行,
+不過目前版本優先可讀性.
+
+## 快速使用
+
+```bash
+# 今日 daily trending(預設)
+python3 fetch_github_trending.py
+
+# 本週
+python3 fetch_github_trending.py --since weekly
+
+# Python 限定(語言要寫在 GitHub URL path,不是 query string)
+python3 fetch_github_trending.py --language python
+
+# 月度 + TypeScript + 輸出到指定路徑
+python3 fetch_github_trending.py --since monthly --language typescript -o /tmp/ts-month.md
+```
+
+## 輸出
+
+每次執行會產生 2 個檔案(路徑可自訂):
+
+| 檔案 | 用途 |
+|------|------|
+| `trending.md` | 給人看的 markdown 表格(預設印到 stdout 同時存檔) |
+| `trending.json` | 程式化後續處理用的 JSON dump |
+
+JSON 結構:
+```json
+[
+  {
+    "rank": 1,
+    "full_name": "permissionlesstech/bitchat",
+    "url": "https://github.com/permissionlesstech/bitchat",
+    "description": "bluetooth mesh chat, IRC vibes",
+    "language": "Swift",
+    "today_stars": 2344,
+    "total_stars": 32007,
+    "contributors": []
+  }
+]
+```
+
+## 參數
+
+| 參數 | 說明 | 預設 |
+|------|------|------|
+| `--since` | `daily` / `weekly` / `monthly` | `daily` |
+| `--language` | GitHub trending 支援的任何語言 slug(`python` / `typescript` / `go` / ...) | 不過濾 |
+| `-o, --output` | markdown 輸出路徑 | `./trending.md` |
+| `--json-output` | JSON 輸出路徑 | `./trending.json` |
+| `--quiet` | 不印 markdown 到 stdout(只寫檔) | 印 |
+| `--retries` | 網路失敗重試次數 | `2` |
+
+## 已知限制

+## 2. 任務設計決策
+
+### 2.1 為什麼選 requests + BeautifulSoup(不用 Selenium / Playwright)
+
+- GitHub Trending 是 server-rendered HTML(看 `nohup` 模式、`<article class="Box-row">` 結構),
+  不需要跑 JS.
+- 額外裝 Playwright = 多 200MB 依賴 + 啟動慢 + 容易被 GitHub 當 bot.
+- requests 抓 1 個頁面 ≈ 0.3 秒,Playwright 啟動 ≈ 3-5 秒.
+
+### 2.2 為什麼只輸出到 markdown + JSON(不存 DB)
+
+- 規格只要「markdown 表格」,不需 SQLite/CSV.
+- 多 dump 一份 JSON 是 zero-cost(已經 parse 完了),讓後續程式化處理有鉤子.
+- 未來要擴展(例如塞進 Notion / Slack),從 JSON 拿資料比再 parse markdown 簡單 100 倍.

+### 2.3 為什麼支援 --since / --language 兩個維度的過濾
+
+- 預設 daily 全部語言 → 14 個 repo(寫這篇 notes 時的實況).
+- 加上 `--since weekly` → 25 個.

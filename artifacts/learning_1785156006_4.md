+# Todo API (FastAPI + SQLite + Rate Limit)
+
+A minimal but production-shaped Todo REST API built with FastAPI, SQLite (via stdlib `sqlite3`), and `slowapi` for IP-based rate limiting. Includes unit tests with `pytest` + `httpx` TestClient.
+
+## Features
+
+- **CRUD endpoints** for todos: create, list, get, update, delete
+- **Toggle completion** endpoint (`PATCH /todos/{id}/complete`)
+- **SQLite persistence** with WAL mode and proper connection lifecycle
+- **Rate limiting** via `slowapi` (default: 60 req/min per IP, write endpoints tighter at 20 req/min)
+- **Pydantic v2 schemas** with field validation
+- **Modular layout**: `app/db` (data layer) ↔ `app/schemas` (DTOs) ↔ `app/api` (transport)
+- **Unit tests** covering happy path, validation errors, rate limit, and DB isolation
+
+## Quick start
+
+```bash
+# install deps (already on system Python 3.12)
+pip install -r requirements.txt
+
+# run dev server
+uvicorn app.main:app --reload --port 8000
+
+# open http://127.0.0.1:8000/docs for Swagger UI
+```
+
+## Run tests
+
+```bash
+cd todo_api
+pytest -v
+pytest --cov=app --cov-report=term-missing
+```
+

+"""SQLite connection management and schema bootstrap.
+
+Design notes
+------------
+* Single connection-per-request is overkill for SQLite (single-writer). We expose
+  a module-level ``get_connection`` that opens with ``check_same_thread=False`` so
+  FastAPI's threadpool can use it, plus per-thread row factory for dict-like access.
+* WAL mode is enabled on init so concurrent reads don't block writes.
+* ``init_db`` is idempotent: safe to call from app startup AND from tests.
+"""
+from __future__ import annotations
+
+import os
+import sqlite3
+import threading
+from contextlib import contextmanager
+from pathlib import Path
+from typing import Iterator
+
+# Module-level lock guards the schema bootstrap from racing between threads.
+_SCHEMA_LOCK = threading.Lock()
+_INITIALISED: set[str] = set()  # db paths that already ran init_db
+
+DEFAULT_DB_PATH = os.environ.get("TODO_DB_PATH", "todos.db")
+
+SCHEMA_SQL = """
+CREATE TABLE IF NOT EXISTS todos (
+    id          INTEGER PRIMARY KEY AUTOINCREMENT,
+    title       TEXT    NOT NULL,
+    done        INTEGER NOT NULL DEFAULT 0,  -- 0 = false, 1 = true
+    created_at  TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
+    updated_at  TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
+);
+
+CREATE INDEX IF NOT EXISTS idx_todos_done     ON todos(done);
+CREATE INDEX IF NOT EXISTS idx_todos_created  ON todos(created_at);
+"""
+
+
+def _resolve_path(db_path: str | os.PathLike[str]) -> Path:
+    p = Path(db_path).expanduser().resolve()
+    p.parent.mkdir(parents=True, exist_ok=True)
+    return p
+
+
+def get_connection(db_path: str | os.PathLike[str] = DEFAULT_DB_PATH) -> sqlite3.Connection:
+    """Open a SQLite connection configured for FastAPI's threaded runtime.
+
+    - ``check_same_thread=False`` is required so multiple worker threads can share.
+    - ``row_factory`` returns dict-like rows so the repository stays serialiser-agnostic.
+    - Foreign keys are ON (defensive — useful if we add related tables later).
+    """
+    path = _resolve_path(db_path)
+    conn = sqlite3.connect(
+        str(path),
+        check_same_thread=False,
+        isolation_level=None,  # autocommit; we use explicit BEGIN/COMMIT
+        timeout=10.0,
+    )
+    conn.row_factory = sqlite3.Row
+    conn.execute("PRAGMA foreign_keys = ON")
+    conn.execute("PRAGMA journal_mode = WAL")
+    return conn

+    """

+        yield conn

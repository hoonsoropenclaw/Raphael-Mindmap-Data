+# GitHub Trending → Markdown
+
+`github_trending.py` 抓取 GitHub 公開 Trending 頁面，解析 repository cards，並以原子寫入方式輸出 Markdown 表格。
+
+## 特性
+
+- Python 3.10+，零第三方套件、零 GitHub token
+- daily / weekly / monthly 時段
+- programming-language 與 spoken-language 過濾
+- 有界重試、timeout、清楚的非零 exit code
+- `mkstemp + flush + fsync + os.replace + directory fsync` 原子輸出
+- 不使用共享固定 `.tmp` 名稱，可抵抗重疊 cron 執行
+- HTML void-element 深度處理，避免 `<img>` / `<br>` 使 parser 狀態漂移
+- Repository URL 去重，截斷 article 丟棄
+- Markdown pipe、反斜線與換行 escaping
+- 空解析 fail closed，不覆蓋上一份有效報告
+- 離線 regression fixture + live GitHub smoke test
+
+## 使用方式
+
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785210606_0
+
+# 每日前 25 名，輸出到預設 github-trending.md
+./github_trending.py
+
+# 每週 Python 前 10 名
+./github_trending.py \
+  --language python \
+  --since weekly \
+  --limit 10 \
+  --output github-trending-python.md
+
+# 中文 spoken-language filter
+./github_trending.py --spoken-language zh --limit 10
+
+# 顯示完整參數
+./github_trending.py --help
+```
+
+成功時 exit code = 0；HTTP / 解析 / 寫檔 / 無效值失敗 = 1；`argparse` 語法錯誤 = 2。
+
+## 測試

+## 3. 資料來源與技術選型
+
+GitHub REST API 沒有官方 Trending endpoint。用 Search API 以「近期建立 + stars 排序」模擬，語意不等同 GitHub Trending，還會引入 token／rate-limit 問題。
+
+因此使用公開頁面：
+
+- Base URL：`https://github.com/trending`
+- Programming language：path slug，如 `/trending/python`
+- Period：`?since=daily|weekly|monthly`
+- Spoken language：`&spoken_language_code=zh`
+
+技術選型：Python 3 標準庫。
+
+- `urllib.request`：HTTPS fetch
+- `HTMLParser`：結構化 HTML parsing
+- `dataclass`：repository record
+- `argparse`：CLI interface
+- `tempfile.mkstemp + os.replace`：concurrency-safe atomic update

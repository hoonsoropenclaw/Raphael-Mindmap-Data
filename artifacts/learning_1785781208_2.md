+"""Pixel-level visual diff using pixelmatch.
+
+Reused micro-skills:
+- `Comprehensive Visual Regression Testing` (calibrate threshold per engine)
+- `visual_regression_dimension_mismatch_handling` (resize+RGBA on mismatch)
+- `pixelmatch_esm_import_fix` (diff buffer MUST be `bytearray`, not `bytes`)
+- `visual_regression_threshold_calibration` (PASS/WARN ratios)
+"""
+from __future__ import annotations
+
+from dataclasses import dataclass, asdict
+from pathlib import Path
+
+from PIL import Image
+from pixelmatch import pixelmatch
+
+
+# ------------------------------------------------------------------
+# Calibrated thresholds (from visual_regression_threshold_calibration)
+# ------------------------------------------------------------------
+PASS_PIXEL_RATIO = 0.005   # <0.5% diff  -> pass
+WARN_PIXEL_RATIO = 0.02    # <2%   diff  -> warn (look at diff PNG)

+
+
+# ------------------------------------------------------------------

+# Cross-browser Visual Regression Framework
+
+A Playwright + pixelmatch based visual regression framework that captures
+UI screenshots across **Chromium / Firefox / WebKit** and **desktop / tablet /
+mobile** viewports, diffs them against a baseline, and emits a self-contained
+HTML report with verdict per shot.
+
+## Layout
+
+```
+.
+├── web_output.html              ← UI under test
+├── visual_regression/
+│   ├── __init__.py
+│   ├── capture.py               ← Playwright cross-browser screenshots
+│   ├── compare.py               ← PIL + pixelmatch diff engine
+│   ├── report.py                ← HTML dashboard + JSON + terminal summary
+│   ├── run.py                   ← CLI: init / run / update
+│   ├── baselines/               ← gitignored, stores reference shots
+│   ├── current/                 ← gitignored, latest run's shots
+│   ├── diff/                    ← gitignored, pixel-level diff PNGs
+│   └── reports/
+│       ├── report.html          ← self-contained dashboard (no CDN)
+│       └── report.json          ← machine-readable
+└── requirements.txt
+```
+
+## Install
+
+```bash
+python3 -m venv .venv && source .venv/bin/activate
+pip install -r requirements.txt
+python -m playwright install chromium firefox webkit
+```
+
+## Usage
+
+### First time — capture the baseline
+
+```bash
+python3 -m visual_regression.run init
+```
+
+### Regular CI run — diff current vs baseline
+
+```bash
+python3 -m visual_regression.run run
+# exit 0 = pass (no fail verdicts)
+# exit 1 = fail (≥1 verdict == fail)
+# exit 2 = error (no baseline / capture failure)
+```
+
+### Promote after a known-good change
+
+```bash
+python3 -m visual_regression.run run   # look at reports/report.html
+python3 -m visual_regression.run update # promote current/ to baselines/
+```
+
+### Run against a specific URL or local file
+
+```bash
+python3 -m visual_regression.run run --target http://localhost:3000
+python3 -m visual_regression.run run --target ./my_page.html
+```
+
+### Restrict to a subset of browsers
+
+```bash
+python3 -m visual_regression.run run --browsers chromium
+```

效能設計準則

Performance Spec

做對的事 ✅

  • 單一檔案、零外部依賴（無 React/Vue/Tailwind CDN）
  • backdrop-filter 半徑 ≤ 12px, 限制模糊元素 ≤ 8 個
  • content-visibility: auto 虛擬化長內容
  • SVG icon 內聯 (避免額外 HTTP 請求)
  • prefers-reduced-motion 全域降級
  • 動畫僅用 transform / opacity (GPU 合成)
  • CSS variables 主題化 (深淺色 0 重新載入)
  • focus-visible 鍵盤焦點 2px 高對比外框

避開的坑 ⚠️

  • 避免 filter: blur() 在大面積背景 (極耗 GPU)
  • 避免在 transition 觸發 layout (改用 transform)
  • 避免 backdrop-filter 套用在動態 list item
  • 圖片必須設 aspect-ratio 避免 CLS
  • 字體改用 system font stack (不必等 webfont)
  • 避免 :hover 改變 box/padding (會重排)
  • 不要 inline 超大 CSS animation keyframes (影響首繪)
  • Tab/Radio 用 role="tab/tabpanel" 而非自訂 div

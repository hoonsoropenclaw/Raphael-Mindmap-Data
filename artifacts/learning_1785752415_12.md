+# Playwright Recon Crawler
+
+以 Playwright 載入「你有權存取」的網頁，抽取渲染後資料，並觀測頁面產生的 HTTP/API 請求與 JSON 回應。
+
+## 功能
+
+- DOM/selector 抓取：用 CSS selector + field map 輸出 `records.json`
+- API 逆向觀測：request/response、HTTP status、content type、JSON response body/schema
+- Endpoint inventory：數字 ID/UUID 正規化，輸出 `endpoints.json`
+- 可重播請求：輸出已遮蔽敏感值的 cURL
+- 動態頁面：等待 selector、點擊、滾動觸發 lazy loading
+- 證據保存：network、console、report、screenshot、可選 rendered HTML
+- 安全：authorization/cookie/token/password 等 header、query、JSON/form 欄位遮罩；不繞過登入或反爬
+
+## 安裝
+
+```bash
+npm install
+npx playwright install chromium
+```
+
+目前環境已驗證：Node v22.22.3、Playwright 1.62.1。
+
+## 使用
+
+```bash
+node crawler.js https://example.com \
+  --output output/example \
+  --selector 'article' \
+  --fields '{"title":"h2","href":"a@href","text":":scope"}' \
+  --save-html
+```
+
+動態網站範例：
+
+```bash
+node crawler.js https://your-authorized-site.test \
+  --wait '.results' \
+  --click 'button.load-more' \
+  --scroll 3 \
+  --include '/api/|graphql' \
+  --body-limit 524288 \
+  --storage-state auth-state.json \
+  --output output/target
+```
+
+欄位規則：`"name":"h2"` 取文字；`"href":"a@href"` 取 attribute；`":scope"` 代表目前重複節點本身。
+
+## 產出
+
+- `report.json`: 執行摘要、頁面狀態、record/API 數量
+- `records.json`: selector 萃取結果
+- `network.json`: 每個請求與回應事件、body、schema、cURL
+- `endpoints.json`: 去重後 API endpoint map
+- `console.json`: browser console 訊息
+- `page.png`: screenshot（可用 `--no-screenshot` 關閉）
+- `page.html`: rendered HTML（只有 `--save-html` 才產生）
+
+## API 逆向工作法
+
+1. 先不加 `--include`，建立完整 network baseline。
+2. 從 `endpoints.json` 找 `fetch/xhr`、status、method、content type。
+3. 在 `network.json` 查看 request payload、response body、JSON schema、cURL。
+4. 用 `--click`/`--scroll` 重跑特定互動，對照新增 endpoint。
+5. 將可重播 cURL 脫離瀏覽器驗證；若需要認證，重新以合法 storage state 或正式 API client 整合。
+
+## 限制與安全邊界
+
+只對已獲授權的目標使用。不要用來繞過登入、CAPTCHA、付費牆、速率限制或存取控制；遵守 robots.txt、網站條款與適用法規。輸出仍可能包含非標準敏感欄位，交付前請人工檢查 `network.json`。

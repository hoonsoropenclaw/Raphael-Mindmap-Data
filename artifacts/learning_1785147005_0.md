+# github_trending.py
+
+Scrape https://github.com/trending and emit a Markdown table.
+
+GitHub doesn't ship a public REST API for the Trending page, so this script
+hits the HTML page directly with `requests` + `BeautifulSoup`. No token, no
+rate-limit, no Selenium.
+
+## Install
+
+```bash
+pip install requests beautifulsoup4 lxml
+```
+
+(Python 3.10+ recommended; uses `dict[str, ...]`-style union hints in spirit
+but the actual annotations are kept compatible with 3.9+ via `from __future__ import annotations`.)
+
+## Usage
+
+```bash
+# Today's top 25 across all languages
+python3 github_trending.py
+
+# Python, this week, top 10
+python3 github_trending.py --language python --since weekly --limit 10
+
+# Save to file
+python3 github_trending.py --output /tmp/trending.md
+
+# JSON instead of Markdown (handy for piping)
+python3 github_trending.py --json | jq '.[0]'
+```
+
+### CLI flags
+
+| Flag            | Default  | Meaning                                              |
+|-----------------|----------|------------------------------------------------------|
+| `--language`    | _all_    | Language slug, e.g. `python`, `go`, `rust`           |
+| `--since`       | `daily`  | `daily` / `weekly` / `monthly`                       |
+| `--limit`       | `25`     | Max number of repos                                  |
+| `--output`      | _stdout_ | Write output to file instead of stdout               |
+| `--json`        | off      | Emit JSON instead of Markdown                        |
+| `--verbose`     | off      | DEBUG-level logging                                  |
+
+## Output shape (Markdown)
+
+```
+| # | Repository | Description | Language | ⭐ Total | ⭐ Period | 🍴 Forks |
+|---|-----------|-------------|----------|---------:|----------:|---------:|
+| 1 | [owner/repo](https://github.com/owner/repo) | ... | Python | 12,345 | 678 | 90 |
+```
+
+## Robustness
+
+* Retries on 5xx and connection errors with exponential back-off (3 attempts).
+* Fails *loud* if the GitHub HTML structure changes — `RuntimeError("... no
+  <article.Box-row> found. Inspect https://github.com/trending and update...")`.
+  Silent partial parses are how you ship broken data.
+* Stars / forks use a tolerant `12.3k` / `2M` / `1,234` parser.
+* A SHA-256 fingerprint of the result is appended to
+  `/tmp/github_trending.fingerprint` after every run, so you can spot-check
+  what was captured later.
+
+## Why not `gh api`?
+
+`gh api` can hit the search API, but the closest thing to "trending" is a
+hand-rolled `created:>... stars:>... sort:stars` query — which is a proxy at
+best and costs your search quota. The HTML page is canonical, free, and
+trivial to parse.
+

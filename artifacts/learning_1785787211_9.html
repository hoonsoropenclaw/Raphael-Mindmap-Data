Design Tokens  /  統一設計系統

基於 Design Tokens 的
統一設計系統

一份 token source of truth，自動派生四個平台（Web / iOS / Android / Flutter）的 樣式定義。設計師改一個色票、PM 改一個間距、四個平台同步更新——不需要逐平台手動修。

● Live · 互動預覽 ↻ Token-driven

三層架構

從 token source of truth 到元件 UI，每一層都只向下消費、不向上硬編碼——改源頭、全平台同步。

① Token Schema
--ds-color-brand-500: #345bff;
設計語意的 single source of truth。W3C Design Tokens 簡化格式，所有視覺值皆從此派生。
② Multi-platform Adapter
Web · CSS Custom Properties iOS · Swift Color/UIFont Android · res/values/styles Flutter · ThemeData + ColorScheme
同一份 token 自動轉成各平台原生格式，避免人工轉譯誤差。
③ Component Library
所有元件只用 token 組成——改 token、元件跟著變；無硬編碼值。

Color Tokens

三層色彩：brand（品牌色階）、neutral（灰階）、semantic（語意色）。所有顏色皆以 --ds-color-* 暴露，點擊 swatch 可複製變數名稱。

Brand 10 階

Neutral 10 階

Semantic success / warning / danger / info

Spacing Scale

4pt grid。從 --ds-space-0 (0px) 到 --ds-space-20 (80px)，所有 padding / margin / gap 都用這份尺規。

Typography

九級字級、四級字重、三級行高。中英文字體分開宣告以避免字型 fallback 錯亂。

Radius

從 xs (4px) 到 full (9999px)，用於按鈕、卡片、輸入框等元件。

Elevation (Shadow)

六階陰影對應 Material Design / iOS HIG 的 elevation 概念，從扁平到浮起。

Motion

三段 duration、兩種 easing。所有過場動畫必須從 token 取值，禁用魔術數字。

Multi-platform Adapter

同一份 token source of truth 自動產出四個平台原生格式的程式碼片段。

/* tokens.css — 從 Design Token Schema 自動產生 */
:root {
  /* color */
  --ds-color-brand-500: #345bff;
  --ds-color-neutral-0: #ffffff;
  --ds-color-success-500: #16a34a;
  --ds-color-danger-500:  #dc2626;

  /* spacing (4pt) */
  --ds-space-1: 4px;
  --ds-space-2: 8px;
  --ds-space-4: 16px;
  --ds-space-6: 24px;

  /* radius */
  --ds-radius-md: 10px;
  --ds-radius-full: 9999px;

  /* motion */
  --ds-duration-normal: 200ms;
  --ds-easing-standard: cubic-bezier(.2, 0, 0, 1);
}

.btn-primary {
  background: var(--ds-color-brand-500);
  padding: 0 var(--ds-space-4);
  border-radius: var(--ds-radius-md);
  transition: background var(--ds-duration-normal)
                              var(--ds-easing-standard);
}
// DesignTokens.swift — 從 Design Token Schema 自動產生
import SwiftUI

public enum DS {
    public enum Color {
        public static let brand500   = Color(hex: "345bff")
        public static let brand600   = Color(hex: "2940e6")
        public static let neutral0  = Color(hex: "ffffff")
        public static let neutral900 = Color(hex: "0e1014")
        public static let success   = Color(hex: "16a34a")
        public static let danger    = Color(hex: "dc2626")
    }
    public enum Space {
        public static let s1:  CGFloat = 4
        public static let s2:  CGFloat = 8
        public static let s4:  CGFloat = 16
        public static let s6:  CGFloat = 24
    }
    public enum Radius {
        public static let md: CGFloat = 10
        public static let full: CGFloat = 9999
    }
}

// 使用範例
Button("Primary") {}
    .padding(.horizontal, DS.Space.s4)
    .background(DS.Color.brand500)
    .clipShape(RoundedRectangle(cornerRadius: DS.Radius.md))

// design_tokens.dart — 從 Design Token Schema 自動產生
import 'package:flutter/material.dart';

class DS {
  static const Color brand500   = Color(0xFF345BFF);
  static const Color brand600   = Color(0xFF2940E6);
  static const Color neutral0  = Color(0xFFFFFFFF);
  static const Color neutral900 = Color(0xFF0E1014);
  static const Color success   = Color(0xFF16A34A);
  static const Color danger    = Color(0xFFDC2626);

  static const double space1 = 4;
  static const double space2 = 8;
  static const double space4 = 16;
  static const double radiusMd = 10;
  static const double radiusFull = 9999;
}

// 使用範例：ThemeData 從 token 派生
final dsTheme = ThemeData(
  colorScheme: ColorScheme.light(
    primary: DS.brand500,
    error:   DS.danger,
  ),
  filledButtonTheme: FilledButtonThemeData(
    style: FilledButton.styleFrom(
      backgroundColor: DS.brand500,
      padding: EdgeInsets.symmetric(horizontal: DS.space4),
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(DS.radiusMd),
      ),
    ),
  ),
);

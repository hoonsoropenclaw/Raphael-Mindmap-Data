+### Bug #1 — React dual-instance 衝突（最關鍵）

+**症狀**：`TypeError: Cannot read properties of null (reading 'useRef')` at react.mjs:2:7835

+**解法**：
+1. importmap 把 `react` / `react-dom` / `react/jsx-runtime` 解析到 esm.sh 的 React 18.2.0 ESM

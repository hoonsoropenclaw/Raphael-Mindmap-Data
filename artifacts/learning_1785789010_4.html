🧱 核心模組

01 SSRF Guard

攔截內網 / loopback / CGNAT / ULA / .local 主機 — 防止爬蟲成為內網探測工具。

  • 協議白名單 (http/https only)
  • DNS 解析後逐 IP 驗證
  • 支援 IPv4 + IPv6

02 RobotsCache

TTL 快取 + RobotFileParser — 自動遵守目標網站的爬蟲政策，避免 429 / IP ban。

  • Origin-level 快取
  • 1 小時 TTL
  • 傳輸錯誤 fail-open

03 Schema Engine

宣告式 schema 驅動數據清洗 — 一次定義，多頁面複用。

  • 支援 price / rating / class-token / list 等 8 種型別
  • required / pattern / choices 三層驗證
  • 相對 URL 自動 join

04 Tier1Static

requests + BeautifulSoup 高速層 — 適合 SSR 頁面。

  • Session 復用 + UA header
  • 15s timeout
  • 支援 list mode (item_selector)

05 Tier2Dynamic

Selenium → Playwright 動態渲染層 — 處理 SPA / 懶加載。

  • headless=new, no-sandbox
  • network-idle wait
  • Selenium 失敗自動 fallback Playwright

06 Tier3Adaptive

選擇器池智能回退 — 當網站改版時自動找到新選擇器。

  • title / price / rating 各有 fallback pool
  • 依序嘗試直到第一個非空結果
  • 救援級與主級共用同一 schema

07 DataCleaner

NFKC 正規化 + 型別強制轉換 + fingerprint 計算。

  • price regex 解析 (£/€/¥ 通用)
  • rating 支援 class token / 文字 / 數字
  • SHA-256 fingerprint (16 chars)

08 SpiderController

編排器 — 自動 Tier 1 → 2 → 3 fallback，無需手動介入。

  • list / detail 兩種模式
  • crawl_many 批次處理
  • 記錄每 URL 的 tier + duration

09 Exporters

JSON + CSV 雙格式輸出，方便接 BI / DataFrame / 數據庫。

  • export_json / export_csv
  • 動態欄位偵測（基於實際資料）
  • UTF-8 + ensure_ascii=False

📐 Schema 定義範例

LIST_SCHEMA (列表頁 — 一 URL → 多 records)

LISTING_SCHEMA = [
    FieldSpec(name="title",   selector="h3 a", attr="title", type="string"),
    FieldSpec(name="price",   selector=".price_color",       type="price"),
    FieldSpec(name="rating",  selector=".star-rating",       type="rating",
              class_token_index=1),    # 讀 classes[1] → "Three" → 3
    FieldSpec(name="url",     selector="h3 a", attr="href",  type="string"),
]

DETAIL_SCHEMA (詳情頁 — 一 URL → 一 record)

DETAIL_SCHEMA = [
    FieldSpec(name="title",   selector="h1",                 type="string"),
    FieldSpec(name="price",   selector=".price_color",       type="price"),
    FieldSpec(name="rating",  selector=".star-rating",       type="rating",
              class_token_index=1),
    FieldSpec(name="in_stock", selector=".availability",     type="string",
              pattern=r"(?i)in stock|out of stock"),
    FieldSpec(name="description", selector="#product_description + p", type="string",
              required=False),
]

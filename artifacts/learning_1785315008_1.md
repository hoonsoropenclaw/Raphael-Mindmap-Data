+# Filesystem LLM Automation
+
+A Linux desktop automation utility that watches a local directory, batches file changes, and invokes any LLM-compatible script or CLI with a structured JSON payload.
+
+## Deliverables
+
+- `filesystem_llm_automation.py` — dependency-free watcher/runner
+- `demo_llm.py` — local deterministic LLM adapter used by smoke tests
+- `run_demo.sh` — executable demo launcher
+- `test_filesystem_llm_automation.py` — unit and end-to-end tests
+
+## Design
+
+1. Polling watcher: standard library only; works without inotify packages and is predictable in a desktop process.
+2. Change identity: file size + nanosecond mtime + SHA-256 for bounded files, so touching a file without changing content does not trigger an LLM run.
+3. Debounce: groups editor save bursts into one batch after a quiet period.
+4. Safe child execution: `shlex.split()` + `subprocess.run(..., shell=False)`; the JSON payload is sent through stdin, not interpolated into a shell command.
+5. Atomic output: child stdout is fsynced to a unique temporary file, then replaced into the destination. A failed generation leaves the previous output intact.
+6. Guardrails: extension/name filters, bounded file previews, command timeout, structured logs, SIGINT/SIGTERM handling.
+
+## Run the deterministic demo
+
+```bash
+mkdir -p watched
+./run_demo.sh watched --once
+# In another terminal, create watched/example.txt while the watcher is running.
+```
+
+The generated report is written to `generated_report.md`.
+
+## Connect a real LLM script
+
+The command must read JSON from stdin and write the generated artifact to stdout. For example:
+
+```bash
+python3 filesystem_llm_automation.py ./watched \
+  --command 'python3 ./my_llm_adapter.py --model local-model' \
+  --output ./generated/output.md \
+  --extension md --extension txt \
+  --exclude .git --exclude generated \
+  --interval 0.5 --debounce 1.0 --timeout 120
+```
+
+The payload shape is:
+
+```json
+{
+  "instruction": "Generate or update the requested artifact from these filesystem changes.",
+  "events": [
+    {
+      "kind": "modified",
+      "path": "/absolute/path/file.md",
+      "size": 42,
+      "content": "bounded UTF-8 preview",
+      "truncated": false
+    }
+  ]
+}
+```
+
+## Verification
+
+```bash
+python3 -m pytest -q
+python3 -m py_compile filesystem_llm_automation.py demo_llm.py test_filesystem_llm_automation.py
+```

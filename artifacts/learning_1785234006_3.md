+      const cards = state.cards.map((c) =>
+        c.id === action.id ? { ...c, ...action.patch } : c

+      return { ...state, cards, ui: { ...state.ui, editingId: null } };

+- **CSS 一個檔案**：沒用 Tailwind / CSS-in-JS，純粹展示 CSS 能力；用 CSS variables 沒必要（主題固定）

+async_crawler
+============
+
+基於 asyncio 的高效網頁爬蟲，具備重試機制與數據緩存。
+
+特色
+----
+
+- **完全 asyncio**：IO 密集場景下高效並發（單一 event loop + 連線池）
+- **智能重試**：指數 backoff + 抖動（jitter），區分可重試 / 不可重試錯誤
+- **兩層緩存**：記憶體 LRU + 磁碟 JSONL append（重啟可繼續）
+- **URL frontier**：去重（SHA256）+ 速率限制（rolling 1s window）+ 自動深度限制
+- **HTML 解析**：BeautifulSoup + lxml，自動萃取 `<a href>` `<img src>` `<link>` `<script>` `<iframe>`
+- **可觀測性**：詳細 stats（KPI、狀態碼分佈、緩存命中率、重試時間軸、frontier 流量）
+- **本地測試 server**：不需網路即可驗證 retry / cache / 503 / 429 行為
+
+套件結構
+-------
+
+```
+async_crawler/
+├── __init__.py        # 公開 API
+├── retry.py           # 重試機制（指數 backoff + jitter）
+├── cache.py           # 緩存（LRU + 磁碟 JSONL）
+├── frontier.py        # URL frontier（去重 + 速率限制）
+├── parser.py          # HTML 解析（BeautifulSoup + lxml）
+├── crawler.py         # 核心 AsyncCrawler 引擎
+├── stats.py           # 統計收集
+└── tests/
+    └── test_server.py  # 本地測試 HTTP server
+```
+

+

+import asyncio

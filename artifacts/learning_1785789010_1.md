+# TokenFlow · 動態設計系統與設計令牌生成器

+## 任務
+基於 Tailwind CSS 與 DaisyUI 開發動態設計系統並生成設計令牌。

+## 設計理念：單一來源 → 多格式輸出
+
+TokenFlow 採用「**Single Source of Truth**」架構：使用者調整幾個 HSL 通道（Hue / Saturation / Lightness），整套 11 階色票、CSS 變數、Tailwind config、JSON 與 SCSS 設計令牌即時生成；下游所有 DaisyUI 元件自動連動。
+
+## 實作摘要
+
+### 1. 核心 token 引擎（純 JavaScript，無框架）
+- **L 曲線** `L_CURVE`：預設 11 階 L 值（50→96 / 100→92 / 200→85 ... 950→14），經驗校準對齊 Tailwind 預設色票
+- **HSL → HEX** 轉換：用於色票卡片顯示
+- **HSL → 相對亮度** 轉換：用於 WCAG 對比檢查
+- **scale(channel)**：輸入 channel 物件（p / a / b）回傳 11 階 { hex, l } 字典
+
+### 2. 4 種匯出格式
+- **CSS Custom Properties** — 即時可貼入任何 HTML
+- **Tailwind config (JS)** — `module.exports` 格式，相容 v3
+- **JSON** — 含 meta / source / scale / system 四層
+- **SCSS variables** — `$primary-50` ~ `$primary-950` 形式
+
+### 3. 4 個預設主題

+1. **CDN 載入策略**：DaisyUI 4 + Tailwind 3 用 Play CDN 時，**不能**靠 plugin 載入 DaisyUI（會失敗）。改用預編譯 `full.min.css` ─ 直接 `<link>` 即可。

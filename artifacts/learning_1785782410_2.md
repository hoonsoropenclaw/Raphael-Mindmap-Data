+# Dynamic Web Crawler + OCR Pipeline
+
+整合 **Playwright**（動態網頁渲染） + **Tesseract OCR**（影像文字提取）的混合內容提取器，專門解決「DOM selector 抓不到的動態內容」問題（canvas、SVG、WebGL、嵌入圖、抗爬 DOM）。
+
+## 架構
+
+```
+URL
+ ↓
+[Playwright 動態渲染]
+  - 自動滾到底觸發 lazy-load
+  - wait_for_selector / wait_for_function 等待 SPA
+  - 整頁截圖 (PNG)
+ ↓
+[Hybrid Extractor 智慧分流]
+  ├─ DOM 文字（CSS selector）→ Block [source=dom, conf=100]
+  └─ 整頁截圖 → OCR (Tesseract)
+       - 影像預處理：放大 2x → 灰階 → 中值濾波 → 二值化
+       - Block [source=ocr, conf=avg_confidence]
+ ↓
+[JSON Output]
+  {
+    url, title, blocks[], summary{}, screenshots[] (base64)
+  }
+```
+
+## 檔案結構
+
+| 檔案 | 角色 |
+|------|------|
+| `ocr_engine.py` | Tesseract OCR + 影像預處理 + token/line 結構化 |

+| `extractor.py` | Hybrid 策略：DOM 優先 + OCR 補強，含 `extract_url()` 一行 API |
+| `app.py` | FastAPI server：`/api/extract`、`/api/ocr`、`/api/test-page`、`/api/health` |

+# GitHub Trending Scraper
+
+Stdlib-only Python script that fetches [GitHub Trending](https://github.com/trending)
+and renders a Markdown table.
+
+## Why stdlib?
+
+No extra deps → zero install friction, runs anywhere Python 3.10+ lives.
+HTMLParser is enough because GitHub's trending page uses stable semantic
+markup (`<article class="Box-row">`, `<span itemprop="programmingLanguage">`).
+
+## Install / run
+
+```
+python3 github_trending.py                          # daily, all langs, 25 repos
+python3 github_trending.py --language python --since weekly --top 10 --out py.md --json
+```
+
+## CLI
+
+| Flag          | Default   | Notes                                       |
+|---------------|-----------|---------------------------------------------|
+| `--language`  | (none)    | Slug used in the path, e.g. `python`, `go`  |
+| `--since`     | `daily`   | `daily` / `weekly` / `monthly`              |
+| `--top`       | `25`      | Cap rows in the table                       |
+| `--out`       | (stdout)  | Write Markdown to this file                 |
+| `--json`      | off       | Also write a `.json` sidecar with raw data  |
+
+Exit code: `0` if at least one row parsed, `1` if zero (likely HTML drift).
+
+## Output columns
+
+1. `#` — rank from GitHub's page
+2. `Repository` — clickable owner/name link
+3. `Description`
+4. `Language` — from `<span itemprop="programmingLanguage">` (fallback heuristic)
+5. `⭐ Total`
+6. `🍴 Forks`
+7. `🔥 <Window>` — stars gained in the chosen window (`today` / `this week` / ...)
+8. `Contributors` — up to 5 contributor avatars (alt text)
+
+## Drift detection
+
+When zero rows parse, the script logs a fingerprint to stderr
+(`html_len`, `had_box_row`, etc.) so you know whether GitHub re-skinned the
+page or whether your network/auth broke.
+
+## Files in this directory

+- `github_trending.py` — the script
+- `trending_test.md` / `trending_test.json` — sample output from the last run

+# Implementation Notes — github_trending.py
+
+Run: 2026-07-27, learning_1785149406_0 session.

+## Goal
+
+Stdlib-only Python that scrapes github.com/trending and emits a Markdown
+table — `--language python`, `--since daily|weekly|monthly`, `--top N`,
+optional JSON sidecar.
+
+## Architecture (3 layers)
+
+```
+fetch(url)              ← urllib + UA header, decode defensively
+        ↓
+TrendingParser(HTMLParser)  ← state-machine on <article class="Box-row">
+        ↓
+Repo dataclass list     ← ranked repos with: owner/name/url/desc/lang/stars/forks/period
+        ↓
+annotate_star_counts()  ← second pass on raw HTML chunks (SVG strip + regex)
+        ↓
+render_markdown()       ← pretty table + metadata header
+```
+
+The HTMLParser does the structural heavy lifting (h2 → owner/name,
+p.col-9 → description, span[itemprop=programmingLanguage] → language).
+Star/fork numbers are intentionally extracted in a **second pass** because
+they live inside or alongside `<svg>` icons and regex-on-visible-text is
+much more reliable than walking the SVG-adjacent anchor tags.
+
+## Bugs hit during this run
+
+1. **`r"[\d,]+"` matched the empty string** when the chunk started with a
+   delimiter (`,`) → `ValueError: invalid literal for int()`. Fix:
+   `r"\d[\d,]*"` (require at least one digit).
+2. **Language came back empty** because I tried to detect it via
+   `repo-language-color` span — that's the *color dot*, not the text.
+   The actual text sits in a sibling `<span itemprop="programmingLanguage">`
+   which has no class at all. Fixed by adding an `itemprop` attr check
+   inside the generic `span` branch.
+3. **`stars_total` was `1,166`** (the period value) because `nums[0]`
+   picked the first integer in the chunk. Fixed by filtering out the
+   known period value, then picking the two largest remaining ints as
+   total_stars + forks. (Sanity check: total ≥ forks ≥ period.)
+
+## Design trade-offs
+
+- **No headless browser.** The page is server-rendered HTML — no need for
+  Playwright/Selenium. Keeps the script < 14 KB and instant.

+  "did the markup change?" from "did the parser break?" — easier to debug
+  if GitHub re-skins.
+- **Drift fingerprint on zero rows.** If `Box-row` class is missing, log
+  to stderr so an operator knows the script didn't just hit a network
+  blip.
+- **stdlib only.** No `requests`, no `bs4`. Means anyone with Python can
+  run it, no `pip install` needed.

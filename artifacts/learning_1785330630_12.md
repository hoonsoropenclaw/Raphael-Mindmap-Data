+# PRD：BeautifulSoup × Selenium 高效網頁數據提取管道
+
+## 目標
+建立一個可直接執行的 Python CLI：以 Selenium 處理 JavaScript、互動與等待，以 BeautifulSoup 負責批量 DOM 解析，避免使用 Selenium 逐元素讀取造成大量 WebDriver round-trip。
+
+## 模組拆解
+1. 瀏覽器層：Chrome/Chromium 自動發現、headless 啟動、頁面導航、顯式等待、互動動作。
+2. 快速路由層：可先用 HTTP 取得原始 HTML；若目標 selector 已存在則略過 Selenium，否則升級到瀏覽器渲染。
+3. 解析層：把單次 `page_source` 快照交給 BeautifulSoup，以 CSS selector + 欄位規則抽取文字、HTML 或屬性。
+4. 穩健性層：有限重試、退避、timeout、driver `finally` 關閉、錯誤分類、原子 JSON 寫入。
+5. 可觀測性層：記錄模式、URL、嘗試次數、耗時、HTML bytes、資料筆數、等待 selector。
+6. 驗證層：靜態 fast path、動態 Selenium path、互動 click path、欄位抽取與錯誤路徑。
+
+## 功能需求
+- `--url`、`--item-selector`、重複 `--field name=selector[@attr|::html|::text]`。
+- `--mode auto|http|selenium`；auto 預設先 HTTP，資料不足才升級 Selenium。
+- `--wait-selector`、`--click-selector`、`--scroll-times`、timeout、retry、user-agent。
+- 輸出 UTF-8 JSON；stdout 或 `--output`。
+- 能以本機動態測試頁真實驗證 JavaScript 渲染後的資料。
+
+## 非目標
+- 不繞過 CAPTCHA、登入權限或網站存取控制。
+- 不做分散式爬蟲、代理池或反偵測偽裝。
+- 不以 Selenium element API 逐筆解析資料。
+
+## 成功標準
+- 單元測試全部通過。
+- 真實 headless Chromium E2E 可取得 JavaScript 延遲插入的 3 筆產品。
+- driver 即使失敗也能關閉。
+- README 含安裝、配置、架構、效能原理與合法使用邊界。

+# BeautifulSoup × Selenium 高效網頁數據提取管道
+
+這是一個已實際執行驗證的 Python 3.12 CLI。核心分工：
+
+- Selenium 只負責瀏覽器工作：JavaScript 渲染、點擊、顯式等待、滾動。
+- BeautifulSoup 負責資料工作：取得一次 `page_source` 後，在記憶體中批量 CSS selector 解析。
+- `auto` 模式先走低成本 HTTP；原始 HTML 已有資料時完全不啟動瀏覽器，沒有才升級 Selenium。
+
+## 為何比「全 Selenium 抽取」有效率
+
+逐筆呼叫 `find_elements`、`.text`、`get_attribute` 都會跨 Python ↔ WebDriver ↔ Browser 邊界。N 筆資料、F 個欄位通常產生 O(N×F) 次遠端呼叫。本管道只有瀏覽器操作與一次 `page_source` 跨邊界，後續解析都在同一 Python process 內完成。
+
+```text
+URL
+ ├─ auto/http → urllib 取得原始 HTML
+ │                └─ selector 已存在 → BeautifulSoup → JSON
+ └─ selector 不存在 → Selenium render/click/wait/scroll
+                          └─ 單次 page_source → quit driver
+                                                └─ BeautifulSoup → JSON
+```
+
+## 安裝
+
+本機採隔離 venv，符合 PEP 668：
+
+```bash
+uv venv .venv --python 3.12
+uv pip install --python .venv/bin/python -e '.[dev]'
+```
+
+Selenium 會依序尋找系統 Chromium/Chrome；若不存在，會尋找 `~/.cache/ms-playwright/chromium-*/chrome-linux*/chrome`。也可明確傳 `--browser-binary /path/to/chrome`。
+
+## 快速使用
+
+靜態頁面或自動判斷：
+
+```bash
+.venv/bin/hybrid-scrape \
+  --url 'https://example.com/products' \
+  --mode auto \
+  --item-selector '.product' \
+  --field 'title=h2' \
+  --field 'price=.price' \
+  --field 'url=a@href' \
+  --field 'sku=@data-sku' \
+  --output artifacts/products.json
+```
+
+動態頁面，需點擊後等待：
+
+```bash
+.venv/bin/hybrid-scrape \
+  --url 'https://example.com/app' \
+  --mode selenium \
+  --click-selector '#load-more' \
+  --wait-selector '.product' \
+  --item-selector '.product' \
+  --field 'title=h2::text' \
+  --field 'description=.description::html' \
+  --field 'url=a@href'
+```
+
+## Field 語法
+
+| 語法 | 意義 |
+|---|---|
+| `title=h2` | 取 `h2` 的合併文字 |
+| `title=h2::text` | 明確取文字 |
+| `body=.description::html` | 取元素 inner HTML |
+| `url=a@href` | 取 `href` 屬性 |
+| `sku=@data-sku` | 從 item 本身取屬性 |
+
+找不到的可選欄位回傳 `null`，不會使整批資料失敗。
+
+## CLI 參數
+
+- `--mode auto|http|selenium`：預設 auto。
+- `--wait-selector`：動態內容完成的明確條件；預設 item selector。

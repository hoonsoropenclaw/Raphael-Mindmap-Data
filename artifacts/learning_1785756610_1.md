+function runDiff(directory, baseline, current, output) {

+}

+# Cross-browser Visual Lab
+
+Reusable Playwright Test framework for functional browser automation and visual regression testing.
+
+## What is included
+
+- Browser matrix: Chromium, Firefox, WebKit, Mobile Chromium (Pixel 5), Mobile WebKit (iPhone 13).
+- Deterministic screenshot policy: reduced motion, hidden caret, UTC locale, fixed device presets, blocked service workers.
+- Explicit baseline lifecycle: normal test runs compare only; `baseline` is the only command that writes snapshots.
+- Functional smoke suite beside visual assertions: ready state, interaction, keyboard shortcut, anchor integrity, route filtering, lane filtering, console/page errors, and horizontal overflow.
+- Custom artifact reporter: machine-readable `artifacts/results.json` plus standalone `artifacts/report.html`.
+- Safe static server: root-locked path resolution, traversal rejection, no-store responses, and correct MIME types.
+- Optional Pillow + NumPy comparator for standalone PNG evidence and CI scripts.
+- Configurable project selection and external target URL through environment variables.
+
+## Quick start
+
+```bash
+npm install
+npx playwright install chromium firefox webkit
+
+# Validate source contracts first
+npm run check
+npm run test:unit
+
+# First run only: create/update browser-specific baselines
+npm run baseline
+
+# Normal run: compare against baselines; never updates them
+npm test
+
+# Rebuild the standalone report from the latest result JSON
+npm run report
+```
+
+The managed server serves `web_output.html` from the project root at `http://127.0.0.1:4173`.
+The server is started and stopped by Playwright for normal runs, so a stale process cannot silently point at a different working directory.

+## Common commands

+```bash
+npm run test:chromium
+npm run test:firefox
+npm run test:webkit
+npm run test:mobile

+
+## 1. Runtime topology
+
+```text
+npm script / visual-cli.mjs
+        │
+        ├── contract ─────────────── file + HTML marker checks
+        ├── test / baseline ─────── @playwright/test CLI
+        │                              │

+        │                              ├── browser project matrix

+        ├── report ───────────────── artifacts/results.json → report.html
+        ├── serve ────────────────── safe static server for manual QA
+        └── diff ─────────────────── pixel_diff.py → JSON + heatmap
+```
+
+## 2. Module responsibilities
+
+| Module | Responsibility | Important invariant |
+|---|---|---|
+| `src/framework/config.mjs` | Parse bounded env settings and construct Playwright device projects | Unknown project names fail before browser launch |
+| `src/framework/stability.mjs` | Freeze animation/transition/caret/font state before screenshots | Visual captures use the same stabilization contract in every lane |
+| `src/framework/server.mjs` | Serve the target root during local runs | Decoded paths cannot escape the configured root |
+| `src/framework/reporter.mjs` | Collect per-test status, timing, errors, attachments | Output is always rooted at the project root, not `tests/e2e` |
+| `src/framework/report.mjs` | Aggregate results and escape report content | Test text cannot inject HTML into the report |
+| `scripts/visual-cli.mjs` | Stable operator interface for test lifecycle | Normal `test` never adds `--update-snapshots` |
+| `scripts/pixel_diff.py` | Optional standalone image comparison | Exit code distinguishes pass, drift, and input error |
+
+## 3. Browser matrix
+
+The matrix is intentionally explicit rather than inferred from a host browser:
+
+- `chromium` → Playwright `Desktop Chrome`
+- `firefox` → Playwright `Desktop Firefox`
+- `webkit` → Playwright `Desktop Safari`
+- `mobile-chromium` → Playwright `Pixel 5`
+- `mobile-webkit` → Playwright `iPhone 13`
+
+Each project owns a separate snapshot directory. A WebKit rasterization difference is not allowed to overwrite a Chromium contract.
+
+## 4. Determinism controls
+
+The framework pins or removes common visual noise sources:
+
+- `reducedMotion: 'reduce'` and injected zero-duration animation/transition CSS.
+- `caret: 'hide'` plus `caret-color: transparent`.
+- `locale: 'en-US'`, `timezoneId: 'UTC'`, and light color scheme.
+- Service workers blocked so stale cached assets cannot survive between runs.
+- Demo surface uses local CSS and deterministic static data; no CDN, API, random value, current timestamp, or fixed background attachment.
+- One worker serializes visual lanes. This is slower than unconstrained parallelism but materially easier to reproduce on a small headless host.
+
+## 5. Baseline lifecycle
+
+```text
+baseline command ──► capture ──► explicit snapshot write
+                                     │
+normal test ───────► capture ──► compare ──► pass/fail + evidence
+```
+
+A missing baseline is an error, not an implicit approval. Baseline updates are a reviewable action and should be scoped to the affected project when possible.
+
+## 6. Failure evidence
+
+A visual failure produces Playwright's expected/current/diff PNGs and, under the configured failure policy, screenshot, video, trace, and error context. The custom reporter writes:
+
+- `artifacts/results.json`: stable machine-readable status/timing/error/attachment data.
+- `artifacts/report.html`: escaped standalone summary suitable for a browser or CI artifact viewer.
+
+The optional `pixel_diff.py` is useful when a pipeline needs a JSON pixel count independent of Playwright's matcher. It reports changed pixel count, percentage, max channel delta, bounding box, dimensions, and whether height cropping occurred.

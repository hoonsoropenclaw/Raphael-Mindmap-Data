+# PRD — Telemetry Arena
+
+Date: 2026-08-03
+Status: implementation-ready
+
+## Goal
+Build an executable Godot 4.3 2D arena game that can autonomously run a deterministic demo, record its viewport to video, and export machine-readable gameplay analytics.
+
+## Modules
+1. Game loop: player movement, projectile firing, enemy spawning/chasing, collision, scoring, health.
+2. Deterministic automation: seeded RNG plus scripted/autopilot input; fixed-duration runs terminate automatically.
+3. Runtime analytics: JSONL event stream, CSV time-series samples, JSON aggregate summary.
+4. Render automation: Godot MovieWriter records the real viewport; FFmpeg converts AVI to MP4.
+5. Verification: headless smoke run, recorded render run, schema/statistical assertions, video probe.
+
+## Functional requirements
+- Native 2D gameplay must be visible and playable.
+- Automation mode must generate movement, shots, enemies, collisions, score and telemetry without human input.
+- Every run creates a unique run directory.
+- Event records include timestamp, event type, and payload.
+- Summary includes duration, frames, score, kills, shots, hits, hit rate, distance, damage, FPS and final state.
+- CSV includes periodic time-series observations suitable for external analysis.
+- Video automation creates a playable MP4 when FFmpeg is installed.
+- CI/headless mode must terminate with exit code 0 and emit `RUN_COMPLETE`.
+
+## Non-functional requirements
+- Godot 4.3 compatible.
+- No third-party Godot addons.
+- Reproducible via fixed seed.
+- No external network dependency.
+- Outputs stay under project `output/`.
+
+## Acceptance criteria
+- `godot --headless --path . -- --automated --duration=4 --no-capture` succeeds.
+- Analytics schema validator succeeds and confirms non-zero frames, shots, movement and events.
+- Render script produces MP4 with non-zero video duration and 1280x720 dimensions.
+- All source files parse without Godot errors.

+#!/usr/bin/env python3
+"""Validate Telemetry Arena run outputs without third-party dependencies."""
+from __future__ import annotations
+
+import argparse
+import csv
+import json
+import math
+from collections import Counter
+from pathlib import Path
+
+
+def fail(message: str) -> None:
+    raise SystemExit(f"VALIDATION_FAILED: {message}")
+
+
+def main() -> None:
+    parser = argparse.ArgumentParser()
+    parser.add_argument("run_dir", type=Path)
+    args = parser.parse_args()
+    run_dir = args.run_dir.resolve()
+
+    required = [run_dir / "summary.json", run_dir / "events.jsonl", run_dir / "timeseries.csv"]
+    for path in required:
+        if not path.is_file() or path.stat().st_size == 0:
+            fail(f"missing or empty {path}")
+
+    summary = json.loads(required[0].read_text(encoding="utf-8"))
+    events = [json.loads(line) for line in required[1].read_text(encoding="utf-8").splitlines() if line.strip()]
+    with required[2].open(newline="", encoding="utf-8") as handle:
+        samples = list(csv.DictReader(handle))
+
+    for key in ("duration_s", "frames", "score", "kills", "shots", "hits", "hit_rate", "distance_travelled_px", "events", "samples"):
+        if key not in summary:
+            fail(f"summary missing key {key}")
+    if summary["schema_version"] != 1:
+        fail("unsupported schema_version")
+    if summary["duration_s"] <= 0 or summary["frames"] <= 0:
+        fail("run did not advance")
+    if summary["shots"] <= 0:
+        fail("automation produced no shots")
+    if summary["distance_travelled_px"] <= 50:
+        fail("player did not move meaningfully")
+    if len(events) != summary["events"]:
+        fail(f"event count mismatch: file={len(events)} summary={summary['events']}")
+    if len(samples) != summary["samples"] or len(samples) < 3:
+        fail(f"sample count mismatch/insufficient: file={len(samples)} summary={summary['samples']}")
+
+    event_types = Counter()
+    previous_ms = -1
+    for index, event in enumerate(events):
+        for key in ("run_id", "elapsed_ms", "type", "payload"):
+            if key not in event:
+                fail(f"event {index} missing {key}")
+        if event["elapsed_ms"] < previous_ms:
+            fail("events are not monotonic")

+# Telemetry Arena
+
+Godot 4.3 native 2D arena game with deterministic autoplay, real viewport video capture, and structured runtime analytics.
+
+## What is included
+

+- JSONL event telemetry, CSV time series, aggregate JSON summary, Markdown analysis.

+- Independent Python validator and ffprobe video contract check.
+
+## Run interactively
+
+```bash
+godot --path .
+```
+
+## Run the complete test suite
+
+```bash
+./run_tests.sh 4
+```
+
+This performs Godot import/parse validation, a 4-second headless integration run, analytics validation and report generation.
+
+## Render an automated gameplay video
+
+```bash
+./render_video.sh 10
+```
+
+The render is deterministic and fixed at 30 FPS. Output appears in:
+
+```text
+output/run_<timestamp>_seed20260803/

+├── video_probe.json
+├── events.jsonl
+├── timeseries.csv
+├── summary.json
+└── analysis.md
+```

+
+## CLI options
+
+- `--automated`: enable autopilot and auto-exit.
+- `--duration=N`: simulation duration in seconds.
+- `--seed=N`: deterministic random seed.
+- `--output=PATH`: output root (default `res://output`).
+- `--no-capture`: marks a headless analytics-only run.
+
+## Analytics model
+
+`events.jsonl` contains monotonic typed events:
+- `run_started`
+- `player_spawned`
+- `enemy_spawned`
+- `shot_fired`
+- `bullet_hit`
+- `enemy_destroyed`
+- `player_damaged`
+- `run_finished`
+
+`timeseries.csv` samples every 250 ms: elapsed time, frame, player position, health, score, enemy count, bullet count and FPS.
+
+`summary.json` stores aggregate metrics: duration, frames, FPS, score, kills, shots, hits, hit rate, damage, distance, max enemies and final state.
+
+## Architecture note

+## 1. 背景
+
+目前工作目錄沒有可直接接入的行政系統原始碼。交付一個可離線、可重複執行、可移植到既有 HTTP 行政系統的測試框架，並以內建 demo API 驗證框架本身。

+## 2. 目標
+
+1. 驗證行政 API 的健康狀態、登入、CRUD、RBAC、輸入驗證與錯誤語意。
+2. 提供 unit / integration / E2E 三層測試入口。
+3. 每次測試具備逾時、隔離、結構化 JSON/JUnit 報告與正確 exit code。
+4. 對敏感輸入做報告遮罩，不把 authorization/cookie/password 寫入報告。
+5. 支援未來以 `ADMIN_TARGET_URL` 指向真實測試環境，但預設只打本機 demo。

+## 4. 驗收標準

+- `python3 -m py_compile` 對所有 source/test 通過。

+- 完整測試至少涵蓋：
+  - health 200
+  - valid/invalid login
+  - unauthenticated protected endpoint 401

+  - invalid input 400

+  - timeout/connection failure 語意
+  - report sensitive-field redaction

+## 模組契約
+
+### contracts.py
+
+- `TestCase`: name, method, path, expected_status, role, body, expected_json, timeout, destructive, tags.
+- `TestResult`: status in PASS/FAIL/SKIP/ERROR, duration, message, sanitized request/response summary.
+- schema validator rejects unknown methods, negative timeout, missing name/path, unsupported expected predicates.
+- sensitive keys recursively redacted.
+
+### client.py
+
+- `HttpClient(base_url, timeout)` accepts only http/https URL.
+- `request()` uses urllib; returns response body even for expected HTTP 4xx/5xx.
+- connection/timeout errors become typed transport errors.
+- response body is bounded before JSON parsing.
+
+### runner.py
+
+- preserve declaration order for deterministic output.
+- no short-circuit: one failure does not prevent later tests.
+- destructive tests default SKIP.
+- per-case request timeout.
+- summary counts must equal total and process exit code reflects FAIL/ERROR.
+
+### reporters.py
+
+- JSON schema with generated_at, target, summary, results.
+- JUnit XML tests/failures/errors/skipped counts match JSON.
+- writes are atomic and permissions follow process umask.
+
+### demo_app.py
+
+- listen only on `127.0.0.1`, random port by default.
+- endpoints: `/health`, `/api/login`, `/api/me`, `/api/cases`, `/api/cases/:id`, `/api/cases/:id/ack`.
+- RBAC: viewer read; staff create/read/update own; chief approve; admin all.
+- unknown/invalid auth fail closed.
+- in-memory state reset per test fixture.
+
+## TDD 順序
+
+1. Write contract/redaction tests → RED → implement contracts.
+2. Write client tests → RED → implement client.
+3. Write runner/report tests → RED → implement runner/reporters.

+5. Write CLI E2E tests → RED → implement CLI/suite.
+6. Run full suite + coverage + fault injection + repeatability.

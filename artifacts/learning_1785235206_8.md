+def fetch_html(language: str, since: str, timeout: int) -> str:

+            "Accept": "text/html,application/xhtml+xml",
+        },
+    )
+    with urlopen(request, timeout=timeout) as response:
+        charset = response.headers.get_content_charset() or "utf-8"
+        return response.read().decode(charset, errors="replace")

+# GitHub Trending Markdown 腳本：實作思路與架構審查
+
+## 目標
+以 Python 標準函式庫抓取 GitHub Trending，將每個 repository 的名稱、連結、描述、主要語言、總 stars、forks 與今日新增 stars 輸出為 Markdown 表格。
+
+## 設計
+
+1. 網路層：使用 `urllib.request` 建立帶 User-Agent 的 GET 請求，支援 language 與 since（日/週/月）查詢參數；不依賴 token 或第三方套件。
+2. 解析層：先以 `<article>` 切分 repository，再以有限範圍 regex 擷取 repository link、description、programmingLanguage 與統計文字。所有 HTML 實體先 `html.unescape`，再清理空白。
+3. 模型層：用 frozen `dataclass Repository` 固定資料契約，避免輸出階段直接依賴 HTML。
+4. 輸出層：集中由 `markdown()` 產生 Markdown；description 中的 `|` 會跳脫，避免破壞表格。預設輸出 stdout，也可用 `--output` 寫檔。
+5. CLI：`argparse` 提供 `--language`、`--since`、`--output`、`--timeout`，錯誤寫 stderr 並以非零狀態結束。
+
+## 可靠性與風險
+
+- GitHub Trending 沒有穩定公開 API，因此 HTML 結構變動是主要風險；若解析不到任何 article，腳本明確失敗，而不是產生空表格。
+- 網路錯誤、HTTP 錯誤與逾時會被捕捉並回報。
+- parser 對缺少 description、language、forks 或今日 stars 的欄位採用 `—`，維持表格欄位完整。
+- 不使用 shell、eval 或外部命令，降低命令注入與環境依賴。
+

+"""JSON response schema 推斷器。
+
+從一堆 JSON response 樣本推斷出「最可能」的 schema 描述。
+這是「API 逆向工程」的核心動作 —— 你看到一坨 JSON，要寫出 OpenAPI / JSON Schema。
+
+策略：
+- object → recurse
+- array → 看第一個元素的型別，標記成 array<typeof(first)>
+- 數字 / 字串 / bool / null → 直接定型
+- 多個樣本同 key 不同型別 → 升級成 oneOf（標記歧義）
+- 樣本之間同 key 偶爾缺 → 標 optional
+
+回傳格式是 dict（相容 JSON Schema draft-07 語法），方便之後直接輸出 OpenAPI。
+"""
+from __future__ import annotations
+
+from typing import Any
+
+
+_TYPE_NAMES = {dict: "object", list: "array", str: "string", int: "number", float: "number", bool: "boolean", type(None): "null"}
+
+
+def _typename(v: Any) -> str:
+    if v is None:
+        return "null"
+    if isinstance(v, bool):
+        return "boolean"
+    if isinstance(v, (int, float)):
+        return "number"
+    if isinstance(v, str):
+        return "string"
+    if isinstance(v, list):
+        return "array"
+    if isinstance(v, dict):
+        return "object"
+    return type(v).__name__
+
+
+def _merge(a: dict, b: dict) -> dict:
+    """合併兩個 schema 推斷結果。
+
+    - type 一樣 → recurse
+    - type 不一樣 → 升級成 oneOf
+    - properties 合併：缺的就標 optional
+    """
+    if a == b:
+        return a
+    if a.get("type") != b.get("type"):
+        # 歧義 → oneOf
+        return {"oneOf": [a, b]}
+    # 同 type，recurse
+    if a["type"] == "object":
+        merged_props: dict = {}
+        required: set = set()

+            in_a = k in a.get("properties", {})
+            in_b = k in b.get("properties", {})

+## 能力
+
+- **事件驅動**：每個模組（攔截 / 推斷 / 記錄 / 圖譜）是獨立 subscriber，靠 EventBus 溝通
+- **即時推斷**：JSON response 自動轉 JSON Schema 草案（含 `oneOf` 歧義捕捉、`required` 集合）
+- **路徑正規化**：`/users/1`、`/users/2` 自動合併成 `/users/{id}` 並累計樣本
+- **HAR-lite NDJSON**：串流寫、不進 RAM、敏感 header 自動遮罩
+- **獨立可重跑**：NDJSON 紀錄可重讀、推斷可重做（`report` 子命令）
+
+## 安裝
+
+零外部依賴（Python 3.12+、aiohttp 3.x、pytest-asyncio）。N100 上已驗證可跑。

+python3 -m api_re report api_re.har.ndjson -o report.json

+### 狀態管理架構
+```
+App state (single useReducer):
+  ├─ tasks: Task[]                    (id, title, status, priority, tags, body, createdAt)
+  ├─ history: Action[]                (past + future for undo/redo)
+  ├─ filter: { status, priority, q, tag }
+  ├─ selection: id | null             (right inspector target)
+  ├─ dragState: { draggingId, hoverColumn }
+  └─ ui: { modalOpen, modalDraft }
+
+Actions:
+  ADD_TASK     → optimistically push task + history snapshot
+  UPDATE_TASK  → patch field + history snapshot (debounced for title edits)
+  DELETE_TASK  → remove + history snapshot
+  MOVE_TASK    → reorder within column / cross-column
+  SET_FILTER   → no history (UI-only)
+  SELECT_TASK  → no history
+  BULK_IMPORT  → merge + history snapshot
+  EXPORT_CSV   → no state mutation
+  UNDO / REDO  → pop from past[]/future[]
+  HYDRATE      → load from localStorage on boot
+```

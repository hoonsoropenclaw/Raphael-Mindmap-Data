About this preview

This is a 1:1 web mirror of the desktop GUI built with the Godot 4.3 engine (project in godot_project/). Both the Godot and this page use the same watch-and-act pattern: poll a directory, diff a snapshot, and run automation (log/JSONL + archive mirror + optional staging copy).

  • The Godot app uses a native polling-based watcher (file_watcher.gd) — no native deps.
  • A Python mirror (python_watch.py) implements the same flow with the watchdog library.
  • The headless smoke test (scripts/smoke_test.gd) verifies create/modify/delete detection.

Sandbox note: this browser preview can't actually access your filesystem, so the buttons simulate the events and log them locally. The Godot and Python versions read/write real files and have been verified end-to-end (see README.md).

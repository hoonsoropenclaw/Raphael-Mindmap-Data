+#!/usr/bin/env python3
+"""Linux system log + resource monitor with threshold-based warnings.
+
+PURE STDLIB — no external dependencies. Designed for headless N100/mini-PC
+environments where installing psutil/requests/etc. is unwanted overhead.
+
+Reads:
+  - /proc/stat        -> CPU usage (delta between two snapshots, ~1s apart)
+  - /proc/meminfo      -> RAM usage
+  - /proc/loadavg      -> 1-minute load average / running+total processes
+  - df (subprocess)    -> disk usage on each configured mount
+  - /var/log/syslog    -> recent error/warning lines since last run
+       (falls back to /var/log/messages, then journalctl --no-pager
+        -p err -n N if neither file exists, then "no log source" notice)
+
+Outputs:
+  - stdout: human-readable status + warning lines
+  - --log-file: append structured WARN/CRIT lines (one JSON object per line)
+  - exit code: 0=OK, 1=WARN(any), 2=CRIT(any)
+
+Default thresholds are tuned for an N100 mini-PC (4 cores, 8GB RAM).
+Override everything via CLI flags — see --help.
+
+Usage:
+  ./monitor.py                       # one-shot check with default thresholds
+  ./monitor.py --cpu 90 --mem 85     # stricter thresholds
+  ./monitor.py --log-file /var/log/monitor.jsonl
+  ./monitor.py --mounts /,/data,/home
+  ./monitor.py --syslog-lines 200 --log-priority err
+
+Designed to be cron-friendly:
+  */5 * * * * /usr/local/bin/monitor.py --log-file /var/log/monitor.jsonl

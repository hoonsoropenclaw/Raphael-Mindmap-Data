FAQ

How is the visual diff calculated?

We use Pillow's ImageChops to compute per-channel deltas, then aggregate into a per-pixel difference map. Any pixel whose max-channel delta exceeds the configured threshold (default 0.15) is flagged.

Can I tune the threshold per page?

Yes — each baseline entry can override the global threshold. Useful for pages that intentionally contain anti-aliased animations.

Does it work offline?

The harness runs fully offline once browsers are installed. The Tailwind CDN is the only network dependency at capture time.

+# Cross-Browser Playwright + Visual Regression Harness
+
+This project is a self-contained test harness for `web_output.html`.
+
+## What it covers
+
+- Chromium, Firefox, and WebKit projects.
+- Core page load/accessibility contract.
+- Smoke-check interaction and state updates.
+- Accessible dark/light theme toggle.
+- Mobile viewport overflow guard at `390x844`.
+- Per-browser visual baselines for dark theme, light theme, and mobile dark theme.
+- Visual gate at `maxDiffPixelRatio: 0.005` (0.5%) with deterministic animation/caret state.
+
+## Run
+
+```bash
+npm install
+npx playwright install chromium firefox webkit  # only if browser binaries are absent
+npm test
+```
+
+The test runner starts a local server on `127.0.0.1:4173` automatically. Override it with `PORT=4300 npm test`.
+
+## Baselines
+
+The first baseline creation is intentional:
+
+```bash
+npm run test:update
+```
+
+After an intentional UI change, review the generated files under `tests/__screenshots__/`, then update them explicitly with `npm run test:update`.
+
+When a visual assertion fails, Playwright stores `-actual`, `-expected`, and `-diff` artifacts under `test-results/` and creates an HTML report:
+
+```bash
+npm run report
+```
+
+## Test selection
+
+```bash
+npx playwright test --project=chromium
+npx playwright test --project=firefox
+npx playwright test --project=webkit
+npx playwright test -g "visual baseline"
+```
+
+## Design decisions
+
+- Baselines are isolated by browser project because font rasterization and layout details are engine-specific.
+- The page uses only local HTML/CSS/JavaScript, so the test does not depend on a network CDN.
+- The static server is bound to loopback and configured through `PORT`, preventing accidental external exposure.
+- No `--no-sandbox` flags are passed to WebKit; browser-specific launch flags are intentionally avoided unless required by the host.

+

+- We use sync SQLAlchemy (not async). FastAPI sync `def` endpoints run in a
+  threadpool, so sync sessions are safe and do not block the event loop.
+- Per trial-and-error `fastapi-async-session-pitfalls.md` Pitfall 2, mixing
+  sync `sessionmaker` with `async def` endpoints causes deadlock under load;
+  we use sync `def` throughout, so this is consistent.
+- `expire_on_commit=False` is set so attribute access after commit does not
+  raise `DetachedInstanceError`.
+- `check_same_thread=False` lets multiple threads (the FastAPI threadpool)
+  share the SQLite connection.

+  on-disk DBs a default `NullPool` would also work, but `StaticPool` is fine
+  for SQLite (single-file DB, no need for connection pooling).

+"""Simple in-memory rate limiter (token bucket per client key).
+
+Design:
+- Token-bucket: each client has a bucket of `capacity` tokens that refills at
+  `refill_rate` tokens per second. A request consumes 1 token. If the bucket
+  is empty, the request is rejected with HTTP 429.
+- Implementation: store `(tokens_remaining, last_refill_timestamp)` per key
+  in a dict protected by a single threading.Lock. The lock keeps it correct
+  across FastAPI's threadpool; for multi-process deployments you'd want a
+  Redis-backed limiter, but in-memory is sufficient for this exercise.
+- Client key resolution: trust `X-Forwarded-For` only if `TRUST_PROXY` env
+  var is set (otherwise an attacker can spoof it). Falls back to the direct
+  client IP (`request.client.host`).
+- Configurable via env vars so tests can dial limits down:
+    TODO_API_RATE_LIMIT_CAPACITY       (default 10)
+    TODO_API_RATE_LIMIT_REFILL_PER_SEC (default 1.0)
+    TODO_API_TRUST_PROXY               (default "0")
+"""
+
+from __future__ import annotations
+
+import os
+import threading
+import time
+from collections.abc import Callable
+
+from fastapi import HTTPException, Request, status
+
+
+class TokenBucketRateLimiter:
+    """Thread-safe in-memory token-bucket rate limiter.
+
+    Args:
+        capacity: maximum tokens a bucket can hold (= burst size).
+        refill_rate: tokens added per second (steady-state rate).
+    """
+
+    def __init__(self, capacity: float, refill_rate: float) -> None:
+        if capacity <= 0:
+            raise ValueError("capacity must be > 0")
+        if refill_rate <= 0:
+            raise ValueError("refill_rate must be > 0")
+        self.capacity = capacity
+        self.refill_rate = refill_rate
+        self._buckets: dict[str, tuple[float, float]] = {}
+        self._lock = threading.Lock()
+
+    def _refill(self, tokens: float, last_refill: float, now: float) -> float:
+        elapsed = max(0.0, now - last_refill)
+        return min(self.capacity, tokens + elapsed * self.refill_rate)
+
+    def consume(self, key: str, cost: float = 1.0, now: float | None = None) -> bool:
+        """Try to consume `cost` tokens for `key`. Returns True if allowed."""
+        if cost > self.capacity:
+            # Single request larger than burst capacity — never allowed.
+            return False
+        if now is None:
+            now = time.monotonic()
+        with self._lock:
+            entry = self._buckets.get(key)
+            if entry is None:
+                tokens, last_refill = self.capacity, now
+            else:
+                tokens, last_refill = entry
+            tokens = self._refill(tokens, last_refill, now)
+            if tokens >= cost:
+                tokens -= cost
+                self._buckets[key] = (tokens, now)
+                return True
+            self._buckets[key] = (tokens, now)
+            return False
+
+    def reset(self) -> None:
+        """Clear all buckets. Useful for tests."""
+        with self._lock:
+            self._buckets.clear()

+## 2. 關鍵設計決策（含 5 個明確「為什麼」）
+
+### 2.1 為什麼用 sync `def` endpoint + sync `sessionmaker`，**不是** `async def` + `async_sessionmaker`
+
+讀 `trial-and-error/references/by-category/fastapi-async-session-pitfalls.md` 後決定走同步路線：
+
+- **Pitfall #2**：async endpoint 內呼叫 sync `sessionmaker` + `.query()` → 100 個 concurrent requests 直接 deadlock（blocking event loop）。
+- 解法只有兩條：(a) 全 async（`async def` + `async_sessionmaker` + `await db.execute()`），(b) 全 sync（`def` + `sessionmaker` + `db.execute()`）。
+- **選 (b) 的原因**：
+  1. SQLite 本身是 synchronous-friendly（單檔、無原生 async driver）。
+  2. 這個 todo API 不需要高併發，rate limit 預設 10 req/s，純 sync 足夠。
+  3. `expire_on_commit=False` 已設，避免 `DetachedInstanceError`（Pitfall 後段規範）。
+  4. async 那條路在 SQLite 要額外裝 `aiosqlite`、加 StaticPool、SQLAlchemy 2.0 async API 還沒完全穩定 —— 引入不必要的複雜度。
+
+**trade-off**：之後要換 async Postgres driver（例如 `asyncpg`），endpoint 必須全部 `async def` 才能保留正確性。這個專案暫時不需要。
+
+### 2.2 為什麼 rate limiter 走「in-memory token bucket + threading.Lock」，不是 Redis 或 middleware
+
+- **範圍**：單機 FastAPI process，不需要跨 process / 跨機協調。
+- **正確性**：Python GIL 讓 `threading.Lock` 在 GIL 邊界內有效；FastAPI 跑 sync endpoints 在 threadpool，多執行緒並發讀寫 bucket map 必須有鎖。
+- **可測試性**：模組級 singleton + `set_active_limiter()` hook 讓測試能注入 capacity=2 的實例而不污染全域狀態。
+- **生產升級路徑**：換 Redis 就是把 `consume()` 改成 `INCR + EXPIRE`，介面不變。文件裡有標註「for multi-process deployments you'd want a Redis-backed limiter」。
+
+**token bucket 公式**：`tokens = min(capacity, old_tokens + (now - last_refill) * refill_rate)`。消耗後寫回。`cost > capacity` 直接拒絕（單請求大於 burst capacity 永不可能通過）。
+
+### 2.3 為什麼 `rate_limit_dependency` 簽名只有 `(request: Request)`，不能多帶 limiter 參數
+
+**踩過的坑**（Cycle 2 早期）：原本想寫
+```python
+def rate_limit_dependency(request: Request, cost: float = 1.0, limiter: TokenBucketRateLimiter | None = None): ...
+```
+結果 FastAPI 在 route 註冊時分析參數，看到 `TokenBucketRateLimiter | None` 不是它認得的型別 → 當成 Pydantic field 嘗試解析 → 拋 `FastAPIError: Invalid args for response field`。
+
+**修法**：
+1. 簽名縮到只留 `request: Request`（FastAPI 唯一會當 dependency-injection 對象的特殊型別）。
+2. 把 `cost` 跟 `limiter` 改成「全域狀態 + setter」：`set_active_limiter()` 換 limiter、`_active_limiter` 全域變數。測試用 `monkeypatch.setattr` 注入。
+3. 寫 docstring 警告「別再加非 FastAPI 標準型別的參數」。
+
+這條 L3 教訓值得進 `trial-and-error`：**FastAPI Depends 函式簽名白名單 = (Request, Response, WebSocket, BackgroundTasks, 其他 Depends)；其他參數會被當 body/query field**。

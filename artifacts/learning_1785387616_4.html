Overview

How this library was built and what it measures.

This page is generated by scraping 20 curated reference sites using BeautifulSoup for static HTML/CSS parsing and Playwright for JavaScript-rendered stylesheets. The pipeline collects every CSS value it can find, then extracts:

  • Typography — font families, weights, tracking, size buckets
  • Color — hex / rgb / hsl, with hue, saturation and brightness classification
  • Geometry — border-radius spectrum, box-shadow tokens, gradients, transforms
  • Motion — transition and animation durations
  • Layout — gap, padding, margin rhythm

All data is then aggregated into global frequency distributions — so the patterns you see are recurring choices across the modern web, not one site's quirk.

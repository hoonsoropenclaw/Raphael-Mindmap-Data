+# Playwright 跨瀏覽器 + 視覺回歸測試
+
+## 產物
+- `web_output.html`：零外部網路依賴的可測試 fixture。
+- `playwright.config.mjs`：依序執行 Chromium、Firefox、WebKit；涵蓋 DOM、互動、console/page error 與 screenshot baseline。
+- `baselines/`：各 browser 的基準 PNG。
+- `artifacts/`：最近一次實際截圖。
+
+## 執行
+```bash
+npm install
+npx playwright install chromium firefox webkit
+npm test
+```
+
+首次執行會自動建立 baseline。更新基準前必須是有意的 UI 變更：
+```bash
+npm run test:update
+npm test
+```
+
+## 設計決策
+- 同一 browser 比對使用 binary screenshot equality，避免把真正的版面變更藏在寬鬆 threshold 裡。
+- 不同 engine 的 rendering 差異不直接互相比對；各自維護 baseline，跨 engine 的差異透過健康與 layout assertions 監控。
+- Chromium 才傳 `--no-sandbox`；Firefox/WebKit 不傳，避免 WebKit 啟動參數不相容。
+- 等待 `document.fonts.ready`，並使用穩定的 fixture 文字，避免字型 warm-up 造成假陽性。
+- 不使用固定的無限等待；所有導覽有 timeout，瀏覽器在 `finally` 關閉。

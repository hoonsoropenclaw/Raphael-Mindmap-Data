+- surrogate pair bug：`\ud83d\udccd` 寫成兩個 lone surrogate → 用 emoji literal
+- `lang=zh` 只動 one-liner，不動 JSON data → 必須 client-side i18n dict
+- long-polling 必須 `offset = update_id + 1`（絕對值），非 `offset += 1`
+- graceful shutdown：退出前最後 getUpdates(offset+1) ack

+### 2.2 為什麼選 long-polling（不用 webhook）
+
+| 模式 | 需求 | 延遲 |
+|------|------|------|
+| **long-polling** ✅ | 只要對外 HTTPS 連線（出向） | 0-30s |
+| webhook | 對外 HTTPS endpoint + cert | <1s |
+
+**決定**：N100 headless 環境沒有 public domain、沒有 HTTPS cert。

+`timeout=30` 才是真正的 long-polling（最長 30s 才回應）**。
+
+**trade-off**：響應延遲 0-30s。對天氣查詢（user-perceived latency 1-3s 的 wttr.in 加上 polling 等待）
+實際感受 < 35s，可接受。

+### Architecture (Round 2 feedback fully internalized)
+
+**1. Centralized HTTP client (Round 2 explicit UA + 403 hard-fail)**
+- `USER_AGENT` constant set to a modern Chrome 124 string — no `urllib` default UA that gets blocked
+- `Accept-Language` and `Accept-Encoding: gzip` headers set explicitly
+- `urllib.error.HTTPError` is caught and re-raised as `TrendingFetchError` with a **hard failure** — no retry on 403. Real test against `httpbin.org/status/403` returns `OK_FETCH_ERROR` immediately, no hang.
+- gzip response decoded if present (urllib doesn't auto-decompress like requests)
+
+**2. Fail-closed HTML parsing (Round 2 hardening)**
+- Required fields are: `<article class='Box-row'>`, `<h2 class='h3'>` with `<a href>`, valid `/owner/repo` regex
+- Optional fields (description / language / stars / forks / stars-today) fall back to `—` rather than crashing — but the **row count itself is non-zero**, so an empty page is detected
+- Three concrete fail-closed tests pass:
+  - HTML with no `Box-row` → exit 4 + "parse failed: no `<article class='Box-row'>` found"
+  - Row with no `h2` → exit 4 + "row N: missing <h2 class='h3'>"
+  - Locked-down DOM cannot silently produce empty rows
+
+**3. Markdown table escaping (Round 2 explicit praise)**
+- `_md_cell()` escapes `|` → `\|` and `\` → `\\` via regex `([|\\])`
+- Newlines in descriptions collapsed to spaces (a single rogue `\n` would otherwise break the table row)
+- Whitespace collapsed to single spaces
+- Empty cells render as `—` (em dash) — readable, not invisible
+- Verified end-to-end: live page #6 `NanmiCoder/MediaCrawler` contains `|` in its Chinese description → renders as `\|` in the markdown → table row stays intact
+
+**4. Atomic file write (Round 2 / 3 priority)**
+- `atomic_write_text()` uses `tempfile.mkstemp` → write → `flush()` → `os.fsync()` → `os.replace()` → `chmod(0o644)`
+- Tmp file is in the same directory as the target so `os.replace` is atomic on the same filesystem (cross-filesystem `rename` is not atomic)
+- `try/except` wrapper guarantees the tmp file is removed on any failure — no `.tmp` debris
+- **Real failure test**: writing to a 0o555 (read-only) directory → script exits 5 with "write failed: [Errno 13] Permission denied", **0 tmp files leaked** in the parent
+- Cron crash / SIGKILL during write: the original `trending.md` is never partially overwritten, because `os.replace` is a single syscall
+
+**5. Four-layer separation (Round 4 internalization)**
+```
+fetcher          → fetch_trending_page() / parse_trending_html()   HTTP only
+parser           → parse_trending_html()                            BeautifulSoup only
+markdown_builder → build_markdown() / _md_cell()                   pure formatting, no I/O
+atomic_io        → atomic_write_text()                              pure I/O, no domain logic
+```
+- Each layer is independently testable. The CLI `run()` is a 30-line orchestrator that wires them together.
+- Domain dataclass `Repo` (frozen, slots) is the **only** object that crosses layer boundaries.
+
+**6. CLI ergonomics that don't bleed into the layers**
+- `--input <file>`: parse from a local HTML file (useful for replaying captured pages without re-hitting GitHub)
+- `--since {daily,weekly,monthly}`: maps to the `?since=` query param
+- `--language <name>`: appends to URL (`/trending/python?since=daily`)
+- `--limit N`: cap the parsed list
+- `--dry-run`: print to stdout, skip the atomic write
+- `--out <path>`: custom output file
+- `--timeout <sec>`: HTTP timeout, default 30

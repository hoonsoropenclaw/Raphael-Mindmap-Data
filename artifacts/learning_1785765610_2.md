+# AsyncCrawler
+
+基於 Python 3.12 `asyncio` + `aiohttp` 的高效、可測試網頁爬蟲。核心設計是「共用 HTTP session、受控並發、每 host 限流、指數退避重試、URL 去重、事件可觀測、單筆失敗不拖垮批次」。
+
+## 目錄
+
+- `crawler/crawler.py`：批次協調、並發與部分失敗結果
+- `crawler/transport.py`：共用 `aiohttp.ClientSession`、redirect、body 上限、HTTP 分類
+- `crawler/retry.py`：bounded exponential backoff + jitter + wall-clock budget
+- `crawler/rate_limiter.py`：每 host concurrency 與 requests/sec 控制
+- `crawler/dedup.py`：async lock 保護的 atomic URL 去重
+- `crawler/extractors.py`：stdlib HTML parser，輸出 title/text/normalized links
+- `crawler/events.py`：事件發布與 handler 錯誤隔離
+- `crawler/cli.py`：JSONL CLI
+- `tests/`：單元、並發、重試、extractor、真實 aiohttp server 整合測試
+
+## 執行
+
+環境已提供 `aiohttp`、`pytest`、`pytest-asyncio`：
+
+```bash
+cd /home/hoonsoropenclaw/.hermes/projects/learning_1785765610_2
+python3 run_crawler.py https://example.com --concurrency 8 --per-host 2 --rate 2
+python3 run_crawler.py https://example.com https://www.python.org -o results.jsonl
+```
+
+輸出為 JSONL；每筆結果包含 `url/status/items/error/attempts/elapsed/duplicate`。
+
+## Python API
+
+```python
+import asyncio
+from crawler import AsyncCrawler, CrawlConfig
+from crawler.extractors import extract_page
+
+async def main():
+    config = CrawlConfig(
+        concurrency=8,
+        per_host_concurrency=2,
+        requests_per_host=2.0,
+        max_attempts=4,
+        retry_base_delay=0.25,
+        retry_max_elapsed=45.0,
+    )
+    async with AsyncCrawler(config, extractor=extract_page) as crawler:
+        results = await crawler.run([
+            "https://example.com",
+            "https://example.com",  # second occurrence is marked duplicate
+        ])
+    for result in results:
+        print(result)
+
+asyncio.run(main())
+```
+
+## 重試語意
+
+- retry：連線/timeout、408、425、429、5xx 等 transient failure
+- no retry：一般 4xx、URL policy violation、body 超過上限、程式錯誤
+- `max_attempts` 與 `retry_max_elapsed` 同時構成上限
+- backoff 使用 exponential cap；預設加入 full jitter，降低 thundering herd
+- `asyncio.CancelledError` 會立即向上傳遞，不會被吞掉
+
+## 安全與維運邊界
+
+- 只允許 `http`/`https`，拒絕 URL credentials
+- redirect 每一跳都受最大跳數限制
+- response body 有明確 bytes 上限
+- per-host rate/concurrency 避免壓垮單一站點
+- 正式使用仍應尊重目標站 `robots.txt`、服務條款與 crawl-delay；本 demo 不繞過反爬或存取控制
+- `AiohttpTransport` 使用共用 session，結束時由 `AsyncCrawler` context manager 關閉

    重要架構決策：
    
    1. 不在每次請求中建立新的 ClientSession，改為 crawler lifecycle 共用 session，保留 TCP/DNS/TLS pooling。
    2. retry sleep 不持有 global semaphore，避免等待中的失敗請求阻塞其他 URL。
    3. 永久錯誤直接 fail-fast，不重試一般 4xx、URL policy violation、body size violation。
    4. asyncio.CancelledError 直接傳遞，不會被 retry wrapper 吞掉。
    5. 每 host 同時受到 rate limit 與 concurrency limit 控制。
    6. 每個 URL 回傳獨立 CrawlResult，批次採 partial failure 模式。
    7. HTML parser 使用 stdlib HTMLParser，靜態頁面不引入瀏覽器 runtime。
    8. 本輪沒有建立 web_output.html，因為本任務是 Python 爬蟲與 CLI，不是網頁前端。

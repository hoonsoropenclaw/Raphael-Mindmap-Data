+# sysmon — Linux 系統日誌 + 資源監控 + 閾值告警
+
+純 Python 的輕量監控腳本。
+適合 cron / systemd timer / k8s sidecar 場景，
+輸出穩定 JSON line `alerts.log`，可被 Loki / Vector / 任何 log pipeline 消費。
+
+## 功能
+- 監控 6 項資源 + 1 項日誌指標：CPU% / MEM% / DISK% / LOAD / proc count / journalctl err/min
+- OOM / segfault / kernel panic 自動升級為 crit（即使數量低）
+- 退出碼：0=ok / 1=warn / 2=crit — 給監控系統讀
+- YAML 或 JSON 設定檔，環境變數可覆寫個別閾值
+- `--watch` 守護模式 + `--test` 自測
+- webhook 可選（Slack / Discord / 自家 IM）
+
+## 安裝
+```bash
+# 無依賴 stdlib-only；想要 YAML 設定才需要 PyYAML
+pip install pyyaml
+chmod +x sysmon.py
+```
+
+## 用法
+```bash
+# 跑一次 + 印 JSON snapshot
+./sysmon.py check --json
+
+# 自訂設定
+./sysmon.py check --config examples/sysmon.yaml
+./sysmon.py check --config examples/sysmon.json
+
+# 守護模式（每 60 秒一次，可改）
+./sysmon.py watch --interval 30
+
+# 自測（強制觸發）
+./sysmon.py test --trigger cpu_percent
+
+# 環境變數覆寫單一閾值（K8s / systemd 友善）
+SYSMON_CPU_CRIT=85 ./sysmon.py check
+```
+
+## 整合 cron
+```
+*/5 * * * * /opt/sysmon/sysmon.py check --config /etc/sysmon.yaml || \
+  /usr/local/bin/notify-oncall "sysmon exit=$?"
+```
+退出碼不是 0 = 有告警 → 通知 oncall。
+
+## alerts.log 格式
+```json
+{"ts":"2026-07-28T12:34:56+00:00","host":"hoonsoropenclaw","worst":"crit","alerts":[{"name":"cpu_percent","value":97.5,...}]}
+```
+
+## 設計重點
+1. **純函數 collector** — 每個 metric 是 `fn(config) -> Reading`，可獨立測試
+2. **無 daemon 預設** — cron-friendly，`watch` 是 opt-in
+3. **無 root 也能跑** — journalctl 透過 `systemd --user` 也可（自行加 `-M user@`）
+4. **failure-soft** — 任一 collector 失敗會降級到 fallback（`/proc` / `df` / `free`）而不是整支 crash
+5. **no token / no secret** — 設 webhook URL 由 ops 自行處理認證（不放設定檔、改走 vault / k8s secret）

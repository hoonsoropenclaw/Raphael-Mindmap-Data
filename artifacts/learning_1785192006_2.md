+"""In-memory TTL cache for weather queries.
+
+Key design choices:
+- Single-process in-memory (no Redis). This bot is small; horizontal scaling
+  hasn't been requested. If it grows, swap to Redis with the same TTLContract.
+- One lock per cache, NOT per key. Reads are O(1) atomic under GIL for dict
+  ops; we only need a lock to avoid thundering herds on cold cache.
+- TTL is 'lazy' (checked on read) — no background sweeper. Stale entries
+  live one extra read at most, then get evicted. Simpler than a cron.
+
+Why not @lru_cache? TTL semantics, not LRU; we want per-key timestamp.
+"""
+
+from __future__ import annotations
+
+import asyncio
+import time
+from dataclasses import dataclass
+from typing import Generic, TypeVar
+
+T = TypeVar("T")
+
+
+@dataclass
+class _Entry(Generic[T]):
+    value: T
+    expires_at: float
+
+
+class TTLCache(Generic[T]):
+    def __init__(self, ttl_seconds: int) -> None:
+        self._ttl = ttl_seconds
+        self._store: dict[str, _Entry[T]] = {}
+        self._lock = asyncio.Lock()
+        self._hits = 0
+        self._misses = 0
+
+    async def get(self, key: str) -> T | None:
+        # Fast path: snapshot the dict without the lock — stale read is fine
+        # because every entry carries its own expiry and we'll re-validate.
+        entry = self._store.get(key)
+        if entry is None:
+            self._misses += 1
+            return None
+        if entry.expires_at < time.monotonic():
+            # Stale. Try to evict lazily — but don't block readers.
+            self._store.pop(key, None)
+            self._misses += 1
+            return None
+        self._hits += 1
+        return entry.value
+
+    async def set(self, key: str, value: T) -> None:
+        async with self._lock:
+            # Cap stored entries to avoid unbounded memory if attackers spam
+            # unique city names. Drop the oldest 25% when we hit 1024.
+            if len(self._store) >= 1024:
+                cutoff = len(self._store) - 768
+                oldest = sorted(self._store.items(), key=lambda kv: kv[1].expires_at)[:cutoff]
+                for k, _ in oldest:
+                    self._store.pop(k, None)
+            self._store[key] = _Entry(
+                value=value,
+                expires_at=time.monotonic() + self._ttl,
+            )
+
+    def stats(self) -> dict:
+        total = self._hits + self._misses
+        return {
+            "hits": self._hits,
+            "misses": self._misses,
+            "hit_rate": (self._hits / total) if total else 0.0,
+            "size": len(self._store),
+        }

+# Telegram Weather Bot

+powered by the free Open-Meteo API (no API key required).
+
+## Quick start
+
+```bash

+
+## Usage
+
+| Command | Description |

+| `/start` | Welcome message |
+| `/help` | Usage instructions |

+| Plain text | Implicit query — same as `/weather <text>` |
+

+
+```
+/weather Taipei        → 25.7°C, 94% humidity, cloudy
+/weather Tokyo         → warm & humid, light breeze
+Springfield, US        → disambiguates IL vs MO (asks you to clarify)
+```

+## Architecture
+
+```
+weather_bot/
+├── config.py       # env loading + fail-fast token check

+### 2.1 四層分離
+
+```
+┌─────────────────────────────────────┐
+│  bot.py (Telegram handlers)         │  ← 唯一知道 Telegram 的檔
+│  ─ /start /help /weather /cache     │
+│  ─ plain text → query 透明路由     │
+└──────────────┬──────────────────────┘
+               │ uses WeatherService
+┌──────────────▼──────────────────────┐
+│  service.py (業務邏輯)              │  ← 純 stdlib + 內部 cache
+│  ─ TTL cache (case-insensitive)     │
+│  ─ 429/5xx retry + backoff + jitter │
+│  ─ "找不到"歧義消解                  │
+└──────────────┬──────────────────────┘
+               │ uses WeatherProvider (Protocol)
+┌──────────────▼──────────────────────┐
+│  provider.py (外部 API)             │  ← 知道 Open-Meteo 的兩個 endpoint
+│  ─ geocoding /search?              │
+│  ─ forecast /forecast?              │
+└─────────────────────────────────────┘
+```
+
+**為什麼 Provider 是 Protocol 不是 abstract class**：
+- Protocol 允許 mock 測試不需要繼承（test 直接 inline `class FlakyProvider`）
+- 換 OpenWeather 只要新建 `OpenWeatherProvider`，service 完全不動
+- 對應 SOUL.md「精瘦」原則：不要在每一層都加抽象
+
+**為什麼 Service 內含 cache，而不是獨立 `WeatherCache` 類別**：
+- 一個業務對象才用得到一個 cache（geocoding cache + weather cache 是 service 內部倆）
+- 拆出去會讓 service 變成 forwarding layer、無業務邏輯
+- TTL 邏輯封裝在 `cache.py` 通用 `TTLCache[T]` 是對的（會 reuse 到未來其他功能）

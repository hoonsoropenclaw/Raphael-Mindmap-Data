CSS grid 動畫展開，無需 JS 高度計算。

Design Token 是設計系統中可被機器讀取的最小決策單元 — 顏色、字級、間距、陰影等設計變數。透過 token 抽象，視覺決策從程式碼分離出來，便於主題切換與跨平台共用。

L0 primitive 是原值（顏色 16 進制），L1 semantic 給原值一個角色（bg-canvas、fg-primary），L2 component 進一步對應到元件（btn-bg）。改 primitive 不影響元件、改 semantic 換主題、改 component 換元件風格。

只在 L2 加新的 component tokens，元件 CSS 引用即可。不要在元件內部寫死顏色或間距，否則失去 token 驅動的價值。

關於 Aurora DS

這是一個純 CSS + 原生 JS 實作的 Design Token 驅動元件庫。所有元件的視覺都透過 CSS Custom Properties 控制 — 你可以：

  • 切換右上角主題 (Aurora / Noir / Solar)
  • 修改 :root 的 primitive tokens 來調整品牌色
  • 新增 [data-theme="..."] 區塊即可擴充主題

+## 3. 模組拆解

+| 模組 | 職責 | 驗收 |

+### B. 執行模擬
+- Given 初始狀態
+- When 點擊 `data-testid=run-suite`
+- Then 狀態依序進入 `RUNNING` 再到 `PASSED`
+- And Chromium / Firefox / WebKit 卡片皆為 `PASSED`
+- And passed-count 為 `3 / 3`

+
+### C. 主題切換
+- Given 預設 dark 主題
+- When 點擊 `data-testid=theme-toggle`
+- Then `<html data-theme>` 改為 `light`
+- And 按鈕 `aria-pressed=true`

+
+### D. 鍵盤
+- Given 頁面載入
+- When 連續按 Tab
+- Then theme toggle 與 run button 依 DOM 順序取得 focus
+- When run button 按 Enter
+- Then 執行流程完成
+
+### E. 響應式
+- Given viewport 390×844
+- Then `documentElement.scrollWidth <= innerWidth`
+- And browser matrix 三卡改成單欄，但資訊不消失
+
+### F. Console / runtime
+- Given 任一瀏覽器 project 載入與操作頁面
+- Then 0 個 `pageerror`
+- And 0 個 console error
+- And 主要 response HTTP 200

+- Desktop: 1280×800 全頁 snapshot
+- Mobile: 390×844 全頁 snapshot
+- 每個瀏覽器 project 使用自己的 snapshot suffix

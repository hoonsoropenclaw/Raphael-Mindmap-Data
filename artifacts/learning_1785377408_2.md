+3. OCR (tesseract via pytesseract) — 掃描影像 fallback
+
+每頁獨立決策,不預先假設類型。
+"""

+import io

+from dataclasses import dataclass, field, asdict
+from pathlib import Path
+from typing import Optional

+@dataclass
+class FieldValue:
+    """單一表單欄位的值 + 信心度 + 來源"""
+    name: str
+    value: str
+    confidence: float          # 0.0~1.0,1.0 = 直接從 PDF 結構拿的、< 1.0 = OCR 來的
+    source: str                # "text_layer" | "form_field" | "ocr" | "fallback"
+    page: int = 0
+
+
+@dataclass
+class PageResult:
+    """單頁提取結果"""
+    page_num: int              # 1-indexed
+    method: str                # "text_layer" | "form_field" | "ocr" | "empty"
+    fields: list[FieldValue] = field(default_factory=list)
+    raw_text: str = ""         # 該頁全部文字(用於人類審閱)
+
+
+@dataclass
+class ExtractionResult:
+    """整份 PDF 的提取結果"""
+    source_path: str
+    total_pages: int
+    pages: list[PageResult] = field(default_factory=list)
+    fields: list[FieldValue] = field(default_factory=list)  # 扁平化所有頁的欄位

+                    "fields": [asdict(f) for f in p.fields],

+# PDF Form OCR Extractor
+
+從 PDF 抽取結構化表單數據 — 三層策略(文字層 → AcroForm → OCR fallback)、CLI + Tkinter GUI 兩種介面、純 stdlib + 三個已預裝的 lib(`pymupdf`、`pytesseract`、`Pillow`)。
+
+## 為什麼這個工具
+
+PDF 表單有 3 種「內部真相來源」,常見工具只支援 1~2 種:
+
+| 類型 | 範例 | 對應 layer | 速度 | 信心度 |
+|------|------|-----------|------|--------|
+| 純文字 PDF | 從 Word/Google Docs 匯出的 PDF | Layer 1: text_layer | 毫秒 | 1.0 |
+| AcroForm 可填欄位 | 政府/醫院的官方 PDF 表單 | Layer 2: form_field | 毫秒 | 1.0 |
+| 掃描影像 | 掃描器、相機拍的 PDF | Layer 3: OCR(tesseract) | 1~10s/頁 | 0.5~1.0 |
+
+**這個工具會自動偵測每頁用哪個 layer** — 同一份 PDF 可以「頁 1 走 Layer 1、頁 2 走 Layer 3」混用。
+
+## 安裝
+
+系統需求:
+
+- Linux: `apt install tesseract-ocr` (英文)、`apt install tesseract-ocr-chi-tra` (繁中)
+- macOS: `brew install tesseract tesseract-lang`
+- Python: 3.10+
+
+Python 依賴(都已預裝在 Hermes N100 主機):
+
+- `pymupdf` (1.26.7 已驗)
+- `pytesseract` (0.3.13 已驗)
+- `Pillow` (跟著 tesseract 一起裝)

+### 2. Babel Standalone 手動 transform（繞過已知 bug）
+**踩坑**：Babel 7.24.x 的 `<script type="text/babel" data-type="module">` 路徑壞了：
+- import 會被轉成 CommonJS `require()`
+- 7.24.x 對 ESM 解析有 race condition
+- 即使能用，import map 也不會作用在這種合成 script
+
+**解法**：手動呼叫 `Babel.transform()`，再用 Blob URL 注入為真實 ES module：
+
+```javascript
+<script type="module">
+  const src = document.getElementById('app-source').textContent;
+  const out = Babel.transform(src, {
+    presets: ['react'],
+    sourceType: 'module',
+    filename: 'app.jsx'
+  }).code;
+  const blob = new Blob([out], { type: 'text/javascript' });
+  const url = URL.createObjectURL(blob);
+  const s = document.createElement('script');
+  s.type = 'module';
+  s.src = url;
+  document.head.appendChild(s);
+</script>
+```
+
+關鍵點：
+- `sourceType: 'module'` 告訴 Babel 保留 import/export
+- Blob URL 讓瀏覽器把它當獨立模組載入，import map 正常生效
+- `filename: 'app.jsx'` 讓 Babel 認知 JSX 副檔名

+# Flowline 工作流控制台 — 實作思路
+
+## 1. 目標
+
+建立一個可直接執行的 React UI 元件，用單一畫面展示複雜狀態管理、清單操作、錯誤防護與響應式 CSS。
+
+## 2. 架構
+
+- `src/WorkflowControlCenter.jsx`：UI 結構、資料模型、reducer、衍生狀態與互動。
+- `src/styles.css`：完整視覺系統、桌面/平板/手機斷點、動效與 reduced-motion。
+- `src/main.jsx`：React 掛載入口。
+- `index.html`：Vite HTML shell。
+
+## 3. 狀態管理
+
+採 `useReducer` 而不是分散的多個 `useState`：
+
+- 工作流集合：狀態、進度、優先程度、執行次數。
+- 搜尋字串、狀態篩選、排序方式。
+- 當前選取項目。
+- loading、error、toast 等系統狀態。
+- `TOGGLE`、`RETRY`、`RUN_ALL` 等事件集中處理，避免 UI 與資料規則互相污染。
+
+衍生清單以 `useMemo` 執行搜尋、篩選與排序，不另外保存重複 state。
+
+## 4. 互動規則
+
+- 執行中工作流可暫停；暫停或排隊中的工作流可啟動。
+- 失敗工作流不可直接啟動，必須經重試事件重新排隊。
+- 「全部執行」會啟動所有非失敗工作流，不掩蓋錯誤項目。
+- 搜尋結果為零時顯示 empty state，並可一鍵清除篩選。
+- 初次載入顯示 skeleton；動態狀態使用 `aria-live`。
+
+## 5. 視覺策略
+
+- 暖灰底色、墨色文字、單一陶土橘 accent，避免常見 AI 紫藍漸層。
+- 使用側欄、數據帶、清單與黏性詳情面板建立高資訊密度。
+- 動效只使用 `transform`、`opacity` 等 GPU 友善屬性。
+- 支援 `prefers-reduced-motion`，鍵盤 focus 使用可見 outline。
+- 980px 與 680px 兩層響應式佈局。
+
+## 6. 驗證紀錄
+
+- `npm install`：成功，0 vulnerabilities。

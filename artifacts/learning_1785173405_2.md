+# GitHub Trending Scraper — 交付報告
+
+## 成品
+- **主程式**: `github_trending.py` (可執行 + 可匯入)
+- **範例輸出**: `trending_weekly.md` (5 個 weekly trending repos)
+
+## 實作思路
+
+### 1. 抓取策略
+- 目標 URL: `https://github.com/trending[/{language}]?since={daily|weekly|monthly}`
+- GitHub Trending 沒有公開 API,直接走 HTML scrape
+- HTTP header 模擬 Chrome,避免被當 bot 擋
+- 網路錯誤 / 非 200 / 0 results 三種情況都會 raise 帶訊息的 error,讓 CLI 回 exit code 1
+
+### 2. HTML 解析
+- 用 `BeautifulSoup` 抓 `article.Box-row` (trending 頁每個 repo 一個 article)
+- 欄位對應:
+  - `h2 a[href]` → `owner/name` 拆出 owner / name / full_name / url
+  - `p` → description
+  - `span[itemprop='programmingLanguage']` → 主語言
+  - 前 2 個 `a.Link.Link--muted` → 總 stars / 總 forks
+  - `span.d-inline-block.float-sm-right` → 「X stars today/this week/this month」Δ
+
+### 3. 數字解析
+- `_parse_count` 處理 `1,234` 與 `31.4k` / `1.2m` 兩種格式
+- 不用 `int()` 直接轉,因為大型 repo 會用 k/m 縮寫
+
+### 4. 輸出格式
+- **Markdown 表格** (預設): 欄位 `# | Repository | Description | Language | Stars | Forks | Δ Stars`
+  - description 內的 `|` 自動 `\|` escape,確保表格不破
+  - Stars/Forks 數字用千分位 + emoji 標記,視覺好讀
+- **JSON** (`--json`): 完整 dataclass 序列化,方便串程式管線
+
+### 5. 設計決策
+| 面向 | 選擇 | 為什麼 |
+|------|------|--------|
+| Type | dataclass + TypedDict-ish | 欄位語意清楚、易除錯、易序列化 |
+| CLI | argparse + sub-style flags | 比手刻 sys.argv 維護成本低,`--help` 內建 |
+| Import | 同檔放 `fetch_trending()` / `render_markdown()` | 下游腳本可 `from github_trending import ...` 直接用 |
+| 錯誤處理 | 對外 raise ValueError/RuntimeError,CLI 收 exit 1 | library 用法乾淨、CLI 用法有正確 exit code |
+| 定時排程 | 沒裝 cron 到系統層 | 使用者沒要求,且讓 script 自己定 `--output` 就好串 cron |
+
+## 驗證證據
+
+跑了 5 種情境,全部 exit code 0:
+
+1. `python3 github_trending.py --limit 5` → Markdown 表格 5 筆 (daily)
+2. `python3 github_trending.py --language python --since weekly --limit 3` → 3 筆 Python weekly
+3. `python3 github_trending.py --language python --since weekly --limit 2 --json` → 合規 JSON
+4. `python3 github_trending.py --since yearly` → argparse 拒絕,顯示 usage
+5. `python3 github_trending.py --since weekly --limit 5 --output trending_weekly.md` → 寫檔成功,stderr 顯示「Wrote 5 repos」
+

+python3 github_trending.py --limit 10 -o top10.md           # 寫到檔

+export function themeReducer(state, action) {
+  switch (action.type) {

+- **避免 prop drilling**：`AppContext` 提供 dispatch，主題、toast 函式，子元件按需訂閱
+- **細粒度 hook**：`useTasks`、`useTheme`、`useToast` 只訂閱需要的 slice，避免全樹 re-render

+## 2. 狀態管理設計

+### 2.1 為什麼選 `useReducer` + `Context`，不用 Redux / Zustand？

+- 不希望引入外部依賴（Vite + React 就夠）

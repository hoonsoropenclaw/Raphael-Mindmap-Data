+# Cross-Browser Visual Regression
+
+Playwright-driven cross-browser automation + pixel-level visual regression
+suit. Self-contained — no external service, all artifacts in this folder.
+
+## Quick start
+
+```bash
+./run_demo.sh
+# 1) build baseline
+# 2) run test (chromium + firefox + webkit)
+# 3) generate self-contained HTML report → web_output.html
+```
+
+Open `web_output.html` in any browser to see the embedded screenshots,
+Δpx ratios, RMSE, and per-pixel diff heatmaps (base64 data: URIs, no
+external links).
+
+## Files
+
+| Path                              | Purpose                                                |
+|-----------------------------------|--------------------------------------------------------|
+| `tests/cross_browser_visual.py`   | Main pipeline: 3 engines + functional checks + diff    |
+| `tests/build_report.py`           | Aggregates runs into the self-contained HTML report    |
+| `test_targets/sample_app/`        | Deterministic sample app used as the regression target |
+| `run_demo.sh`                     | One-shot: baseline → test → report                     |
+| `demo_regression.sh`              | Demo: shows 2 distinct regression failure modes       |
+| `web_output.html`                 | The deliverable — open it to see results               |
+| `baseline/`                       | Reference PNGs (one per browser)                       |
+| `artifacts/<run_id>/`             | Per-run screenshots, diff heatmaps, `report.json`     |
+
+## Modes
+
+```bash
+python3 tests/cross_browser_visual.py --mode baseline   # first time / UI redesign
+python3 tests/cross_browser_visual.py --mode test       # compare to baseline
+```
+
+## Engines tested
+
+- **chromium** (Playwright bundled, headless)
+- **firefox**  (Playwright bundled, headless)
+- **webkit**   (Playwright bundled, headless)
+
+All three run with the same `1280x800` viewport, `device_scale_factor=1`,
+`color_scheme=light`, `reduced_motion=reduce` for stable diffs.
+
+## Functional checks (run per browser)
+
+- `#cta-btn` visible & enabled
+- nav active link is "Home"
+- 4 feature cards rendered
+- hero h1 text matches expectation
+
+## Visual diff metrics
+
+For each browser: Δpx ratio, RMSE, max channel diff. A run **passes** when
+Δpx ratio ≤ 0.1% (or for size_mismatch, immediately fails).
+
+## Three bugs caught during the demo (worth remembering)
+
+1. **HTTP cache poisoning** — Chromium re-uses cached CSS across runs even
+   with `no-store` headers. Fix: cache-busting query string + `page.reload()`.
+2. **`:hover` masks regressions** — `page.locator(...).click()` moves the
+   physical mouse to the button, so the screenshot is taken with the
+   `:hover` color rendered. Fix: dispatch click via JS instead of physical
+   click.
+3. **Port collision** — when multiple test projects share `127.0.0.1:8765`
+   you get `OSError: Address already in use`. Fix: `HTTPServer((host, 0), ...)`
+   and read back `server_address[1]`.

+## Design choices (why these not something else)
+
+* **`data-testid` over CSS selectors** — the playwright_testing_and_scraping
+  micro-skill explicitly warns against volatile CSS classes; `data-testid` is
+  stable across style refactors.
+* **`document.fonts.ready` + animation-disabling stylesheet** — both the
+  visual regression micro-skill and the playwright one call these out as the
+  two biggest sources of false-positive diffs across browsers.
+* **Two scenarios share one baseline** — `web_output.html` populates the
+  baseline directory on first run; `baseline_broken.html` is compared against
+  the same baseline, so we can prove the diff pipeline actually fires when a
+  real visual change exists.

+# GitHub Trending Markdown
+
+抓取 GitHub Trending 頁面，使用 Python 標準函式庫解析 repository cards，輸出 Markdown 表格。
+
+## 使用方式
+
+```bash
+python3 github_trending.py
+python3 github_trending.py --language python --since weekly -o trending.md
+```
+
+輸出欄位：repository、description、language、stars today、total stars、forks。
+
+## 設計思路
+
+1. 使用 `urllib.request` 發送帶 User-Agent 的 HTTP GET，避免第三方依賴。
+2. 使用 `html.parser.HTMLParser` 解析每個 `article.Box-row`，不依賴脆弱的正則表達式抓整頁 HTML。
+3. 對 Markdown cell 的 `|` 和換行做 escape，避免描述破壞表格。
+4. 以 `--language`、`--since` 和 `--output` 提供可重用的 CLI 介面。
+5. 沒有解析到 repository cards 時直接失敗並回報原因，避免產生看似成功的空檔案。
+
+## 驗證
+
+```bash
+python3 -m py_compile github_trending.py
+python3 github_trending.py --since daily -o /tmp/github-trending-check.md
+sed -n '1,12p' /tmp/github-trending-check.md
+```
+

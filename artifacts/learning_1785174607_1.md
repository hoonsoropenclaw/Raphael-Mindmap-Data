+# GitHub Trending → Markdown
+
+`github_trending.py` retrieves GitHub's Trending page and renders repository cards as a Markdown table.
+
+## Requirements
+
+- Python 3.10+
+- Python standard library only
+- Network access to `github.com`
+
+## Usage
+
+Print today's trending repositories:
+
+```bash
+python3 github_trending.py
+```
+
+Write a file atomically:
+
+```bash
+python3 github_trending.py --since weekly --limit 25 --output trending.md
+```
+
+Filter by language:
+
+```bash
+python3 github_trending.py --language Python --since daily --output python-trending.md
+```
+
+The script retries transient HTTP failures (429/5xx), validates that repository cards were parsed, and never silently treats a bot-check or changed page layout as valid data.
+
+## Design
+
+- `urllib.request`: no third-party dependency or package installation.
+- `html.parser.HTMLParser`: parses semantic HTML attributes rather than brittle CSS positions.
+- Void HTML elements such as `img` and `br` do not corrupt card nesting; `<br>` becomes a word separator.
+- `tempfile.mkstemp` + `os.replace`: atomic, fsynced output. Unique sibling temporary names prevent overlapping cron runs from colliding.
+- Webhook credentials are not relevant to this read-only tool, so no secret-bearing CLI or config parameters are introduced.
+
+## Verification
+
+```bash
+python3 -m py_compile github_trending.py test_github_trending.py
+python3 -m unittest -v test_github_trending.py
+python3 github_trending.py --limit 5 --output /tmp/github-trending-smoke.md
+head -8 /tmp/github-trending-smoke.md
+```
+
+GitHub may rate-limit or serve a bot-check page. In that case the command exits non-zero with an explicit error; it does not generate fabricated or stale rows.

+## Implementation approach
+
+1. `fetch_html()` requests `https://github.com/trending` with `since` and optional language query parameters. It uses a descriptive User-Agent, a bounded timeout, and exponential backoff only for transient HTTP/network failures.
+2. `TrendingParser` uses Python `HTMLParser` and semantic markers (`article.Box-row`, `itemprop="programmingLanguage"`, repository links) to extract repository name, URL, description, language, stars, forks, and stars-today.
+3. HTML void elements (`img`, `br`, `meta`, etc.) are handled explicitly so depth-based card boundaries remain correct. A `<br>` contributes whitespace to captured text.
+4. `parse_trending_html()` fails loudly if zero cards are found. This distinguishes a layout change/bot-check from a legitimate empty result.
+5. `render_markdown()` escapes table delimiters and produces a stable Markdown table.
+6. `write_atomic()` writes to a unique same-directory temp file, flushes/fsyncs, then calls `os.replace()`. Exceptions clean up the temp file.
+7. `main()` validates the row limit, fetches, parses, truncates, and either prints to stdout or writes the requested output file.

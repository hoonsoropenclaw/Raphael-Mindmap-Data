+# PRD：基於機器學習的智慧日誌分析系統
+
+## 目標
+建立一個完全在瀏覽器執行、無需編譯、可直接開啟的單檔日誌分析工作台。使用者可貼上或載入日誌，讓系統抽取結構化特徵、訓練無監督異常模型、檢視異常排名與模式分群，並匯出 JSON 報告。
+
+## 使用者旅程
+1. 使用者載入內建樣本或貼上 raw logs。
+2. 系統辨識時間、嚴重度、服務、HTTP 狀態、延遲、IP、訊息內容。
+3. 使用者按「分析」，系統以 robust scaling + Isolation Forest 類型的隨機切割森林完成無監督學習。
+4. 系統呈現風險摘要、時間分布、嚴重度、異常排行、模式群組與可解釋原因。
+5. 使用者可用搜尋、嚴重度與「只看異常」篩選，展開單筆證據，匯出分析 JSON。
+
+## Must
+- 單一 `index.html`，原生 HTML/CSS/JS，不需 build。
+- 能在 `file://` 直接操作核心分析；不依賴外部 CDN。
+- 支援多種常見 log 格式與無法解析行的安全降級。
+- 真正的資料驅動異常評分，不是固定假資料。
+- 至少包含：嚴重度、延遲、HTTP 狀態、爆量、稀有服務/樣板等特徵。
+- 每個異常提供可讀原因與分數。
+- 支援檔案匯入、搜尋、篩選、重新訓練、匯出 JSON。
+- Responsive、鍵盤可操作、具 reduced-motion 支援。
+- 有自動測試與瀏覽器實測證據。
+
+## Non-goals
+- 不提供伺服器端持久化、即時 Kafka ingestion、登入或多租戶。
+- 不宣稱本地無監督分數可取代 SIEM/SOC 人工判斷。
+- 不把來源 IP 或使用者識別資訊傳送到網路。
+
+## 驗收條件
+- 樣本資料可解析至少 25 行。
+- 至少能標記數筆由 5xx、極高延遲、panic/OOM/認證爆量造成的異常。
+- 更改 contamination 後重新訓練，異常數量同步變更。
+- 搜尋與篩選能改變表格結果。
+- 匯出報告可產生有效 JSON。
+- JS 語法檢查、核心單元測試與瀏覽器 console 檢查皆通過。

+# 規格：智慧日誌分析系統
+
+## 架構
+- `index.html`：完整 UI、樣式、資料處理、ML、視覺化與匯出。
+- `tests/core.test.cjs`：從 HTML 擷取純函式區塊，驗證 parser、template normalization、feature engineering、forest scoring。
+- `sample.log`：可匯入的實際樣本。
+- `architect_review.md`：實作與除錯報告。
+
+## 資料流程
+Raw lines → parser → structured records → message templates → frequency/burst context → numeric feature vectors → robust median/IQR scaling → random cut forest ensemble → normalized anomaly score → contamination quantile threshold → explanation engine → dashboard.
+
+## 特徵
+1. severity：DEBUG=0、INFO=1、WARN=2、ERROR=3、FATAL=4。
+2. latency：`log1p(ms)`。
+3. HTTP status：狀態碼距離與 4xx/5xx indicator。
+4. message length：`log1p(chars)`。
+5. digit ratio：訊息中數字比例。
+6. template rarity：正規化訊息樣板的逆頻率。
+7. service rarity：服務名稱逆頻率。
+8. local burst：60 秒窗口內同服務事件數。
+9. keyword risk：panic/OOM/timeout/denied 等字詞。
+10. time gap：與前一筆事件間隔。
+
+## ML 方法
+使用 isolation-style random cut forest：每棵樹遞迴隨機挑選有變異的特徵與切點，直到 singleton 或高度上限。平均 path length 經 Isolation Forest 公式轉為 0–1 異常分數。固定種子 PRNG 讓測試可重現。小資料集以至少 32 棵樹，UI 預設 96 棵。
+
+## 安全與韌性
+- 所有 raw log 用 `textContent` render，避免 XSS。
+- 檔案大小限制 5 MB，行數上限 20,000。
+- 無法解析的資料保留並標記，不因單行壞資料中止批次。
+- 分母、IQR、時間戳皆有 finite/zero guard。
+- 不做任何網路請求。
+
+## 自動驗證
+- `node tests/core.test.cjs`
+- 抽取 inline JS 後 `node --check`
+- 本機 HTTP server + browser 實測分析、篩選、展開與匯出。

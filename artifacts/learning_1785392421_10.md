+# fsw — file system watcher with real-time event delivery
+
+`fsw` watches a directory tree, dispatches events to user-defined
+rules, persists them to SQLite, and (optionally) serves a live web
+dashboard. Everything is **pure Python standard library** — no
+third-party packages required.
+
+```
++---------+      +-------------+      +---------------+      +-----------+
+| inotify | ---> | queue.Queue | ---> | dispatch loop | ---> | rule match|
++---------+      +-------------+      +---------------+      +-----+-----+
+   (libc                                                          |
+    ctypes)                                                       v
+                                                          +---------------+
+                                                          | action runner |
+                                                          +-------+-------+
+                                                                  |
+                                                                  v
+                                                          +---------------+
+                                                          | event store   |
+                                                          | (SQLite WAL) |
+                                                          +-------+-------+
+                                                                  |
+                                                                  v
+                                                          +---------------+
+                                                          | web dashboard |
+                                                          |  (SSE + JSON) |
+                                                          +---------------+
+```
+
+## Quick start
+
+```bash
+# Demo (self-test, no configuration):
+python3 -m fsw demo /tmp/fsw-demo
+
+# Watch a real directory with a rules file and a live dashboard:
+python3 -m fsw watch /srv/inbox \
+    --rules rules.example.json \
+    --db /var/lib/fsw/inbox.db \
+    --port 8765
+
+# Browse http://127.0.0.1:8765/ for the live event stream.
+# Replay historical events from a database:
+python3 -m fsw replay --db /var/lib/fsw/inbox.db --limit 50
+```

+## Architecture (one paragraph each)

+action_spec)`. First match wins. Actions come in three flavors:
+`command` (argv + JSON envelope on stdin, no shell), `webhook`

+callable for tests and the dashboard beep).

+**Store** — `EventStore` writes every event to a SQLite database in
+WAL mode. The dispatch thread is the writer; the dashboard is the
+reader. Reads never block writes. Bounded history (`max_rows`,
+default 50,000) prevents unbounded growth.

+interface on a stdlib `ThreadingHTTPServer`. SSE polls the store and
+streams new events; `/api/events` returns a JSON snapshot for the

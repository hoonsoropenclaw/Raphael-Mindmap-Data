+# Telegram 天氣 Bot
+
+用 `python-telegram-bot` v21 (async) + **Open-Meteo**（免 API key）做的極簡天氣查詢機器人。
+
+---
+
+## 為什麼選 Open-Meteo 不用 OWM / wttr.in
+
+| API | 需要 API key | 需要註冊 | CORS | 中文地點 |
+|---|---|---|---|---|
+| **Open-Meteo** | ❌ | ❌ | ✅ | ✅（geocoding API 內建多語） |
+| OpenWeatherMap | ✅ | ✅ | ❌ | ✅ |
+| wttr.in | ❌ | ❌ | ⚠ 部分 | ❌（要帶 `format=j1` 才穩） |
+
+Open-Meteo 同時提供 `geocoding-api`（地名 → 經緯度）跟 `forecast`（經緯度 → 天氣），一套打完全程，零設定，適合 demo / 個人 bot。
+
+---
+
+## 安裝
+
+```bash
+python3 -m venv .venv
+source .venv/bin/activate
+pip install -r requirements.txt
+```
+
+## 設定
+
+從 BotFather 拿 token 後，用**任一**方式提供：
+
+```bash
+# 方式 1：環境變數（推薦）
+export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
+
+# 方式 2：.env 檔（自動讀取，python-dotenv 已內建於 python-telegram-bot）
+echo 'TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."' > .env
+```
+
+## 啟動
+
+```bash
+python weather_bot.py
+```
+
+跑起來會印：
+
+```
+⚕ weather_bot 啟動中… 按 Ctrl+C 停止
+```
+
+---
+
+## 用法
+
+Bot 支援兩種觸發方式：
+
+| 輸入 | 回應 |
+|---|---|
+| `/weather 台北` | 完整天氣卡片 |
+| `/weather Tokyo` | 完整天氣卡片 |
+| `天氣 高雄` | 同上（純文字觸發） |
+| `天氣 京都` | 同上 |
+| `/start` | 歡迎訊息 + 用法 |
+| `/help` | 詳細說明 |

+## 2. 設計選擇與取捨
+
+### 為什麼用 Open-Meteo 不用 OpenWeatherMap
+- **零 API key、零註冊**：適合 demo / 個人 bot / 學習用途
+- 同一個 provider 給 geocoding（地名 → lat/lon）+ forecast（lat/lon → 天氣），一條鏈路打完全程
+- 免費額度 10000 req/day + 600 req/min，個人用戶不會碰到上限
+- OWM 要註冊、要 key、免費額度還限 60 req/min；wttr.in 沒 key 但中文地點支援不穩
+
+### 為什麼用 python-telegram-bot v21 不用 polling 自幹
+- v21 是新版 async API，`ApplicationBuilder` + handler 註冊模式乾淨
+- 官方支援 `run_polling` / `run_webhook` 兩種 deploy 模式
+- 自幹 polling 要處理 offset、retry、backoff——不必要
+
+### 為什麼 geocoding 加 `language` 偵測
+**踩坑紀錄**：第一次寫 `language=zh` 永遠 → 「New York」會被解析成內布拉斯加的 York, NE（人口 7864），因為 NYC 在中文模式下 API 沒回 population（回 0）。改成「純 ASCII 輸入 → language=en、含中文 → language=zh」才正確。
+
+### 為什麼額外加 `count=5` + population ranking
+即使 language 對了，Open-Meteo 有時候同一個地名會回 5 個相似的結果。按人口降冪可以穩定命中大城市。

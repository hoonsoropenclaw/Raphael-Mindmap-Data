+## 3. 🔧 技術選型理由
+
+### 為什麼把 `weather.py` 跟 `bot.py` 分開?
+
+- **測試不需要 mock Telegram**:weather.py 完全沒 import `telegram.*`,所以 `test_weather.py` 全跑純函式(mock 只有 `urllib.urlopen` 一個點)。

+### 為什麼用 `urllib.request` 而不裝 `requests`?
+
+- **少一個依賴**:`requests` 是 Python 生態最常用的 HTTP client,但 Open-Meteo 只要 GET JSON,`urllib` 完全夠用。
+- **少一個 supply chain 攻擊面**:相依套件少 = 漏洞少。
+- **測試更容易**:`urllib.urlopen` 一行 patch 就 mock 掉,`requests` 還要處理 `Session` / `adapter` / 連線池。

+### 為什麼 WMO code 對照表寫死 21 條 + fallback?

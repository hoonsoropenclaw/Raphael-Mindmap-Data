事件記錄

架構說明：本前端使用 MediaRecorder 將麥克風以 Opus/WebM 編碼切成 2-8 秒的小段，週期性上傳到 Next.js /api/transcribe route。 後端使用官方 openai SDK 呼叫 whisper-1 模型，採用 httpx + tenacity 指數退避重試。 每段返回的文字以時間戳 + 串接方式即時顯示在前端。

Next.js 端實作：參考 /api/transcribe/route.ts — 接收 multipart/form-data，呼叫 OpenAI SDK，API Key 由 process.env.OPENAI_API_KEY 提供。 完整程式碼在程式碼區塊的「▼ Next.js 後端程式碼」摺疊區。

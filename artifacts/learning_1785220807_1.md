+"""
+sysmon — Linux 系統日誌與資源監控腳本
+====================================
+
+功能：
+  1. 定期輪詢 CPU / 記憶體 / 磁碟 / load average / swap 使用率
+  2. 增量讀取指定日誌檔，計算每個 pattern 命中次數
+  3. 任一指標超過閾值 → 透過 sinks（stdout + log file）發出告警
+  4. 每個告警有 cooldown，避免同一事件風暴式觸發

+  - 純 stdlib + psutil，零外部依賴

+  python3 src/sysmon.py --config config/thresholds.yaml --once     # 跑一次就退出

+
+### 4.1 資源採樣（`sample_resources`）
+- 一次 `psutil.cpu_percent(interval=1.0)` 拿 CPU 1 秒平均

+### 4.2 閾值比對（`check_resource_thresholds`）
+- **嚴格 `>` 比較**（不是 `≥`）→ 邊界值不觸發、有 unit test 守住
+- 越界指標全部列出（不是 fail-fast 第一個就退出）
+
+### 4.3 日誌增量讀取（`LogReader`）
+- offset 紀錄「讀到第幾 byte」（不是行號，rotate 比較穩）
+- 檔案被 truncate（變小）→ 自動重置 offset 從頭讀

+
+### 4.5 Graceful shutdown
+- 接 `SIGINT` / `SIGTERM` → 下一輪結束時落盤 offset 才退出
+- 不會因為 Ctrl-C 漏寫 offset

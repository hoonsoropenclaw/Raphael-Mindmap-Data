+- N100 環境 / 受限環境 / 沒有 pip 的沙盒都能跑
+- HTML 結構簡單（`article.Box-row`），用 `HTMLParser` 寫一個專用 parser 比 BeautifulSoup 更精準、更少誤判
+
+### 為什麼主路徑是 HTML scrape
+- **GitHub 沒有公開的 Trending API** — 這是真的限制
+- `/trending` HTML 結構穩定（`article.Box-row` 模式多年沒變）
+- HTML 包含「今日/本週/本月 stars」這是 API 沒有的（API 只能給總星數 + 建立時間 proxy）
+
+### API 備援（fallback）為什麼有意義
+- HTML 結構偶爾改版（GitHub 改版頻率不低） → parser 失效時仍可工作
+- 在受限網路（擋 github.com 但放 api.github.com）仍能跑
+- 用 `created:>cutoff` + `sort=stars` 當 proxy：雖然不是真正的「trending」，但視覺上夠用
+
+### 三條路徑驗證（4 個 smoke test）
+1. **HTML parse**：用真實 github.com/trending 結構的簡化樣本，驗證 parser 抓得到 full_name / url / description / language / stars_total / stars_period / forks
+2. **API fallback**：monkeypatch `urlopen`，驗證 JSON 解析路徑
+3. **main() 整合**：驗證 `--format markdown/json/stdout` 與 `-o 寫檔` 都正常
+4. **Markdown escape**：description 內含 `|` 與 `\n` 時必須正確 escape

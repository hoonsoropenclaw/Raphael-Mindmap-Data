+# AsyncCrawler
+
+一個以 `asyncio` 為核心的高效網頁爬蟲框架，提供：
+
+- 有界並發：worker pool + `asyncio.Queue`，不會為每個 URL 無限制建立 task。
+- 連線傳輸：預設使用 stdlib `urllib` 並透過 `asyncio.to_thread` 非阻塞執行；可注入 `AiohttpTransport` 使用 connection pool。
+- 智能重試：只重試明確的暫時性 HTTP 狀態（408/425/429/5xx）與網路錯誤；指數退避、full jitter、`Retry-After` 支援。
+- 每 host 限速：避免並發爬蟲瞬間壓垮單一站點。
+- 去重與統計：URL 去重、狀態碼、重試次數、bytes、成功/失敗計數。
+- 安全邊界：只接受 HTTP(S)，限制 response body 大小，不自動繞過 CAPTCHA、登入或反爬機制。
+- 解析：stdlib `HTMLParser` 解析 title/text/links；JSON 及純文字也有合理 fallback。
+- 可測試設計：Transport protocol 可替換，不需要網路即可測試重試與並發。
+
+## 檔案
+
+- `async_crawler.py`：框架核心與 CLI。
+- `test_async_crawler.py`：7 個單元/整合測試，使用 scripted transport。
+- `architect_feedback.md`：任務指定的架構意見檔；本輪工作目錄中不存在，已記錄為缺失輸入，未臆造內容。

+## Python API
+
+```python
+import asyncio
+from async_crawler import AsyncCrawler, CrawlRequest, RetryPolicy
+
+async def main():
+    crawler = AsyncCrawler(
+        concurrency=16,
+        requests_per_second=5,
+        policy=RetryPolicy(max_attempts=4, base_delay=0.25, max_delay=8),
+    )
+    try:
+        result = await crawler.fetch(CrawlRequest("https://example.com"))
+        print(result.ok, result.response.status if result.response else None, result.data)
+        print(crawler.stats.snapshot())
+    finally:
+        await crawler.close()
+
+asyncio.run(main())
+```

+## Retry decision
+
+重試只適用於「下一次可能成功」的錯誤：
+
+| 類型 | 預設行為 |
+|---|---|
+| 408/425/429/500/502/503/504 | retry，最多 `max_attempts` |
+| timeout / connection / DNS 類錯誤 | retry，最多 `max_attempts` |
+| 400/401/403/404/405/409/422 | 不 retry |
+| parser callback 例外 | 不重新發 HTTP 請求；結果標記失敗 |
+| task cancellation | 立即向上拋出，不吞掉取消 |
+
+`Retry-After` 為數字秒時優先使用，但不超過 `max_delay`。錯誤訊息保留最後錯誤 domain，不把 HTTP、網路、解析錯誤混成同一種。
+

+```

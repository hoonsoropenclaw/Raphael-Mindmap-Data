+# Playwright 跨瀏覽器視覺回歸架構評估
+
+## PRD 拆解
+1. 測試目標：以 TARGET_URL 測單頁；未提供時以 web_output.html 作為可重現樣本。
+2. 瀏覽器矩陣：Chromium、Firefox、WebKit。
+3. 穩定化：固定 viewport、禁用動畫、等待 fonts.ready、固定色彩配置。
+4. 基準管理：baseline 與 current 分離；只在 baseline 模式更新基準。
+5. 比對：pixelmatch 產生 diff pixels、diff ratio、diff PNG。
+6. 報告：輸出 machine-readable JSON、self-contained HTML 與 report screenshot。
+
+## 吸收的舊知識
+- SKILL_CATALOG 命中 playwright_testing_and_reporting。
+- 沿用 Playwright screenshot + pixelmatch + pngjs 樣板。
+- 修正舊樣板缺口：不同瀏覽器不可互相比；每個 browser+viewport 各自維護 baseline。
+- 避免 learning_logs 記錄的 headless IntersectionObserver 空白問題：樣本頁不以 observer 隱藏內容。
+- 不依賴遠端字型、時間戳或動畫，降低視覺測試 flake。
+
+## 風險與回復
+- 風險：各瀏覽器字型 rasterization 天生不同。控制方式：只與同一瀏覽器自己的 baseline 比。
+- 風險：缺瀏覽器執行檔。控制方式：npm run install:browsers。

+function compareImages(baselinePath, currentPath, diffPath) {
+  const baseline = PNG.sync.read(fs.readFileSync(baselinePath));
+  const current = PNG.sync.read(fs.readFileSync(currentPath));
+  if (baseline.width !== current.width || baseline.height !== current.height) {
+    return { status: 'failed', reason: `dimension mismatch ${baseline.width}x${baseline.height} vs ${current.width}x${current.height}`, diffPixels: baseline.width * baseline.height, diffRatio: 1 };
+  }
+  const diff = new PNG({ width: baseline.width, height: baseline.height });
+  const diffPixels = pixelmatch(baseline.data, current.data, diff.data, baseline.width, baseline.height, {
+    threshold: 0.12,
+    includeAA: false,
+    diffColor: [255, 62, 99],
+    aaColor: [255, 215, 64],
+  });
+  fs.writeFileSync(diffPath, PNG.sync.write(diff));
+  const diffRatio = diffPixels / (baseline.width * baseline.height);

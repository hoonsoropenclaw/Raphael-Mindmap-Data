+# Cross-browser visual regression harness
+
+## Run
+
+```bash
+npm install
+npx playwright install chromium firefox webkit
+npm test
+```
+
+The target defaults to `http://localhost:5000`; override with `BASE_URL=https://...`.
+Use `HEADED=1 npm test` for headed debugging.
+
+## Baselines
+
+Create or intentionally update snapshots with:
+
+```bash
+npm run test:update
+```
+
+Never update snapshots in the same change as an unreviewed UI change. Review the generated `test-results/` diffs and HTML report first.
+
+## Design decisions
+
+- Browser-specific projects avoid Chromium-only launch flags; Firefox and WebKit receive clean launch options.
+- `devices` is imported from `@playwright/test` rather than read from a browser instance.
+- Screenshot comparison is performed by Playwright's built-in PNG comparator, avoiding a pixelmatch byte-format dependency.
+- Determinism is improved with fixed viewport, locale, timezone, dark color scheme, reduced motion, hidden caret, and font readiness.
+- Console errors and uncaught page errors fail every test before visual comparison.
+- CI retries are enabled only in CI; local failures remain immediate and debuggable.
